# 餐桌划分、标签、EPPF与出现次序中的频率

## 1. 先造划分，再证明交换

<a id="crp-proof-eppf"></a>

固定α>0。Πₙ为{1,…,n}的划分，餐桌按最小成员即出现次序编号。n=0时第一人开桌；n≥1时，新顾客加入第j桌的概率为nⱼ/(α+n)，另开一桌的概率为α/(α+n)。有限划分状态可数，归一化核用第8章顺序构造实际产生无限相容划分。

\[ P(\Pi_n=\pi)=p(n_1,\ldots,n_k)=\frac{\alpha^k}{(\alpha)^{\uparrow n}}\prod_{j=1}^k(n_j-1)!,\qquad n\ge1. \]

对一个给定的划分π，按1,…,n逐项乘概率。每桌首次出现贡献α，其后依次贡献1到nⱼ−1，分母为α的n阶上升阶乘；第一次的α也包含在分母中并抵消。此概率只看无序块大小，任何有限置换都保律，称为交换划分概率函数EPPF。它是某个具体划分的概率，不是“块大小取这些数”的概率，后者还要计数可能划分。

\[ p(n_1,\ldots,n_k)=\sum_{j=1}^k p(n_1,\ldots,n_j+1,\ldots,n_k)+p(n_1,\ldots,n_k,1). \]

各扩展相对原概率的比值分别为nⱼ/(α+n)和α/(α+n)，和为1，证明删除最后一个标签的采样一致性。空划分概率设1。由一致性与有限置换得到整条划分的交换性；没有调用47章paintbox。

## 2. 给餐桌贴标签，不等于把相等值分桌

<a id="crp-proof-labels"></a>

预先取独立于Π的iid标签Zⱼ∼H；顾客i的值Xᵢ取其餐桌标签。可等价地用新的均匀变量先决定创新，创新则开桌，非创新则从前n人中均匀选一人复制其餐桌。于是给定餐桌和已用标签，下一值的分布是αH加全部顾客点质量，再除α+n；它只依赖已经看见的X，不依赖隐藏分桌。塔式给同一可测预测核Qₙ，所以记录律就是T-DIRICHLET-PROCESS构造的Pólya序列。

\[ P(X_1\in A_1,\ldots,X_n\in A_n)=\sum_{\pi\in\mathcal P_n}\frac{\alpha^{|\pi|}}{(\alpha)^{\uparrow n}}\prod_{B\in\pi}\left[(|B|-1)!\int_E\prod_{i\in B}\mathbf1_{A_i}(z)H(dz)\right]. \]

上式只是对有限个餐桌划分求和，再独立积分各桌标签，所有项非负；有原子的H也成立。若H无原子，可数iid标签几乎必然互异，因此餐桌块等于观测值相等块。一般H中后者只是前者按重复标签合并得到的粗划分。

\[ c_H=P(Z_1=Z_2)=\int H(\{z\})H(dz),\quad P(X_1=X_2)=\frac1{\alpha+1}+\frac{\alpha}{\alpha+1}c_H. \]

标准Borel空间的对角集合可测，Tonelli给第一式。H的正质量原子至多可数，故碰撞概率也是其质量平方之和。第二式分别按同桌、异桌分解。新桌概率α/(α+n)，新观测值概率却是αH(E差{X₁,…,Xₙ})/(α+n)。H=δz时观测恒为z，尽管餐桌仍不断产生。

## 3. 删除第一桌，发现剩余问题与原来相同

<a id="crp-proof-deletion"></a>

记Iᵢ为顾客i是否坐第一桌，I₁=1。已有n₁人坐第一桌、r=n−n₁人坐其他桌时，下一人进第一桌的机会为n₁/(α+n)；不进的机会为(α+r)/(α+n)。给定不进，其他桌的相对规则是nⱼ/(α+r)和α/(α+r)，恰为以r人为过去的原CRP。

独立生成一个初始质量(1,α)的二色Pólya序列I₂,I₃,…，再生成一份独立CRP用于压缩后的非第一桌顾客。按I把它们插回时间轴，上述一阶条件核与原CRP逐项一致，因此完整律相同。这个构造实际证明第一桌指标过程与残余CRP独立，不只是根据边缘规则猜测独立。有限Dirichlet混合与强律给第一桌频率V₁∼Beta(1,α)，且0<V₁<1。

余下顾客比例1−V₁正，故其压缩序列无限。对独立残余CRP重复同一分解，依次得到相互独立的Beta(1,α)变量V₂,V₃,…；对每个有限层的独立性由刚才的乘积构造归纳得到，随后只取可数共同满测集合。任一固定桌j都有正密度，故确实在有限时刻出现。

\[ \frac{N_j(n)}n\longrightarrow P_j=V_j\prod_{i<j}(1-V_i)\quad\text{a.s. for every }j,\qquad \sum_{j\ge1}P_j=1. \]

绝对频率等于压缩频率乘该子序列的密度，逐层相乘给上式。总和1由T-STICK-BREAKING的剩余质量证明，而不是从“每桌有频率”自动推出。这建立的是按出现次序的剩余切割律，未声称按大小排列后的频率仍独立。频率只从Π提取，因此与预先独立生成的全部标签独立。

## 4. 经验概率与随机原子的过程级识别

<a id="crp-proof-identification"></a>

令qⱼ(n)=Nⱼ(n)/n，尚未出现的桌取0。q(n)与P都是自然数上的概率。对固定J，前J项逐项收敛，且尾质量分别为1减前J项之和。因此ℓ¹差可由有限头部差加两份尾部控制，先令n增大，再令J增大，得到ℓ¹收敛。

\[ \sum_{j\ge1}|q_j(n)-P_j|\longrightarrow0,\qquad d_{\rm TV}\!\left(\frac1n\sum_{i=1}^n\delta_{X_i},\sum_{j\ge1}P_j\delta_{Z_j}\right)\le\frac12\sum_{j\ge1}|q_j(n)-P_j|\longrightarrow0. \]

推送到标签空间只合并坐标，不增加总变差；也可直接对任意集合A把正、负误差分开证明该界。G*=ΣPⱼδZⱼ因此是经验概率的共同极限。它与43章记录指导概率在可数决定代数上评价一致，故作为整份概率几乎必然相同，给定G*时观察为iid。若标签碰撞，单独各桌频率仍不能从观测值中恢复；可识别的是合并后的G*。

此处总变差收敛不与43章均匀连续指导律的反例冲突：本章每份指导律离散，有限头部能够抓住任意多质量。界对一个好样本点上的全部A同时成立，靠的是可数权重的ℓ¹控制，不是交换不可数个强律零集。

## 5. 桌数的增长来自独立创新

<a id="crp-proof-count"></a>

使用每一步新的均匀变量决定开桌，开桌指标Bᵢ可取为独立Bernoulli(α/(α+i−1))，B₁=1。它们不是座位归属指标，而仅表示这一步是否创新。概率和发散，第二Borel–Cantelli给无限多次创新。其和Kₙ的均值为αlog n+O(1)，方差不超过均值。

\[ EK_n=\sum_{i=1}^n\frac{\alpha}{\alpha+i-1},\qquad \frac{K_n}{\log n}\longrightarrow\alpha\quad\text{a.s.} \]

均值渐近由与α/i之差可求和得到。取nₘ=⌊exp(m²)⌋，Chebyshev使|Kₙₘ−EKₙₘ|>εlog nₘ的概率为O(m⁻²)，故可求和。Borel–Cantelli给子序列上的比值极限；Kₙ递增，且log nₘ₊₁/log nₘ→1，夹逼得到全序列。若H无原子，这也是不同观测类别数的渐近；有原子时两者不能混同。
