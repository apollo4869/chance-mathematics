# T-KINGMAN-COALESCENT：有限合并、无限路径与从无穷下降

本页固定每对当前块的合并率为1，时间向共同祖先方向增加。它是本章专用的Kingman构造，不调用第56章一般合并理论。返回[第47章](../chapters/47-partitions.md#partitions-infinite-process)。

## 1. 有限样本的路径和生成矩阵

<a id="kingman-proof-finite"></a>

π∈Pₙ有b块时，等待Exp(\(q_b\))，\(q_b\)=b(b−1)/2，再从全部无序块对中均匀选一对合并；b=1吸收。每一步使用新的独立指数与选择变量。至多n−1跳，因此非爆炸。第21章指数竞争或直接乘等待密度，给每指定块对速率1，生成矩阵如下。交换标签保留无序对集合，故整条路径而非仅边缘律交换。

\[ L_n f(\pi)=\sum_{\{B,C\}\subseteq\pi}\big[f(\operatorname{merge}_{B,C}\pi)-f(\pi)\big],\qquad q_b=\binom b2. \]

下一跳的类型与等待时间独立，且\(q_b\)只看块数，不看各块大小。把新指数按经过的块数倒序索引，块数从n到b的时间与独立变量的和同律。不同n的这些辅助指数无需被误认为某个既定投影耦合中的同一组实际等待时间。

## 2. 删除样本不会改变可见块对的速率

<a id="kingman-proof-consistency"></a>

设N≥n，R把\(\mathcal P_N\)限制到[n]。每个限制后的块对应唯一一个完整块。两个可见块合并只可能来自这两个完整块合并，速率仍1；合并含空投影的块不改变限制。故对每个f有下面的逐状态恒等式。

\[ L_N(f\circ R)=(L_nf)\circ R,\qquad P_t^N(f\circ R)=(P_t^nf)\circ R. \]

第二式不是另加假设：对有限矩阵，归纳得所有幂的相同身份，再在绝对收敛指数级数中逐项求和。给定完整过去，未来限制的条件期望为\(P_t^nf\)作用于当前限制；再用塔式就是限制自身的Markov性质。反复条件化给全部有限时间联合律，故得到路径限制的一致性，不是只得到一个时刻的边缘相容。

## 3. 用有理时间构造同一个无限概率空间

<a id="kingman-proof-path"></a>

把第n条有限链记录在非负有理时间上，值空间Pₙ的有理次可数乘积标准Borel。上一节给这些记录随n的相容分布。第8章把全体(n,q)资料放进同一个可数积概率空间；所有限制身份在可数n,q上共同成立。还需检查路径，这一步不能被有限维分布四字替代。

对固定n，好记录满足：q<s时划分只粗化；q=0为单点划分；每个有理q都有有理r>q，使[q,r)内所有有理时刻的值等于q处值。这些是可数Borel条件，有限链以概率1满足。粗化使全时间轴上的真正改变至多n−1次。取全部n的共同好集，在任意实t定义为有理r从右递减到t的最终值。有限状态与有限改变保证极限存在；有理处右连续条件保证恢复原记录。左极限同样存在，得到有限限制的càdlàg路径。坏记录统一补成常值路径。

有理限制身份经右极限延到所有实t。因而存在唯一Π(t)∈P∞具有这些有限限制。取度量d(π,ρ)=Σ2⁻ⁿ1{rₙπ≠rₙρ}：先控制有限头部的右连续或左极限，再把尾和压到任意ε，证明Π是该紧可度量空间上的càdlàg路径，且Π(0)为单点划分。可测性由每个有限坐标与有理右极限给出。

## 4. 无限过程的Markov核与合并操作

<a id="kingman-proof-markov"></a>

给π的块按最小成员编号，另取独立的从单点开始的Kingman划分Ξ(t)，把π中编号在同一Ξ块内的块合并，记Coag(π,Ξ(t))。检查两个标签是否相连，只需π在有限前缀内决定的块编号，再读Ξ的有限限制，所以Coag可测。其律\(K_t(\pi,\cdot)\)为概率核；rₙ推送恰是以rₙπ为初态的有限合并链。

有限核的半群身份逐柱集给\(K_sK_t=K_{s+t}\)。对构造的Π，有限过去柱集的Markov条件身份来自有限链，再以单调类推广到σ{Π(u):u≤s}与全部有界Borel测试。因此无限过程的转移核确实是\(K_t\)。有限置换不变也由有限限制证明到整条路径；无需给无穷块同时安装一个未定义的“总指数时钟”。

## 5. 从无穷下降的准确时间计算

<a id="kingman-proof-coming-down"></a>

令Nₙ(t)为前n人的块数，N(t)=supₙNₙ(t)，并令\(T_b^{(n)}\)首次到不超过b块。投影耦合给Nₙ随n递增及\(T_b^{(n)}\)随n递增；\(T_b\)取其极限。有限构造给下面的分布与期望。对b≥1，指数变量Eⱼ的速率为qⱼ，各自独立。

\[ T_b^{(n)}\stackrel d=\sum_{j=b+1}^n E_j,\quad E_j\sim\operatorname{Exp}\!\binom j2,\qquad \mathbb ET_b^{(n)}=2\left(\frac1b-\frac1n\right),\quad \mathbb ET_b=\frac2b. \]

最后一步是非负单调收敛，不是先把无限跳链当作已经存在。{N(t)>b}={\(T_b\)>t}，所以P(N(t)>b)≤2/(bt)。令b→∞得每个固定t>0时N(t)<∞；先在正有理时刻共同成立，再由粗化性得所有t>0同时成立。且T₁有均值2，故全部谱系在有限时间内最终合成一块。

为严谨识别极限的方差，可在辅助空间用同一组独立Eⱼ构造部分和。其尾和有限均值，且方差和有限，部分和在L²收敛；它的极限分布由\(T_b^{(n)}\)的分布极限唯一决定。因此\(T_b\)与此指数尾和同律，其均值和方差确为下面的量。没有假设投影中的实际等待时间跨n独立。

## 6. 速度常数2，以及极限的方向

<a id="kingman-proof-speed"></a>

\[ \operatorname{Var}(T_b)=\sum_{j>b}\frac4{j^2(j-1)^2}\le\frac C{b^3},\qquad bT_b\longrightarrow2\quad\text{a.s.},\qquad T_{N(t)}\le t<T_{N(t)-1},\qquad tN(t)\longrightarrow2\quad(t\downarrow0)\ \text{a.s.} \]

由方差界，P(|\(bT_b\)−2|>ε)≤C/(ε²b)。取b=m²，概率可求和，Borel–Cantelli给该子列极限。\(T_b\)随b递减，而(m+1)²/m²→1，用相邻平方夹逼推广到全部整数b。N(t)随t↓0趋无穷：对每个n，有限限制在0附近尚未首跳，故N(t)≥n。由\(T_{N(t)}\le t<T_{N(t)-1}\)，将两侧乘N(t)，用前述整数极限得到tN(t)→2。下标中的N(t)−1指块数减1。

“从无穷下降”不意味着t=0发生一次允许无穷块参与的跳。每个有限限制在0右连续；无穷个越来越小尺度的有限合并使正时间块数有限。若把每对合并率改为c>0，所有时间除以c，速度变成tN(t)→2/c；不应在不同速率约定间沿用常数2。

## 7. 在所有正时刻同时定义频率

<a id="kingman-proof-frequencies"></a>

每个固定正有理q，Π(q)交换且块数有限。T-PAINTBOX说明零频率块只能为单点；若dust质量正，条件独立抽样几乎必然产生无穷单点，矛盾。因此该时刻无dust、各块频率正且总和1。对全部正有理q取共同满概率集。

任意t>0选有理q<t。q处只有有限个块，此后每个块是它们的有限并，所以t处的频率存在，并为相应有限和。这个论证在同一集合上适用于所有t，而不是对不可数时刻求零集交。按大小排序的S(t)在每个[ε,∞)上只有有限次合并，是ℓ¹值càdlàg阶梯路径。0处频率全零、dust为1。

\[ \mathbb E\sum_i S_i(t)^2=\mathbb P\{1\sim_{\Pi(t)}2\}=1-e^{-t}. \]

第一式来自paintbox，第二式来自二人限制的Exp(1)合并时间。最大频率的平方不超过ΣSᵢ²，且最大频率随合并递增。因此t↓0时它的单调极限为0几乎必然，因其期望平方被1−e⁻ᵗ压住。于是S(t)在逐坐标拓扑趋全零，但ℓ¹范数恒1。dust瞬时消失和有限限制右连续并不矛盾，它们使用不同观察尺度。

## 8. 质量合并的规则及实际边界

<a id="kingman-proof-scope"></a>

正时间有有限个谱系，每对当前块速率1；对应质量变成Sᵢ+Sⱼ，再排序。按质量大小择两个个体的概率却与SᵢSⱼ有关，这不是同一选取规则。可由独立Coag核证明后续质量过程只依赖当前质量：未来对每对块使用同一速率，块的旧名称及构成不进入核。只在正时间的有限块范围声明这个生成机制。

本页证明Kingman的二元、每对率1模型及专用极限。不包括Λ/Ξ多重或同时合并的分类、一般碎裂对偶、谱系的CRT极限或任何非交换机制。那些改变并非单纯给本页的公式换一个符号；第56章承担其额外一致性与构造。
