# 随机指导概率、标准Borel结构与de Finetti主证

## 1. 概率本身怎样成为可测参数

<a id="directing-proof-space"></a>

设E非空标准Borel，P(E)表示其全部可数可加概率，先赋予评价σ代数：由所有μ↦μ(A)生成。若A是一个包含E的可数生成代数，只用A中的评价就生成同一σ代数。证明是考虑所有评价已可测的集合：补集和可数不交并保留性质，再用π–λ定理。A也决定每一份概率。

还要实际证明这个参数空间标准Borel，才能合法讨论其分布和后验。用第10章的Borel编码b把E双射到B⊂[0,1]，逆映射可测。先编码[0,1]上的概率：取全部有理q处的CDF值。以下约束只涉及可数次交并，构成可数立方体中的Borel集合C。

\[ 0\le F_q\le1,\quad F_q\le F_r\ (q<r),\quad F_q=\inf_{\substack{r>q\\r\in\mathbb Q}}F_r,\quad F_q=0\ (q<0),\quad F_q=1\ (q\ge1). \]

对每个合法代码F及0<u<1，令Q(F,u)为满足Fq≥u的有理q的下确界。它在[0,1]中，且联合可测，因为{Q<a}是{u≤Fq}对有理q<a的并。右连续约束保证Q(F,U)的CDF恰为F：在有理q上，{Q≤q}由所有r>q的{U≤Fr}相交得到。于是每个代码真的解码成概率μF，而不是仅仅一组满足有限相容性的数字。

\[ \mu_F(A)=\int_0^1\mathbf1_A(Q(F,u))\,du,\qquad \mathcal C_B=\{F\in\mathcal C:\mu_F(B)=1\}. \]

对每个Borel A，上式关于F可测，所以C的子集Cᴮ为Borel。在Q不落于B时统一取固定e₀解码；对Cᴮ中的每个F，这只改动u的零测截面。因此Cᴮ与P(E)之间存在双向可测一一对应。概率空间的标准Borel性以及评价可测性都实际建立了，不借第49章的一般随机测度拓扑。

## 2. 对任意信息σ代数取得一份真正的条件律

<a id="directing-proof-conditional"></a>

本节核对第10章结论在本章的确切适用范围：结果空间E标准Borel，条件σ代数H可以是原概率空间上的任意子σ代数，不要求H本身有一个标准Borel商空间。不能把这和任意结果空间上都存在正则条件概率混为一谈。

对Y=b(X)，在有理q上取E[1{Y≤q}|H]的版本。可数共同零集以外，它们在0与1之间、随q递增、边界值正确。对每个有理q选择有理序列递减到q，条件单调收敛给右连续约束；只需可数个这样的序列。坏H可测集合上统一换成δb(e₀)的代码。上节解码给[0,1]上的概率核。

先在有理半直线上核对条件积分身份，再用单调类推广到全部Borel集。这也给核在B上的质量几乎必然为1，因为Y∈B。将这个单一坏集合上的核统一置δb(e₀)，再经b⁻¹推回，就得到处处为概率的E值条件核。涉及不可数多个测试集合的积分身份按每个固定集合模零理解；核的可数可加性则在所有样本点上成立。

同样的结论可用于整个记录X=(X₁,X₂,…)：可数乘积Eᴺ仍标准Borel。因此随后给定J的整条路径条件核也确实存在。没有预设第45章带任意外参数的共同析取定理。

## 3. 从递减信息到条件乘积

<a id="directing-proof-products"></a>

在无限交换的标准Borel记录空间上，取ν为X₁给定J的上述条件律。它是P(E)值、J可测的随机变量。对可数生成代数A中的每个集合，有限群条件平均与反向鞅给经验评价收敛到ν的评价。对这些集合同时取共同零集。

\[ L_N(A)=E[\mathbf1_A(X_1)\mid\mathcal G_N]\longrightarrow E[\mathbf1_A(X_1)\mid\mathcal J]=\nu(A)\qquad(A\in\mathcal A). \]

对任意固定k和A中的k个集合，前一专题已证明，给定Gₙ的前k项矩形事件条件概率等于无放回平均，与经验评价乘积的差至多c。反向鞅又使左边趋向给定J的条件概率，右边趋ν评价乘积。所以得到下面的身份。字长与代数元组仍然可数。

\[ E\!\left[\prod_{\ell=1}^k\mathbf1_{A_\ell}(X_\ell)\,\middle|\,\mathcal J\right]=\prod_{\ell=1}^k\nu(A_\ell). \]

关键顺序是先从条件律取得ν的可数可加性，再由经验平均识别它；没有先对所有集合取频率极限，再未经论证地宣布它是概率。

## 4. 整条记录的核与共同零集

<a id="directing-proof-path"></a>

对每个μ∈P(E)，第8章或第10章顺序构造给唯一积概率μ的无限积。它对μ是一份概率核：有限柱集评价是μ评价的有限乘积；使评价可测的路径集合构成Dynkin类，故对全部路径事件可测。把这种核记为K(μ,·)。

\[ K(\mu,A_1\times\cdots\times A_k\times E\times\cdots)=\prod_{\ell=1}^k\mu(A_\ell),\qquad K(\mu,\cdot)=\mu^{\otimes\mathbb N}. \]

令Rω为整个记录给定J的正则条件律。上节在所有可数代数柱集上说明Rω与K(ν(ω),·)相等。去掉这些身份的共同J零集以后，两者在每个剩余ω上都是概率，且在一个决定类上一致；π–λ使它们作为整份路径测度相等。于是K(ν,·)本身就是给定J的一个路径条件核。

\[ P(X\in D\mid\mathcal J)=K(\nu,D),\qquad P(X\in D\mid\sigma(\nu))=K(\nu,D)\quad(D\in\mathcal E^{\otimes\mathbb N}). \]

第二式来自σ(ν)⊂J及塔式，因为K(ν,D)对σ(ν)可测。因此给定ν后各项独立且同律ν。对ν的分布M积分，得到完整混合；逆向以任意M生成这份混合，有限置换保持每个积核，故仍为交换律。

\[ P(X\in D)=\int_{\mathcal P(E)}\mu^{\otimes\mathbb N}(D)\,M(d\mu),\qquad M=\mathcal L(\nu). \]

对任意参数事件B和记录事件D，同样的条件积分还给P(ν∈B,X∈D)=∫B K(μ,D)M(dμ)。先在参数—记录矩形上成立，再以π–λ扩张为联合律身份。因此后面涉及“经验极限等于当前参数”这类依赖μ的联合可测事件，也能够合法按该核积分。

这里的共同零集是用于证明两份核作为测度相等的可数决定类零集；不是宣称所有条件期望身份都能在一个样本点上对一切与样本点有关的事件同时取值。两种量词不能交换。

## 5. 尾可测的指导概率版本

<a id="directing-proof-tail"></a>

对编码后的观察Y=b(X)，在每个有理q上取经验CDF的limsup。有限前缀的删除只造成趋零误差，所以这些读数对原始尾σ代数T可测。它们在一个概率1集合上等于ν的CDF代码，因而满足合法代码及质量集中B的条件。

这些合法性条件在代码空间中为Borel，故可以在无效尾代码上统一采用δe₀。得到一个真正T可测的P(E)值随机变量νᵀ，并且νᵀ=ν几乎必然。用它替换原ν，不改变任何条件iid结论。对一个可数代码统一修复，避免了分别修改不可数多个集合评价而破坏可数可加性。

## 6. 指导概率和混合律的唯一性

<a id="directing-proof-unique"></a>

若同一空间上的Λ也使记录给定Λ为iid(Λ)，对每个固定μ，第12章SLLN在可数决定代数上同时成立。其事件对(μ,记录)联合可测。条件核积分后便给原空间中Lₙ(A)→Λ(A)，对全部可数A同时成立。而前面已经给Lₙ(A)→ν(A)，故Λ和ν在决定类上一致，几乎必然是同一份概率。

若只给另一份混合分布M′而没有原空间上的Λ，在P(E)×Eᴺ上用M′(dμ)K(μ,dx)实际建立联合实验。上一段使从记录提取的指导概率等于μ，故其分布为M′。但这份提取是由记录律P确定的可测函数，分布已经为M。因此M′=M。一般参数θ可以不可识别；唯一的是其产生的概率μ，不是任意参数标签。
