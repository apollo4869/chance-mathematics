# T-CRT-SAMPLING：Brownian CRT有限约化子树的实际密度

本专题证明[第54章有限采样定理](../chapters/54-brownian-crt.md#crt-sampling-law)。固定37、53章时长1的标准游程e，使用Tₑ而非T₂ₑ。依赖26章被杀Brownian核与首达密度、53章实际重核的游程有限维密度，以及[T-REAL-TREE-CODE](t-real-tree-code.md)。不调用Aldous边长定理、CRT空间极限或未来线段生长构造。

## 1. 先固定游程的尺度

<a id="crt-sample-kernels"></a>

\[ g_t(z)=\frac{e^{-z^2/(2t)}}{\sqrt{2\pi t}},\quad
q_t(x,z)=g_t(z-x)-g_t(z+x),\quad
h_t(a)=\frac{a}{\sqrt{2\pi}t^{3/2}}e^{-a^2/(2t)},\quad c_1=(2\pi)^{-1/2}. \]

x,z,a均正。hₜ(a)是标准Brownian从a首达0的时间密度，不是编码函数h。为避免混淆，本专题编码始终写e。对0<t₁<⋯<tₖ<1，e在这些时刻取x₁,…,xₖ的密度为下式。它可由53章三个标准桥的范数及球坐标Gaussian积分得到；该处入口为2h、出口为h，所以此处系数是2而非4。

\[ \frac{2}{c_1}h_{t_1}(x_1)
\prod_{i=1}^{k-1}q_{t_{i+1}-t_i}(x_i,x_{i+1})
h_{1-t_k}(x_k). \]

给定这些端点，中间各段具有独立的正半轴被杀Brownian桥律。实际理由是：再插入任意有限个时刻，上式密度除以端点密度后在各段分解，因子正是q核桥；连续路径的Borel域由有理评价生成，π–λ将有限维因子提升为段路径的条件核。这是固定正时间端点的正则条件律身份，不是在零概率终点上直接相除定义概率。

## 2. 最低值的密度由屏障移动得到

<a id="crt-sample-minima"></a>

在端点x,z之间把整段限制在y以上，其中0≤y<min(x,z)。26章反射原理给被杀于y的转移核q⁽ʸ⁾。严格越过y与不触及y的区别在桥中没有额外原子：反射给连续的最低值分布，下面的端点极限也直接核对全部质量。

\[ q_t^{(y)}(x,z)=g_t(z-x)-g_t(x+z-2y),\qquad
-\partial_yq_t^{(y)}(x,z)=2h_t(x+z-2y). \]

条件桥的最低值超过y的概率为q⁽ʸ⁾/q⁽⁰⁾。可先要求在逐渐稠密网格上不低于y，再以路径连续性及反射的无原子最低值通过极限；这也验证事件的可测性。y下降到0时比值趋1，上升到min(x,z)时趋0。因此导数确实给全部最低值概率，没有端点质量。

记yᵢ为相邻采样时刻之间的最低值，令Δt₀=t₁、Δtᵢ=tᵢ₊₁−tᵢ、Δtₖ=1−tₖ。条件段分解允许逐段对屏障求导，得到以下联合密度；所有因子非负，故随后的积分交换均由Tonelli保证。

\[ \frac{2^k}{c_1}\prod_{i=0}^{k}h_{\Delta t_i}(r_i),\qquad
r_0=x_1,\quad r_i=x_i+x_{i+1}-2y_i\ (1\le i<k),\quad r_k=x_k,
\quad 0<y_i<\min(x_i,x_{i+1}). \]

## 3. 把随机采样时间积分掉

<a id="crt-sample-time"></a>

首达时间满足h(a)∗h(b)=h(a+b)，卷积在时间变量上。26章专用强Markov性给出证明：Brownian先从a+b到b，再从b到0，两段首达时间独立且分别具有h(a)、h(b)密度；有限性a.s.由反射尾概率趋0得到。由显示的密度公式，h延为负时间的0后是有界一致连续函数，且积分1；以其中一个概率密度支配，用有界收敛可证卷积连续。因此几乎处处的卷积身份也处处成立。迭代得到k+1项卷积，不需要Laplace反演黑箱。

\[ \int_{\substack{\Delta t_i>0\\\sum_{i=0}^{k}\Delta t_i=1}}
\prod_{i=0}^{k}h_{\Delta t_i}(r_i)\,d\Delta t_0\cdots d\Delta t_{k-1}
=h_1\!\left(\sum_{i=0}^{k}r_i\right),\qquad
\sum_{i=0}^{k}r_i=2L,\quad L=\sum_{i=1}^{k}x_i-\sum_{i=1}^{k-1}y_i. \]

k个独立均匀时刻的次序统计量密度为k!。上式遂使有序时间的高度与最低值联合密度化为2ᵏ⁺¹k! L exp(−2L²)。这一步是总跨度长度出现的原因：行走从根出发，经过全部样本再回根，恰将每条约化边走两次。

## 4. 从高度坐标换到边长坐标

<a id="crt-sample-jacobian"></a>

上述联合律对2k−1维Lebesgue测度有密度，故不同y相等的事件、x与相邻y相等的事件均概率0。以最小y递归分左右组，就得到k叶二叉平面树，带一条从根进入第一个分枝的根边。根及叶均为一度，内部节点三度，边数2k−1；k=1为单边约定。

固定一个平面形状，每个x对应叶节点绝对高度，每个y对应一个分枝节点绝对高度。边长是子节点高度减父节点高度，根高0。将节点按祖先在前排序，这个线性变换的矩阵三角且对角为1，Jacobian绝对值1。正边长恰对应该形状的开坐标区域；不必人为限制不同支路的分枝高度顺序。

恢复原始样本标签1,…,k：给定有序时刻，标签排列独立均匀，故每个带标签平面形状的密度除以k!。再忘掉平面左右次序。每个非平面、保留叶标签的二叉根形状有2ᵏ⁻¹种左右定向；叶标签阻止交换子树后产生重复的标号定向。因此得到实际采样定理：

\[ \boxed{\quad
P\{\operatorname{shape}(R_k)=\tau,\ (\ell_a)_{a\in E(\tau)}\in d\ell\}
=4^kL e^{-2L^2}\prod_{a\in E(\tau)}d\ell_a,\qquad
L=\sum_{a\in E(\tau)}\ell_a,\quad\ell_a>0.\quad} \]

## 5. 归一化、形状与总长

<a id="crt-sample-normalization"></a>

这种非平面标号根形状共有Nₖ=(2k−3)!!个，约定N₁=1。实际计数：加入标签k+1时，选原树的一条边，插入一个分枝点再接新叶；删去新叶并压掉二度点是唯一逆操作。原树有2k−1条边，故Nₖ₊₁=(2k−1)Nₖ。没有将平面Catalan计数误作这里的形状数。

m=2k−1个正边长之和固定为L时，单纯形切片体积因子为Lᵐ⁻¹/(m−1)!；由反复积分或变量ℓₘ=L−Σ前项可直接得出。每个形状的总概率因而如下，恰为1/Nₖ。

\[ \frac{4^k}{(2k-2)!}\int_0^\infty L^{2k-1}e^{-2L^2}\,dL
=\frac{2^{k-1}(k-1)!}{(2k-2)!}=\frac1{(2k-3)!!},\qquad 2L_k^2\sim\operatorname{Gamma}(k,1). \]

因此形状均匀，且独立于总长；给定形状与总长，边长比例在单纯形均匀，即Dirichlet(1,…,1)，并与二者独立。若改以2e编码，边长全乘2；变量变换的Jacobian为2⁻⁽²ᵏ⁻¹⁾，每个形状密度变成L exp(−L²/2)。特别k=1时，Tₑ中根到均匀质量点的高度密度为4r exp(−2r²)，T₂ₑ中才是r exp(−r²/2)。

## 6. 删叶相容性与增加一个样本

<a id="crt-sample-consistency"></a>

使用同一串独立均匀时刻，删去最后标签当然还原Rₖ。还可直接核对密度：给旧树总长s，新枝长b>0，接在一条旧边的内部位置a。拆开该边的两段及新边到(a,b)的Jacobian为1，故新旧密度比为

\[ \frac{4(s+b)}s\,e^{-2((s+b)^2-s^2)}\,da\,db,\qquad
\int_{T_{\rm old}}da=s,\qquad
2L_{k+1}^2-2L_k^2\mid R_k\sim\operatorname{Exp}(1). \]

对a积分后，b密度为4(s+b)exp{−2((s+b)²−s²)}，积分1；接点按旧树边长均匀，与b条件独立。这是已经构造的CRT中有限样本增长的条件律，不是从有限核直接宣布一个独立无限生长空间存在；完整生长构造仍归第57章。

## 7. 核验的范围

<a id="crt-sample-scope"></a>

所有概率密度在本专题实际从游程核计算，卷积、变量变换、形状乘数与归一化分别核对。Brownian特殊结构将用于[质量与随机性的专题](t-crt-randomness.md#crt-random-leaves)。本证明没有使用53章尚待专家终审的高度紧性论证来反证自身；只使用53.11已明确给出的游程核，其径向Gaussian推导与本专题入口常数一致。
