# T-PROKHOROV-COUPLING：从集合不等式到质量耦合

本页完成[第55章](../chapters/55-metric-measure-limits.md#geometry-prokhorov)的概率距离工具。S为Polish空间，使用一个完备相容度量；测度均为Borel概率。第24章的Portmanteau与Prokhorov紧性定理、第10章固定Polish空间上的条件核、第8章可数核构造为前置。这里的Strassen论证实际给出，不反向借用GP完备性。

## 1. 定义以及容易的一半

<a id="prok-definition"></a>

\[ \begin{aligned}
A^\varepsilon&=\{x:d(x,A)<\varepsilon\},\\
d_P(\mu,\nu)&=\inf\{\varepsilon>0:\,
\mu(A)\le\nu(A^\varepsilon)+\varepsilon,\
\nu(A)\le\mu(A^\varepsilon)+\varepsilon
\ \text{for every Borel }A\}.
\end{aligned} \]

开邻域总为开集。距离不超过1。利用连续从上及闭集逼近，dP=0推出两测度在闭集上一致，因而相等。若一份耦合q使距离大于ε的配对质量至多ε，则对任意δ>ε，落在A的第一坐标除去坏配对后，第二坐标落在A的δ邻域，所以dP≤ε。集合邻域的迭代包含于半径之和的邻域，直接给三角不等式；对称性已在定义中。

## 2. 有限加权匹配引理的证明

<a id="prok-hall"></a>

给有限行质量aᵢ和列质量bⱼ，双方和均为1；某些格子允许运输。记N(I)为行集合I所能到达的列。若每个I满足a(I)≤b(N(I))+α，就能在允许格子中运输至少1−α质量。证明不需要把实质量假装成整数：在有限闭有界多面体上最大化总运输量，得极大流f。

从所有未饱和行出发，在允许行到列的边上前进，在携带正流的列到行反向边上前进。若能到未饱和列，有限简单增广路上的最小剩余量为正，可增加f，矛盾。故可达列全饱和；所有这些列恰为N(I)，其中I为可达行。没有外部行向N(I)送正流，否则它也可达；I外各行皆饱和。因此未运质量恰为a(I)−b(N(I))≤α。剩余两侧质量相等，可任意乘积配对以补成完整耦合。

## 3. 从有限匹配到Strassen耦合

<a id="prok-strassen"></a>

\[ d_P(\mu,\nu)\le\varepsilon
\quad\Longleftrightarrow\quad
\exists q\in\operatorname{Cpl}(\mu,\nu):
q\{(x,y):d(x,y)>\varepsilon\}\le\varepsilon . \]

只需ε<1时证明反向构造。先取α>dP，选紧集各承载至少1−δ质量，将其划成有限个直径至多2δ的Borel格，选中心；余下为尾格0。所有涉及尾格的格子皆允许，其余格子在中心距离至多α+4δ时允许。对行子集I，令A为其格的并。若I含尾格，所有列都是邻居；否则A的α邻域只可能落在邻居列中：两格有相距小于α的点时，中心距离至多α+4δ。因此集合不等式给加权匹配条件。

匹配质量至少1−α。把每格的运输按该格内两测度的归一化限制乘积展开；零质量格不需定义归一化。非尾格的已匹配点距离至多α+8δ，涉及尾格的总质量至多2δ。故完整耦合满足坏距离α+8δ的质量至多α+2δ。选α下降到ε、δ下降到0。所有这些耦合因边缘固定而一致紧：紧K、L之外质量至多μ(Kᶜ)+ν(Lᶜ)。第24章给弱收敛子列q。其边缘仍为μ、ν，因坐标投影连续。

对每个η>0，闭集{d≤ε+η}在充分后期承载至少1−α−2δ质量。Portmanteau闭集不等式给q{d≤ε+η}≥1−ε；令η下降到0即得精确阈值结论。即使下确界最初没有被取得，极限仍建立所需耦合。正向已在第一节证明。

## 4. 它确实刻画弱收敛

<a id="prok-weak"></a>

若dP(μₙ,μ)→0，对闭F用定义并让邻域半径下降到0，得到limsup μₙ(F)≤μ(F)，第24章Portmanteau给弱收敛。反向，设μₙ⇒μ。选紧K承载1−η质量，以有限个半径小于η、边界μ零的球覆盖K；这可以做到，因为固定中心的互不相交球面中只有可数多个具有正μ质量。依次取差得到直径小于2η的有限格以及μ质量至多η的余格，各格边界μ零。

各格质量收敛。在同名格中配对两质量的较小者，总未匹配质量为有限格质量差的一半之和；它趋0。余格的坏质量至多η+o(1)，其余配对距离小于2η。用第三节容易方向，limsup dP≤2η；令η趋0。由此不是把耦合定理当成弱收敛定义，而是证明了等价。

## 5. 拼接耦合与完备性

<a id="prok-complete"></a>

若q₁耦合μ、ν，q₂耦合ν、ζ，在共同的中间坐标y下析取为K₁(y,dx)、K₂(y,dz)，用ν(dy)K₁K₂构造三坐标联合律。这使用第10章Polish条件核；不声称任意可测空间均可如此。两份坏事件相加给端点耦合误差。

对dP Cauchy列取子列，使相邻距离小于2⁻ⁱ，用Strassen取相邻耦合，并用上述条件核及第8章可数核构造实现链Yᵢ。相邻距离大于2⁻ⁱ的概率至多2⁻ⁱ；Borel–Cantelli说明只有有限次坏步。之后距离和有限，因此Yᵢ在完备S中几乎必然收敛到Y，且Y作为可测映射列的点态极限可测。在第N步以后无坏步时，d(Y(N),Y)≤Σᵢ≥N2⁻ⁱ；坏步联合概率也至多该尾和。容易方向给dP(LawY(N),LawY)趋0，原Cauchy列也收敛。

最后，把承载大部分质量的紧集投到可数稠密集中的有限网，并用有理权重近似，得到可数稠密的有限原子概率。因此概率测度空间在dP下完备可分。这个结果将用于不同空间被粘合后的公共背景，而不要求公共背景紧。回到[第55章](../chapters/55-metric-measure-limits.md#geometry-strassen)。
