# T-POISSON-SPACE：空间Poisson与Cox构造

返回[第48章](../chapters/48-point-processes.md#points-poisson-construction)。构造先在标准Borel空间及σ有限强度下成立；成为Mₚ值对象另需局部有限条件。

## 1. 有限质量：先抽数目再抽位置

<a id="poisson-space-finite"></a>

给有限测度μ，λ=μ(E)。λ=0置N=0；否则抽K∼Poisson(λ)，再独立抽iid μ/λ位置，置N=\(\sum_{i\le K}\delta_{Z_i}\)。每个Borel计数是可测随机和，故N为评价可测。对任意非负可测f，条件于K计算后对Poisson级数求和，得到下式，允许积分无穷并约定exp(−∞)=0。

\[ \mathbb E e^{-Nf}=e^{-\lambda}\sum_{k\ge0}\frac{\lambda^k}{k!}\left(\frac1\lambda\int e^{-f}\,d\mu\right)^k=\exp\{-\mu(1-e^{-f})\}. \]

## 2. σ有限拼接与独立散布

<a id="poisson-space-sigma"></a>

将E分成可数不交Borel片Dₘ，每片μ有限，按第8章在一个乘积空间独立构造上述Nₘ，再置N(A)=ΣNₘ(A∩Dₘ)。这是一份可数原子计数测度，容许取∞。有限片联合的Laplace乘积在片数增大时以有界收敛收敛，指数内以单调收敛收敛，故仍有同一泛函。对不交A₁,…,Aᵣ代入\(\sum_i t_i\mathbf1_{A_i}\)，指数分解；有限强度时向量Laplace唯一性给独立Poisson计数。无限强度A则对任意t>0有Eexp(−tN(A))=0，所以N(A)=∞几乎必然。跨所有有限强度不交族的这项性质称独立散布。

唯一性先比较有限强度片Dₘ内任意有限组Borel计数的联合Laplace；这些向量有限，前专题的唯一性直接适用。任意A的计数都是ΣₘN(A∩Dₘ)，所以这些有限强度读数已经生成全部评价σ域。柱集π–λ遂给整份律唯一，不依赖选择的分片。相反，若一个计数随机测度具有这些独立Poisson计数，先算非负简单f的泛函，再令简单函数递增逼近一般f，便得到同一泛函。因此构造、独立散布刻画与泛函刻画确实等价，不是只匹配总计数。

## 3. 局部有限与简单是两项不同条件

<a id="poisson-space-local"></a>

现在E局部紧第二可数，μ为局部有限Radon测度。每个Kₘ有EN(Kₘ)=μ(Kₘ)<∞，故在一个共同满概率集合上全部窗口计数有限；计数测度于是Radon且属于Mₚ。反过来，若某紧K强度无穷，刚才的泛函证明N(K)=∞几乎必然，不会得到局部有限点过程。仅有σ有限性不保证这一点，例如实线上强度\(\mathbf1_{(0,1)}(x)\,dx/x\)。

在此局部有限范围，N简单几乎必然当且仅当μ无原子。若μ无原子，有限片上任意两次抽样及不同片抽样重合的概率为零，对可数对取并即可。若μ({x})=a>0，N({x})∼Poisson(a)以正概率≥2，故不可能几乎必然简单。局部有限允许有限重数；它与简单性不可混同。

## 4. 强度本身随机时的可测概率核

<a id="poisson-space-cox"></a>

令Λ为随机局部有限Radon测度，只假定每个Borel评价Λ(A)可测。固定穷竭分片Dₘ，每个Λ(Dₘ)有限。对坏参数（某个穷竭窗口质量无穷）置强度0；若仅几乎处处局部有限，这只修改一个可测零集。Poisson参数分布的逆CDF关于参数与均匀数可测；非零时Λ(·∩Dₘ)/Λ(Dₘ)是概率核，零时用固定墓点概率。第10章核随机化用新独立均匀数产生位置。

把这些可测步骤可数次组合，得到(Λ,新均匀数)↦N的评价可测映射，继而得到Poisson律关于Λ的可测核。积分掉新均匀数，逐参数的构造证明给定Λ的整份条件律是Poisson(Λ)，不只是各窗口边缘。称此为Cox过程。

\[ \mathbb E[e^{-Nf}\mid\Lambda]=e^{-\Lambda(1-e^{-f})},\qquad L_N(f)=\mathbb E e^{-\Lambda(1-e^{-f})}. \]

若Λ=Zμ、Z有限非负随机，N在每个紧窗口仍有限，哪怕EZ=∞。对不交A,B且EZ²<∞，条件独立与全协方差公式给Cov(N(A),N(B))=Var(Z)μ(A)μ(B)，一般不为0。这说明随机强度不是把一个常数替换成其平均数。Λ的完整拓扑留给第49章；本构造仅使用评价可测性和已经建立的标准Borel核工具。
