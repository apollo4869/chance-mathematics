# T-COALESCENT-MUTATION：突变模型怎样真正产生Ewens公式

固定Kingman每对活跃谱系合并率1，突变率为每条活跃谱系θ/2，θ>0。无限等位类型意味着不同突变产生不同类型，不是有限类别中可碰撞的标签。返回[第47章](../chapters/47-partitions.md#partitions-mutation)。

## 1. 无突变的固定时刻并不是Ewens

<a id="mutation-proof-counterexample"></a>

无突变时，两标签在时刻t仍不同的概率为e⁻ᵗ；三标签全不同的概率为e⁻³ᵗ，因为尚未任何合并。Ewens(θ)下，这两个概率分别为θ/(θ+1)与θ²/[(θ+1)(θ+2)]。若强令二人概率匹配，e⁻ᵗ=θ/(θ+1)，三人概率就不能匹配：所需恒等式θ(θ+2)=(θ+1)²差了1。

所以不能通过选择一个确定时间就把无突变Kingman各有限限制认作同一Ewens族。下面加入一个明确的新随机机制，并证明它的终端类别划分恰具有Ewens律。

## 2. 沿祖先线遇到首次突变就冻结

<a id="mutation-proof-construction"></a>

有限样本的状态包含互不交的活跃块和已经冻结的类型块，合起来划分[n]。任意活跃块对以率1合并；每个活跃块以率θ/2冻结并获得一个从未用过的新类型。冻结块不再参加活跃合并，也不与其他冻结块合并。所有等待和选择由独立指数构造。

\[ q_b^{(\theta)}=\binom b2+\frac{b\theta}{2}=\frac{b(b-1+\theta)}2,\qquad b\ge1. \]

每个事件使活跃块数减少1，故恰经过n个事件就没有活跃块。各持有时间有限，最后b=1的冻结率θ/2也正，所以终端划分在有限时间内存在。θ=0时最后一块永不冻结，本证明不把其退化情形混进θ>0公式。

这也可准确实现为普通有限Kingman树上的突变。沿其有限条分支独立放置率θ/2的Poisson时钟，并给最后共同祖先之后接一条无限向过去的根支；第21章保证这条支上首次突变有限。每个样本沿祖先方向读到的首次突变决定类型，不同突变点使用不同类型。

更精确地，可把完整状态写为祖先划分R、尚未定类型样本的活跃分块A、以及已冻结分块D。每个R块至多含一个A块。R的任意块对以率1合并；其中若有两个A块便同时合并，若只有一个则保留它；D不变。每个含A块的R块以率θ/2把这个A块移入D，R不变。这个状态集合有限，构造独立指数链即可。投影(R,A,D)到(A,D)：每对可见A块对应唯一一对R块，故合并率1；每个A块冻结率θ/2；其余R合并不改变投影。于是生成矩阵分块身份逐状态成立，再以有限矩阵指数证明整个投影的Markov律。这给出忽略已定类型谱系的完整依据。

为什么丢弃已找到类型的谱系合法？把完整树中仍未找到首次突变的部分标为活跃。活跃—活跃合并率仍1；与不活跃谱系的合并不改变任何活跃样本集合，只延续其未定祖先线；沿延续分支的突变等待因独立增量与指数无记忆仍为率θ/2。忽略这些不可见事件后，活跃/冻结状态的生成矩阵恰是上述矩阵。有限链的生成矩阵分块恒等式及指数级数，如T-KINGMAN-COALESCENT第2节，给整个投影过程同律。因此冻结不是把一个被突变阻隔的类型与更古老的祖先类型强行认作同类。

## 3. 删除标签后的路径与终端相容

<a id="mutation-proof-consistency"></a>

将活跃/冻结块限制到[n]并删除空块。每个可见活跃块对应一个完整活跃块，突变率仍θ/2；两个可见活跃块的合并率仍1。可见块与不可见活跃块合并、不可见块突变等都不给限制增加跃迁。故生成矩阵在限制下相容，有限时间联合律按相同的有限矩阵证明相容。

终端状态在各有限系统中有限时达到，且冻结后不变。取确定t→∞，有限状态指标的有界收敛把时间t限制身份延到终端。因此终端划分律在所有n上采样一致。第8章或T-PAINTBOX的可数限制构造给唯一无限交换终端划分。这个无限对象不要求全体无穷样本在某个共同有限时刻全部冻结；实际证明的是每个有限限制及其相容性。

## 4. 第一事件递推：每一项的含义

<a id="mutation-proof-recursion"></a>

令u(π)为n个单点活跃块开始、最终得到指定等位类型划分π的概率。若首次事件是i的冻结，π必须把i单独成块，因为此类型以后不再出现；删i后剩下同一n−1谱系模型。若首次是i,j合并，则它们必须属于π的同一块；压成一个复合标签后，也是n−1谱系模型。速率只看谱系，不看复合标签含几个原样本。

\[ q_n^{(\theta)}u(\pi)=\frac\theta2\sum_{i:\{i\}\in\pi}u(\pi\setminus i)+\sum_{\substack{i<j\\i\sim_\pi j}}u(\pi^{ij}),\qquad u(\{\{1\}\})=1. \]

所有右侧都是较少标签的概率，所以递推唯一决定u。不能把首次合并的一对任意放进不同终端类型，因为合并以后它们共享同一未定祖先线，其最近突变必定相同。

## 5. 逐因子验证Ewens，而不是只援引经典联系

<a id="mutation-proof-ewens"></a>

把u候选为θᵏ∏(nⱼ−1)!/θ的n阶上升阶乘。删掉一个单点，候选概率的比值为(θ+n−1)/θ；把某大小m≥2块中的一对压成一个标签，比值为(θ+n−1)/(m−1)。代入递推，单点项各贡献候选u乘(θ+n−1)/2；一个m块有m(m−1)/2对，总贡献候选u乘m(θ+n−1)/2。

\[ \frac{\theta+n-1}{2}\left(\#\{\text{singleton blocks}\}+\sum_{j:n_j\ge2}n_j\right)=\frac{n(\theta+n-1)}2=q_n^{(\theta)}. \]

初值n=1也相同，故归纳证明候选就是终端概率。再按大小块数计数得到T-PARTITION-PREDICTION第2节的Ewens采样公式。因此CRP增长与带突变的后向合并产生相同静态终端划分律，却不是同一时间参数化的路径过程；两者的路径空间和转移机制都不同。

## 6. 实际证明范围和速率约定

<a id="mutation-proof-scope"></a>

每对合并率为c>0、每谱系突变率为μ>0时，同时除以c把模型变成本页约定，θ=2μ/c。Ewens参数因而是两种速率的比，不是任意时刻t。无突变与θ↓0的有限采样极限都给最终一类，但不是本页θ>0首次突变构造的原样替代。

本页没有证明有限人口模型在何种人口尺度下趋向Kingman，也没有把自然选择、重组、有限类型碰撞或多重合并纳入这个等位模型。这些修改会改变状态、速率或识别规则，不能从Ewens公式倒推出它们仍有同一分布。数学成立于已声明的中性、二元合并、独立无限等位突变规则。
