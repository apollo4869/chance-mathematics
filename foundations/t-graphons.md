# T-GRAPHONS：随机图、有限模式与表示非唯一性

本专题证明标准Borel表示的有限柱集等律判据，以及二元对称无环图的graphon联系、非唯一性和可识别范围。这里不把graphon看成所有有向、带权、稀疏模型的统一定义，也不声称已证明一般坐标同构分类。返回[第46章](../chapters/46-arrays.md#arrays-graphon)。

## 1. 有限柱集给完整的等律判据

<a id="graphon-proof-cylinders"></a>

为E取可数生成代数𝓐，包含E。对于分别交换函数F，任意有限矩形及其中每个格的Aᵢⱼ∈𝓐，计算下面的积分。联合交换时则使用同一顶点池、反向共享W，并为真正对角乘D的测试。

\[ I_F((A_{ij}))=\int\prod_{i=1}^m\prod_{j=1}^n\mathbf1_{A_{ij}}\big(F(z,u_i,v_j,w_{ij})\big)\,dz\,d\mathbf u\,d\mathbf v\,d\mathbf w. \]

两个表示给同一数组律，当且仅当所有这些可数积分相等。必要性直接来自柱集概率；充分性先用有限维矩形π–λ扩张，再用可数数组的柱集唯一性。不能只比较每格边缘律、每行律、若干低阶矩，或某个有限列表的测试。这个判据允许标准Borel值且包括对角与方向，没有要求表示函数逐点相同。

## 2. 从成对随机化得到graphon

<a id="graphon-proof-representation"></a>

设X为{0,1}值、Xᵢⱼ=Xⱼᵢ、Xᵢᵢ=0的联合交换图。T-ARRAYS给对称F；定义W(z,u,v)=∫1{F(z,u,v,w)=1}dw。它联合Borel且在u,v上对称，取值[0,1]。给定全局与顶点输入，所有不同无序边条件独立，成功率W，所以可改用阈值构造。

\[ X_{ij}=\mathbf1\{W(U_0,U_i,U_j)>W_{\{i,j\}}\},\quad i\ne j;\qquad X_{ii}=0. \]

阈值处的严格或非严格不影响概率，因为成对均匀数连续且独立。固定z时W(z,·,·)是一份graphon；不变律的全局混合允许它随机。这里随机graphon指联合Borel参数族及随机参数，不预设函数商空间的可测选择。若图律分离，T-ARRAY-ERGODIC允许固定一个好z，所以一份确定graphon即可。这里随机的是概率核，不是把当前抽到的一张有限邻接矩阵误称为唯一graphon。

## 3. 普通子图概率怎样恢复全部诱导图规律

<a id="graphon-proof-patterns"></a>

\[ t(H,W)=\int_{[0,1]^{V(H)}}\prod_{ab\in E(H)}W(x_a,x_b)\,d\mathbf x. \]

H为有限简单无环图。此积分是所有指定H边出现的概率，不约束其余边。若要指定顶点集合上恰好出现E而其余潜在边B都不出现，条件独立给∫∏E W·∏B(1−W)。展开后得到下式。

\[ \mathbb P_W\{\text{induced edges exactly }E\}=\sum_{J\subseteq B}(-1)^{|J|}t((V,E\cup J),W). \]

因此两份确定graphon产生同一无限图律，当且仅当t(H,W)对所有有限简单H相同。这是精确的采样等价判据；没有证明也不需要在此宣称它们必由一个可逆坐标置换相连。随机全局W时，相同论证把t替成E t，仍是完整图律判据。

还可识别随机向量(t(H,W))的分布。有限多个密度的任意乘积，是对应图的不交并的密度，重复次数给幂。于是全部有限维多项式矩由图律确定。密度在[0,1]；产品Bernstein多项式一致逼近立方体上的连续函数，证明是对每个坐标的二项平均分别用方差界并合并有限个误差，与第13章一致。故矩决定每个有限向量的律，再由柱集唯一性决定整个可数密度向量的律。没有假定原graphon坐标由此恢复。

## 4. 相同每行规律，却有不同三角形

<a id="graphon-proof-row-counterexample"></a>

取W₁恒为1/2；另把[0,1]分成等长两半，W₂在两点位于不同半区时为1，否则为0。两份graphon的度函数都恒为1/2。给定某个顶点潜变量，它向其他顶点的边都是iid Bernoulli(1/2)，所以每一行的de Finetti指导律都相同且确定。

\[ t(K_3,W_1)=1/8,\qquad t(K_3,W_2)=0. \]

第二个图的每个三角形中跨区次数为0或2，不可能三边都出现。这直接证明：每行的表示分别正确，也不能决定跨行共享指标怎样对齐。两种图都分离，因此即便已经去掉全局环境，这项失败仍存在。

## 5. 非可逆坐标也能保持同一图律

<a id="graphon-proof-nonunique"></a>

令T(x)=2x模1。区间原像分成两段各缩半，故T保持Lebesgue概率，先对区间再π–λ即证。取W(x,y)=xy、V(x,y)=T(x)T(y)。因为T(Uᵢ)仍是iid均匀数，两者给同一图律，所有有限模式密度相同。

但不存在模零可逆、保测S使V(x,y)=W(Sx,Sy)几乎处处。若存在，对y积分，因S保测，得到T(x)/2=S(x)/2，所以S=T模零。任何全测度集合同时在几乎每对x与x+1/2上取点，两点T值相同，故T不可能在全测度集合上单射。这个反例否定“函数非唯一只差可逆改名”的过强断言。

一般表示中，固定的保测输入重参数化给等律的充分条件：共同顶点池使用同一变换，分别池可以各用自己的变换，无序对噪声必须仍在两方向共享。它不是已证明的必要分类。全部有限柱积分相等才是这里实际证明的通用充要条件；graphon全密度判据是二元对称特例。一般Hoover坐标等价的更强分类、cut距离分类均不计作本专题已证。

## 6. 有限交换图不能自动无限延拓

<a id="graphon-proof-finite"></a>

三个顶点上均匀选一条边，得到S₃交换图。若它有无限交换延拓，每个三元组必几乎处处恰含一条边；可数三元组给同一个满概率事件。事件X₁₂=1有概率1/3，在该事件上对每个k≥3，三元组{1,2,k}迫使X₁k=X₂k=0；再由{1,k,l}迫使所有k,l≥3间边都为1。于是{3,4,5}有三条边，矛盾。

无限性是表示定理的真实前提。有限图采样可有近似理论，但不能把有放回潜变量模型的精确无限表示无条件写给任意有限交换邻接阵。
