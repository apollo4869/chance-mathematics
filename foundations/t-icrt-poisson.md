# T-ICRT-POISSON：重复时钟、接枝与紧性边界

回到[第58章](../chapters/58-multifurcation.md)。唯一模型来源为[Aldous–Pitman, PTRF118(2000),455–482](https://www.stat.berkeley.edu/~pitman/525.pdf)第2节的公开构造。完整ICRT质量分类及加性合并入口边界不是本专题已证范围。

## 1. 一类时钟决定分散接枝，另一类决定重复枢纽

<a id="ic-clocks"></a>

\[ \theta_i\ge0,\quad \theta_0^2+\sum_{i\ge1}\theta_i^2=1. \]

标准ICRT族另要求\(\theta_0>0\)或\(\sum_{i\ge1}\theta_i=\infty\)；正指标按非增排序只是参数表示约定。下文先在只要求归一化平方可和的放宽参数域上证明时钟与接枝引理，不能把这些引理等同于一般ICRT质量和紧性定理。第4节的单枢纽例故意位于标准参数域之外。

独立取三角形\(\{(x,y):0<y<x\}\)上强度\(\theta_0^2 dx\,dy\)的Poisson点，以及每个i≥1速率θᵢ的Poisson时刻\(\xi_{i,1}<\xi_{i,2}<\cdots\)。三角形点的x为切点、y为接点；第i类只把j≥2的时刻作为切点，接点恒为\(\xi_{i,1}\)。第一次出现不是切点。

[0,R]中第i类切点期望为\(\theta_i R-(1-e^{-\theta_i R})\le\theta_i^2R^2/2\)。加上三角形点的期望\(\theta_0^2R^2/2\)，总期望有限，所以切点局部有限几乎必然。独立连续时刻与可数并排除重合；每个正速率类有无限切点，若只有θ₀>0亦如此，所以切点可排为\(0<\eta_1<\eta_2<\cdots\uparrow\infty\)。

## 2. 有限树、无限完备化与无穷度数

<a id="ic-tree"></a>

从[0,η₁]开始，在第j个切点把新段\((\eta_j,\eta_{j+1}]\)接到对应接点。接点小于切点，因此已经存在于旧树。每一步新增的是一条正长度悬枝，有限空间是紧实树，旧距离保持。全部步骤可测，因为有限窗口Poisson配置可测枚举，接枝距离为有限个加减和min操作。联合空间可分，完备化是实树：第57章完备化引理不要求全有界，仅用原空间唯一弧和四点不等式；在完备空间中用近似中点构造测地。

若θᵢ>0，第i类的全部后续接枝都在同一枢纽。每根新枝长度严格正，其内部点删除枢纽后处于不同开连通分支；未来只接枝不识别旧点，完备化也不识别正距离点。因此该枢纽有可数无穷度数。分散三角形接点彼此不同且不与枢纽重合，故有限阶段通常只是二叉插入。不同层次的接点机制不能被一个固定k概括。

## 3. 第一次重复的分布

<a id="ic-repeat"></a>

\[ P(\eta_1>t)=\exp(-\theta_0^2t^2/2)
\prod_{i\ge1}(1+\theta_i t)e^{-\theta_i t}. \]

无切点意味着三角形中没有x≤t的点，并且每个Poisson时钟在t前至多出现一次。独立性给有限乘积；令类数增大用递减事件连续性得到无限乘积。其收敛由\(0\le u-\log(1+u)\le u^2/2\)及平方和有限保证，因而t<∞时为正。该公式已区分Brownian分散部分和持续大权重；只有二阶和为1不足以使所有θ向量产生同一分布。

## 4. 一个揭示参数边界的反例

<a id="ic-boundary"></a>

放宽参数后取θ₁=1、θ₀=θ₂=⋯=0；它不满足标准ICRT参数条件，因此这里只是接枝算法的边界反例。所有枝接在同一枢纽。相邻切点间距为独立Exp(1)，几乎必然有无穷多个大于1的枝；每枝距枢纽1的位置彼此距离2，所以该球内没有有限1/2网。完备化不局部紧，更不紧。

公开ICRT理论因此施加额外条件；Aldous–Pitman所用参数域为\(\theta_0>0\)或\(\sum_{i\ge1}\theta_i=\infty\)，并另行构造质量。该参数域内一般对象也不能未经检验就纳入本书紧GHP空间。本专题完整证明有限接枝、完备实树、枢纽与第一次切点律；一般参数下的质量构造、采样一致性、紧性分类以及与不均匀生日树的极限识别，尚无本书完整证明。θ₀=1的分散时钟强度为rdr，给第57章2e规范，而标准e应把全部边长减半，等价时钟4rdr。
