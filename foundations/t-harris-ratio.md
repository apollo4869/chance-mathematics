# 再生比极限与保守Hopf定理

## 1. 无须有限平均周期的报酬比

<a id="ratio-cycles"></a>

沿用T-HARRIS-REGENERATION，允许μ=∞。设m|f|<∞、g≥0且0<mg<∞。周期报酬\(F_i\)、\(G_i\)、\(A_i\)分别为f、g、|f|的半开周期和，独立同分布，可积，均值分别mf、mg、m|f|。对任意可积非负Y，ΣP(Y>εi)<∞，故\(Y_i\)/i→0；这里只需同分布，不需独立。这同时控制最后一个未完成周期的绝对报酬与g报酬。

每个周期长度有限，故n→∞时已完成周期数N(n)→∞，即使N(n)/n→0。强律给\(\sum _{i\le k}\)\(F_i\)/k→mf和Σ\(G_i\)/k→mg。初始前缀有限且f、g为处处有限版本；余项至多\(A_{N+1}\)、\(G_{N+1}\)=o(N)。若函数只在m几乎处处有限，则先取有限版本，并只对不命中所改零集的初始条件声明；本章直接采用处处有限可测函数以避免隐含的初始例外。

\[ \frac{\sum_{j=0}^{n-1}f(X_j)}{\sum_{j=0}^{n-1}g(X_j)}\longrightarrow\frac{mf}{mg}\quad\mathbb P_x\text{-a.s. for every }x. \]

分母最终正且趋∞，因为每周期平均g报酬严格正。非周期性不参与此证明。若μ<∞且f有界或π|f|<∞，再用\(R_k\)/k→μ，得时间平均→πf。μ=∞时，对于可积有界g，同样的计算与N(n)/n→0给时间平均0；这已用于排除不变概率。

## 2. σ有限保测系统中的一个完整Hopf版本

<a id="ratio-hopf"></a>

本节给另一种比极限，精确范围为可逆、遍历、保σ有限测度的变换T，并假设T与T⁻¹保守：每个正测度集合中的几乎每点在两个时间方向都无穷次返回。取0<m(A)<∞。由遍历性，A的双向饱和覆盖全空间模零；前后保守性使几乎每点都有前后访问。令τ为A的首返，\(T_A\)=T^τ为诱导变换。

按最近一次过去访问A的位置分割，集合Tʲ(A∩{τ>j})两两不交且覆盖全空间模零。把B⊂A的前一次访问分片，同样给m(\(T_A\)⁻¹B)=m(B)。若B⊂A在\(T_A\)下不变，将其沿这些周期塔展开，得到T不变集合；遍历性迫使B在A中全或零。所以\(T_A\)在归一化m|A下保概率且遍历。

对m可积f及非负可积g，令\(f_A\)=\(\sum _{j<\tau }\)f∘Tʲ，\(g_A\)同理。塔分割与Tonelli给∫A \(f_A\)=mf、∫A \(g_A\)=mg，以及∫A\((|f|)_A\)=m|f|。对诱导概率系统用第41章Birkhoff，周期报酬比趋mf/mg。末周期的报酬除以周期数趋0：在诱导系统下它们同分布且可积，尾和与Borel–Cantelli给出所需界。有限进入延迟无影响，因此原系统上得到与上节形式相同的比极限。

这不是任意非保守或一般非奇异变换的比定理。例如T(k)=k+1在Z计数测度上保测且遍历但耗散，f=\(\mathbf1_{0}\)、g=\(\mathbf1_{1}\)有相同积分，从k=2出发未来分母恒为0。保守性不是装饰。一般非可逆正算子Hopf版本、非保测与连续时间比极限不由本节冒充完成。

## 3. 概率系统中的随机比

<a id="ratio-probability"></a>

若T保概率但不遍历，f,g∈L¹、g≥0，第41章直接给在{E[g|I]>0}上平均之比趋E[f|I]/E[g|I]。不能无条件把两个随机条件平均换成两个全局积分。两份不沟通环境各有不同访问比例时，极限比也保留环境。

回到[第42章比遍历](../chapters/42-harris-coupling.md#harris-ratio)。上面三个版本的假设不同：再生Markov链允许无限m和所有初态；保守Hopf版本为可逆遍历σ有限系统的几乎处处结论；概率版本允许随机条件极限。
