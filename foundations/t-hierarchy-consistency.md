# T-HIERARCHY-CONSISTENCY：有限限制、嵌套paintbox与树表示的范围

本页证明[第56章](../chapters/56-fragmentation-hierarchies.md#hierarchy-space)的层级构造。依赖8章可数概率构造、43章标准Borel de Finetti、47章paintbox及54章祖先距离机制。一般无层时标交换层级的完整IP树表示分类不在本页已证范围；下文分别证明全部有限层级、全部可数指定层的嵌套划分，以及无层间dust时的概率实树表示。

## 1. 层级是有限观察的相容族

<a id="hierarchy-projective"></a>

有限集[n]上的层级H包含空集、[n]和所有单点，并满足任意A、B∈H相交时必有一者包含另一者。限制rₘH={A∩[m]:A∈H}仍满足这些条件。令Hₙ为空间中全部此类有限族，它是有限离散空间；无限层级定义为相容序列(Hₙ)而不是未经限定的2ᴺ的任意随机子族。相容条件在有限离散空间可数积中闭，故该逆极限是紧Polish空间，评价Borel域由有限限制生成。

若概率pₙ满足(rₙ)₊pₙ₊₁=pₙ，对任意多个限制坐标，取最大坐标的p律并向下投影，得到相容有限维律。8章可数构造给乘积空间概率；可数相邻相容事件概率1，故它集中于逆极限。柱集唯一性给唯一律。每个pₙ在[n]重编号下不变，则对任意有限置换、任意柱集，取足够大N直接用p(N)不变性，扩张到全Borel域。构造因此真的给无限交换层级。

## 2. 有限树的表示不自动赋予一致边长

<a id="hierarchy-finite-tree"></a>

对非空层级成员A≠[n]，其严格超集因层级性完全排序，故有唯一最小者parent(A)。把A连到这个父节点。严格包含排除环路，每点向上到根；单点为叶。一个非单点节点的极大真子成员不相交，且因单点齐全而覆盖该节点；所以至少有两个子节点。反向，根到叶的祖先集合产生同一层级。两个构造互逆，得到无平面顺序、无边长、无冗余一子节点的有根叶标号树。

限制对应删去未观察的叶、再压缩冗余一子节点；这不保存任意指定的单位边长。例如三叶树中{1,2}先同祖先，叶1到叶3走三条单位边；只保留1、3后重新每边赋1，距离变成2。故拓扑限制的一致性不等于这些重新赋长的度量限制一致。

## 3. 有时标嵌套划分怎样产生层级

<a id="hierarchy-clocked"></a>

设Πₜ为只细分不合并的划分路径，每个有限限制右连续。对[n]取所有有理t≥0时的块，再加根、单点、空集，得到有限层级Hₙ。在有限限制中，每次有效改变增加块数，最多n−1次；任何在实数t出现且非单点的块，由右连续性在某个右侧有理时刻仍出现。因此有理时刻没有遗漏有限可见类别。限制操作与取这些块及补单点相容，给无限层级。

层级忘掉了分裂时刻，甚至忘掉两个不同分枝上分裂的先后。给定层级不能恢复等待分布。反之，一般相容层级未被预先赋予这样的右连续Markov时钟；本页不以这个专用构造声称任意层级都已有碎裂动力学。

## 4. 同一份指导概率耦合全部指定层

<a id="hierarchy-nested-paintbox"></a>

定理：对m=1,2,…给一族共同交换且逐层细化的划分Π⁽ᵐ⁾，存在随机Q∈P([0,1]ᴺ)，使条件于Q的iid行Xᵢ，按第m坐标相等产生这些划分的联合律。证明：每层各块按最小成员枚举，独立贴连续均匀标签Zₘ,ⱼ，令Xᵢ(m)为其块标签。可数标签共同几乎必然不碰撞；任意有限行、层的标签律只依赖原层级关系，所以Xᵢ作为[0,1]ᴺ值序列交换。43章给可测指导Q及条件iid。各层等价关系由坐标相等逐项恢复，故获得原来的全部联合限制。

\[ i\sim_{\Pi^{(m)}}j\ \Longleftrightarrow\
X_i(m)=X_j(m),\qquad
Q^{\otimes2}\{x_m=y_m,\ x_\ell\ne y_\ell\}=0
\quad(\ell<m). \]

最后一个条件由原嵌套事件概率1及条件期望得到，对可数层对统一零集。它也是反向构造的充分条件：给这样一份Q，对可数样本对和层对取交后，坐标等价关系同时嵌套。每层的paintbox频率是Q的该坐标边缘的排序原子质量，dust是非原子部分；强律在可数层和可数原子上共同成立。辅助Q不唯一，重新标记各层颜色不会改变划分；本页不声称Q的坐标名称可识别。

## 5. 逐层频率相同，层间组织仍可不同

<a id="hierarchy-marginals"></a>

两层的频率分别取(.6,.4)与(.4,.3,.2,.1)。模型A在第一父块内放.4与.2，在第二父块内放.3与.1。模型B在第一父块内放.3、.2、.1，在第二父块内只放.4。两层各自的排序向量完全一样，但三个样本同父且属于三个不同子块的概率，A为0，B为6×.3×.2×.1=.036。这证明独立指定各层paintbox，甚至各层边缘全部正确，也没有指定正确的层级律。

## 6. 无层间dust时，实际构造一棵概率实树

<a id="hierarchy-tree"></a>

现在另加准确假设：每个有限层的边缘Qₘ都是纯原子概率。给定一个好Q，第m层正质量颜色只有可数多个，每个子颜色唯一属于一个父颜色：否则在该子原子内取两份iid样本有正概率父颜色不同，违背上节Q²条件。以这些颜色为节点，补根，父子相连，第m层高度aₘ=1−2⁻ᵐ。线段并上用树路长，完备化后得到可分实树。

这里不能只靠“完备化仍是树”略过证明。Cauchy列的高度有极限h≤1；在任何严格低于h的固定层，祖先必须最终相同，否则两点距离有正下界。若h<1，有限多个低层之后它收敛到某条已有线段上的点；若h=1，稳定的全部祖先构成一条无限地址，并添加其端点。任意两点共同祖先由最长共同地址确定，根线按高度等距参数化，沿共同祖先拼接给测地；删除其内部点把两端分在不同前缀分枝中，任意连续弧必须经过它，故弧唯一。

\[ d_T(\partial x,\partial y)
=2(1-a_{L(x,y)})=2^{1-L(x,y)},\qquad
L(x,y)=\sup\{m:x_m=y_m\},\quad 2^{-\infty}=0. \]

Q几乎所有地址在各层正原子中，逐层节点点态收敛到边界点∂x；这是可测映射，因为有限层地址可测、目标度量完备。推前Q得到Borel概率μ；层节点的fringe质量就是相应原子质量。iid μ样本的所有层fringe恢复原嵌套划分。中间边点不增加类别；边界永久同址样本所成类别在每个有限样本中也会在足够深层出现，单点照定义另行加入。因此有限层级限制完全相同。若每层仅有限多个正块，则任一ε只需有限深度的有限网，树紧；反向若某层无限多正块，取其边界各一点有统一正距离，故不紧。

## 7. dust与没有时标的一般层级：真实边界

<a id="hierarchy-scope"></a>

若第一层全为dust，上述固定高度会给所有不同样本距离2。55章已证明这不可能是一份可分度量概率空间的iid距离律；不能悄悄把不可数正长星形树当作Polish概率树。嵌套paintbox定理仍成立，因为[0,1]ᴺ上的坐标相等不是宣称该前缀距离是可分相容度量。更一般交换层级的实树表示需要不同的高度构造与质量结构等价理论，此处如实未证，不由上节专用版本代替。

紧情形的随机树可测性也能实际验证。在每层有限正块的条件下，额外取条件iid Q地址，前k个样本截到第m层所得有限根跨度只取有限多个组合形式，边高固定、节点经验质量1/k，故是GHP值Borel随机元。k趋无穷时每个有限层原子都被命中，经验质量强律使其GHP趋第m层全树；m趋无穷时在原树内把叶推到第m层祖先，Hausdorff及质量配对距离都≤1−aₘ，故再趋整树。两次度量极限给随机紧树的可测版本。一般非紧无dust情形，根与iid边界距离的读数可测，由55章的GP Borel刻画给支撑加根的随机GP对象，不把它称为紧GHP对象。

即使树表示存在，层级也不识别GHP几何。只在一条根到叶的边端放全部质量，不论边长1还是2，采样层级都只有根类别及单点；根到样本距离却不同。层级不自带分裂时钟、度量或Markov性质。返回[正文的树表示边界](../chapters/56-fragmentation-hierarchies.md#hierarchy-tree-boundary)。
