# T-POINTED-GW-TREES：典型个体、祖先再生与临界局部极限

本页补全[第57章的脊柱抽样](../chapters/57-regenerative-growth.md#growth-pointed-spine)。使用52章平面GW树的独立地址构造和20章灭绝分类、有限方差临界生存渐近。它不重证20章超临界L log L，而研究不同的抽样权重和条件极限。

## 1. 先选择怎样的典型个体

<a id="pointed-total-palm"></a>

\[ 0<m=E\xi<1,\qquad E|T|=\sum_{h\ge0}EZ_h=\frac1{1-m},\qquad \widehat P(T=t,V=v)=(1-m)P(T=t),\quad v\in t. \]

非负求和用Tonelli；有限期望也保证T有限几乎必然。最后一个式子对全部有限平面树和其中节点求和为1，故定义合法概率。它先按总人口|t|加权选树，再在树内均匀选一个节点。若先按原P选树再均匀选节点，联合概率为P(t)/|t|，与这里不同。典型节点不必是叶，也不必处在最后一代。

## 2. 有限脊柱的乘积密度

<a id="pointed-many-to-one"></a>

\[ \widehat p_\ell=\frac{\ell p_\ell}{m},\quad\ell\ge1;\qquad Q_h(t,v)=m^{-h}P(t)\mathbf1_{\{|v|=h\}}. \]

构造Qₕ：连续h个祖先独立按大小偏置后代数取ℓ，均匀挑其中一个孩子继续脊柱，其余每个孩子各挂独立原GW树；第h个标记节点以下挂一整棵原GW树。一个给定祖先有ℓ孩子并指定脊柱孩子时，概率因子是(ℓpℓ/m)(1/ℓ)=pℓ/m，而不是ℓpℓ/m。连乘h次，其他全部节点仍贡献原p，得到显示密度。总质量为E Zₕ/mʰ=1。这也给任意非负树—节点测试F的many-to-one身份。

\[ E_P\sum_{|v|=h}F(T,v)=m^h E_{Q_h}F(T,V). \]

概率空间可在可数地址上以独立整数、均匀孩子选择和独立原GW环境构造，使用52章的可测树编码；各旁生树及终端树在给定脊柱后代数与孩子选择后独立。这是真正的条件独立结论，不是仅凭树形图判断。

## 3. 随机终点使再生成为一个可计算的表示

<a id="pointed-geometric-spine"></a>

\[ P(H=h)=(1-m)m^h,\qquad h\ge0,\qquad \widehat P=\sum_{h\ge0}(1-m)m^h Q_h. \]

右边给每对(t,v)的概率为(1−m)mʰ×m⁻ʰP(t)，正好等于第一节。故典型个体深度是几何变量；给深度后，祖先后代环境iid大小偏置，旁生树及标记节点以下仍是原GW。深度H独立于用于构造无限候选脊柱的环境，再在H截断；因此在尚未终止的祖先处，剩余几何长度有相同律，旁生树重新开始。这是在代数步数上的再生，不是假设物理出生间隔组成19章更新过程。

大小偏置发生在必须连向抽中个体的祖先，不在所有节点。标记个体本身的后代数仍服从p。这一差别正由乘积密度支持；若删除选择哪个孩子的1/ℓ因子，会同时破坏归一化和这项解释。

## 4. 临界树看向远处，会产生另一种无限脊柱

<a id="pointed-critical-limit"></a>

\[ m=1,\quad0<\sigma^2=\operatorname{Var}\xi<\infty,\qquad a_N=P(Z_N>0)\sim\frac2{\sigma^2N}. \]

此时总人口期望无穷，第一节的总人口加权无法归一化。固定观察高度h，条件于前h代的σ代数Fₕ，N≥h时生存事件的条件概率为1−(1−a(N−h))^{Zₕ}。每个第h代个体的后续家族独立，故这个公式没有隐含额外条件。取20章已证a(N)渐近，得到如下密度极限。

\[ \frac{dP(\,\cdot\mid Z_N>0)|_{\mathcal F_h}}{dP|_{\mathcal F_h}}=\frac{1-(1-a_{N-h})^{Z_h}}{a_N}\longrightarrow Z_h\quad\text{in }L^1(P). \]

逐点极限由(1−(1−a)ᶻ)/a→z及a(N−h)/a(N)→1。上界1−(1−a)ᶻ≤za给密度≤CZₕ，对足够大N有统一C，而E Zₕ=1；控制收敛证明L¹，故前h代律实际按总变差收敛。极限密度Zₕ相容，因为人口过程是均值1鞅。按ℓpℓ选择每代脊柱后代数、均匀选继续孩子、其余挂独立临界GW，直接构造相容无限树；有限h的乘积计算恰给密度Zₕ。

原临界旁生树几乎必然有限，数目可数，所以共同好集上所有旁生树都有限，脊柱是唯一无限祖先线。这一常称Kesten树的局部极限，只用这里明示的有限方差生存渐近；不计无限方差的一般推广。

## 5. 局部脊柱极限不是紧CRT极限

<a id="pointed-scope"></a>

条件在第N代仍生存、保留单位边长并固定h，产生上述无限局部树；条件总规模n、将边长缩为σ/(2√n)，产生55章的紧CRT。这两个条件事件、尺度与拓扑不同。不能把“都有脊柱”当作两极限等价，也不能把次临界总人口Palm、临界生存偏置和Brownian质量样本混为同一份典型抽样。本页证明离散祖先再生及两种准确的大小偏置；一般连续再生CRT分类另有条件，未由本页得到。[返回正文](../chapters/57-regenerative-growth.md#growth-local-global)。
