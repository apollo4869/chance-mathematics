# T-ROTATABLE：有限旋转与无限Gaussian混合

本专题建立实值无限序列的旋转不变表示；不涉及第46章数组表示。工具是紧群轨道条件化、第12章强律、第24章紧性、第43章指导律及第14章多维特征函数唯一性。回到[第45章](../chapters/45-invariance.md#rotation-sequences)。

## 1. 球面概率从哪里来

<a id="rotatable-sphere"></a>

O(n)是矩阵空间中由QᵀQ=I给出的闭有界群，因而紧可度量。其Haar推送到单位球面得到唯一O(n)不变概率。若Z₁,…,Zₙ独立标准正态，联合密度只依赖平方范数；正交变换Jacobian绝对值为1，故Z的律不变。其范数几乎处处不为0，所以Z/||Z||也不变，恰为该球面概率。n=1时为两个端点各半。

\[ \sqrt n\,(U^{(n)}_1,\ldots,U^{(n)}_k)\ \stackrel d=\ \frac{(Z_1,\ldots,Z_k)}{\sqrt{n^{-1}\sum_{i=1}^nZ_i^2}}\ \longrightarrow\ (Z_1,\ldots,Z_k). \]

右边可以在同一无限正态列上构造，分母由强律几乎处处趋1。因此每个固定k的收敛直接成立，不是把高维球面画成Gaussian曲线就算证明。

## 2. 有限维旋转留下半径，而不是自动留下Gaussian

<a id="rotatable-finite"></a>

设实向量X∈Rⁿ的律O(n)不变。轨道正是范数相等的球面及零点；T-ORBITS给定半径后的均匀球面条件律。因此可在等律构造中写X=RU，其中R=||X||的分布任意，U为独立均匀单位方向，零半径单独送到0。有限维不变性不强制R服从Gaussian半径律。

单位球面上的均匀向量不是非零中心Gaussian的尺度混合：在任何正尺度下Gaussian范数无上界，而球面范数恒为1。再要求各坐标独立则不同。n≥2时旋转给各坐标同分布且对称，设共同特征函数φ。独立性和二维旋转给φ(s)φ(t)=φ(√(s²+t²))。φ在0附近为正，反复使用φ(t)=φ(t/√2)²知它处处正。连续函数u↦log φ(√u)在非负实数上可加，故为cu，且c≤0。于是φ(t)=exp(ct²)，为中心Gaussian或零点质量。独立性在此承担了额外而实质的责任。

## 3. 无限兼容性先迫使半径尺度紧

<a id="rotatable-tightness"></a>

称无限实列可旋转，若对每个n，初始n维向量的律在O(n)下不变。令Sₙ为前n个平方的平均；没有任何矩假设。有限维轨道公式给第一坐标的分布如下，右边可取Sₙ与U独立。

\[ S_n=\frac1n\sum_{i=1}^nX_i^2,\qquad X_1^2\stackrel d=S_n\,n(U^{(n)}_1)^2. \]

上一节球面极限给常数c,δ>0与n₀，使n≥n₀时P{nU₁²>c}≥δ。故δP{Sₙ>K}≤P{X₁²>cK}。X₁是有限实随机变量，右边随K趋∞而趋0。其余有限多个n分别紧，因此全部Sₙ的律紧。这一步排除了未假设二阶矩时“半径逃往无穷”的风险。

## 4. 识别所有有限维极限

<a id="rotatable-mixture"></a>

抽Sₙ的弱收敛子列，记极限V，取值于非负有限实数。对固定k，前k坐标的律一直不变，同时等于√Sₙ乘球面的前k缩放坐标。为了严格通过随机尺度极限，令ψₙ(v,t)为这一球面向量在尺度√v下的特征函数。用共同正态列表示球面，分母趋1，且对0≤v≤K，指数差的上界可取min(2,√K||t||·||Z前k||·|分母倒数−1|)。它几乎处处趋0且至多为2，故ψₙ在v的紧区间上一致趋下式。

\[ \exp(-v\|t\|^2/2),\qquad \mathbb E\exp\!\left(i\sum_{j=1}^kt_jX_j\right)=\mathbb E\exp(-V\|t\|^2/2). \]

先截Sₙ≤K，紧区间一致误差趋0；剩余由紧性控制，最后令K趋∞。极限函数关于v连续有界，弱收敛可用于其积分。第14章多维唯一性识别全部有限维律，再由第8章柱集唯一性识别无限记录律：它与先取V、再条件独立生成N(0,V)列相同。反向显然成立，因为每个固定V的Gaussian向量正交不变，混合后仍不变。

在该混合构造中，对每个固定有限V，条件强律给Sₙ趋V几乎处处；对V再积分即得无条件结论，不要求EV有限。这个收敛是记录空间事件，因此原序列也有几乎处处极限V*，且它的律唯一确定混合分布。经验测度也条件弱收敛到N(0,V*)，于是第43章的指导随机测度正是这份随机Gaussian律；所有条件概率身份在可数决定类上统一，再推广。

所以结论不是“旋转对称意味着独立Gaussian”。它意味着无限可旋转列是中心Gaussian列的随机方差混合；V*非退化时保留共同依赖。例如V*独立取1或4，两坐标的平方各自虽有固定边缘分布，却共同报告同一尺度，因而不独立。反过来iid Rademacher列交换但不旋转不变；两个坐标旋转45度后出现0与绝对值√2，原坐标只取±1。

在上面的二点方差例子中，E[X₁²X₂²]=17/2，而E[X₁²]E[X₂²]=25/4，差为9/4。这直接验证了依赖，并不只靠“共享隐藏参数”作语言判断。
