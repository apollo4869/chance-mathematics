# T-SELFSIMILAR-FRAGMENTATION：有限分裂测度的全部实指数、侵蚀与爆炸

本页完成[第56章](../chapters/56-fragmentation-hierarchies.md#fragment-selfsimilar)的准确范围：ν有限、ν{(1,0,…)}=0、c≥0、α任意实数，允许可数子块、损失质量及有限时间shattering。一般无限ν的块依赖停止线时间变换未在本页证明，不把下述全参数有限ν定理冒充它。

## 1. 从一条局部时钟建立每块的路径

<a id="selfsim-clock"></a>

令λ=ν(S↓)。在可数Ulam–Harris节点上独立取Eᵥ∼Exp(λ)、sᵥ∼ν/λ；λ=0时E=∞、不取s。一块出生质量m>0，局部操作时间u的存活质量为m e⁻ᶜᵘ，物理时间为Aₘ(u)。到u=E时分成质量m e⁻ᶜᴱsᵢ的子块；其余质量进入dust。

\[ A_m(u)=\int_0^u(me^{-cr})^{-\alpha}\,dr
=m^{-\alpha}
\begin{cases}
(e^{\alpha cu}-1)/(\alpha c),&\alpha c\ne0,\\
u,&\alpha c=0 .
\end{cases} \]

A在质量为正时严格连续递增；以其逆函数决定物理时刻的质量。u趋∞但A有有限终点时，把终点及以后质量置0。微分核对给x′(t)=−c x(t)^(α+1)，而操作指数时钟的物理跳率是λx(t)^α，不是λx(t)^(−α)。子块重复相同独立构造。

## 2. 区间实现使交换性与质量都可检查

<a id="selfsim-intervals"></a>

以[0,1)为初始区间。每个节点使用一段半开区间J，长度等于出生质量；操作年龄u保留其最左长度m e⁻ᶜᵘ，右端被侵蚀。在分裂时按s的顺序把保留区间切成可数个半开子区间，未分配的尾部为dust。出生区间与子区间端点由有限随机变量的可测函数构成，全树地址可数，所以整个环境可测。

独立取iid均匀Uᵢ。时刻t，共处于一个当前正长区间的标签同块，其余各为单点。若一个标签沿无穷地址在有限时间积累，只要质量趋0就将它变为dust。两份不同U不可能共处同一个零长嵌套区间交，因此不会凭空产生一个有限或无限的零质量非单点块。端点使用半开约定，移动侵蚀边界到达U时恰在该时刻剥离。

## 3. 不能把爆炸留给一句“极限存在”

<a id="selfsim-explosion"></a>

先截断到有限代。任意时刻质量至少ε的区间不超过1/ε个；每个的分裂率至多λ max(1,ε^α)。故这些大块的总率有一致常数界Cε。有限代指数竞争或有界率Poisson加空跳证明，至t的大块分裂次数期望至多Cεt；代数截断递增，单调收敛给完整构造也只有有限次。侵蚀只减少质量，不增加这个率界。

因此有限时间内无穷祖先分裂的质量必趋0，否则某个ε的大块会无穷次分裂。对任何不同标签，若永远不分开，它们必须一直在同一嵌套区间内；在有限累积时刻区间长度趋0将强迫U相等，这是零概率。可数标签对统一以后，每对有合法的分离时刻；每个[n]仅能有效细分n−1次，得到右连续有限路径。其投影来自同一U与环境，因而一致。整个划分过程càdlàg，且重编号U不改律，所以交换。

对均匀样本的全区间经验分布应用T-HOMOGENEOUS-FRAGMENTATION已证的一致分布函数强律，所有区间的经验频率同时趋其长度，包括此处随机端点和所有时间。故当前正块质量真等于区间长度，不是给区间模型另外猜一份质量。排序过程及dust的共同版本用同页的分离时刻证明，仍只宣称坐标拓扑càdlàg。

## 4. Markov分枝与自相似身份

<a id="selfsim-markov"></a>

给定截至当前时刻已揭示的正区间环境和过去，未用的子代环境仍独立；现存节点的操作指数等待具有无记忆性。给定这份过去环境和过去的标签分类，现存标签在当前区间中仍条件独立均匀：全部过去祖先区间包含当前区间，不施加更小的条件；这个身份先对有限标签和有限过去时刻由乘积Lebesgue条件化证明，再用单调类扩张。正质量子块中的标签顺序也没有偏好。

\[ \mathcal L\big(X^{(x)}(t)\big)
=\mathcal L\!\left(
\operatorname{rank}\{x_i X_j^{(i)}(x_i^\alpha t):i,j\ge1\}
\right),\qquad X^{(i)}\ \text{independent unit copies}. \]

时钟恒等式Aₘ=m⁻ᵅA₁证明每块质量m的独立未来是m乘单位过程、时间加速m^α。给定无限划分，其块频率已是当前状态的Borel函数；未来核只依赖这些频率及当前标签分组，不依赖区间位置。塔式遂给划分过程的Markov性；排序后同理给质量过程Markov性。dust单点吸收，不重新聚集。α≠0时有限观察本身一般不是Markov链，因为它未必知道块的真实质量；一致性仍是同一过程的路径限制，不是错误地宣称一族质量未知的有限Markov生成矩阵。

## 5. 可计算的质量生成关系

<a id="selfsim-generator"></a>

\[ \begin{aligned}
F_q(x)&=\sum_i x_i^{q+1},\qquad q>0,\quad q+\alpha\ge0,\\
\mathcal A_\alpha F_q(x)
&=-\left[c(q+1)+\int(1-\sum_j s_j^{q+1})\nu(ds)\right]
\sum_i x_i^{q+1+\alpha}.
\end{aligned} \]

这是期望半群在0的逐点右导数。先从质量1开始。短时间没有分裂时侵蚀给导数−c(q+1)；第一分裂概率λt+o(t)，条件子向量贡献趋Σsⱼ^(q+1)，后续任意多小块由非负和≤1受控，故导数为方括号的负数。还需交换无穷初始块与导数：记单位过程f(t)=E Fq(X(t))，初始正质量的率局部有界给|f(t)−1|≤Ct在小t成立，而f∈[0,1]使调整C后对全部t成立。

由分枝式，初始x的期望是Σxᵢ^(q+1)f(xᵢ^αt)。其差商由CΣxᵢ^(q+1+α)支配；q+α≥0使该和≤Σxᵢ≤1，故受控收敛证明公式。零质量项直接置0，不计算0的负次幂。若删去这个可积条件，该求和可能无穷，本页不宣称导数有限。

## 6. 正指数守恒与负指数shattering

<a id="selfsim-conservation"></a>

ν几乎处处Σsᵢ=1且c=0时，α≥0保证全部时间保质量。沿一个典型均匀标签，每次分裂按sᵢ大小偏置选择子块，从不选到dust；连续操作等待是iid Exp(λ)，其和几乎必然无穷。物理等待m⁻ᵅE≥E，故有限时间不能无限分裂而丧失标签。由交换性/paintbox，ES(t)=P(典型标签仍在正块)=1；有理时间加单调性给全时守恒。λ=0平凡同理。

\[ \nu=\delta_{(1/2,1/2,0,\ldots)},\quad c=0,\quad\alpha<0:
\qquad
\zeta_{\rm tag}=\sum_{k\ge0}2^{\alpha k}E_k<\infty\quad\text{a.s.} \]

每次二等分都守质量，但负指数加速小块，典型标签在有限时间经历无穷分裂。还能证明全树有限时间变dust：令Mₖ为第k代2ᵏ个独立Exp(1)变量的最大值，EMₖ≤1+k log2，由尾积分P(Mₖ>u)≤min(1,2ᵏe⁻ᵘ)得到。Z=Σ2^{αk}Mₖ具有有限期望，故几乎必然有限，支配所有谱系的寿命。到Z以后没有正块，S=0。这是守恒分裂测度仍可产生整体损失的完整反例。

## 7. 三个条件彼此不能替代

<a id="selfsim-counterexamples"></a>

ν为(1/3,1/3,0,…)的单位点质量，α=0、c=0，给交换、自相似但非守恒的过程。反过来，用二等分、每块绝对质量x的率r(x)=1+x，得到交换且保质量的独立块过程：率≤2，典型标签不会有限时间无限分裂。但它不自相似，因为自相似将要求r(x)=r(1)x^α，而在x=1/2、1/4分别要求.75和.625为同一幂律的一次、二次幂，.75²≠.625。

若专门剥离标签1而保持所有其他标签同块，频率总质量一直为1，却不是交换律；三标签模式{1}|{2,3}在换1、2后不同。频率守恒不会弥补标签偏好。无限ν的自相似扩展、一般守恒充要判据与特殊CRT碎裂指数均未由本页推出。返回[正文](../chapters/56-fragmentation-hierarchies.md#fragment-three-conditions)。
