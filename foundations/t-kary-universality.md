# T-KARY-UNIVERSALITY：孩子数、连续度数与抽样质量

本专题回到[第58章](../chapters/58-multifurcation.md)。只使用已发表的Brownian CRT与条件GW极限；不含任何未发表研究。

## 1. 固定k的精确概率模型

<a id="ku-model"></a>

固定整数\(k\ge2\)，取\(p_0=(k-1)/k,p_k=1/k\)，其余为零。于是\(E\xi=1\)，\(\operatorname{Var}\xi=k-1>0\)。一棵有\(I\)个内部节点的完整k叉平面树有\(kI\)条边、\(n=kI+1\)个节点和\((k-1)I+1\)片叶。由逐节点独立构造，它的无条件概率为\(p_k^I p_0^{(k-1)I+1}\)，只依赖I。因此给定规模n，树在全部这样的有根平面树上均匀。

可行规模恰为\(n=1+kI\)。必要性来自计数；充分性可用把一片叶替换为k片叶的操作逐次构造。每棵有限树的概率为正。增量\(\xi-1\)的支持为\(\{-1,k-1\}\)，最大格点跨度为k；这与总规模条件并非可以忽略的周期约定。

## 2. 空间极限及其真正的输入

<a id="ku-limit"></a>

\[ \left(T_n,\frac{\sqrt{k-1}}{2\sqrt n}d,\rho,\frac1n\sum_{v\in T_n}\delta_v\right)\ \Rightarrow\ (\mathcal T_e,d_e,\rho_e,\mu_e),\qquad n\in1+k\mathbb N,\quad n\to\infty. \]

证明：第55章的条件GW带根GHP定理要求临界、非退化、有限正方差的固定后代律，并沿可行规模取极限。上一节逐项验证了这些条件，代入方差即得公式。这里使用的e为第54章长度1的标准Brownian excursion，没有换成2e。该应用不重新证明第53章的条件桥与高度控制；它们仍是明确的上游证明责任，而不是由普通Donsker替代。经典理论的原始来源包括Aldous《The Continuum Random Tree III》(1993)，[公开原文](https://www.stat.berkeley.edu/~aldous/Papers/CRT3.pdf)。

## 3. 为什么有限样本足以排除四个方向

<a id="ku-degrees"></a>

第54章有限约化树定理说：根与任意有限个独立\(\mu_e\)样本张成的树几乎必然为二叉形状，且\(\mu_e\)无原子、满支撑并集中于叶。取可数无限样本；满支撑与可数基保证样本稠密，所有有限约化树二叉在一个共同概率1事件成立。若整树某点b的补集有至少四个连通分支，每个分支都是非空开集，因而各含一个样本。四点张成的树在b有至少四个方向，和某棵有限约化树二叉矛盾。因此所有分枝点的无向度数为3。

根不是分枝点，指向根的一个方向应从无向度数中扣除。所以这里“二叉”意指非根分枝点有两个向后的子方向，不是说它的无向度数等于2。离散k叉模型的极限对每个固定k都满足这个结论。GHP收敛不保持逐节点度数：长度趋零的一串分叉可以被识别；没有持续正长度的方向不必留在极限。

## 4. 一个明确抽样的三分质量律

<a id="ku-mass"></a>

取根0与两个独立质量样本1、2，令b为三条连接路径的交点。记移去b后三个方向的质量为\(M_0,M_1,M_2\)，按这三个标签定向。则

\[ (M_0,M_1,M_2)\sim\operatorname{Dirichlet}(1/2,1/2,1/2). \]

证明从有限约化形状出发。含标签0和n个样本的无根二叉形状在其标签形状上均匀；第54章的密度对每个形状相同。增加一个标签的逆操作，是从所有\(2n-1\)条边均匀选边、插入一个分叉并添加新叶；删去该标签和抑制二度点唯一恢复原树，所以该条件核正确。初始三方向各有一条边。若某方向已有a片标签叶，则该方向含\(2a-1\)条边；添叶后增加两条边。故三方向的边数是初值\((1,1,1)\)、每次增加2的Pólya urn。

除以2后是Dirichlet初参数均为\(1/2\)的标准urn。第44章的完整预测表示与条件强律给出三个计数比例的Dirichlet极限。另一方面，在实际CRT上，条件于树及前两个样本，随后样本仍独立服从\(\mu_e\)；三个分支是开集，b的质量为零。因此条件强律把相同计数比例识别为\(M_i\)。两种极限唯一，结论成立。所用三分支由根和两个典型叶选出；没有在“全部分枝点”上假设一份均匀分布，也没有声称所有抽样机制都给同一Dirichlet律。
