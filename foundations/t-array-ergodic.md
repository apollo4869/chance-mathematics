# T-ARRAY-ERGODIC：分离性、极端律与可观察的全局信息

在非空标准Borel数组记录空间上，分别考虑共同编号群或行列分别编号群。允许有限阶关系与顶点标记。交换群均只含有限置换，因而可数。这里完整证明分离性、极端交换律、不变信息与条件分解的关系；不是借用尚未建立的任意群遍历分解。返回[第46章](../chapters/46-arrays.md#arrays-dissociation)。

## 1. 有限群平均与真正的不变信息

<a id="array-ergodic-average"></a>

令Gₙ为前n个顶点的全部置换；分别交换时取前n行与前n列置换的直积。P为交换律，𝓘ₙ为模P的Gₙ不变事件σ代数，𝓘为全体有限置换下的不变信息。有限平均Aₙf属于𝓘ₙ，且在任意𝓘ₙ事件上与f积分相同，所以等于条件期望。

\[ A_nf=|G_n|^{-1}\sum_{\pi\in G_n}f\circ T_\pi=\mathbb E[f\mid\mathcal I_n],\qquad A_nf\longrightarrow\mathbb E[f\mid\mathcal I]\quad\text{a.s. and in }L^2\ (f\text{ bounded}). \]

σ代数递减，第15章反向鞅给该收敛。其交确为𝓘的完备版本：每个群元最终属于Gₙ；若事件只模零不变，把其指标的Aₙ平均取limsup，便得到逐点对每个固定群元不变、且几乎处处仍等于该指标的版本。所有群元可数，因此共同零集合法。

## 2. 无相交指标为何在条件下独立

<a id="array-ergodic-collision"></a>

先取有界柱函数f,g，分别只使用互不交的k、l个顶点，以下取n大到包含它们的全部指标。Aₙf Aₙg是独立抽取两份无放回有序顶点表后的平均；Aₙ(fg)则要求两表合起来也无重复。前一种抽样的碰撞概率至多kl/n，且条件于没有碰撞，其分布恰为后一种。于是逐个固定数组有下界中的误差控制。

\[ |A_n(fg)-A_nf\,A_ng|\le\frac{2kl}{n}\|f\|_\infty\|g\|_\infty,\qquad \mathbb E[fg\mid\mathcal I]=\mathbb E[f\mid\mathcal I]\mathbb E[g\mid\mathcal I]. \]

第二式由反向鞅极限取得，不是假定原f,g已经独立。分别交换时，若两块既无公共行也无公共列，碰撞概率界改为“行数乘积加列数乘积”除以n，同一条件化抽样证明成立。若只行不交而共用列，这个论证不成立，且列潜变量确实能保留依赖。有限多个块逐次避开已选指标，可得任意有限块族的条件乘积身份。

定义dissociation，或分离性，为这些不相交块的无条件独立。联合交换按互不交顶点集合，分别交换按行列两类集合都互不交。由上式，𝓘平凡立即蕴含分离性；无限块资料的版本由有限柱集和单调类得到。

## 3. 分离性、极端性与平凡不变信息的等价

<a id="array-ergodic-extreme"></a>

反过来若P分离，取A∈𝓘，以0≤g≤1的有限柱函数逼近\(\mathbf1_A\)于L¹，误差ε。找有限置换τ把g涉及的指标移到一份不相交拷贝；分别交换时两类指标都移开。由于A不变，g∘τ也以同样误差逼近\(\mathbf1_A\)，而分离性给E[g(g∘τ)]=(Eg)²。两个近似误差与均值误差合计，得|P(A)−P(A)²|≤4ε。ε任意，所以𝓘平凡。

若𝓘有非平凡A，按A与补集条件化得到两份不同交换律，P不是交换概率凸集的极端点。反向若P=tP₁+(1−t)P₂，0<t<1，Radon–Nikodym给h=dP₁/dP≤1/t。P与P₁都交换，换元测试给h∘τ=h模P，对每个有限τ成立。可数群共同化后h属于𝓘；𝓘平凡使h恒为1，P₁=P，P₂亦同。因此三个性质等价。

## 4. 把条件期望真正析取成极端概率

<a id="array-ergodic-kernel"></a>

记录空间标准Borel，所以其L²可分。取可数生成代数的指标，条件期望hₘ=E[\(\mathbf1_{A_m}\)|𝓘]的有理线性包在L²(𝓘)稠密：先在全部L²逼近一个𝓘函数，再取条件投影。逐次几乎处处子列说明𝓘模零由(hₘ)生成。每个hₘ可取原记录Borel σ代数中的版本：以简单函数逼近完备可测版本，将其可数水平集分别换成模零相同的Borel集，再取极限，全部m只增加一个共同零集。故Z=(hₘ)为一个Borel值编码，σ(Z)与𝓘完备化相同。

第10章给\(P_z\)=Law(X|Z=z)。上一节的条件独立身份与交换积分身份，在可数柱代数、可数指标块和可数置换上统一零集，证明\(P_z\)几乎处处同时交换且分离。好z集合Borel，因为这些只是可数个核评价等式；坏点可换为固定常数阵的律。因而它们是一个真正的Borel极端概率核，且P=∫\(P_z\) Law(Z)(dz)。

令Θ=\(P_Z\)。概率参数空间P(记录空间)的标准Borel性由43章证明；Θ(Aₘ)=hₘ，所以𝓘=σ(Θ)模零。这里可观察的是这份随机极端律，不是任意表示公式中U₀的名字或全部内容。U₀可以附带输出根本未使用的独立随机数。

## 5. 混合唯一，但函数不唯一

<a id="array-ergodic-unique"></a>

交换且分离的概率构成P(记录空间)的Borel子集：交换与分离都可用可数柱代数的等式刻画。若P还有另一份在这个集合上的混合π，对每份极端μ，有限群平均Aₙ\(\mathbf1_{A_m}\)几乎处处趋μ(Aₘ)。对π积分，并对m取共同零集，便知同一条观测记录的这些极限恰给被混合的μ的全部决定性评价。其分布只由P决定，故π唯一。

表示中固定U₀以后，不相交块使用互不交的独立输入，故其条件律分离。若P本来极端，这些条件律几乎处处都等于P：否则某个可数决定性评价的水平集把混合分成两份不同交换律，矛盾。因此可固定一个好U₀值，得到不需要随机全局输入的表示。反向，无全局输入的表示显然给分离性。于是“全局输入可以省略”恰对应分离/极端，而不意味着顶点、成对关系都独立。
