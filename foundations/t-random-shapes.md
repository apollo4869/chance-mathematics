# T-RANDOM-SHAPES：测度、路径和随机覆盖的闭集

返回[第51章](../chapters/51-random-closed-sets.md#sets-examples)。E采用T-FELL；空间覆盖实例专取欧氏空间。仅用48–49的可测测度/标记Poisson构造及本章闭集拓扑，不依赖52随机树。

## 1. 支撑可测，却未必随测度连续

<a id="shapes-support"></a>

Radon μ的支撑定义为每个开邻域都有正质量的点。其补为可数基中所有零质量开集的并，故补的μ质量0。对开U有\(\operatorname{supp}\mu\cap U\ne\varnothing\Longleftrightarrow\mu(U)>0\)：左到右用支撑定义，右到左用可数零开集覆盖的逆否。因此μ↦supp μ是从49评价Borel域到Effros域的可测映射；零测度支撑为空。

即使概率总质量不变，也没有一般连续性：\(\mu_n=(1-1/n)\delta_0+(1/n)\delta_1\Rightarrow\delta_0\)（n≥2），但每个支撑都是{0,1}，不趋{0}。它们的1处质量消失，存在性却不消失。反之整数局部有限点测度上的支撑映射vague→Fell连续：若Nₙ vague→N，N支撑点x的任意邻域可选非负紧支撑测试f，Nf>0，故最终Nₙ也命中该邻域；若紧K避让supp N，可用截断χ≥1于K、支撑在与supp N不交的相对紧邻域，Nₙχ→0，整数性使最终Nₙ(K)=0。两项Fell子基本条件均满足。这正是不能把整数点测度与任意小质量混同的原因。

## 2. 有限时间与无限时间的范围

<a id="shapes-ranges"></a>

连续路径γ:[0,t]→E的像紧。若γₙ在proper度量中一致趋γ，则\(d_H^\rho(\gamma_n[0,t],\gamma[0,t])\le\sup_{s\le t}\rho(\gamma_n(s),\gamma(s))\)。所有像最终留在γ像的一个紧邻域，紧化度量与ρ在其上均匀相容，故范围映射到Fell空间连续。随机连续路径因此有合法随机紧范围，路径弱收敛可经24章映射定理推出有限时段范围收敛。

无限时间必须先取闭包：γ(s)=1/(1+s)的像为(0,1]，不是闭集。闭包范围命中开U恰当路径本身命中U；连续性又使后者等价于某个非负有理时刻落在U。因此闭包范围可测。但映射不连续于局部一致拓扑：γₙ在n以前为0，在[n,n+1]线性升至1，之后保持1。它们局部一致趋零路径，闭范围却一直是[0,1]，不趋{0}。无限观察时域与有限时域是不同的极限操作。

## 3. Poisson与Cox的随机闭点集

<a id="shapes-poisson"></a>

局部有限点测度的支撑闭；它命中紧K恰当N(K)>0。48章PRM给\(T(K)=1-e^{-\mu(K)}\)，可有强度原子与重数。Cox过程则给\(T(K)=1-Ee^{-\Lambda(K)}\)。它不是\(1-e^{-E\Lambda(K)}\)，平均强度不足以识别形状。\(\delta_U\)和2\(\delta_U\)有完全相同支撑及容量，却有不同点测度律；闭集记录合法，但有意忘掉了重数。

## 4. 随机覆盖必须先保证并集闭

<a id="shapes-boolean"></a>

在\(\mathbb R^d\)，令父点与非空紧颗粒G的标记PRM强度为a(dx)Q(dG)，其中aσ有限。紧颗粒空间是Fell空间的Borel子集：紧集恰被某个紧穷竭Kₘ包含，包含事件是避让开补集；再去掉空集即可。因此48章标准Borel标记构造适用。平移作用联合连续：若xₙ→x、Gₙ→G，命中点与上极限点分别减去xₙ后，T-FELL的两项序列判据恰变成Gₙ→G的判据；再加回x即得。(x,G)是否有(x+G)∩K非空是联合Borel。假设对每个紧K，

\[ I_K:=\int a(dx)\int\mathbf1_{\{(x+G)\cap K\ne\varnothing\}}Q(dG)<\infty. \]

命中K的颗粒数有有限期望\(I_K\)，故有限a.s.；对可数紧穷竭统一零集，颗粒族局部有限。于是\(F=\bigcup_i(x_i+G_i)\)闭：每个位置的紧邻域只遇到有限个闭颗粒，在该邻域内部用有限闭并即可检查闭性。开命中是PRM对可测命中标记集的正计数，故F随机闭。无颗粒命中K的概率由Poisson给出，因而

\[ T(K)=1-e^{-I_K}. \]

实线齐次父强度κ、固定颗粒[−r,r]（r≥0）时，对区间[a,b]有I=κ(b−a+2r)，这是可计算覆盖律，不是只画一团随机圆。局部命中积分条件是本构造的充分条件，不宣称必要：无限多重叠颗粒有时也能形成闭并。若删去控制，并集却可能不闭。取父强度在各位置1/n处各放一份单位质量，固定颗粒为{0}；因此每个位置独立出现Poisson(1)个单点。独立Poisson计数使无穷多标签出现a.s.（7章Borel–Cantelli），其并不含0，却以0为聚点。闭包会增加原记录没有的位置；不能把无限并自动叫闭集。
