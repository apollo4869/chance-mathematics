# T-FELLER-BOUNDARIES：可达检验、入口与边界规则

与[第36章](../chapters/36-scale-speed.md#diffusion-access)配套。沿用非退化局部Lipschitz的一维SDE及T-SCALE-SPEED已证的紧区间命中、占用公式。局部强Markov性由第35章全局截断方程的强Markov性在出紧区间以前给出，再用可数穷尽拼合。此处不构造全部正则端点延拓或奇异速度时间变换，二者由第37章接续。

## 1. 有限时退出、Volterra解与Feller检验

<a id="boundary-access"></a>

先验证寿命有限时必趋某一端点，而不是在两个内部点间无限往返。对紧内部a<b及稍大的紧区间，停止SDE的二阶最大估计给从a出发在δ内先到b的概率≤Cδ/(b−a)²，选δ使其小于1/2；反向同样。若离开稍大区间，之前也已跨过所需距离，同一停止估计仍控制。强Markov使每次交替跨越有至少1/2概率花时间δ，因而条件Laplace因子至多q=(1+e⁻δ)/2<1。n次跨越总时长的负指数期望≤qⁿ，故无限次跨越不可能在有限时间积累。

若ζ有限却无端点极限，连续路径要么最终留在一个紧区间（第35章可延长，矛盾），要么在某两个有理内部水平间无限跨越（上段排除）。因此有限寿命必有Xₜ→ℓ或r，按扩展实数的拓扑理解。以后说右端可达，精确指某个x>c下Pₓ(ζ<\(\tau_c\)、ζ<∞、X_ζ−=r)>0；与选取c、x无关，由紧区间命中概率及强Markov连接。

\[ \Sigma_r=\int_c^r m((c,y))p(y)dy,\qquad \Sigma_r(x)=\int_c^x m((c,y))p(y)dy. \]

若S(r)=∞，因m((c,y₀))>0，Σ必为∞。若Σ有限，则S(r)<∞，Tonelli给Σ=∫_cʳ(S(r)−S(y))m(dy)。对c<x<b↑r，紧退出时间\(\tau_c\wedge\tau_b\)递增，其期望由Green核一致有界：y≤x部分在紧集可积；y≥x时\(G_{c,b}\)(x,y)≤S(r)−S(y)。故退出时间极限τ*有限几乎必然。

事件{\(\tau_b<\tau_c\)}随b增大递减，概率趋(S(x)−S(c))/(S(r)−S(c))>0。在其交集上，寿命方向引理或有界尺度鞅的极限使退出值为r而非c，故Σ有限确实给正概率有限时抵达。不会因τ*有有限均值就无依据地指定退出方向。

逆向不能使用期望发散。对λ>0，线性ODE Lv=λv取v(c)=1、v′(c)=0。局部ODE存在唯一，积分式为下式。v保持正且非减：一旦v>0，v′/p=λ∫_cˣv dm≥0，故不能首次跌破1。

\[ v(x)=1+\lambda\int_c^x(S(x)-S(y))v(y)m(dy),\quad v(x)\ge1+\lambda\Sigma_r(x),\quad \frac{v^\prime(x)}{v(x)}\le\lambda p(x)m((c,x)). \]

最后一界给v(x)≤exp(λ\(\Sigma_r\)(x))。因此Σ有限时v在r有有限上界，Σ无穷时v(r−)=∞。对t∧\(\tau_c\wedge\tau_b\)，e⁻λᵗv(Xₜ)的Itô漂移为0，系数在紧集有界，所以真鞅。在\(\tau_b\le T\)且\(\tau_b<\tau_c\)的事件上其停止值至少e⁻λᵀv(b)，由非负性得到正文概率界。若Σ无限，令b↑r再对整数T取并，有限时到r的概率为0。左端对−X作同样证明。

改变参考c只添加有限紧积分及一项有限常数乘尺度尾；若该尺度尾无限，Σ原本已经无限，若有限则不改变可积性。N的参考点变化同理：其有限性先保证速度尾有限，因而加减常数的项有限。可达/不可达的概率定义也给另一份与参考点无关的核验。

## 2. 不可达端点的入口：构造与必要性

<a id="boundary-entrance"></a>

先固定右端\(\Sigma_r\)=∞，在(c,r)运行到c后吸收。入口指从扩展端点r开始、路径在[c,r]的顺序紧化拓扑连续、每个正时刻在到c以前严格小于r、在内部遵守原强Markov规律的过程；不包括永久停在r的平凡扩张。定理：这样的连续即时入口存在且其律唯一，当且仅当\(N_r\)=∫_cʳ(S(y)−S(c))m(dy)<∞。

若N有限，则速度尾有限；若S(r)也有限，Σ≤(S(r)−S(c))m((c,r))有限，矛盾。所以S(r)=∞。对任何a>c，由单边Green公式，所有x≥a满足下面的均值界。\(N_r(a)\)随a↑r趋0，因为被原N的可积尾控制。

\[ E_x\tau_a=\int_a^x(S(y)-S(a))m(dy)+(S(x)-S(a))m((x,r))\le N_r(a):=\int_a^r(S(y)-S(a))m(dy)\downarrow0. \]

在同一Brownian空间从xₙ↑r解SDE，并在c停止。相同系数的路径顺序由第35章局部路径唯一性给出：两条连续路径交换次序必须先相遇，停后重启的唯一性使它们随后相同；低路径到c后留在c，不会反过来穿越高路径。于是Xⁿ逐时刻单调增加。还不能直接假设极限是有限连续路径。

\[ \sup_nP\!\left(\sup_{\delta\le t\le T}X_t^n\ge b\right)\le\frac{2N_r(a)}{\delta}+\frac{S(a)-S(c)}{S(b)-S(c)},\qquad c<a<b<r,\quad 0<\delta<T. \]

证明这份界：从a以上的初值先等到a，Markov不等式使\(\tau_a>\delta/2\)概率至多2\(N_r(a)\)/δ；已到a后的路径若再到b，强Markov与命中公式给第二项。从a以下的初值由单调性被从a出发的路径控制。先a↑r使第一项小，再b↑r使第二项小。因此正时间路径不会以正概率堆在r。

在[δ,T]上限制于[c,b]时，停止SDE系数有统一界，连续鞅四阶上界给E|Xₜ−Xₛ|⁴≤C|t−s|²。若δ时已越b，以前一概率界先去掉该事件；对\(\mathcal F_\delta\)事件分片后作相同停止估计。故这些过程在C([δ,T])紧。各有理时刻的单调极限有限，任一连续路径弱极限均有同一有理坐标规律，因此有唯一连续版本Z。这里的重建只用可数有理坐标：在每个有理紧窗口检查有理网格振荡的可数一致连续条件，条件成立时以有理值唯一连续延拓。该条件在连续路径弱极限的坐标律下概率1，故原空间的有理极限也以概率1满足，可测重建Z。

这里还需把律上的连续版本接回共同空间。Z的有理坐标是原空间的单调极限；紧性使任一(Xⁿ,Z)的子列极限集中在对角（各有理坐标差依概率趋0），所以||Xⁿ−Z||_[δ,T]依概率趋0。取可求和子列得到几乎必然一致收敛，再由单调性与Dini将整列升级为该紧区间上的一致收敛。对有理δ、整数T取共同零集，Z连续适应于全部正时间。

从δ起、直到离开任一内部紧区间，局部稳定估计与积分等距使Z满足原SDE；初值\(X^n_\delta\)→\(Z_\delta\)有限，先限制初值于有界\(\mathcal F_\delta\)事件即可。Z到c时所有较低Xⁿ已在c，故以后也留在c。对a>c，选a′>a，单调性给从r的首次到a时间至少从a′到a的时间，后者严格正几乎必然。因此Z在时间0从顺序拓扑连续地离开r；还要传递首次到a的时间：\(\tau_a^{x_n}\)随n递增，均值被\(N_r(a)\)控制，极限L有限且由从a′出发的时间下界而严格正。正时间紧窗上的一致收敛与Xⁿ在相应命中时刻等于a给\(Z_L\)=a；路径排序又给\(\tau_a^{x_n}\)≤\(\tau_a^Z\)，故L=\(\tau_a^Z\)。MCT保留均值界，随a↑r趋0。在c以后可用第35章从内部点c重启原方程，得到整个I上的入口直到另一端的寿命。强Markov性在正时刻由内部方程及唯一性给出，入口过程实际构造完成。

任何另一入口过程，首次到a的时刻随a↑r趋0，之后路径规律为从a出发的唯一内部规律。对正时间连续路径的有界连续圆柱函数用强Markov和DCT，其期望必须为\(\lim_{a\uparrow r}E_aF\)：上面正时间窗的共同紧性给圆柱读数的一致连续控制，因而τ_a→0产生的时间移位误差依概率趋0，随后对有界F用DCT。因此入口律唯一，不需要额外猜测边界分布。

必要性：令u(x)=\(E_x\)[e⁻λ\(\tau_c\);\(\tau_c<\infty\)]。它严格正、不超过1，并由相同噪声路径排序而非增。局部C²性可实际证明：在任意紧(α,β)解Lu=λu且边界取期望函数的端值；线性ODE的边值解存在唯一（零端值解由最大值原理为0），停止Itô给相同的折扣退出表示，强Markov使期望函数满足该表示，因此二者相同。

若有入口，强Markov在首次到a处给u(r)=u(a)E_r e⁻λ\(\tau_a\)。入口连续且即时进入使\(\tau_a\)↓0，故d=lim_{a↑r}u(a)=u(r)>0。u(r)>0是因为从任一内部位置到c有正概率，在某个正时间条件化即可。令w=u′/p≤0，则w′=λum′。若S(r)<∞，d>0迫使速度尾有限（否则w最终为正），进而Σ有限，矛盾。因此S(r)=∞。

\[ w(r-)=0,\quad -w(x)=\lambda\int_x^r u(y)m(dy),\quad 1-d=\lambda\int_c^r(S(y)-S(c))u(y)m(dy)\ge\lambda dN_r. \]

w单调增加，其极限若严格负，u会随无穷尺度下降到负数，故只能为0。Tonelli给最后一式，说明N有限。必要性至此闭合。左端镜像。对可达正则/出口端点的全部连续延拓与入口等价定理不由本段自动推出，仍按蓝图由37承担；本段已完整证明不可达端点的入口判据。

## 3. 四类实例及爆炸反例的计算

<a id="boundary-examples"></a>

Brownian在有限端点：p=1、m′=2，Σ与N为有限二次积分，故正则。平方根扩散dZ=2√Z dW在0：p=1、m′=1/(2x)，Σ₀=∫₀ᶜx m′dx=c/2有限，N₀=∫₀ᶜ(c−x)m′dx=∞，为出口。系数延为2√|x|后满足35的一维模条件，初值0仅有零解，故该SDE确不能从0进入正半轴。

三维半径R=|B|，B从0出发。每个正δ时Bδ≠0几乎必然；第33章已用调和函数1/|x|证明从非零点不碰原点，条件于Bδ并对有理δ取并，得Rₜ>0对全部t>0。同时E(1/Rₛ)=C/√s，因三维Gaussian径向密度在0处为常数倍r²，积分有限，所以E∫₀ᵀRₛ⁻¹ds<∞。

在δ以后停止离原点的紧环域，对|x|用Itô得dR=(B/R)·dB+R⁻¹dt。令δ↓0，漂移由上式Tonelli/DCT通过，鞅由L²等距通过。β=∫₀ᵗ(Bₛ/Rₛ)·dBₛ（在R=0处置0）括号为t，由Lévy刻画为Brownian。故从0的入口满足正时间方程。p=x⁻²、S=−1/x、m′=2x²，Σ₀=∞，N₀=∫₀ᶜ(1/x−1/c)2x²dx=c²/3有限，核对入口类别。

零漂移几何Brownian的p=1、m′=2/x²使Σ₀=∫₀ᶜ2/x dx=∞、N₀=∞，为自然；显式正解exp(Wₜ−t/2)验证有限时不碰0，从0的全局Lipschitz方程唯有零解。更一般Bessel漂移(δ−1)/(2x)、σ=1有\(p=x^{1-\delta}\)、\(m^\prime=2x^{\delta-1}\)，幂积分给δ≤0为出口、0<δ<2正则、δ≥2入口。本表指0端，奇异边界的所有延拓不因此自动构造。

正文两份x²漂移例子取不影响积分判别的正常数归一化。σ=x时p=e⁻²ˣ、m′=2e²ˣ/x²，S(∞)−S(x)=e⁻²ˣ/2，所以Σ∞尾积分为∫x⁻²dx有限，命中r=∞先于任意较小内部c有正概率。σ=x²时p=e²ᐟˣ，∞尺度为∞；在0，∫₀ᶜe²ᐟˣdx=∞（换u=1/x），尺度为−∞。两端不可达，因此最大解终生留在(0,∞)。系数在正半轴局部Lipschitz；没有用超线性系数的全局增长定理来假定非爆炸。

## 4. 相同内部算子的不同边界过程

<a id="boundary-rules"></a>

令Y=x+B、x≥0，τ₀为首达0。吸收过程\(A_t=Y_{t\wedge\tau_0}\)，杀死过程在τ₀跳入独立墓地状态；二者在(0,∞)的生成元都是½f″，但在保留端点的模型中A从0恒为0。反射过程R=|x+B|有折叠Gaussian核，积分为1；对任意路径有限维读数，Brownian符号对称使给定Yₛ的未来绝对值规律只依赖|Yₛ|。

R的停止时刻也是Y的停止时刻，因为R的自然滤过包含在Y的滤过内。Brownian强Markov和整条未来增量的符号对称给R强Markov，不只确定时刻Markov。它从0立即具有半正态分布，区别于吸收。吸收与杀死也由停止Brownian强Markov性得到强Markov过程。

对f∈C²([0,∞))、f、f″在无穷远趋0且f′(0)=0，F(z)=f(|z|)为C²；固定长度Taylor差商用f、f″的界还给f′有界，所以Itô鞅项在有限时间真可积，取期望给Pₜ^{ref}f−f=½∫₀ᵗPₛ^{ref}f″ds。折叠Gaussian保持C₀并强连续：|Rₜ−x|≤|Bₜ|，C₀函数一致连续，先以小增量控制再用Brownian尾界。因此上式在C₀范数除t取极限，Af=½f″，Neumann条件实际进入定义域。

杀死半群作用于C₀((0,∞))，连续测试必须在0趋0，给Dirichlet条件；例如内部紧支撑C²函数属于生成元域。吸收半群作用于C₀([0,∞))，Af(0)=0；对同样C²且f″(0)=0的函数，停止Itô与强连续性给内部½f″及端点0。这里列出可验证的定义域子类和必要边界要求，不冒充三个生成元完整最大定义域的分类。
