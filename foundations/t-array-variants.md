# T-ARRAY-VARIANTS：方向、对角与分别交换的完整构造

目标空间E非空标准Borel。联合交换已经由[T-ARRAYS](t-arrays.md)建立；这里实际处理有向与对角公式、分别交换二维数组，并给有限多类型的高阶推广。返回[第46章](../chapters/46-arrays.md#arrays-separate-proof)。

## 1. 两个群作用与两种成对噪声

<a id="array-variants-groups"></a>

\[ (X_{ij})\stackrel d=(X_{\pi(i)\pi(j)})\quad\text{joint};\qquad (X_{ij})\stackrel d=(X_{\pi(i)\sigma(j)})\quad\text{separate}. \]

π、σ均为N的任意有限置换。分别交换蕴含联合交换，反向不成立：确定的单位矩阵对共同重排不变，但只交换两行就改变了它。分别交换的行、列是两种对象；下标(i,i)没有共同顶点的含义。联合交换允许Xij与Xji有额外依赖，因为它们描述同一对象对的两个方向。

T-ARRAYS的带标记有序解码给Borel F、D及独立均匀输入，使联合交换矩阵的律如下。每个无序对只取一个W，不能把反向边的W改成另一个独立数。D可以同时输出额外的标准Borel顶点标记。

\[ X_{ij}=F(U_0,U_i,U_j,W_{\{i,j\}})\quad(i\ne j),\qquad X_{ii}=D(U_0,U_i). \]

这不要求F对两个顶点输入对称；原阵对称时可以选择对称F。一般有向情形，T-ARRAYS将两个方向存成同一个成对标签，再以连续顶点标记确定解码顺序，因而确实构造出共享W的两条方向，而不只是分别匹配边缘律。

## 2. 给两个对象群体一个共同的编号空间

<a id="array-variants-color"></a>

现在X分别交换。独立取iid颜色Cₐ∈{0,1}，各半；两种颜色均出现无穷多次几乎必然，例如直接用独立强律。r(a)为颜色0顶点在自然枚举中的出现次序，c(a)为颜色1的次序。在共同编号空间定义有向关系H：仅当Cₐ=0、\(C_b\)=1时取\(X_{r(a),c(b)}\)，其余取新符号†，并保留顶点颜色。

E与{†}的不交并仍标准Borel。给定整条颜色列，任何有限顶点重排只诱导有限个行编号与列编号的分别重排；X的分别交换性保证对应联合律不变。颜色本身iid，所以(H,C)联合交换。依T-ARRAYS，存在独立均匀U₀、Tₐ、\(W_{\{a,b\}}\)及Borel h,d，使Hₐb=h(U₀,Tₐ,\(T_b\),\(W_{\{a,b\}}\))、Cₐ=d(U₀,Tₐ)。仅a≠b的关系会被后面抽取；对角恒为†。

条件于U₀=z，颜色iid，成功率p(z)=∫1{d(z,t)=0}dt。条件强律给颜色0频率趋p(z)，而原构造中的频率恒趋1/2。二者同律，故p(z)=1/2几乎处处。这保证按类型抽取不会无意中重新加权全局环境；不是凭一句“每种颜色各半”就跳过条件参数。

## 3. 抽取颜色之后，哪些随机源仍然独立

<a id="array-variants-thinning"></a>

\[ Q_z^c(dt)=\frac{\mathbf1_{\{d(z,t)=c\}}\,dt}{p_c(z)},\qquad p_c(z)=\int_0^1\mathbf1_{\{d(z,t)=c\}}dt\quad(c=0,1). \]

在\(p_c\)=0处用固定概率补全；这是定义在全部z上的Borel核，且好z上两分母均为1/2。第10章统一核随机化给\(a_c(z,u)\)生成\(Q_z^c\)。下面证明抽出的两类T并非只各自iid，而且两族条件独立。

固定好z，可反过来生成一列T：先取iid类型序列，每类概率\(p_c(z)\)；独立地为两类各取iid \(Q_z^c\)序列，再按类型出现顺序交织。任意有限类型字与对应T值的概率，等于各位置\(p_c(z)Q_z^c(dt)\)的乘积；求和类型便得到iid Lebesgue T。这个有限乘积核身份和可数乘积唯一性证明交织构造与原T序列同律。重新抽开时显然正是独立生成的两族，因此结论成立。

成对W原本独立于所有T及U₀，颜色抽取只依赖这些顶点资料。给定类型与顶点资料，任意有限组不同的“第i个0类—第j个1类”对应不同无序顶点对，所以其W仍是独立均匀数，并独立于抽出的T。这用有限条件乘积直接验证，不能把任意依赖边值的抽样也当作合法。

## 4. 完成分别交换表示，包括全部矩阵位置

<a id="array-variants-separate"></a>

\[ F(z,u,v,w)=h(z,a_0(z,u),a_1(z,v),w),\qquad (X_{ij})\stackrel d=(F(U_0,U_i,V_j,W_{ij})). \]

遇†时把F改为固定x₀∈E；好参数下交叉类型关系原本取E值，故修改只在总乘积测度零集上，所有可数矩阵格可共同修复。U₀、全体Uᵢ、Vⱼ、Wᵢⱼ相互独立均匀。原H构造中按类型重新抽出的关系就是原X；上一节证明表示端重新抽出的潜变量恰有公式所用的条件独立律。因此不是只验证公式给出的阵可交换，而是恢复任意原X的全部联合律。

反向由独立输入在行、列有限置换下仍同律直接成立。这里Wᵢⱼ与Wⱼᵢ是独立数，因为行i和列j属于不同群体；“i=j”也只是一格普通交叉关系。这与联合交换公式中的共享无序对噪声及真正对角D不同。

## 5. 有限多类型及高阶分别交换，不省略共享子集

<a id="array-variants-higher"></a>

固定d种对象，分别有N编号，给按各类独立置换不变的d元关系数组。独立为共同顶点取iid类型1,…,d，各概率\(p_c\)>0；仅当有序d元组的第c顶点属于类型c时，存原关系相应出现次序的值，否则取†。保留类型为单点标记。给定类型，有限共同重排诱导各类有限重排，所以该带标记有序关系联合交换。T-ARRAYS的有限阶有序版本于是适用。

在该表示中，类型只依赖U₀与单点噪声；原类型频率强律和表示中的条件强律逐类比较，给\(p_c(U_0)\)=\(p_c\)几乎处处。用上一节的有限乘积交织证明，同时得到d个相互条件独立的单点噪声池，分别服从相应\(Q_z^c\)。每个大小至少2的子集噪声独立于这些类型选择；不同类型化部分指标集合对应不同的无序顶点子集，因此抽取后仍是相互独立的均匀族。

\[ X_{i_1,\ldots,i_d}=F\left(U_\varnothing,\big(U^A_{(i_c)_{c\in A}}\big)_{\varnothing\ne A\subseteq[d]}\right). \]

单点输入先通过可测Q随机化，其他子集输入保持原均匀数；这给Borel F。有限个元组同时抽取时，映射在它们全部部分指标集合上保持相等与不等：共享哪一类对象子集，才共享哪一个U。逐个有限乘积验证、再用柱集唯一性得到全族律；反向由每类指标置换保持所有独立子集输入的律。此为任意固定有限d的分别交换表示，不含无限种类型或非标准Borel推广。

## 6. 数组的置换与数组的正交旋转不可混同

<a id="array-variants-rotations"></a>

这些定理处理重新编号，不处理任意线性组合。iid Rademacher矩阵分别交换，但两个行坐标正交混合后出现0与±√2，所以不是分别旋转不变。反之Xᵢⱼ=ZᵢVⱼ，Z与V是独立的iid标准正态列，对任意有限行正交变换与有限列正交变换都保律：正交变换分别保持Z和V的独立正态律。

这个矩阵的单格二阶矩为1、四阶矩为9，故并非独立标准Gaussian矩阵；每个2×2行列式还恒为0。若额外假定所有格本来iid，再用第45章两坐标旋转的特征函数方程，才迫出共同中心Gaussian格律。一般分别旋转数组的完整分类没有由此证明，继续登记为46的开放理论责任；不能把Aldous–Hoover置换表示冒充该分类。
