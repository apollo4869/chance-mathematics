# T-PUBLIC-KARY-GROWTH：公开选边模型与持久节点质量

回到[第58章](../chapters/58-multifurcation.md)。本专题重建Haas–Stephenson模型的有限构造与urn结论；整树缩放定理的本书证明边界在最后明确列出。

## 1. 每一步究竟做什么

<a id="kg-rule"></a>

固定\(k\ge2\)。\(G_0\)是一条根边。给定\(G_n\)，从其全部边均匀选择一条，插入新顶点把它分成两条，再从新顶点接出\(k-1\)条新边。每条新组合边均取长度1；所谓分边不是保留旧实数边长的等距嵌入。平面次序可用一套固定插入规则保存，下面的无向计数不依赖这种选择。选择核是有限集合上的可测核，独立均匀变量序列给出全部无限步骤。

\[ |E(G_n)|=kn+1,\qquad |\mathrm{Leaves}(G_n)|=(k-1)n+1,\qquad |\mathrm{Internal}(G_n)|=n. \]

归纳证明：每一步边数增加k，叶数增加k−1，内部节点增加1。根端点不计入叶。k=2是Rémy式二叉边增长；k≥3时一次出生一批叶，出生标签不是独立质量抽样的标签。删除最新的一批并压缩新顶点可恢复前一步，但这仅是出生次序一致性，不能替代任意均匀删叶一致性。

## 2. 首个分枝点的全部方向

<a id="kg-urn"></a>

固定第一次插入的顶点v。移去它后有\(k+1\)个方向，编号\(0,\ldots,k\)，0指向根。在\(G_1\)每个方向各有一条边。令\(N_i(n)\)为步骤2至n在方向i内进行的操作次数；于是\(E_i(n)=1+kN_i(n)\)，\(\sum_iN_i(n)=n-1\)。v旁边的边也始终归其原方向，之后分边不使方向混合。

\[ P(\text{next direction}=i\mid G_n)=\frac{1+kN_i(n)}{kn+1}. \]

这是初始权重均为1、强化k的urn。对任意长度m的方向词，若各方向出现\(m_i\)次，其概率恰为

\[ \frac{\prod_{i=0}^{k}\prod_{j=0}^{m_i-1}(1+kj)}{\prod_{j=0}^{m-1}(k+1+kj)}
=\frac{\Gamma((k+1)/k)}{\Gamma((k+1)/k+m)}
\prod_{i=0}^{k}\frac{\Gamma(1/k+m_i)}{\Gamma(1/k)}. \]

右式是Dirichlet\((1/k,\ldots,1/k)\)混合iid方向词的积分，利用第44章的Dirichlet积分即可验证。有限维唯一性与条件强律给出同一原始增长概率空间上的几乎必然极限

\[ \frac{N_i(n)}n\longrightarrow D_i,\qquad (D_0,\ldots,D_k)\sim\operatorname{Dirichlet}(\underbrace{1/k,\ldots,1/k}_{k+1}). \]

## 3. 叶质量、条件结构与不允许的外推

<a id="kg-leaves"></a>

方向\(i\ge1\)的叶数为\(1+(k-1)N_i(n)\)，根方向为\((k-1)N_0(n)\)。除以\((k-1)n+1\)都趋于\(D_i\)。没有把边数与叶数在有限n时等同，而是分别计算后识别极限。给定各方向被选的完整序列，每次在所选方向内部仍均匀选边；用独立的内部随机数实现，可得方向间内部演化的条件乘积核。

上述Dirichlet结论是持久离散节点的经验叶质量定理。它本身没有证明树直径的尺度，没有证明GHP紧性，也没有把这个节点识别为某个连续极限中的指定节点。后面三个结论不能由一次urn计算偷渡。Haas–Stephenson公开定理证明了整体增长树的不同连续极限；这里的有限证明只是该模型中可独立核算的一部分。

## 4. 公开定理及本书尚缺的证明

<a id="kg-public"></a>

[Haas–Stephenson, Ann. IHP 51 (2015), 1314–1341](https://archive.numdam.org/articles/10.1214/14-AIHP622/)，[公开全文](https://www.math.univ-paris13.fr/~haas/AIHPB2015514.pdf)，定理1.1证明：单位边长的\(n^{-1/k}G_n\)连同均匀叶测度，在其自然增长耦合下依概率GHP收敛到一个k叉自相似碎裂树。这里n是插入的内部节点数，和条件GW的总节点数不同。

这项整树缩放定理在本书本轮只作有来源的外部定理介绍，不登记为已完整重证。其分裂测度极限、Markov branching空间紧性和从有限保留树控制整树的误差仍缺本书完整证明。参数k=2也不自动确定与标准e的常数换算，须另核对。上述未完成项是实质覆盖边界，不仅是专家终审尚未签字。
