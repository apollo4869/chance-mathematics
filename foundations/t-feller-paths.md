# T-FELLER-PATHS：从正算子到路径与强Markov

E为非空局部紧Polish空间。先从正压缩C₀半群构造次概率核；路径与强Markov定理则明确假设这些核保守。证明只使用已经建立的测度工具、第8章扩张、第15章离散鞅与反向条件期望、第24章Polish紧性，以及T-OPERATORS。

## P.1 截断、紧化与可数观测

<a id="t-feller-topology"></a>

局部紧与可数基给可数个相对紧开集覆盖E；有限并的闭包构成紧穷竭，其内部覆盖E。紧F包含于相对紧开U时，下式为紧支撑连续函数，在F上为1，在U外为0。以有限最大值逐步覆盖穷竭，得到0≤χₘ递增趋1，且在每个紧集上最终为1。

\[
\chi_{F,U}(x)=\frac{d(x,E\setminus U)}{d(x,E\setminus U)+d(x,F)}.
\]

分母不为0；E紧且U=E时直接用常数1。添一点Δ，以紧集补集作为Δ的邻域，得到紧Hausdorff空间K。紧性由覆盖中含Δ的开集留下一个紧余集得到；Hausdorff性由局部紧邻域分离Δ与任意点。可数基中闭包嵌入另一个相对紧基集的配对，给可数个上述分离函数，也分离Δ（函数在Δ为0）。映入可数个[0,1]的乘积是连续单射，紧到Hausdorff的逆连续。因此K可度量且紧。

C₀(E)等同于C(K)中在Δ为0的闭子空间。C(K)可分：取K内可数稠密点，以有限个有理高度的函数qᵢ+L d(x,xᵢ)的最小值逼近连续函数，L取正整数；一致连续先给大的L下的下包络逼近，再取足够密有限网与有理高度。由此得到可数稠密族。子空间可分，取非负部分后得C₀正锥可数稠密族(fⱼ)。

## P.2 所需的有界正泛函表示，实际证明

<a id="t-feller-riesz"></a>

先在紧度量K上给正泛函ℓ，令M=ℓ(1)。正性给范数ℓ=M；M=0时结论平凡。以半径趋0的有限球覆盖K，取支撑在这些球内的连续分割统一ψᵢ，选球内锚点xᵢ。分割可显式用距离到球补集的非负函数，除以这些函数的和得到。构造离散概率如下。

\[
\mu_n=M^{-1}\sum_i\ell(\psi_i)\delta_{x_i},\qquad\left|\int f\,d\mu_n-M^{-1}\ell(f)\right|\le\omega_f(2/n).
\]

K紧，第24章的Prokhorov定理给弱收敛子列μ。上式对每个连续f同时识别极限，故ℓ(f)=M∫f dμ。若两份有限测度表示同一泛函，对闭集F用连续函数max(0,1−n d(x,F))递减逼近其指标；控制收敛给闭集质量相等，π–λ给全部Borel集相等。

一般E上，设L为C₀有界正泛函，M=范数L。将它延拓到C(K)，规定ℓ(f+c)=Lf+cM，其中f(Δ)=0。若f+c非负，则c≥0且f⁻≤c，故Lf≥−cM，延拓正。表示所得有限测度记μ。对截断χₘ，Lχₘ递增到M：对0≤f≤1，fχₘ一致趋f且L(fχₘ)≤Lχₘ，再对f取上确界。于是μ(E)=M=μ(K)，Δ无原子，限制到E就是唯一表示。

这是有界有限测度版本。开集有距离截断给出的闭内逼近，闭集的开外逼近由取补得到。具有开外逼近与闭内逼近的集合构成σ代数：补集交换两者；计数并的开外误差分配为ε乘2的负n次方，闭内逼近先截有限并，再用有限总质量控制剩余并集。因此全部Borel集正则。再将闭内逼近与固定紧穷竭相交，以有限质量控制尾，得到紧内逼近，即Radon正则性；未将一般局部有限泛函或随机测度理论算作本专题结论。

## P.3 核的可测性与Chapman–Kolmogorov

<a id="t-feller-kernel-proof"></a>

对Tₜ和x应用上一节，得唯一质量不超过1的Pₜ(x,·)。对开U，用χₘ乘min(1,m d(x,Uᶜ))递增逼近指标；U=E直接用χₘ。于是Pₜ(x,U)为连续Tₜfₘ(x)的极限。可测集合类对补集封闭；不交可数并由测度可加性给可测函数之和，所以它是λ系。开集为π系，π–λ给全部Borel集。补集使用Pₜ(x,E)，并不假设它等于1。

强连续与空间连续还给(t,x)↦Tₜf(x)联合连续，同一逼近给Pₜ(x,B)联合Borel。PₛPₜ是次概率测度，在C₀上积分等于TₛTₜf=Tₛ₊ₜf；表示唯一性给核的Chapman–Kolmogorov，包括t=0的单位核。

## P.4 有理网格上的超鞅与共同单侧极限

<a id="t-feller-regularization"></a>

以下Pₜ(x,E)=1。第8章扩张给原始坐标过程X，对任意初始律π成立。取上一节可数正稠密族，令观测族为所有Rₙfⱼ，其中n为正整数。由于nRₙf一致趋f，这个族分离K的点。对h=Rₙfⱼ，e⁻ⁿᵗh(Xₜ)是有界非负超鞅：半群作用后恰删去一段非负积分。

\[
e^{-ns}T_sR_nf=R_nf-\int_0^s e^{-nr}T_rf\,dr\le R_nf.
\]

固定整数时间窗[0,N]，用嵌套有限网格逐步包含其中所有有理数。第15章上穿不等式对超鞅的负值应用，下穿用超鞅自身；有界性使每个有理阈值区间的期望穿越次数被与网格无关的常数控制。网格增加后，单调收敛给总穿越次数有限。可数地取所有观测、阈值与N的交集，得到同一概率一事件。

若某个实t处有理右极限或左极限不存在，就有两个不同的上下聚值；夹在它们之间的有理阈值产生无限穿越，矛盾。连续指数因子不改变单侧极限存在性。紧K给状态聚点，分离族保证其唯一。注意这里不是对每个t分别取概率一事件，而是用有限穿越同时控制所有t。

## P.5 共同紧致包含排除无穷远

仍须排除随机时刻的Δ。给正α、截断χₘ，设gₘ=αRαχₘ。它在C₀中，介于0和1，且由保守性逐点增至1。Uq=1−e⁻ᵅqgₘ(Xq)为非负次鞅。将终点T加到有限有理网格，对U用最大不等式；取0<δ<1，gₘ小于δ蕴含U大于1−δ，故有如下上界。

\[
P_\pi\!\left(\inf_{q\in\mathbb Q\cap[0,T]}g_m(X_q)<\delta\right)\le\frac{1-e^{-\alpha T}E_\pi g_m(X_T)}{1-\delta}.
\]

先α小，再m大，右边任意小，Kₘ={gₘ≥δ}紧。对误差趋0的序列取相应紧集，作有限并得到递增紧集Hⱼ。事件“整个有理路径不在Hⱼ中”的概率趋0，故几乎必然存在某个Hⱼ包含整个有理路径。左右聚点都在该紧集内，排除了值或左极限逃到Δ后再回来。对整数T取交。所选确定紧集可依赖π和T，但不依赖样本；依赖路径的是最终容纳路径的索引j。结论是每个π下几乎必然有限时间紧致包含。

## P.6 真正的càdlàg修改与可测路径族

枚举分离观测hⱼ。在K上用下列度量，与紧化原拓扑相容：连续单射到可数乘积的紧像给逆连续。每个标量有理函数取右极限后右连续且有左极限；若右连续失败，可选tₖ向右趋t，并在每个tₖ极近处选有理qₖ，使其值逼近右极限，直接违背t处已有有理右极限。左极限同理。有限坐标加级数尾控制，将该结论传到状态度量。

\[
d_H(x,y)=\sum_{j\ge1}2^{-j}\min(1,|h_j(x)-h_j(y)|),\qquad Y_t=\lim_{q\downarrow t,\ q\in\mathbb Q}X_q.
\]

上一节使所有Y值和左极限留在E。固定t，对任意h在C₀，Markov性给下式；强连续使右边趋0。所以h(Xq)依概率趋h(Xₜ)，又几乎必然趋h(Yₜ)。对可数分离族同时成立便有Yₜ=Xₜ几乎必然，确为修改。

\[
E_\pi|h(X_{t+s})-h(X_t)|^2=E_\pi[T_sh^2(X_t)-2h(X_t)T_sh(X_t)+h(X_t)^2]\longrightarrow0.
\]

为得到所有起点共用的可测修改，固定P.1中内部覆盖E的递增紧穷竭Kₘ。将良好事件定义为所有可数穿越条件，及对每个整数N存在m使全部q在有理[0,N]上的Xq都属于Kₘ。这是不依赖π的可数Borel条件。P.5的随机紧集必含于某个Kₘ：穷竭内部覆盖该紧集，有限子覆盖后用递增性。因此此固定良好事件在每个初始律下概率1；补集统一指定同一个固定常值路径。每个Yₜ是有理坐标的可测函数，càdlàg性还给联合可测性。原始有限维律随起点x可测，π–λ扩到有理坐标σ-代数，正则化映射也只依赖这些坐标，所以x↦Y的路径律是可测Markov族。固定时刻修改保留全部有限维分布，确定时间Markov性由柱函数条件平均及单调类保留。路径律在坐标σ-代数上由有理时刻唯一决定。

## P.7 完成自然滤过的右连续性

<a id="t-feller-filtration"></a>

以下将Y重记X，固定π。令Gₜ为自然滤过加上终端路径σ-代数中所有Pπ零集及其子集。对sₙ递减到t，需证∩Gₛₙ=Gₜ。先取有限柱乘积Z，各因子在C₀加常数中；对足够大n，sₙ位于t之后第一个未来观察时刻r之前。Markov递推给条件平均为过去乘积乘Tᵣ₋ₛₙg(Xₛₙ)，其中g在C₀加常数中。

保守性使T保常数，且C₀加常数是乘法代数。强连续和路径右连续使上述条件平均有界趋于E(Z|Gₜ)。反向条件期望定理又把同一极限识别为E(Z|∩Gₛₙ)。这些柱函数生成路径σ-代数；函数单调类将相等扩到全部有界路径变量，完成后的零集不影响条件平均。取交中事件指标，便得事件属于Gₜ。记这个右连续完成滤过为Fₜ。

这是给定π的完成。原始Markov核族随x可测，并不意味着所有Pₓ的零集相同；本结论没有作这种声明。

## P.8 停止状态、开集首入与强Markov

<a id="t-feller-strong-markov-proof"></a>

在[0,t]上用向右网格并在t封顶，右连续给Xₛ为B([0,t])乘Fₜ可测。τ∧t是Fₜ可测，代入联合可测映射得Xτ∧t可测。因此{Xτ在B}与{τ≤t}的交在Fₜ，停止状态在有限τ上Fτ可测。开U首入τU满足{τU<t}=∪q<t{Xq在U}，故右连续滤过给{τU≤t}=∩n{τU<t+1/n}在Fₜ。

对有界τ取τₙ=2⁻ⁿceil(2ⁿτ)。τₙ为停止时刻，且A在Fτ蕴含A与每个{τₙ=k2⁻ⁿ}的交属于该网格信息。逐格应用确定Markov，对f在C₀有正文等式。τₙ与τₙ+s均从右趋近，路径右连续、Tₛf连续和有界性给两边控制收敛。所得条件恒等式用常数和单调类扩到全部有界Borel f。

一般τ，对A在Fτ，以A∩{τ≤m}和τ∧m应用有界结论；该事件属于Fτ∧m，因为在t<m时其与{τ∧m≤t}的交为A∩{τ≤t}，t≥m时为A∩{τ≤m}。m趋无穷得到有限τ上的结论。未来多时刻乘积依次在τ+tᵢ条件平均；未来càdlàg路径的坐标σ-代数由有理时间生成，π–λ遂给完整未来强Markov公式。所有τ无穷上的终端表达都带有限τ指标，不擅自定义X∞。

闭集首入不能仅用开邻域极限证明。例如路径在s<1时为1−s，s≥1时为1。它càdlàg，从未碰到0，但0的开邻域首入时刻趋于1。本专题不使用未证明的debut定理。

## P.9 Dynkin公式及折扣停止

<a id="t-feller-dynkin"></a>

对f在D(A)，Af有界。联合可测性给时间积分，Markov性和有界条件Fubini给正文M的鞅性。若τ≤T，取上述τₙ，有限网格上按下式展开。指标在增量开始时刻可测，所以每项期望0。

\[
M_{\tau_n}=M_0+\sum_{k=0}^{\lceil2^n(T+1)\rceil}\mathbf1_{\{\tau_n>k2^{-n}\}}(M_{(k+1)2^{-n}}-M_{k2^{-n}}),\qquad |M_{\tau_n}|\le2\|f\|+(T+1)\|Af\|.
\]

右连续与确定界给EMτ=0，这就是有界Dynkin。若Eτ有限，对τ∧n应用结论，积分由τ范数Af支配，终端f有界，得一般版本。

对u=Rλf，(A−λ)u=−f。直接对确定时段用指数乘半群的积分式，条件Fubini证明下面是鞅；不需随机积分或乘积公式黑箱。

\[
N_t=e^{-\lambda t}u(X_t)-u(X_0)+\int_0^t e^{-\lambda s}f(X_s)\,ds.
\]

有限网格停止与上面相同，统一界2范数u加范数f/λ甚至与T无关。对τ∧n停止后令n趋无穷，指数尾支配积分；τ无穷上的终端趋0，有限τ上的终端最终等于所需值。得到正文任意停止时刻的resolvent分解。
