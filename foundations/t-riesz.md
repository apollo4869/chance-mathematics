# T-RIESZ：从连续测试到局部有限测度

本专题为[第48章](../chapters/48-point-processes.md#points-tests)建立所需的正泛函表示；不以第49章尚未建立的随机测度拓扑为前提。

## 1. 空间与局部工具

<a id="riesz-space"></a>

全篇E为局部紧第二可数度量空间，固定相容度量。取可数相对紧开覆盖，逐次用有限多个这样的开集覆盖前一步紧闭包，并取并的闭包，得到紧穷竭Kₘ⊂int Kₘ₊₁。所需截断可以直接构造：紧K⊂开U，用有限多个小球找开V使K⊂V⊂cl V⊂U、cl V紧；令χ(x)=d(x,E∖V)/(d(x,E∖V)+d(x,K))，则χ=1于K、0≤χ≤1且支撑在cl V内。空K时取χ=0。若V=E（此时E紧），用χ=1。这样不需另借未经证明的泛函表示或一般拓扑定理。

有限开覆盖下的紧支撑分割也由此直接得到。给紧集每一点选支撑在某一覆盖成员内且在该点为正的非负函数，取有限子族ψᵢ；它们的和在紧集附近正。用一个支撑在该邻域、在紧集上为1的χ乘ψᵢ/Σψⱼ，得所需分割。因而任何支撑被开族覆盖的f∈\(C_c^+\)均能有限分解为非负fᵢ，每项支撑在一个覆盖成员内。


还将使用一个测度正则性事实。在该空间上，任意局部有限Borel测度ν都是Radon。开U是紧集Kₘ∩{d(x,E∖U)≥1/m}的递增并（U=E时用Kₘ），故开集内正则；ν在一个相对紧开窗口V内有限，V中相对开集的闭内逼近给其补集的开外逼近。在有限测度下，“同时可闭内逼近、开外逼近”的集合构成σ代数：补集交换两项；可数并先令有限个内逼近控制尾部，再把各外误差取可求和。它包含开集，故包含全部Borel集。闭内逼近再交V内紧穷竭，成为紧内逼近。最后将相对紧开窗口的可数覆盖先拆成不交Borel片，对每片的A部分作窗口内外逼近并取可求和误差，再将所得开集并起来，便得全局外正则。这里的证明也适用于映射所得的局部有限Borel强度。


还可由截断造相容完备度量。选χₘ=1于Kₘ、支撑在int Kₘ₊₁、值在[0,1]，令φ=Σₘ(1−χₘ)。这个和局部只有有限非零项，故连续；在Kₙ外至少前n−1项为1，所以φ的有界下水平集紧。d′(x,y)=d(x,y)+|φ(x)−φ(y)|相容且完备：Cauchy列的φ有界，列留在一个紧集内，有子列收敛，再由Cauchy性得到全列收敛。可分性来自原可数基。因此E确为Polish、标准Borel，这为后面核随机化提供已经核实的空间条件。

## 2. 从正性得到局部有界

<a id="riesz-bound"></a>

设L:\(C_c(E)\)→R线性且正。若f支撑在紧K、χ≥1于K，则|L(f)|≤‖f‖∞L(χ)。因此不需要预先假设另一种泛函连续性。要构造的唯一Radon测度μ应满足L(f)=∫f dμ。先对开集U定义下列候选质量。

\[ m(U)=\sup\{L(f):f\in C_c(E),\ 0\le f\le1,\ \operatorname{supp}f\subset U\}. \]

m单调；对不交开集有限可加，并且对任意开集覆盖U⊂∪Uᵢ有m(U)≤Σm(Uᵢ)：每个测试的紧支撑有有限子覆盖，上一节的分割把测试拆开。对不交开集的反向不等式，把有限个各自近最优的测试相加；它们的和仍不超过1。令有限项数增加，得到不交开集的可数可加比较。

## 3. 外测度及Borel可测性

<a id="riesz-outer"></a>

\[ \mu^*(A)=\inf\{m(U): A\subset U,\ U\text{ open}\}. \]

开覆盖比较证明μ*是外测度，且μ*(U)=m(U)。若A、B有正距离，任意覆盖其并的开U中可取不交开邻域分别容纳A、B，再用不交开集可加比较，得μ*(A∪B)≥μ*(A)+μ*(B)。因此这是度量外测度。这里列出其Borel可测性的关键一步，避免将其当作另一项表示定理。

对闭F及任意A，先处理μ*(A)<∞。令Aₖ={x∈A:d(x,F)≥1/k}。正距离可加给μ*(A)≥μ*(A∩F)+μ*(Aₖ)。还需μ*(A∖F)≤lim μ*(Aₖ)。为此把距离按递减阈值分成壳层，奇数壳与奇数壳之间、偶数壳与偶数壳之间任意有限子族都有正间隔。其外质量的和均不超过μ*(A)，故壳层尾和趋零；A∖F除去Aₖ只剩这项尾部。于是得到Carathéodory等式。μ*(A)=∞时若两部分外质量和有限则次可加矛盾，否则所需等式自动成立。闭集因而可测，Borel集亦可测。限制μ=μ*于Borel集即为测度。

相对紧开U的质量被任一在其闭包上≥1的测试χ的L(χ)控制，故μ局部有限。定义给外正则；开集上的内正则如下：给一个支撑在U的测试f，令K=supp f，则μ(K)≥L(f)，因为每个含K的开V都有m(V)≥L(f)。取上确界得\(\mu(U)=\sup_{K\subset U,\ K\ \mathrm{compact}}\mu(K)\)。对任意Borel A，在有限质量窗口内用A的补集外逼近可得A的紧内逼近；再用紧穷竭处理全空间。因此μ是Radon。

## 4. 恢复积分，而不只恢复开集

<a id="riesz-integral"></a>

对0≤f∈\(C_c\)、步长δ>0，取有限个层开集Uⱼ={f>jδ}。在每层内选0≤gⱼ≤1的紧支撑测试。逐点δ\(\sum_{j\ge1}\)gⱼ≤f，故L(f)≥δ\(\sum_{j\ge1}\)m(Uⱼ)，这里先逐项逼近上确界再求有限和。δ↓0给L(f)≥∫₀∞μ{f>t}dt=∫f dμ。反向使用连续层函数hⱼ=min(1,(f−jδ)₊/δ)。对j≥1，其支撑包含于{f>(j−1)δ}，所以L(hⱼ)≤m({f>(j−1)δ})。j=0项以支撑附近固定χ控制，L(h₀)≤L(χ)。恒等式f=δ\(\sum_{j\ge0}\)hⱼ（末层按同一截断公式）于是给L(f)≤δL(χ)+δ\(\sum_{j\ge1}\)m({f>(j−1)δ})。两侧Riemann和相差趋零，因为μ(supp f)有限；故等式成立。正负部分给一般f。

任一Radon表示测度在开U上的质量都是这些测试积分的上确界，因而等于m(U)。开集决定Borel测度：在每个相对紧窗口中用有限测度π–λ唯一性，再用穷竭。于是表示唯一。整个论证只用第5–6章的外测度、单调类及非负积分，没有借第49章。
