# T-TREE-CODING：有限平面树与三种路径的双向编码

本专题给出[第52章](../chapters/52-discrete-trees.md#trees-addresses)实际使用的全部离散编码证明。边长一律为1，树包含根，先处理有限树；没有把这些双射直接推广到任意无限树或连续实树。

## 1. 地址、祖先与可测状态空间

<a id="coding-addresses"></a>

\[ \mathcal U=\bigcup_{h\ge0}\mathbb N_+^h,\qquad \mathbb N_+^0=\{\varnothing\}. \]

词的拼接记为连接书写，长度记为绝对值。平面树是上述可数地址集的子集，包含空词，对前缀封闭，并且每个保留地址的孩子恰为按次序排列的前若干正整数：

\[ u\in T\ \Longrightarrow\ \exists k_T(u)\in\mathbb N_0:\quad uj\in T\ \Longleftrightarrow\ 1\le j\le k_T(u). \]

把子集看成二值指示族，取可数乘积Borel域。根条件是柱事件；前缀条件是可数个蕴含；孩子条件是对每个地址可数并的可数交。因此局部有限平面树组成可测子空间。每层有限由根开始归纳：有限个父节点各有有限个孩子。有限树子空间可数，因为可数集合的有限子集只有可数多个，故其中一切映射到可数空间的函数都可测。完整无限树的构造见[T-GW-TREES](t-gw-trees.md#gw-tree-space)。

祖先关系就是前缀关系。两词的最长公共前缀是最近共同祖先。从一个词走向另一个词，必须先删去直到公共前缀的末尾字母，再逐个接上目标剩余字母；这是唯一不重复边的路径。故图距离为

\[ d_T(u,v)=|u|+|v|-2|u\wedge v|,\qquad T_u=\{w:uw\in T\}. \]

右式还定义去掉地址前缀后的后代子树。平面次序是保留的额外结构：忘掉兄弟次序会把某些不同地址树视为同一个无序树，不能据此把平面树计数直接称为无序树计数。

## 2. 待访问槽位与Łukasiewicz双射

<a id="coding-lukas"></a>

有限树按先访问父节点、再依次完整访问各孩子子树的规则列出。记节点数为n，列表从第0项开始。令每项的孩子数为下式中的k，定义路径：

\[ v_0=\varnothing,\ldots,v_{n-1},\quad k_j=k_T(v_j),\quad S_0=0,\quad S_{j+1}=S_j+k_j-1. \]

维护一个有序的待访问地址列表：初始只有根；每次删掉第一项，并把它的孩子按次序插在列表最前方。列表长度每次改变孩子数减1，故访问前的长度等于1加路径值。列表在树尚未访问完时非空，结束时为空。因此

\[ S_{j+1}-S_j\in\{-1,0,1,\ldots\},\quad S_j\ge0\ (0\le j<n),\quad S_n=-1. \]

反过来，给一条满足这些条件的整数路径，用每个增量加1作为孩子数，执行同一列表算法。归纳得每步前列表长度是1加路径值，所以不会提前取空列表；最后恰好为空，不再留下未实现的孩子。每个新地址只由唯一父节点产生，编号连续，所以得到一棵平面树，恰有n个节点。孩子插到最前面确保在下一兄弟前访问完当前子树，故所得次序确为先序。算法逐步被孩子数唯一决定，证明单射与满射。总孩子数等于节点数减1，也就是边数。n为1时路径为从0降至−1的一步。

## 3. 子树首次下降与高度的弱纪录公式

<a id="coding-height"></a>

\[ r_i=\inf\{j>i:S_j=S_i-1\},\qquad 0\le i<n. \]

从访问该节点前开始，只跟踪由这个节点产生、尚未访问的子树槽位。初始一个；在其子树尚未处理完时，列表最前方总属于该子树，槽位数等于1加路径相对起点的变化。下降步至少为−1，故首次归零正是上述首次下降；全树有限保证它发生。于是该子树恰占连续指标从i到首次下降前一项。对后面的节点，其属于这棵子树当且仅当路径在两指标之间没有低于起点。

\[ v_i\preceq v_j\ (i<j)\ \Longleftrightarrow\ S_i=\min_{i\le k\le j}S_k,\qquad |T_{v_i}|=r_i-i. \]

高度等于严格祖先的数目，将上式对所有更早节点求和，得到完整的路径到高度转换：

\[ H_j=|v_j|=\sum_{i=0}^{j-1}\mathbf1\!\left\{S_i=\min_{i\le k\le j}S_k\right\}. \]

这是弱纪录，不能把等号替换为严格不等号。固定终点并倒读路径，令倒读值为终点减此前值；上式要求该倒读值达到截至此处的最大值，允许并列。只有一个孩子的长链在最后一个叶子以前路径恒为0，高度却逐项增加；严格纪录会把这些祖先全部漏掉。

## 4. 仅靠高度序列恢复每个父节点

<a id="coding-height-inverse"></a>

\[ H_0=0,\qquad 1\le H_j\le H_{j-1}+1\quad(1\le j<n). \]

定理：有限整数序列是某棵平面树的先序高度序列，当且仅当满足上式，而且树唯一。必要性来自先序的下一节点：或者是当前节点的第一个孩子，深度加1；或者先退到某个祖先，再走到尚未访问的孩子。根只访问一次，所以后续高度至少为1。

充分性用活动祖先栈。先放根；读到新高度时，删除栈中深度不小于新高度的节点。上界保证删除前栈深至少达到新高度减1，下界保证根仍在；故剩余末节点恰可作为父节点。把新节点作为其下一个孩子并入栈。每个弹出的节点以后不再接收孩子，因而新列表确为构造树的先序。父节点必是此前最近出现的高度低1的节点；任何实现原高度序列的树都必须如此连接，故唯一。

这说明高度序列虽不直接列出孩子数，却没有丢掉亲缘关系；删去序列次序，只保留每个高度出现几次，则退回每代人数，双射随即消失。

## 5. 轮廓、Dyck路径及其逆向算法

<a id="coding-contour"></a>

\[ C_0=C_{2(n-1)}=0,\qquad C_\ell\ge0,\qquad C_{\ell+1}-C_\ell\in\{-1,1\}. \]

从根出发，沿每条边以单位速度走向下一个孩子，孩子子树走完后沿同一边返回。每条边恰走两次，所以时长为边数的两倍；整数时刻记录距根距离，整数间线性插值。n为1时定义在单点时刻0。这给出上述非负Dyck路径。

逆算法维护当前祖先栈：每个上升步创建当前节点的一个新孩子，按创建次序编号，并把它压入栈；每个下降步弹出末节点。非负性使算法不会在根处下降，终点为0使所有创建边最终返回。上下步数相等且各为节点数减1，故节点数正确；每条边的首次下降恰在其子树已经完成之时，所以构造出的轮廓就是给定路径。所有上升步都必须创建新孩子，不能随意选择旧孩子，否则同一高度路径便不再表示约定的轮廓遍历。由此得到又一个真正的双射。

## 6. 两种时钟与最近共同祖先

<a id="coding-clocks-distance"></a>

\[ b_j=2j-H_j,\qquad C_{b_j}=H_j,\qquad 0\le j<n. \]

首次到达第j个非根节点以前，已创建j条边，故有j个上升步；当前深度等于上升步数减下降步数，所以下降步数为j减深度。相加即得首次访问时刻公式。相邻首次访问时刻之差为前一高度减后一高度再加2，至少为1。在两时刻之间，轮廓先下降到后一高度减1，再上升一步；最后一次首次访问以后一直下降至根。因而这些时刻及全部轮廓都由高度序列唯一确定。反向在轮廓每次上升首次创建节点时读出高度，又恢复原序列。

\[ d_T(v_i,v_j)=H_i+H_j-2\min_{b_i\le t\le b_j}C_t\qquad(i\le j). \]

若前节点是后节点的祖先，在两次访问之间轮廓不离开此前节点的子树，最低点就是它；否则轮廓从前节点所在孩子子树退到最近共同祖先，再进入后节点所在孩子子树。先序保证中间不会退到这个共同祖先之上。因此轮廓最低点恰为共同祖先深度，代入地址距离即得公式。最低值可以在整数时刻取得，线性插值不改变它。

\[ |v_i\wedge v_j|=\min_{i<k\le j}H_k-1\qquad(i<j). \]

后一公式不包含前指标：从前节点走向后节点的首次访问列表中，至少有一个节点是该共同祖先的孩子，所有其他节点也在其某个孩子子树内，故最小高度恰为共同祖先深度加1。把区间改成两端都包含、又忘掉减1，会出错：两个连续访问的兄弟叶子高度都是2，它们共同祖先的深度是1，而非2。本章恢复的是整棵带单位边长的离散平面树；连续函数商空间及其极限不是这个有限证明的自动推论。回到[第52章的时钟与距离](../chapters/52-discrete-trees.md#trees-distance)。
