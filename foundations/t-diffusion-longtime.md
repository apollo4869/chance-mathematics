# T-DIFFUSION-LONGTIME：比较、常返与速度平衡

与[第36章](../chapters/36-scale-speed.md#diffusion-comparison)配套。主设仍为I上的非退化局部LipschitzSDE。比较先停于共同紧区间；长期结论如无特别说明，要求两端不可达、最小过程保守。只使用本章已证明的命中、Green/折扣核及第12章i.i.d.大数定律；不借第41章遍历或42章Harris理论。

## 1. 同噪声比较，不借Tanaka

<a id="diffusion-order"></a>

设dXᵢ=bᵢ(Xᵢ)dt+σ(Xᵢ)dW，同一σ、同一W，b₁≤b₂，初值X₀¹≤X₀²。停于两状态离开共同紧区间的最小时刻τ；系数有共同Lipschitz常数L。Z=X¹−X²。以第35章的φₙ逼近|z|，取ρ(u)=Lu（L=0时扩散差恒0，二阶项直接省去）。令ψₙ=(φₙ+z)/2，0≤ψₙ′≤1，ψₙ→z⁺；在z≤−aₙ₋₁时ψₙ′=0，在负窄带内|z|≤aₙ₋₁。

b₁(X¹)−b₂(X²)≤b₁(X¹)−b₁(X²)≤L|Z|。乘ψₙ′后，正半轴贡献≤LZ⁺，负窄带≤Laₙ₋₁；扩散二阶项≤C/n，由φₙ″(z)L²z²≤2/n。停止Itô、鞅均值0，给下式。初始Z₀≤0使ψₙ(Z₀)≤0而趋0；也可用绝对误差aₙ₋₁统一估计。

\[ E\psi_n(Z_{t\wedge\tau})\le a_{n-1}+L\int_0^tE(Z_{s\wedge\tau})^+ds+La_{n-1}t+Ct/n. \]

n→∞用停止有界DCT，Gronwall给E Zₜ∧τ⁺=0。对有理t及可数紧区间穷尽取共同零集，得共同寿命前路径排序。σ不同则dX=dW、dY=2dW从0出发已无法保持排序，尽管漂移相同。对于相同全部系数，首次相遇后的路径唯一性也直接证明初值单调，入口构造使用的是这个更简单情形。

## 2. 常返与端点极限的完整时钟论证

<a id="diffusion-recurrence-proof"></a>

若S(ℓ)=−∞、S(r)=∞，从x>a出发，P(\(\tau_b<\tau_a\))→0使\(\tau_a\)<∞几乎必然；x<a时从左镜像。每次到a再到b、返回a的时刻都有限，强Markov迭代给无限多次往返。边界已不可达，寿命无限；有限时间内不能积累这些跨越，见边界证明1。

若两端尺度有限，Y=S(X)为有界连续鞅。先在整数时刻用第15章离散鞅收敛。又E[Y]ₜ=E(Yₜ−Y₀)²≤C，MCT给E[Y]∞有限；Doob使每段[n,n+1]内相对Yₙ的最大平方期望≤4E([Y]ₙ₊₁−[Y]ₙ)，其和有限，故这些段内振荡几乎必然趋0。于是整个连续时间Y趋有限Y∞，并有[Y]∞有限几乎必然。若Y∞位于尺度区间内部，X最终留在紧区间，其pσ有正下界，所以[Y]∞=∫₀∞p(X)²σ(X)²dt=∞，矛盾。因此Y∞只能是端点值。DCT给EY∞=S(x)，解两点混合即正文端点概率。

若S(r)<∞、S(ℓ)=−∞，令Z=S(r)−S(X)≥0。非负局部鞅是超鞅，收敛于有限值；可由停止Fatou与上穿证明，不要求总体L²。最大不等式给P(supZ≥K)≤Z₀/K，故supZ有限几乎必然。停于首次Z≥K，连续性使停止过程有界，所以上段方法给其总括号有限。在未达到K的事件上这就是原括号；对K取并，原括号有限几乎必然。极限若Z∞>0，则X趋内部位置并使时钟无穷，矛盾；故Z∞=0，X→r。另一端镜像。这个证明无需提前引用扩散的遍历性或DDS一般时间变换。

## 3. 不变概率：从对称resolvent到实际平稳性

<a id="diffusion-invariance-proof"></a>

假设两端不可达且m(I)<∞。T-SCALE-SPEED 4给最小resolvent的m对称性。保守性给Rλ1=1/λ。对非负有界f，Tonelli与对称性得到

\[ \int_I R_\lambda f\,dm=\int_I fR_\lambda1\,dm=\lambda^{-1}\int_If\,dm,\qquad \int_0^\infty e^{-\lambda t}\!\left(\int_IP_tf\,dm\right)dt=\lambda^{-1}\int_If\,dm. \]

对有界连续f，h(t)=∫Pₜf dm有界连续，因为每条路径连续且m有限，可两次DCT。所有正λ的Laplace变换等于常数的变换，故h为该常数。可直接核验唯一性：令差g有界连续，取整数λ=n+1，u=e⁻ᵗ后得到[0,1]上有限有符号测度g(−logu)du的全部多项式矩为0；第13章Bernstein多项式逼近使该测度为0，连续性给g处处0。于是归一化m在每个t上对连续测试平稳，再以有限测度唯一性推广到所有有界Borel f。

m有限及端点不可达还迫使S(ℓ)=−∞、S(r)=∞：若S(r)有限，则\(\Sigma_r\)≤(S(r)−S(c))m((c,r))有限，矛盾；左侧同理。因此它在上述常返范围内。为证唯一性，设ν为任意不变概率。f∈\(C_c^\infty\)时Lf有界，Itô余项在有限T由2||f||∞+T||Lf||∞控制而为真鞅，积分ν后得到∫Lf dν=0。

把μ=aν视作局部有限测度、q=b/a。弱方程是∫f″dμ+∫qf′dμ=0。下面实际解它，不预设ν有密度，也不以未经建立的分布论定理代替步骤。若θ光滑紧支撑且∫θdx=0，则它是某个光滑紧支撑f的导数，故T(θ)=∫θ′dμ+∫qθdμ=0。选定单位积分θ₀，以θ−(∫θ)θ₀分解，得T(θ)=C∫θdx。

令有符号局部测度η=qμ−Cdx，取其从固定内部点起的定向累计F(x)。F局部有界变差，Fubini给∫θ′Fdx=−∫θdη；上式也给∫θ′dμ=−∫θdη。故μ−Fdx对所有θ′积分为0。再以任意零积分光滑ψ=θ′检验，测度唯一性说明μ−Fdx=Kdx。因此μ具有局部BV密度v=F+K，而且dv=η=(qv−C)dx，实际为局部绝对连续。

p′=−qp，普通绝对连续乘积法则给(pv)′=−Cp。积分得pv=A−CS，改写J=−C便得到

\[ \nu(dx)=\{C+JS(x)\}\,m(dx). \]

为统一记号，把上式常数A改记C。S遍历整个R，非负ν及连续密度因子迫使J=0；总质量1使C=1/m(I)。同样在两端尺度无穷但m(I)=∞时，不可能有不变概率。我们没有从这一局部方程推导任意反射/有源边界的平稳律，那些边界可注入流量或原子，须另给条件。

## 4. 返回周期、时间平均与无限均值

<a id="diffusion-cycle-proof"></a>

假设尺度两端无穷，选a<b，D=S(b)−S(a)。周期从a运行到b，再首次回a。两个命中时间均有限几乎必然，故每个周期长度L>0有限几乎必然。强Markov给各周期的长度及路径收益成对i.i.d.。由单边Green，a→b的核在y≤a为D，在a<y<b为S(b)−S(y)，在y≥b为0；b→a的核在y≤a为0，在a<y<b为S(y)−S(a)，在y≥b为D。相加为D，得到

\[ ER_f=D\int_If\,dm\quad(f\ge0),\qquad EL=Dm(I). \]

m有限时，对有界Borel f，|\(R_f\)|≤||f||∞L可积。记\(T_n\)=∑₁ⁿLᵢ、N(t)=max{n:\(T_n\)≤t}。i.i.d. SLLN给\(T_n\)/n→μ=EL>0、(∑Rᵢ)/n→ER，故N(t)/t→1/μ。积分尾部求和∑P(L>εn)≤EL/ε，Borel–Cantelli给\(L_n\)/n→0。因此未完成周期的误差至多||f||∞\(L_{N(t)+1}\)/t→0，得到时间平均ER/EL=∫f dm/m(I)。

若EL=∞，对截断L∧K用SLLN得liminf \(T_n\)/n≥E(L∧K)，再K→∞得\(T_n\)/n→∞，N(t)/t→0。对紧支撑有界f≥0，ER=D∫f dm有限，所以∑Rᵢ/n→ER且\(R_n\)/n→0。未完周期收益不超过整份下一周期收益\(R_{N+1}\)，除t仍趋0（分别用\(R_n\)/n→0及(N+1)/t→0）。因此时间平均为0，不要求不可积周期长度本身的尾段比率趋0。

任意内部初值先等首次到a，等待时间有限几乎必然，不需有限均值；其有界f的初始贡献除t趋0。上述结论于是对任一内部起点成立，各固定f取相应概率1集合，不擅自同时对所有Borel f相交。没有以时间平均结论代替任意初值的分布/总变差混合收敛；后者为42章的另一理论责任。

## 5. OU与Brownian的可核算结论

<a id="diffusion-stationary-examples"></a>

OU的\(p=e^{\theta x^2/\sigma^2}\)，\(m^\prime=(2/\sigma^2)e^{-\theta x^2/\sigma^2}\)，S两端无穷且m有限；归一化得N(0,σ²/(2θ))。由32的显式解，固定初值时Xₜ的均值e⁻θᵗx、方差σ²(1−e⁻²θᵗ)/(2θ)，给分布趋该Gaussian。本章周期计算还给有界Borel f的几乎必然时间平均，不把二者混同。

Brownian的m=2dx为无限总量，故虽常返却无不变概率；任一固定有界区域的时间比例趋0，来自上一节而非一句“零常返”的命名。几何Brownian在(0,∞)的S=x、左端尺度0、右端∞，保守，故趋左端0；这与32的指数解一致，但本章不需重新计算指数积分。返回[第36章认识成果](../chapters/36-scale-speed.md#diffusion-insight)。
