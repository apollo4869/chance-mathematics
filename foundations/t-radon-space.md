# T-RADON-SPACE：一般非负Radon测度空间

返回[第49章](../chapters/49-random-measures.md#mass-polish)。E为局部紧第二可数度量空间。以下先建立确定性\(\mathcal M_+(E)\)，再谈其随机元。仅用[T-RIESZ](t-riesz.md)、第5–6章与第48章已实际构造的紧穷竭和测试族；不用未来Palm理论。

## 1. 同支撑的可数测试

<a id="radon-tests"></a>

取\(K_m\subset\operatorname{int}K_{m+1}\)、\(\bigcup_mK_m=E\)，以及\(0\le\chi_m\le1\)、\(\chi_m=1\)于\(K_m\)、\(\operatorname{supp}\chi_m\subset K_{m+1}\)。通过先扩大穷竭和有限并截断，可同时取χₘ递增。有限网、距离帽函数及有限分割单位给每个紧窗口中的可数一致逼近族：网点取自可数稠密集，半径和函数值取有理数，再乘截断函数。对任意\(f\in C_c\)，有某个固定较大K，使这一族中支撑于K的函数一致逼近f。对非负f选非负逼近，正负部分分别处理。

把χₘ及非负有理线性组合加入非负族\((f_j)\)，再以其有理线性张成V处理线性关系。Riesz唯一性使这些坐标分离测度。若\(\mu_nf_j\to\mu f_j\)，则\(\sup_n\mu_n(K_m)\le\sup_n\mu_n\chi_m<\infty\)。对支撑于K的f及逼近g，误差至多\(\|f-g\|_\infty(\mu_n(K)+\mu(K))\)。先固定逼近再取n极限，最后缩小误差，得全部\(C_c\)收敛。

## 2. 正泛函极限与相对紧性

<a id="radon-compact"></a>

设\(\sup_n\mu_n(K_m)<\infty\)对每个m成立。每个坐标有界，逐次抽取并取对角子列，使全部V坐标收敛。定义\(Lq=\lim_n\mu_nq\)于V。它是有理线性的，q≥0时非负，且固定支撑K上\(|Lq|\le a_K\|q\|_\infty\)。对任意实\(C_c\)函数，以共同支撑内的V逼近定义Lf；误差界保证极限存在、不依赖逼近序列。要比较两个不同共同支撑，只取包含二者的较大紧集，使用同一界。实线性由有理近似系数得到。

正性也保留：可直接选非负逼近，或在逼近误差δ时加δ倍等于1的截断，再令δ趋0。T-RIESZ给唯一非负Radon测度μ。相同误差界给子列对全部紧支撑测试收敛于μ。因此逐紧质量有界族序列相对紧，在度量空间中其闭包紧。反向，若闭包紧，连续函数μ↦μχₘ在其上有有限上界，遂得逐紧质量界。

## 3. 完备、可分与整数闭子空间

<a id="radon-polish"></a>

\[ d_v(\mu,\nu)=\sum_j2^{-j}(1\wedge|\mu f_j-\nu f_j|). \]

此度量诱导vague拓扑。\(d_v\)-Cauchy序列的每个坐标是实Cauchy，尤其截断坐标有界；上一节给收敛子列，再由Cauchy性得到全序列收敛。因此这一具体度量就是完备的。可分性不能用整数配置：必须允许有理权重。给定有限多个测试和δ>0，先将μ截到包含它们支撑的紧K；按有限个测试共同的一致连续尺度把K分成有限Borel小片，每片质量移到附近的固定可数稠密点。读数误差≤δμ(K)，再有理逼近有限多个质量。这个可数有限有理原子族在度量中稠密。

整数测度子空间\(\mathcal M_p\)的闭性用[T-POINT-MEASURES](t-point-measures.md#point-space-compact)的连续性球论证：对Radon极限，局部有限性保证除了可数半径以外球面质量0；连续截断使这些球的质量为整数极限。缩球得到整数单点质量，非原子点有零质量小邻域，可数基排除剩余部分。故这个子空间闭而Polish。有限加权原子在\(\mathcal M_+\)稠密，却不意味着整数原子稠密；这是不同结论。

## 4. 评价域、共同零集与随机核

<a id="radon-evaluation"></a>

令\(\mathcal E\)为全部\(\mu\mapsto\mu(A)\)生成的σ代数。每个非负Borel积分由简单函数与MCT给出，故连续测试坐标\(\mathcal E\)-可测；度量空间可分，开集是可数基的并，故\(\mathcal B_v\subset\mathcal E\)。反向，开U的示性可用递增\(C_c^+\)函数逼近，故μ(U)是Borel。固定相对紧开V，集合A⊂V中评价可测者含开子集，且由有限μ(V)可作相对补集并对不交可数并封闭。π–λ得V内全部Borel评价；可数V穷竭给全空间所有Borel评价。于是\(\mathcal E=\mathcal B_v=\sigma\{\mu f_j:j\ge1\}\)。

若一个随机映射已经每次取Radon测度值，可数读数可测便足够。若只给定随机线性读数，则还必须假设在可数V上a.s.满足有理线性、正性和逐窗口有限界。这些关系至多可数个；删掉它们的联合零集后，逐实现重复上面的延拓与Riesz构造。坏集上统一定义为零测度。所得映射全部可数坐标可测，故确为随机测度，版本唯一性也先在可数坐标统一零集再扩至全部Borel集。不能把对每个f分别a.s.成立误写成无需论证的共同版本。

特别地，\(P(E)=\{\mu:\mu(E)=1\}\)是Borel子集，且是Polish：\(\mu(E)=\sup_m\mu\chi_m\)，所以\(\{\mu(E)\le1\}\)闭，\(\{\mu(E)\ge1\}=\bigcap_k\bigcup_m\{\mu\chi_m>1-1/k\}\)是Gδ。闭集也是度量空间Gδ，故P(E)为Polish空间的Gδ子集；其weak拓扑等于下页证明的vague子空间拓扑。这里使用的Gδ完备可度量结论也可直接构造：若G=∩Uⱼ，在完备底空间中把x嵌入(x,(1/dist(x,Uⱼᶜ))ⱼ)；Uⱼ为全空间时对应坐标取0。图像在底空间与实序列的积中闭，继承完备度量，且与G原拓扑相同；可数基保证可分。
