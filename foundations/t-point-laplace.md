# T-POINT-LAPLACE：泛函识别与点过程极限

返回[第48章](../chapters/48-point-processes.md#points-laplace)。空间与计数测度拓扑均由[T-POINT-MEASURES](t-point-measures.md)实际建立。

## 1. 非负向量的Laplace唯一性

<a id="point-laplace-vector"></a>

若有限非负随机向量Y、Z在所有非负参数t上有同一Laplace变换，把每个坐标变成exp(−Yᵢ)∈(0,1]。整数参数给紧立方体上全部混合矩。多元Bernstein多项式一致逼近连续函数：将各坐标独立二项抽样，网格偏差的二阶矩至多维数除以4n，均匀连续性加Chebyshev给一致误差趋零。这是第13章逼近证明的有限坐标乘积。故两个像测度在全部连续函数上相同；开集由连续距离截断逼近，π–λ给全部Borel。指数映射有Borel逆，得到Y、Z等律。有限非负测度也可先由零参数识别总质量再归一化。

## 2. 整份点律怎样被识别

<a id="point-laplace-unique"></a>

\[ L_\Xi(f)=\mathbb E e^{-\Xi f},\qquad f\in C_c^+(E). \]

对决定族f₁,…,fₖ，以f=Σtᵢfᵢ代入，唯一性给所有(Ξf₁,…,Ξfₖ)联合律。可数坐标生成Mₚ的Borel域，柱集π–λ便给整份点过程律唯一。知道各Ξfᵢ的边缘并不够；参数的任意有限线性组合正是恢复联合性的步骤。也可将测试限定为前专题选出的可数有理锥，再对参数用有界收敛推广。

## 3. 紧性不能只控制总空间

<a id="point-laplace-tight"></a>

若对每个紧穷竭窗口Kₘ，计数Ξₙ(Kₘ)关于n一致紧，则对任意ε选整数aₘ使supₙP{Ξₙ(Kₘ)>aₘ}<ε2⁻ᵐ。前专题说明同时满足这些界的配置族有紧闭包，故过程律紧。反向若过程律紧，在每个紧族上连续测试χₘ的积分有界，控制Ξₙ(Kₘ)；概率质量先限制到这个紧族，得到局部计数的一致紧性。因此这是充要的概率紧性条件。只要求整个空间中的总数有限既过强，也不能表达无界空间中的合适极限。

## 4. Laplace收敛到一份已存在的点律

<a id="point-laplace-convergence"></a>

定理：对Mₚ值Ξₙ、Ξ，Ξₙ⇒Ξ当且仅当Lₙ(f)→L(f)对每个\(C_c^+\)测试成立。必要性因exp(−ξf)有界连续。充分性先证明紧性，不能只说泛函已经逐点收敛。对χₘ≥1于Kₘ及a>0有下界估计。

\[ \mathbb P\{\Xi_n(K_m)>R\}\le\frac{1-L_n(a\chi_m)}{1-e^{-aR}}. \]

Ξχₘ有限几乎必然，a↓0时L(aχₘ)→1。先选a使分子极限足够小，再选R使分母接近1；有限多个初始n另外放大R。这给一致局部计数紧性。Mₚ已证Polish，故可用第24章Prokhorov抽取弱子列。每个子列极限具有L的全部测试，由唯一性等于Ξ的律；若全序列不收敛，再抽一条停留在极限邻域外的子列即矛盾。这也明确了这里使用第24章而非第49章。

连续性集计数提供另一组实际读数。若ξₙ→ξ vague、A相对紧且ξ(∂A)=0，连续内外逼近给ξₙ(A)→ξ(A)。对随机极限要求P{Ξ(∂A)=0}=1，然后应用连续映射定理于任意有限组这样的集合。可以选可数基的球均有这一性质：在一个紧窗口内，事件Ξ(K)≤l上至多l个同心球面被命中，所以具有正命中概率的半径只有可数个；对l及窗口取并，再选稠密半径。不能在有边界原子的集合上无条件使用这个结论。

## 5. 独立稀有位置的极限

<a id="point-laplace-rare"></a>

每行有限多个独立实验，第j项以概率pₙⱼ出现一个点，其条件位置律Qₙⱼ，否则为空。记νₙ=ΣpₙⱼQₙⱼ。假设νₙ vague→局部有限Radon μ，并对每个紧K有maxⱼpₙⱼQₙⱼ(K)→0。则所有点的叠加趋强度μ的Poisson点过程。它比仅要求每个实验概率小更贴合局部观察，也允许有些实验几乎必然在遥远处发生。

\[ a_{nj}=p_{nj}\int(1-e^{-f})\,dQ_{nj},\quad L_n(f)=\prod_j(1-a_{nj}),\quad \sum_j a_{nj}=\nu_n(1-e^{-f})\longrightarrow\mu(1-e^{-f}). \]

f支撑在K时max aₙⱼ→0，Σaₙⱼ有界，故Σaₙⱼ²≤max aₙⱼΣaₙⱼ→0。对0≤a≤1/2，|log(1−a)+a|≤2a²，得到所需Poisson Laplace极限。前一定理完成过程级收敛。独立性确不可删：让所有实验共用一个概率1/n的触发，并在触发时放n点，总期望仍为1，但点过程以概率趋1为空，不趋强度1的Poisson。
