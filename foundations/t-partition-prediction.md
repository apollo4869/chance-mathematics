# T-PARTITION-PREDICTION：EPPF、Ewens与两参数预测的实际证明

本页不重复第44章DP构造；从划分而非标签出发，证明预测、有限概率与频率的联系。返回[第47章](../chapters/47-partitions.md#partitions-ewens)。

## 1. EPPF的递推为什么足以构造无限划分

<a id="partition-proof-eppf"></a>

设p为全部正整数有限向量上的非负对称函数，p(1)=1，且满足下面的加法规则。给一个具体[n]划分π赋概率p(各块大小)。n到n+1的每个扩展，恰为把新标签加进一个旧块或另开新块，因此规则给全部扩展概率之和等于原概率。归纳从n=1起，有限概率总和为1。交换性来自大小对称，投影相容来自递推；T-PAINTBOX第1节的可数构造给唯一无限律。

\[ p(n_1,\ldots,n_k)=\sum_{j=1}^k p(n_1,\ldots,n_j+1,\ldots,n_k)+p(n_1,\ldots,n_k,1). \]

p>0时扩展概率就是右侧各项除p；p=0的状态总概率为零，可用任意合法扩展核补全。反向，任何无限交换划分按块大小定义p：同大小的两个具体划分可由有限置换互换，故概率相同；分解扩展事件即得递推。这给真正的EPPF充要条件，而不是只验证某个公式归一化。

## 2. 由具体划分概率到Ewens采样公式

<a id="partition-proof-ewens"></a>

统一用θ>0记第44章的一参数集中量，该章的α在这里改名为θ，避免与本页的折扣α混用。其已经证明的具体划分概率如下。现在Aⱼ表示样本中大小恰为j的块数，而不是某一桌的编号。

\[ p_\theta(n_1,\ldots,n_k)=\frac{\theta^k}{\theta^{\uparrow n}}\prod_{i=1}^k(n_i-1)!,\qquad \theta^{\uparrow n}=\prod_{r=0}^{n-1}(\theta+r). \]

若Σj aⱼ=n，将n个标签先排成一列，切成规定长度的组。组内j!排列和同长组之间aⱼ!排列不改变划分，故有n!除以这些因子的划分。乘上每份具体划分概率，约掉j!与(j−1)!，得Ewens公式。归一化已由CRP或上节递推建立，不另假设一个未证组合恒等式。

\[ \mathbb P\{A_j=a_j,1\le j\le n\}=\frac{n!}{\theta^{\uparrow n}}\prod_{j=1}^n\frac{\theta^{a_j}}{j^{a_j}a_j!},\qquad \sum_{j=1}^n j a_j=n. \]

在paintbox语言中，这份律的排序质量是第44章GEM(0,θ)出现次序质量的降序排列，称PD(0,θ)。残余乘积趋零的实际证明见T-STICK-BREAKING与T-CRP；所以无dust，但有无穷多正质量块。一个指定n元组同块的概率也给出EΣSⱼⁿ=(n−1)!/(θ+1)的n−1阶上升阶乘。此矩是新采样解释，不使排序质量变成独立变量。

\[ \mathbb E\sum_jS_j^n=p_\theta(n)=\frac{(n-1)!}{(\theta+1)^{\uparrow(n-1)}},\qquad n\ge1. \]

## 3. 可以严格建立的两参数扩展

<a id="partition-proof-two-parameter"></a>

取0≤α<1；α=0时θ>0，α>0时θ>−α。已有n人、k块时，旧块j权重nⱼ−α，新块权重θ+αk，分母θ+n。这些数严格为正且和为1。顺序核实际构造无限划分。逐项乘路径概率，每块除首次外依次贡献1−α到nⱼ−1−α，新块贡献θ+α到θ+(k−1)α，得到下面的对称EPPF。

\[ p_{\alpha,\theta}(n_1,\ldots,n_k)=\frac{\prod_{i=1}^{k-1}(\theta+i\alpha)}{(\theta+1)^{\uparrow(n-1)}}\prod_{j=1}^k(1-\alpha)^{\uparrow(n_j-1)}. \]

初人概率为1；空乘积取1，所以n=1无奇异。扩展比正好是刚才的权重，递推与交换性已证。参数可包含α>0、θ=0或负θ，但不是任意实数；本页不声称负折扣有限物种族、α=1端点或所有Gibbs划分的分类。特别地，“局部概率和为1”本身不保证交换，交换是由整个路径乘积的对称性另外证明的。

## 4. 删除第一块，证明独立剩余切割而非猜测

<a id="partition-proof-deletion"></a>

第一块已有n₁人，其外r=n−n₁人时，下一人进第一块的概率(n₁−α)/(θ+n)，不进概率(θ+α+r)/(θ+n)。把第2人起是否进入第一块的指标独立构造成初始质量(1−α,θ+α)的二色Pólya；其均匀变量独立于另一份参数(α,θ+α)的餐馆。

给定不进第一块，旧的其他块j权重变成(nⱼ−α)/(θ+α+r)，新块权重为(θ+α+αk′)/(θ+α+r)，其中k′是其他块数。这就是独立残余餐馆规则。将其顾客按二色指标插回时间轴，有限路径概率逐项因子分解，等于原餐馆；柱集唯一性给无限过程同律。故第一块指标列与残余划分确实独立。

第44章有限Dirichlet/Beta混合和条件强律适用于任意正初始质量，所以第一块密度V₁服从Beta(1−α,θ+α)，位于(0,1)。残余顾客仍无限；在其自身时间轴重复上述分解。归纳有限层乘积并取可数共同满概率集，得到相互独立的Vⱼ，以及出现次序频率Pⱼ。

\[ V_j\sim\operatorname{Beta}(1-\alpha,\theta+j\alpha)\ \text{independently},\qquad P_j=V_j\prod_{i<j}(1-V_i). \]

## 5. 为何这些频率的总和确实等于1

<a id="partition-proof-total-mass"></a>

α=0时Vⱼ iid且均值正，强律使ΣVⱼ=∞。α>0时令a=1−α；直接用Beta积分给EVⱼ=a/(θ+1+(j−1)α)，其和发散；EVⱼ²=a(a+1)/[(θ+1+(j−1)α)(θ+2+(j−1)α)]，其和有限。第12章独立中心级数的有限方差判据给Σ(Vⱼ−EVⱼ)收敛，故ΣVⱼ=∞。没有用未来的稳定subordinator来证明本页自身。

\[ 0\le\prod_{j=1}^m(1-V_j)\le\exp\!\left(-\sum_{j=1}^m V_j\right)\longrightarrow0,\qquad \sum_{j\ge1}P_j=1\quad\text{a.s.} \]

每个递归第一块都有正密度，并在有限时刻出现；固定有限个块的绝对频率，由压缩时间轴密度相乘得到Pⱼ。上式排除频率之外漏掉一份dust。按大小排序定义PD(α,θ)，按出现次序定义GEM(α,θ)；本页实际证明了这份预测律的频率表示，但没有证明所有交换划分都属于这两个参数族。

## 6. 哪些一致性与识别结论不能混同

<a id="partition-proof-boundaries"></a>

一个反例说明概率核归一化不够：前两人同块概率取1/2；若前两人同块，第3人一定入该块；若不同，第3人确定加入第1人的块。于是{1,3}|{2}概率1/2，而{1,2}|{3}概率0。每一步都合法，却不交换。

本章的Ewens针对餐桌或无原子标签的相等值划分。第44章已有原子基时，异桌可能同名，观测相等划分是粗化，不保持同一EPPF。两参数预测不自动等于Kingman合并的任一固定时刻分布；突变联系在独立的T-COALESCENT-MUTATION准确构造。一般Λ/Ξ合并、碎裂与层级仍由第56章承担。
