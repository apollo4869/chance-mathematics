# T-REGENERATIVE-SPINE：CRP生长、Brownian脊柱与再生分解

本页证明[第57章](../chapters/57-regenerative-growth.md#growth-spinal-crp)的具体树增长与再生结论。Nₖ=(2k−3)!!，N₁=1；树有标号叶、无平面左右顺序，并保留根干边。CRP折扣记a，与56章自相似时间指数α区分。完整的非Brownian连续再生树分类不由本页声称。

## 1. 度量生长忘掉长度以后，怎样选边

<a id="regen-uniform-edges"></a>

由T-LINEBREAKING-CRT密度，给形状和总长，2k−1条边的比例服从Dirichlet(1,…,1)，与二者独立。接点按长度均匀，因此只给形状时，每条边被选的概率为1/(2k−1)。全部早先形状是当前标号形状的删叶函数，故这也是真正给定形状历史的转移规则。每个新形状都有唯一删去最新标签的旧形状与插入边，归纳概率1/[Nₖ(2k−1)]=1/Nₖ₊₁。

均匀边是形状过程的核，不是已知实际边长后的度量核。后者必须按长度，不能用均匀选边再在线段内均匀代替。对子树随机左右定向，根分成i及n−i叶的大小律如下；给实际标签分组，两侧形状独立均匀。因此它满足T-MARKOV-BRANCHING的完整条件。

\[ q_n(i)=\frac{\binom ni N_iN_{n-i}}{2N_n},\qquad1\le i<n,\quad n\ge2. \]

## 2. 沿标签1的脊柱，把树分成有次序的森林

<a id="regen-forest-count"></a>

令m=k−1。沿根到叶1的路径，由根向叶依次记录旁生子树的标签块\(B_1,\ldots,B_b\)，大小nⱼ，合为{2,…,k}。给定这一有序划分及每块内部二叉树，沿一条脊柱依次接它们并以叶1封尾，唯一恢复整棵形状；反之沿脊柱拆开唯一恢复这些数据。故一个指定有序标签划分的概率为下面的乘积。

\[ P(B_1,\ldots,B_b\text{ in spinal order})=\frac{\prod_{j=1}^bN_{n_j}}{N_{m+1}}. \]

给该有序划分，内部形状独立且各均匀，因为每组形状组合在均匀整树中概率相等。忘掉几何顺序，一个具体无序划分有b!种顺序，所以EPPF为b!∏Nₙⱼ/Nₘ₊₁；即使大小重复，标签块仍不同，不能再除同大小块阶乘。

## 3. CRP参数是由边数推出的

<a id="regen-crp"></a>

\[ P(\text{join block }j)=\frac{2n_j-1}{2m+1}=\frac{n_j-1/2}{m+1/2},\qquad P(\text{new block})=\frac{b+1}{2m+1}. \]

旁生块j连同其接到脊柱的干边有2nⱼ−1条边；脊柱自身分成b+1条边。前者被选时，新标签加入同一旁生块；后者被选时，在相应间隙开新块。总边数Σ(2nⱼ−1)+(b+1)=2m+1，故这些概率是从实际树生长推出来的CRP(1/2,1/2)。m=0时必开第一块，不将0/0作为公式。新块在b+1个间隙中均匀插入，因此给无序划分，几何顺序均匀；出现次序则按第一次被样本看到编号，二者不同。

\[ p_{1/2,1/2}(n_1,\ldots,n_b)=\frac{b!\prod_j(2n_j-3)!!}{(2m-1)!!}. \]

把47章两参数EPPF代入a=θ=1/2，逐个把(1/2)的上升阶乘写成双阶乘，即得此式，与计数完全一致。此处没有用一个预测参数猜CRT，而是从已经识别的树律得到预测规则。

## 4. 删除第一个旁生块以后，剩余结构重来

<a id="regen-decrement"></a>

\[ r(m,j)=\binom mj\frac{N_jN_{m-j+1}}{N_{m+1}},\qquad1\le j\le m. \]

首个根侧旁生块有j人的事件：先选其标签，有binom(m,j)种；其形状Nⱼ种，余下含标签1的树Nₘ₋ⱼ₊₁种。这个分解穷尽且互斥，故r的和为1。给首块实际标签后，它的内部树与剩余标记树独立均匀；删除该块并压掉相应脊柱顶点，剩余树的旁生大小序列重新服从m−j版本。归纳给有序大小组成的再生乘积公式。

\[ P(C_m=(n_1,\ldots,n_b))=\prod_{j=1}^b r\!\left(m-\sum_{i<j}n_i,n_j\right). \]

这是有限样本的再生，不声称无限CRT从根数起存在“第一个正质量旁生块”。连续脊柱上分枝可以向根累积，有限根侧第一个块的质量极限可能为0。再生公式是按有限剩余标签数递归，不能未经额外论证换成iid物理间距。

## 5. 完整的有限度量脊柱分解

<a id="regen-metric"></a>

\[ \left(\frac{A_1}{L},\ldots,\frac{A_b}{L},\frac{H}{L}\right)\ \sim\ \operatorname{Dirichlet}(2n_1-1,\ldots,2n_b-1,b+1),\qquad2L^2\sim\operatorname{Gamma}(m+1,1). \]

Aⱼ是旁生有限树的骨架总长，H是到叶1的脊柱长，均不是完整CRT分量的概率质量。给有序块划分，先取独立均匀内部形状，再取独立L。用每条边一个独立Exp(1)变量并除总和，实现全体Dirichlet(1,…,1)边长比例。把变量按b个子树和脊柱分组，各组和独立Gamma，组内比例独立Dirichlet且与组和独立：这由变换Gᵢ=S pᵢ的Jacobian S^(d−1)和乘积指数密度直接因子分解得到。各组维数恰为2nⱼ−1与b+1，遂得显示律。

给这些组总长，各旁生树内的边比例独立均匀单纯形，脊柱b+1段亦然；用这些长度沿脊柱依次接回，精确恢复Rₘ₊₁律。这是有限几何的完整条件分解和重建。给L后各组总长受总和约束，并不独立；也没有把Aⱼ/L等同于下节的频率Pⱼ。

## 6. 连续树脊柱上的真实质量频率

<a id="regen-mass"></a>

在已经闭合的Brownian CRT取独立质量叶ξ₁，去掉闭脊柱[ρ,ξ₁]。其补集各连通分量开，因空间可分而至多可数，每个非空开分量由满支撑具有正质量。54章叶质量与弧零质量给μ([ρ,ξ₁])=0，故这些分量质量和为1。条件于树与ξ₁，再取iid质量样本，强律同时识别所有分量频率。有限约化树的旁生块正是这些分量的样本限制：实树唯一弧和Brownian二叉性排除了同一附着点的多组混淆。

\[ P_j=V_j\prod_{i<j}(1-V_i),\qquad V_j\sim\operatorname{Beta}\left(\tfrac12,\tfrac{j+1}2\right)\text{ independently};\qquad (P_j)^{\downarrow}\sim\operatorname{PD}(1/2,1/2). \]

有限旁生划分已经是CRP(1/2,1/2)，所以47章实际证明的删第一桌、Beta切割与总和1定理给出现次序GEM及排序PD律。第一桌是由样本ξ₂所选的大小偏置分量，E P₁=1/3，等于两位额外样本落入同一旁生分量的概率。这证明了具体的连续质量脊柱结论；没有断言完整旁生几何给定所有频率后必为某个独立缩放CRT族。那需要额外的度量分解证明。

## 7. 一族合法递归增长，不预先保证交换

<a id="regen-general-growth"></a>

\[ 0<a<1,\quad\theta>0:\qquad \text{root-edge weight }a,\quad \text{off-spine subtree weight }u-a,\quad \text{marked subtree weight }v-1+\theta. \]

对一棵n=u+v叶二叉树，把含最小标签的孩子称标记侧，另一侧大小u。按上述三项权重选择根干边或某一子树，和为n−1+θ；若选子树，就在其中按同样规则递归，直到选中一条边。单叶树只有一条边，必选。将选中边分成两段并接新叶，只规定无长度形状。所有权重正，递归大小下降，故每一步为合法有限Markov核；可数独立均匀变量给无限添叶序列。删除最新标签逐样本恢复旧树，但这尚非任意抽样一致性。

## 8. 同一递归确实诱导两参数CRP

<a id="regen-general-crp"></a>

\[ P(\text{join }j)=\frac{n_j-a}{m+\theta},\qquad P(\text{new})=\frac{\theta+ab}{m+\theta}. \]

沿叶1脊柱展开递归时，含该叶子树的权重恰与下一层的总分母相消。于是第j旁生子树的总选择权重是nⱼ−a；每个旧分枝之前的脊柱间隙权重a，最后通向叶1的间隙权重θ。合并间隙即得显示CRP概率。若选旁生树，内部独立随机数运行同一递归；外部分配只看叶数，所以给分配历史后各子树的内部增长独立。这里没有把折扣a认作某个几何自相似指数。

47章的EPPF证明使旁生划分本身交换，并给GEM(a,θ)频率；但三叶整树的三种樱桃对概率为下式。全部标签交换要求三者相等，只能a=θ=1/2。在这个特例，归纳可数根侧和侧树边数，证明递归恰为每条边同权，回到本页第一节。其他参数下，删除最后标签的相容并没有使出生标签成为iid质量样本。

\[ P(\{1,2\}\text{ cherry})=\frac a{1+\theta},\quad P(\{1,3\}\text{ cherry})=\frac\theta{1+\theta},\quad P(\{2,3\}\text{ cherry})=\frac{1-a}{1+\theta}. \]

## 9. 再生结论的真实边界

<a id="regen-scope"></a>

实际证明包括：Brownian一致Markov branching形状、完整有限度量脊柱分解及重建、再生组成r、连续脊柱的PD(1/2,1/2)质量、上述准确参数内的递归CRP增长，以及标签交换仅在Brownian点成立的三叶检验。未证明一般两参数非Brownian紧CRT极限、完整连续旁生几何独立缩放定理、一般再生CRT表示分类；这些不能靠GEM频率填补。Pitman–Winkel的原文研究更广的树增长，并明确区别弱和强采样一致性；本页没有把一组出生标签不交换的结论误写成其去标签族绝不可能弱一致。[返回正文](../chapters/57-regenerative-growth.md#growth-crp-boundary)。
