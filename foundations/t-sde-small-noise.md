# T-SDE-SMALL-NOISE：反馈方程的路径大偏差

与[第35章](../chapters/35-sde-wellposedness.md#sde-small-noise)配套。本页完整证明有限T、固定初值x、全局有界Lipschitz b:Rᵈ→Rᵈ及σ:Rᵈ→Rᵈˣᵐ的Freidlin–Wentzell定理，允许σ退化。噪声为εW，速度为ε⁻²；若改写成√εW，速度相应为ε⁻¹。前置仅为第29章Schilder/收缩原理、第32章Itô、第33章非负随机指数超鞅，以及本章已经完成的强解与稳定估计。

## 1. 可连续读取的Euler映射

<a id="sde-proof-euler-map"></a>

网格h令η_h(s)为包含s的格子左端，终点不足一格也保留。对任意连续w、w₀=0，递归定义F_h(w)：格子起点状态y已知后，格内取y+b(y)(t−tᵢ)+σ(y)(wₜ−wₜᵢ)。有限次递归与系数连续性表明F_h从一致路径空间到一致路径空间连续。X^{ε,h}=F_h(εW)就是冻结Euler过程。第29章给其好LDP，代价为

\[ I_h(\phi)=\inf\left\{\tfrac12\|u\|_{L^2}^2:F_h\left(\int_0^\cdot u_sds\right)=\phi\right\}. \]

注意F_h的连续性只在固定h断言。网格越来越细时，不存在这里已经证明的一份一致连续Itô映射；下文用指数逼近跨过这一距离。

## 2. 控制能量的紧性及真实控制方程

<a id="sde-proof-control"></a>

对u∈L²([0,T],Rᵐ)，控制方程φ=x+∫b(φ)ds+∫σ(φ)u ds以普通积分理解。其Lipschitz常数相对于有限测度(1+|u|)ds可积；在该测度小于1/(2L)的连续小段上作压缩映射，有限次拼接给唯一绝对连续解。有界系数直接给局部振幅上界

\[ |\phi_t-\phi_s|\le B|t-s|+B\sqrt{|t-s|}\,\|u\|_2,\qquad \|\phi\|_T\le|x|+BT+B\sqrt T\|u\|_2. \]

在||u||²₂≤2R上，共同有界等度连续。冻结控制解ψ_h=F_h(∫u)也满足这些界。其格内振幅≤B(h+√(2Rh))。与φ比较，用相对于(1+|u|)ds的Gronwall得到

\[ \sup_{\|u\|_2^2\le2R}\|\psi_h-\phi(u)\|_T\le C_{R,T}\sqrt h\longrightarrow0. \]

还需核验能量球上的弱控制收敛。若uₙ⇀u于L²，则φ(uₙ)的任一一致收敛子列有极限φ；σ(φₙ)一致趋σ(φ)，所以∫σ(φₙ)uₙ−∫σ(φ)uₙ趋0，由Cauchy–Schwarz；余下∫₀ᵗσ(φ)uₙ由弱收敛对每个t通过极限。共同振幅界将有理t的收敛提升为一致收敛。漂移用DCT，故φ满足u的控制方程，唯一性给整列收敛。

L²能量闭球弱序列紧，可由可数正交基的坐标对角抽取及Bessel界直接得到，极限范数不增。上段表明它在控制解映射下的像紧。对某条φ若代价有限，取趋近下确界的控制，弱子列与范数下半连续使下确界达到。因此I(φ)=inf{||u||²₂/2:φ(u)=φ}的水平集恰为这些紧像，I为好速率函数。

## 3. 指数鞅上界不需要真密度

<a id="sde-proof-exp-bound"></a>

连续局部鞅M₀=0若[M]ₜ≤v，则对a>0、θ>0，将exp(θM−θ²[M]/2)停于首次M≥a及T。它非负，局部化后Fatou给超鞅，故到达概率≤exp(−θa+θ²v/2)。最小化θ=a/v得exp(−a²/(2v))；v=0时M恒0。这里没有把严格局部鞅指数当作概率密度。对m维Brownian，分坐标并用并集界得到

\[ P\!\left(\sup_{s\le h}|W_s|>r\right)\le2m\exp\left(-\frac{r^2}{2mh}\right). \]

## 4. 真实解与冻结解的超指数距离

<a id="sde-proof-exponential-approximation"></a>

令Y=X^{ε,h}，e=Xε−Y，V_s=Y_s−Y_η(s)，b、σ上界为B，Lipschitz常数为L。固定目标r>0与小ρ>0，定义τ_e=inf{|e|≥r}，τ_V=inf{|V|≥ρ}。格子边界V重置为0，以格内连续首次到达定义τ_V；可数格子拼合使其为停止时刻。τ_V以前，漂移误差β与扩散误差Γ满足|β|+||Γ||≤L(|e|+ρ)。

对F(e)=log(1+|e|²/ρ²)用Itô，停止于τ=τ_e∧τ_V∧T。其梯度为2e/(ρ²+|e|²)，Hessian为2I/(ρ²+|e|²)−4eeᵀ/(ρ²+|e|²)²。漂移上界≤C(1+ε²)，因为(|e|+ρ)²/(|e|²+ρ²)≤2；负的Hessian项可删。鞅项K的括号≤Cε²T。因此对0<ε≤1，F(eₜ∧τ)≤C_T+Kₜ∧τ，[K]ₜ∧τ≤C_Tε²。

\[ P(\|e\|_T\ge r,\tau_V>T)\le\exp\left[-\frac{\bigl(\log(1+r^2/\rho^2)-C_T\bigr)_+^2}{2C_T\varepsilon^2}\right]. \]

另一份错误来自冻结路径本身在格内走得太远。若Bh≤ρ/2，则由格内表达式、||σ||≤B及上节Brownian界，

\[ P(\tau_V\le T)\le2m(1+T/h)\exp\left(-\frac{\rho^2}{8mB^2\varepsilon^2h}\right). \]

B=0时这个概率为0，单独处理。取ρ=h¹ᐟ⁴：ρ²/h→∞，且log(1+r²/ρ²)→∞。先ε→0时有限网格因子的ε²对数趋0，再h→0，两项都超指数小。于是完整得到

\[ \lim_{h\downarrow0}\limsup_{\varepsilon\downarrow0}\varepsilon^2\log P(\|X^\varepsilon-X^{\varepsilon,h}\|_T>r)=-\infty\qquad(r>0). \]

误差过程连续，停止处的r恰被达到，无跳跃越界问题。所有Itô与指数步骤可先停于有界局部化再放开，括号上界不依赖局部化。这个证明没有假定Itô解映射对一致Brownian路径连续，也没有用普通L²小误差冒充指数误差。

## 5. 开闭集上下界的实际传递

<a id="sde-proof-fw"></a>

下界：开集G中取有限代价φ(u)，选r>0使其2r球在G内。第2节保证固定充分小h时ψ_h(u)距φ(u)<r/2。Euler的LDP对ψ_h(u)的r/2球给指数下界至少−||u||²₂/2。真实解不在G但Euler在该球，只可能因误差>r；选h使其误差指数比||u||²₂/2严格大。若a_ε的下指数≥−c，b_ε的上指数≤−M且M>c，则(a_ε−b_ε)₊与a_ε同下指数；由b_ε/a_ε→0直接验证。于是liminf ε²logP(Xε∈G)≥−||u||²₂/2，对u取下确界得开集下界。

上界：对闭集F及r>0，以Fʳ={ψ:dist(ψ,F)≤r}，有P(Xε∈F)≤P(Y∈Fʳ)+P(||e||>r)。Euler闭集上界与超指数逼近给两项指数最大值。需要验证其代价下确界不会在h→0、r→0时突然变小。若相反存在hₙ→0、rₙ→0以及控制uₙ，能量≤A且ψ_hₙ(uₙ)距F≤rₙ，取弱L²子列。第2节使φ(uₙ)一致趋φ(u)，同时||ψ_hₙ(uₙ)−φ(uₙ)||→0。闭性给φ(u)∈F，弱范数下半连续给I(φ(u))≤liminf能量。因而

\[ \lim_{r\downarrow0}\liminf_{h\downarrow0}\inf_{\psi\in F^r}I_h(\psi)\ge\inf_{\phi\in F}I(\phi). \]

若右侧∞，以任意有限A作同样反证即可。对固定r先h→0使误差指数趋−∞，再r→0，得到全部闭集上界，不只紧集上界。与第2节的紧水平集结合，本章的好LDP证明闭合。

## 6. 精确范围、退化与代价的含义

<a id="sde-proof-fw-scope"></a>

若a(x)=σ(x)σ(x)ᵀ可逆，则在绝对连续φ、φ₀=x上，点态最小范数控制为σᵀa⁻¹(φ′−b)，代价等于半积分(φ′−b)ᵀa⁻¹(φ′−b)；条件是这个控制在L²。若a退化，只允许φ′−b落在σ的像中且存在平方可积控制，其他路径代价∞。不能把伪逆数值有限误认为自动满足像空间条件。

σ恒0时唯一有限代价路径是确定性ODE解，代价0；b=0、σ=I时恢复Schilder平方能量。反馈系数的普适部分是控制能量通过实际存在的动力规则传递，而不是所有随机路径都拥有同一种可达性。这里只完成有界Lipschitz的有限时间版本；无界系数、爆炸、无限时间退出率、非Lipschitz小噪声选择和跳跃小噪声LDP均不作为本页已证成果。
