# T-TREE-CUTS：长度Poisson切割、有限样本一致性与模型边界

本页完成[第56章](../chapters/56-fragmentation-hierarchies.md#fragment-geometric-cuts)中实际使用的几何切割。先给固定紧实树，再对54章连续编码的随机树给可测条件构造。Brownian CRT切割的特有自相似律、加性合并对偶没有在此证明。

## 1. 总长度无穷也能定义切点

<a id="cuts-length"></a>

取紧有根实树(T,d,ρ)、Borel概率μ和可数稠密点vᵢ。令Rᵢ=∪ⱼ≤ᵢ[ρ,vⱼ]，每次新增部分是从旧树唯一附着点到vᵢ的半开线段，长度有限。给这些互不重叠的新增线段赋弧长，求可数和，得到σ有限长度测度ℓ。它覆盖所有非叶骨架：对一个有严格后代的点，其上方开分枝含某个稠密vᵢ。遗漏的稠密端点及根均是ℓ零点，不影响弧长。每条有限弧的ℓ长度正是其距离，可在Rᵢ内逼近其端点并用连续性验证。

在时间×这些可数弧参数上，以dt da放Poisson点，再映入T，便有强度dt ℓ(dz)的切点。全树有限时间切点数可以无穷；有限样本根跨度R(x₁,…,xₙ)只有有限总长，故其中切点数局部有限。这才是有限观察合法的原因，不能把CRT紧性误读成长度有限。

## 2. 弧上的避让定义一份划分

<a id="cuts-partitions"></a>

\[ i\sim_{\Pi_t}j
\quad\Longleftrightarrow\quad
N([0,t]\times[x_i,x_j])=0,\qquad
P(i\sim_{\Pi_t}j\mid T,x_i,x_j)=e^{-t\,d(x_i,x_j)}. \]

取独立于切点的iid μ样本xᵢ。长度无原子，故条件于全部可数样本，切点几乎必然永不正好命中其中任一点；这使上式自反。实树的弧包含[x,z]⊂[x,y]∪[y,z]给传递性，故是等价关系。重编号样本不改联合律，所以整条划分路径交换。有限样本仅需看有限跨度中的有限切点；其有效改变至多n−1，且限制完全使用相同样本与切点。因此过程路径、可测性、右连续及采样一致性全部成立。

可测性也可从弧判据直接检查：z∈[x,y]当且仅当d(x,z)+d(z,y)=d(x,y)，它是闭条件；对Poisson点的可数和给可测计数。两个时间方向的分离事件由切点时刻确定，没有使用未来随机积分。

## 3. 随机编码树上的条件可测构造

<a id="cuts-random"></a>

对54章连续编码h，选固定稠密有理时刻qᵢ，vᵢ=pₕ(qᵢ)，附着高度aᵢ=maxⱼ<ᵢ mₕ(qᵢ,qⱼ)，第一个最大值取0。新增弧以高度u∈(aᵢ,h(qᵢ)]参数化。aᵢ和端点对h连续。高度u的祖先点可取qᵢ以前最后一次达到u的编码时间；其对(h,u)为Borel，因为“最后时间>r”可写为可数个紧区间上min|h−u|=0的事件。祖先投影的距离由54章最低值公式给可测读数。

在固定空间时间×N×非负高度上先放强度dt #di du的Poisson测度，保留aᵢ(h)<u≤h(qᵢ)的点。48章可测核稀释构造允许这样条件于h选点；再用上述祖先映射得到切点。在独立均匀时刻取pₕ(Uⱼ)作质量样本。整个构造在固定可测空间中完成，所以e随机时也给合法随机过程，而不是对每棵树各选一个无法统一的版本。

## 4. 单位线段给一个真正自相似的切割模型

<a id="cuts-interval"></a>

取T=[0,1]，μ为Lebesgue，切点强度dt dz。质量x的现存区间被切的率为x，切点条件位置均匀。不同区间上的未来Poisson限制独立，故其长度质量按有限ν、c=0、α=1的自相似碎裂演化，ν为排序(U,1−U)的概率律。因为全区间长度1，有界时间内只有有限切点，所有区间长度之和一直1。这是实际构造与参数识别，不是所有实树的普遍属性。

一般树上，切割后的完整分量几何具有Poisson未来独立性；但只记录样本划分或质量，可能丢掉决定后续速率的几何，所以本页不宣称它们自动有同一种Markov分枝律。对同一个CRT，可改成有界Borel权重w(z)ℓ(dz)的切点或根本不切；两样本首次分离率分别为∫[x,y]w dℓ或0。几何存在没有指定演化。

Brownian CRT切割的特有指数、分量条件律及与加性合并的特殊时间反演必须另外证明，本轮登记未完成，不能借57、58填补。回到[正文](../chapters/56-fragmentation-hierarchies.md#fragment-geometric-cuts)。
