# T-CRT-RANDOMNESS：质量、随机性与有限距离读数

本专题补全[第54章](../chapters/54-brownian-crt.md#crt-mass)中质量推前、随机实树的可测解释及Brownian质量性质。确定性实树已由[T-REAL-TREE-CODE](t-real-tree-code.md)证明，有限采样密度由[T-CRT-SAMPLING](t-crt-sampling.md)实际计算。本专题不预设第55章的GH、GP或GHP拓扑。

## 1. 推前质量与满支撑

<a id="crt-random-mass"></a>

\[ \mu_h=(p_h)_*\operatorname{Leb}_{[0,1]},\qquad
\int_{T_h}f(x)\,\mu_h(dx)=\int_0^1 f(p_h(t))\,dt. \]

pₕ连续，故这是一份商空间Borel概率；紧度量空间上的有限Borel测度为Radon，可用49章已证的正则性。若O非空开，pₕ⁻¹O非空相对开，在[0,1]有正Lebesgue质量，所以μₕ满支撑。不能由此推断无原子：三角形编码顶端若停留一段正时间，顶端便有相应正原子。

给定h，独立均匀时刻Uᵢ的像是条件iid的μₕ样本。质量是遍历时间推前，不是默认每段边按长度均匀赋值。同一线段由匀速上升下降和带停顿的上升下降编码，可有相同根距离树而有不同质量；树度量与质量须作为两个对象保留。

## 2. 不先借空间拓扑，仍能说明随机性

<a id="crt-random-measurable"></a>

令E₀为全部连续非负、两端0编码，取一致范数Borel域。最小值对函数一致扰动是1-Lipschitz，故对所有s,t，两个编码的距离读数相差至多4倍一致误差。

\[ \sup_{s,t}|d_h(s,t)-d_g(s,t)|\le4\|h-g\|_\infty,\qquad
\Phi_{k,F}(T_h,\rho_h,\mu_h)
=\int_{[0,1]^k}F\!\left((h(t_i))_i,(d_h(t_i,t_j))_{i<j}\right)\,dt_1\cdots dt_k. \]

F为任意有限坐标上的有界连续函数。若hₙ一致趋h，上式坐标逐点趋近且在一个共同有界范围内；有界收敛给Φ连续。取所有紧的有根满支撑测度实树的根保测等距类，并以这些采样读数生成σ域。则h↦(Tₕ,ρₕ,μₕ)是可测映射。e是C([0,1])值可测随机元，所以逐样本商构造真的给一份随机有根测度实树。此处只声明这个σ域的随机性，不提前宣称其某个空间度量已完备可分。

条件抽样和共同零集也可放在固定可数记录上处理。对每个h，用有理时间q的像pₕ(q)作稠密中心，用有理正半径作球基。它们的质量是对t积分事件\(d_h(q,t)<r\)的示性函数；距离对(h,q,t)连续，所以这些质量及有限样本命中事件联合可测。对这一个固定可数编号族取共同好集，就能在随机h下合法使用下面的稠密性和叶性质论证。

## 3. 有限抽样读数确实识别整棵带质量树

<a id="crt-random-identification"></a>

需证明上述观察没有把不同满支撑树误当同一类。更一般地，设两个紧有根度量概率空间μ满支撑，且所有k的根与iid样本距离数组同律。它们的无限数组律也同，由可数乘积唯一性得到。各自在固定紧Polish空间的无限iid样本与数组之间作正则条件化，10章允许在共同数组律上独立抽两套条件样本；得到距离数组逐项相等的耦合。具体地，对数组中每个坐标和有理阈值，其条件示性均值等于共同数组的相应0/1读数；在这些可数测试上统一零集，条件核便集中于产生该数组的样本序列。

iid样本在每个空间都几乎必然稠密：对可数基中每个非空开集，永不抽中的概率为lim(1−μO)ⁿ=0。合并可数零集后成立。相等距离数组将两个稠密样本集合连同根对应为等距映射；重复点由零距离同时识别，故映射良定义。完备性将其唯一延拓为满射根保等距。

它还保质量。紧度量空间的连续函数有可数一致稠密族。一个实际构造是先用\(f_L(x)=\inf_y\{f(y)+Ld(x,y)\}\)一致逼近连续f：一致连续性控制近处误差，有界性使远处项在L增大后不可能取到更低值；所得函数为L-Lipschitz。再用可数稠密点的有限网和有理高度，取有限个“有理高度加有理斜率乘距离”的最小值，就一致逼近每个Lipschitz函数。这给可数族；对这一族应用12章强大数律，并用一致逼近，样本经验测度几乎必然弱趋μ。耦合中延拓等距对每个经验测度都相互推送，连续函数测试取极限便推送极限质量。于是两空间根保测等距。此论证只用了固定紧空间中的普通弱收敛，未用55章不同空间间的GP重构定理。

对于随机树，还要从无条件采样律恢复读数自身的联合律。两个读数的乘积等于在两组互不重叠的iid样本上取乘积测试的一个更大读数；任意有限乘积同理。因此全部有限距离数组律给出任意有限读数向量的所有混合矩。读数有界，紧盒上的多项式逼近（13章Bernstein乘积证明）识别其联合分布。柱集唯一性随后识别读数生成σ域上的整份随机树律，而非只识别每个读数的均值。

## 4. 无原子及几乎处处为叶的质量

<a id="crt-random-leaves"></a>

以下h=e。有限约化子树定理使两个独立质量样本的距离严格正，概率1。因此条件于树的碰撞概率∫μₑ({x})μₑ(dx)的期望为0；它非负，所以a.s.为0，每个原子都被排除。根也没有原子。这个结论来自采样密度，不由“e在每个固定时刻有密度”直接推出。

称非根x为叶，若它没有严格后代，等价于去掉x后只有一个连通分支。叶集合可测：固定可数稠密D，x非叶当且仅当某个z∈D满足|z|=|x|+d(x,z)、d(x,z)>0。正向因一个严格后代方向含非空开集，必遇D；反向由树的祖先线成立。右边是可数个Borel条件。

取同一串条件iid质量样本。几乎必然每个有限Rₖ中所有已采样点都是叶，这是采样密度的正边长结论，k可数所以共同成立。若第一个样本在整树中不是叶，其某个严格后代方向是非空开集，满支撑使该方向有正质量，未来样本几乎必有一个进入它。此时第一个样本已在根到未来点的路径内部，成为某个Rₖ的非叶，矛盾。条件积分得μₑ(叶)=1。

## 5. 二叉性、长度与质量的差别

<a id="crt-random-branches"></a>

同一串样本a.s.稠密，且全部有限约化树二叉。在一棵实树中，删点后的各连通分支开：每个不等于删点的点都有足够小的球留在原分支。若整树某点有四个或更多分支，稠密样本在其中四个各取一点，某个有限Rₖ便含四叉，矛盾。因此所有分枝点的度恰为3。根的度为1：e在(0,1)严格正，任意两个非根点的编码时间之间最低值正，故它们的连接不经过根。

这一论证不对不可数点逐一取零集，而是在一个稠密序列与全部有限样本共同好集上一次排除所有高阶分枝。每个三叉点也由某三个稠密样本的连接恢复，因此分枝点至多可数；不据此断言全部树点可数。

任意非退化树弧的内部点不是叶，端点无原子，故μₑ给每条弧质量0，而该弧有正度量长度。有限Rₖ也质量0，但其并稠密：每个样本已在其中。总长随k趋无穷a.s.，可由采样增长核的2Lₖ²独立指数增量及强大数律得到。有限枝上的长度与整树的概率质量因此确实不同；没有把“均匀选时间”误作“沿无穷骨架归一长度”。

## 6. 换根读数与尚未承担的空间极限

<a id="crt-random-root"></a>

有限采样密度仅依赖所有边长之和，且视根为额外叶标签0时，对标签0,…,k完全对称。将根与某个均匀样本交换，不改变相应有限距离数组律。要比较换根后k个新样本，先抽k+1个旧样本，在k+2个标签中交换0与1再删去标签1，得到相同结论。于是对所有采样读数，均匀质量换根的CRT与原CRT同律。这里无需假设原根本身按μ抽样；结论来自上述标签对称性。

上述所有断言属于实际构造和识别：紧实树、根、质量、有限采样与随机律。并未建立不同树空间上的GH/GP/GHP度量、Polish性或条件GW树的空间收敛，这些由55章承担。完整无限线段生长归57，一般Lévy树归58；本专题不给这些未来结果提前登记完成。[返回第54章认识成果](../chapters/54-brownian-crt.md#crt-insight)。
