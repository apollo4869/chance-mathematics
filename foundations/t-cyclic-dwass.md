# T-CYCLIC-DWASS：编号切口、首次下降与总规模

本专题完整证明[第52章](../chapters/52-discrete-trees.md#trees-cycle)的循环引理和Dwass公式，并处理可行性、计数与条件采样。此前仅使用[T-TREE-CODING](t-tree-coding.md#coding-lukas)的列表双射及[T-GW-TREES](t-gw-trees.md#gw-tree-forest)的iid探索；不使用条件树极限定理。

## 1. 循环引理：恰有多少个合法编号切口

<a id="cycle-indexed"></a>

\[ a_i\in\{-1,0,1,\ldots\},\quad \sum_{i=1}^{n}a_i=-m,\quad 1\le m\le n. \]

在每个编号切口之后从头读一遍循环词，切口编号取0到n减1。称切口合法，如果新部分和在结束前始终严格大于−m，结束时为−m。定理：恰有m个合法编号切口。一个周期词的不同切口可能给出同一词，仍然按切口编号分别计算。

\[ S_0=0,\quad S_j-S_{j-1}=a_j,\quad a_{j+n}=a_j,\quad S_{j+n}=S_j-m\qquad(j\in\mathbb Z). \]

把增量周期延到全部整数时刻，累积和按上式延拓。向左趋正无穷，向右趋负无穷。下降一次不超过1，因此每个整数层都在某个时刻首次命中；首次命中以前所有值严格更大，否则从左侧高处第一次降到更低位置必先经过该层。记这些首次命中时刻如下。周期关系同时给出其平移公式。

\[ t_h=\min\{j\in\mathbb Z:S_j=h\},\qquad t_{h-m}=t_h+n. \]

从任何首次命中时刻切开，到一个周期以后才首次到达低m的层，所以此前相对增量严格大于−m。这种切口合法。反过来，若某个切口r合法，取任意更早时刻j，选正整数q把它平移到从r到下周期终点之前。合法性与周期式给出

\[ r\le j+qn<r+n,\qquad S_j=S_{j+qn}+qm>S_r+(q-1)m\ge S_r. \]

因此r也是其所在层的全局首次命中。合法切口恰为这些首次命中时刻的模n余数。层高相差m的首次命中时刻恰相差n；反之，两个首次命中时刻若模n相同，其层高也模m相同。这在层高模m与合法切口模n之间建立双射，故合法切口恰有m个。证明允许零增量、重复最小值及周期词，没有偷偷假设路径各次旋转不同。

## 2. 一棵树的切口为什么取第一次最小值

<a id="cycle-first-min"></a>

\[ m=1,\qquad r=\min\operatorname*{arg\,min}_{0\le j<n}S_j. \]

这是唯一合法切口。直接验证也能看清并列时如何选。若最小值为0，第一次最小值就在起点，结束前全部非负。若切口在后面，最小值至多为−1；切口以后到原词终点之间，各值减去最小值均非负，包括原终点−1。绕回词首以后、尚未到切口以前，各旧值因第一次最小值的定义至少比它大1；新部分和等于这些差再减1，仍非负。末步总和为−1。

例如增量依次为−1、0、0。第一次最小值在第一个增量之后，旋转得到0、0、−1，是合法单树路径；最后一次最小值给0、−1、0，提前结束后又有读数，不合法。若m等于n且增量全部为−1，全部n个切口合法，却只产生一个不同的词。这说明“一共m个”与“m个不同旋转词”是两种陈述。

## 3. Dwass公式：无需在零概率事件上条件化

<a id="dwass-formula"></a>

\[ \xi_1,\ldots,\xi_n\overset{\mathrm{iid}}{\sim}p,\quad S_j=\sum_{i=1}^j(\xi_i-1),\quad \tau_m=\inf\{j\ge0:m+S_j=0\}. \]

对每个切口，将“该切口合法且终点为−m”的指示相加。循环引理给出总和为m乘终点事件的指示；终点不对时指示全取0。iid乘积律在任何循环置换下不变，故各项期望均为原路径首次到−m恰在第n步的概率。取期望得

\[ nP(\tau_m=n)=mP(S_n=-m),\qquad P(N^{(m)}=n)=\frac mn\,P\!\left(\sum_{i=1}^n\xi_i=n-m\right)\quad(n\ge m\ge1). \]

探索定理把首次下降换为森林总规模，证明完成。总规模小于根数的概率为零。后代律可以超临界、均值无穷或有零概率取值，公式仍计算有限总规模；无穷规模质量另记。整个论证没有除以终点概率，所以即使右侧终点事件不可能发生，等式也合法地给出0。一个祖先和一个节点的情形正好给出零后代概率。

## 4. 格点可行性：必要余数不是小规模的充分条件

<a id="dwass-feasibility"></a>

\[ P(N=n)>0\ \Longleftrightarrow\ \exists k_1,\ldots,k_n\in\operatorname{supp}p:\ \sum_{i=1}^n k_i=n-1. \]

必要性由树的总边数；充分性由该后代词的合法循环切口与正乘积权重。若零后代不可能，所有项至少为1，没有有限树。若只可能零后代，只有根。其余情形取正后代支持的最大公约数；因为支持含0，它也是后代分布的最大格点跨度。

\[ p_0>0,\quad d=\gcd\{k\ge1:p_k>0\}\quad\Longrightarrow\quad P(N=n)>0\ \Longrightarrow\ n\equiv1\pmod d. \]

反向对所有充分大的正确余数成立。证明不能只写“格点显然”：从支持选有限多个正整数，其最大公约数已经为d，这可由逐次取公约数的递减整数序列终将稳定看出。除以d后公约数为1，取其中一个数a。其余生成数在模a的有限群中生成全部余数；非负组合也生成该群，因为在有限群中每个生成元的逆是其若干次正和。为每个余数选一个非负组合代表，任何同余且不小于该代表的数再加若干个a即可表示。于是所有充分大的整数都有非负组合表示。乘回d，表示n减1；组合中的正项数不超过n减1，可补零到n项。

小规模仍需检查实际和。例如后代支持为0、4、6时，跨度为2，规模3虽满足奇数条件，却要求用这些值加出2，不可能。支持为0、2时则恰好所有奇数规模可行。条件于规模的表达式只在实际正概率规模上使用。

## 5. 度数剖面、Catalan数与条件剖面律

<a id="dwass-profiles"></a>

\[ \sum_{k\ge0}n_k=n,\quad \sum_{k\ge0}k n_k=n-1\quad\Longrightarrow\quad \#\{t:|\{u:k_t(u)=k\}|=n_k\ \forall k\}=\frac1n\frac{n!}{\prod_k n_k!}. \]

固定一份有限支持剖面，所有排列词共有多项系数那么多个。每个词有且仅有一个合法编号切口，而每个合法词可以从恰n个“原词、切口编号”对得到：每个编号唯一确定反向旋转词。这是带编号的双计数，不按不同旋转轨道个数作未经证明的除法。除以n并用编码双射即得公式。

\[ \#\{t:|t|=n\}=\frac1n\binom{2n-2}{n-1},\qquad
\#\{\text{full }r\text{-ary plane trees with }j\text{ internal vertices}\}
=\frac1{rj+1}\binom{rj+1}{j}\quad(r\ge2). \]

第一个式子把所有总和为n减1的n项非负整数词一起计数：在n减1个记号间放n减1道分隔，得到二项系数，再作同样的切口双计数。第二式只允许孩子数为0或r，内部节点j个，叶子数为(r减1)乘j再加1；代入剖面式即可。这里计数有根有序形状，不是带任意顶点标签的树。

每个给定剖面树的GW权重是各后代概率的剖面乘积。乘上剖面树数，再除以Dwass规模概率，可见条件于总规模时，孩子数的无序剖面与iid后代串在其和为n减1条件下的剖面同律。这不说明有序先序串是普通iid桥：它还必须满足首次下降条件。

## 6. 从iid桥到条件树的精确旋转

<a id="dwass-conditioned"></a>

假定终点事件概率为正。先按iid后代串条件于和为n减1取样，再在增量部分和第一次最小值处旋转，最后用列表算法恢复树。这样得到的恰为原GW树条件于总规模n的分布。

证明还需核对旋转原像的权重。总增量为−1的整数词不可能有非平凡周期：若由相同短块重复q次，−1就能被q整除，故q只能为1。每个合法词因此有n个不同旋转原像；每个原像乘积权重相同，而且都由唯一合法切口送回该词。条件桥将它们总共赋予下式概率，正好等于该树的条件权重。

\[ \frac{n\prod_{i=1}^n p_{k_i}}{P(\sum_{i=1}^n\xi_i=n-1)}
=\frac{\prod_{i=1}^n p_{k_i}}{P(N=n)}. \]

这是每个可行有限规模上的精确等式，不是大规模极限定理。让桥变大、研究最小值切口的连续性、控制高度与轮廓，仍然需要新的条件紧性和极限证明。第53章才承担这些责任；本专题不以普通Donsker替代它们。回到[第52章](../chapters/52-discrete-trees.md#trees-conditioned)。
