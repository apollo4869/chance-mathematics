# T-PALM-APPROXIMATION：局部条件化、误差与拓扑

返回[第50章](../chapters/50-palm-gibbs.md#palm-local)。全页区分三种结论：窗口加权的精确Palm身份；非空条件化的近似；一般非平稳Palm核的几乎处处版本。没有把模零版本变成所有位置的唯一条件概率。

## 1. 先选配置还是先选一次出现

<a id="palm-local-bound"></a>

设Ξ为平稳局部有限点过程，0<λ<∞。取有界Borel窗口B、0<|B|<∞，N=Ξ(B)、m=EN=λ|B|、p=P(N>0)>0。令\(Q_B\)为先条件N>0，再在B中的N次出现里均匀选X、观察θXΞ的律。令\(R_B\)为配置按N/m加权后，再同样选X的律。可测枚举使选点概率核合法；T-PALM的平稳身份恰给\(R_B=P^0\)，对任意B精确成立。

\[ P^0=\frac pm Q_B+\frac{m-p}{m}D_B,\qquad d_{\rm TV}(Q_B,P^0)\le\delta_B:=\frac{m-p}{m}=\frac{\mathbb E(N-1)^+}{m}. \]

若m=p，后一项零；否则\(D_B\)来自按(N−1)⁺/(m−p)加权的配置和同一选点核。恒等式逐配置由N=1{N>0}+(N−1)⁺得到。总变差采用事件差上确界，因此显示的常数没有遗漏二倍。对有界F，期望差至多2‖F‖δB。还可用(N−1)⁺≤N(N−1)/2得到二阶充分上界，但一般定理不需要二阶矩。

## 2. 简单性给出无需二阶矩的局部极限

<a id="palm-local-simple"></a>

设Ξ简单，B⊂半径r的原点球。因为\(m-p\le\mathbb E[N\mathbf1_{\{N\ge2\}}]\)，中心化Campbell给

\[ \delta_B\le\frac1{|B|}\int_B P^0\{\eta(B-x)\ge2\}\,dx\le P^0\{\eta(B(0,2r))\ge2\}\longrightarrow0. \]

P⁰下根处恰一次出现，局部有限使每个实现的其他点与0有正距离，所以最后的概率趋0。这证明\(Q_B\)→P⁰于总变差，不需要对N²作任何假设。对齐次Poisson，p=1−exp(−m)，因此δB≤m/2，给显式小窗口误差。

若不重新居中，只看\(\mathcal L(\Xi\mid N>0)\)，对vague空间的有界连续F有

\[ \left|\mathbb E[F(\Xi)\mid N>0]-\mathbb E^0F(\eta)\right|\le2\|F\|_\infty\delta_B+\mathbb E^0\sup_{|x|\le r}|F(\theta_{-x}\eta)-F(\eta)|\longrightarrow0. \]

第一项沿用配置层的同一混合分解；加权后未居中配置的律为|B|⁻¹∫B Law(θ₋ₓη)dx。第二项由T-PALM联合连续性逐实现趋0，界2‖F‖允许支配收敛。上确界可取可数稠密x，故可测。这里得到weak而非一般TV：弥散Poisson的未居中条件律仍以概率1在精确原点无点，Palm律则在原点有点，因此两律的TV始终1。

有重数时简单性不可省。取49章Poisson父位置，各簇独立为δ₀或2δ₀、概率各半。Palm根重数2的概率为2/3。小窗口条件非空时，父数≥2的条件概率趋0，故被选簇重数2趋概率1/2；背景在所选父位置无点a.s.。因此即使重新居中，也与P⁰保持至少1/6的极限事件差。零概率除法的直觉在这里确实给错权重。

## 3. 非平稳核的局部平均：weak与支配下的TV

<a id="palm-kernel-averages"></a>

设Campbell析取\(C(dx,dz)=\nu(dx)Q_x(dz)\)，νσ有限，S为Polish环境空间。把E分成有限ν质量片Dⱼ，再用可数Borel基前n个集合细分每片，得递增可数分区\(\mathcal A_n\)生成全部Borel域。对ν(A)>0的单元定义\(Q_A=C(A\times\cdot)/\nu(A)\)，ν零单元取固定概率。对每个有限ν片及S的可数基有限并G，\(Q_{A_n(x)}(G)\)是Qₓ(G)对递增分区的条件期望。15章闭鞅收敛给ν-a.e. x的极限Qₓ(G)。对可数G合并零集。

任意开U可由这些基开集的有限并从下穷竭，故liminf \(Q_{A_n(x)}\)(U)≥Qₓ(U)。24章Portmanteau推出\(Q_{A_n(x)}\)⇒Qₓ，ν-a.e.。这是指定细化分区上的核平均极限，不是任何收缩集合、任何指定零测度位置都可条件化。若ν局部有限且正支持，分区还可加入细网使单元直径趋0；否则只用可数生成版本。

若另有固定概率R，使\(Q_x(dz)=k(x,z)R(dz)\)，k联合可测且∫k(x,z)R(dz)=1 ν-a.e.，则可升级TV。每个有限ν片上，平均密度kₙ是k对“分区x、完整z”递增σ域的条件期望；k在该片×S中L¹，闭鞅定理给乘积a.e.收敛kₙ→k。Fubini给ν-a.e. x的R-a.e.收敛；两边密度积分均1，Scheffé计算\(\int|k_n-k|dR=2-2\int\min(k_n,k)dR\to0\)，故TV趋0。

没有支配条件，TV结论会错。令Ξ=\(\delta_U\)、U均匀于[0,1]，环境为Ξ。则Qₓ=\(\delta_{\delta_x}\)，而对任何正长度分区单元A，\(Q_A\)是在A均匀选一个点的配置律。对固定x，其给单配置{δₓ}概率0，Qₓ给1，所以TV=1；细分单元仍weak趋Qₓ。这里边缘有限、版本合法，失败只来自拓扑被错误升级。
