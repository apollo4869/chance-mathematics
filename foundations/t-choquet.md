# T-CHOQUET：从一致命中概率构造随机闭集

返回[第51章](../chapters/51-random-closed-sets.md#sets-choquet)。E和包括空集的闭集空间采用T-FELL。完整证明LCSC度量版本，只用8章可数一致分布扩张、π–λ与可数紧邻域族，不把Choquet名称当作构造工具。

## 1. 条件与有限观察表

<a id="choquet-finite"></a>

定理：紧集上的T是随机闭集律的容量，当且仅当\(0\le T\le1,\ T(\varnothing)=0\)，对每个r≥1及紧A,K₁,…,Kᵣ满足下式完全交替，并且Kₙ↓K的递减紧列满足T(Kₙ)↓T(K)。允许空实现；不要求T(E)=1，非紧E甚至不在定义域。

\[ D_{K_1}\cdots D_{K_r}T(A):=\sum_{I\subset\{1,\ldots,r\}}(-1)^{|I|}T\!\left(A\cup\bigcup_{i\in I}K_i\right)\le0. \]

必要性：这和恰为\(-P(F\cap A=\varnothing,\ F\cap K_i\ne\varnothing\text{ for every }i)\)。逐实现展开“至少一次命中”的有限乘积即可验证。递减连续来自F∩Kₙ的紧性和嵌套性：全部非空便有共同点，因此命中示性真正下降到交集命中。

充分性先不猜闭集。令q(K)=1−T(K)，把H(K)记为尚未构造的命中位。要求避让A并命中每个Kᵢ，唯一可能的概率是

\[ p(A;K_1,\ldots,K_r)=\sum_{I\subset\{1,\ldots,r\}}(-1)^{|I|}q\!\left(A\cup\bigcup_{i\in I}K_i\right). \]

r≥1时等于−D…DT(A)，所以非负；r=0是q(A)≥0。对任意有限0/1模式，把要求为0的集合并成A，其余作为Kᵢ赋此概率。逐个把某一位为0与为1的两项相加，新增集合的正负项相消，最后剩q(∅)=1；同一消去说明删去坐标后的边缘正是较小表。因此得到真正一致的有限维概率，不只是若干非负数。

## 2. 只扩张可数记录

<a id="choquet-countable"></a>

取T-FELL的可数有限并紧族R。8章扩张给{0,1}ᴿ上的概率及坐标H(K)。有限表直接给H(∅)=0、L⊂K时H(L)≤H(K)，以及H(K∪L)=max(H(K),H(L))，各自a.s.。最后一个关系先由单调性给一边；“都避让但并集命中”的概率为q(K∪L)−q(K∪L)=0。指标及指标对可数，故能在同一满测度集合取得全部关系。

对每个K∈R使用预选外逼近Lₙ∈R，K⊂int Lₙ、Lₙ↓K。单调性给H(Lₙ)↓H*≥H(K)，但EH*=lim T(Lₙ)=T(K)=EH(K)，故H*=H(K) a.s.。预选序列也只有可数条，可以再统一零集。这份好记录集合由可数坐标条件定义，确实可测；在坏记录上统一赋空集。

## 3. 实现为闭集，而非任意随机子集

<a id="choquet-realization"></a>

\[ F=E\setminus\bigcup_{\substack{L\in R\\H(L)=0}}\operatorname{int}L. \]

这是闭集。证明对每个K∈R，H(K)=1恰当F命中K。若H(K)=0，外连续性给某个H(Lₙ)=0，且K⊂int Lₙ，故F避让K。反过来，F若避让K，每个x∈K在某个H(L)=0的int L内；紧性给有限子覆盖。它们的并命中位为0，包含K，单调性便给H(K)=0。不能省掉反方向，否则只是把记录任意闭包化，未证明记录被保持。

对开U，F命中U恰当它命中某个K∈R、K⊂U；事件因此是可数个坐标事件的并。加上可测坏记录上的空集约定，全部开命中可测。T-FELL给F为闭集Polish空间中的随机元，不只是逐点归属可测。

## 4. 任意紧测试与唯一概率律

<a id="choquet-uniqueness"></a>

任取紧K，不要求属于R。选Lₙ∈R外逼近K、Lₙ↓K；F闭保证命中Lₙ的示性下降到命中K。因此P(F命中K)=lim T(Lₙ)=T(K)，全部定义域均兑现。两份闭集律若容量相同，有限表公式给R上所有命中坐标的联合律相同；有限柱事件是生成Fell Borel的π类，π–λ即给概率律相同。

取递增紧穷竭Kₘ，非空事件是命中某个Kₘ，故P(F=∅)=1−lim T(Kₘ)。非空a.s.需要另加此极限为1；不应偷偷混入容量归一化。这个结论也说明容量不只辨认形状，还辨认完全没有形状的那部分概率。

## 5. 两个缺条件的反例

<a id="choquet-counterexamples"></a>

三点空间中令单点T=1/2，两点及三点T=1，空集0。单调、次可加、有限空间的递减连续性均成立，但“三个点全部命中”的有限表概率为−1/2，三阶交替差为+1/2。两两命中互斥，却要让三个单点概率和达到3/2，不可能。

在[0,1]取T(K)=1当K无限，否则0。有限并无限当且仅当至少一个成员无限，所以交替差只有0或−1，完全交替成立。但Kₙ={0}∪{1/k:k≥n}下降到{0}，容量一直1却不趋0。若有表示，每个单点命中概率0，使可数K₁的命中概率也0，与T(K₁)=1矛盾。递减连续性确实排除不能实现的记录。
