# 从预测核到Dirichlet随机概率及后验

## 1. 先构造无限记录，不先假定随机测度

<a id="dp-proof-sequence"></a>

E为非空标准Borel空间，H为概率，α>0，β=αH。对n≥0定义下列预测核，n=0时和为空。每个固定A的评价对过去记录可测；每个过去记录上它是概率。第10章顺序核构造实际给Eᴺ上的唯一律Qβ。

\[ Q_n(x_{1:n},A)=\frac{\beta(A)+\sum_{i=1}^n\mathbf1_A(x_i)}{\alpha+n}. \]

对任意有限可测分区\(A_1,\ldots,A_d\)，记录其颜色，预测核变成T-POLYA-DIRICHLET的有限Pólya规则，参数aⱼ=β(Aⱼ)。其具体颜色字概率只看计数。对任意给定的有限多个Borel测试集合，取它们的全部Boolean原子为共同有限分区，将矩形事件写成有限个颜色字的并。这证明Qβ的全部有限维律置换不变；柱集唯一性再证明完整记录交换。可测归一化只负责存在；上升阶乘才负责交换。

## 2. 指导概率给出所有有限分区的同一份实现

<a id="dp-proof-director"></a>

第43章标准Borel de Finetti给一份P(E)值指导概率G；评价σ代数及P(E)的标准Borel结构已经实际建立。对有限分区，给定G的颜色记录为iid，指导向量是(\(G(A_1),\ldots,G(A_d)\))。另一方面，T-POLYA-DIRICHLET证明该颜色律也由Dir(a)先验混合产生。有限状态上的指导律唯一性识别这两个混合，所以有下式。

\[ (G(A_1),\ldots,G(A_d))\sim\operatorname{Dir}(\beta(A_1),\ldots,\beta(A_d)). \]

以满足这一条件的随机概率之律定义Dβ，即DP(α,H)。每个G(ω,·)已经是可数可加概率；不是先在不可数集合索引上套Kolmogorov扩张，再未经论证声称样本函数可数可加。分区细化相容性由Gamma合并证明，但本页还用实际指导概率完成了路径上的共同实现。若E只有一个点，得到该点的确定概率，一样满足定义。

## 3. 唯一性与参数可测性不是额外假设

<a id="dp-proof-kernel"></a>

有限评价柱集生成P(E)的评价σ代数。任何有限组集合可同时细化成分区，所以定义给这些柱集的全部联合律；π–λ证明Dβ唯一。只用一个可数生成代数也足够：指标评价的可测性由单调类推广到全部Borel集合，概率的相等由π–λ确定。这核对了第43章最小随机概率结构在本章的使用。

后验需要β随数据变化，因此还须证明Dβ是一份参数核。用参数空间(0,∞)×P(E)表示(α,H)。对每个固定可测集合A，上节Qₙ的评价关于参数与过去联合可测，而对A是概率测度；对有限柱集逐次核积分，其概率关于参数可测。路径事件中使评价可测的类为Dynkin类，故Qβ本身是一份到Eᴺ的参数核。顺序构造的存在逐参数成立，核的可测性另由柱集与单调类给出。

固定第43章的同一Borel编码b:E↔B⊂[0,1]。对任意记录取经验有理CDF的limsup，若它构成合法且集中B的概率代码就解码，否则统一取δe₀。由43章的CDF可测解码，这是一个与β无关的Borel映射Ψ:Eᴺ→P(E)。对每个β，交换表示证明Ψ几乎必然是指导概率。于是Dβ(C)=∫1{Ψ(x)∈C}Qβ(dx)，对β可测。这个核使下面的后验公式具有实际可测版本，而非只逐数据点挑一种律。

## 4. 后验核的完整证明

<a id="dp-proof-posterior"></a>

在先抽G∼Dβ、再给定G按无限积核取iid观察的联合空间上工作。给任意实际数据x₁,…,xₙ，令βₓ=β+Σδxᵢ，总质量α+n>0；α+n及βₓ/(α+n)对x可测。因此Kₙ(x,·)=Dβₓ由上节确为概率核，连原模型下概率0的数据也定义好了。

\[ \mathcal L(G\mid X_1,\ldots,X_n)=\mathsf D_{\beta+\sum_{i=1}^n\delta_{X_i}}. \]

证明先取G的有限分区评价的任意有界Borel函数F，以及样本矩形B₁×…×Bₙ。把分区与所有Bᵢ共同细化为R₁,…,Rₘ。向量(G(Rⱼ))具有Dirichlet律；给定它，样本颜色iid：完整积核的颜色字概率只依赖该向量，再作塔式即可验证。有限Dirichlet后验已证：对每个正概率颜色字，后验参数为β(Rⱼ)+字计数。向粗分区合并后，F的后验积分恰是∫F(μ)Dβₓ(dμ)，而且在每个颜色字上只取决于这些计数。零概率字对积分贡献0。

\[ E[F(G)\mathbf1_{\{X_{1:n}\in A\}}]=E\!\left[\mathbf1_{\{X_{1:n}\in A\}}\int F(\mu)\mathsf D_{\beta+\sum_i\delta_{X_i}}(d\mu)\right]. \]

上式先对样本矩形成立，Dynkin类扩张到全部样本事件A。再对概率参数空间中的有限评价柱集用单调类，推广到全部有界Borel F。这正是条件律的积分定义；没有假设实际观察仅携带某一个固定分区的计数信息。Kₙ在全部数据点上都是概率，在可数决定类上的条件身份可统一零集并识别任意其他正则条件版本。

## 5. 预测、二阶结构与条件iid的范围

<a id="dp-proof-prediction"></a>

Gamma矩公式先给EG(A)=β(A)/α。将后验核用于评价，再作塔式得到预测公式。因此先预测后表示、先DP后iid两种实验具有相同的全部顺序核和记录律。这里每次使用“给定G与过去”时的独立性来自整条记录的积核，不是仅有下一项边缘同律。

\[ E[G(A)\mid X_{1:n}]=P(X_{n+1}\in A\mid X_{1:n})=\frac{\alpha H(A)+\sum_{i=1}^n\mathbf1_A(X_i)}{\alpha+n}. \]

将A、B分成A∩B、A差B、B差A及补集，应用Dirichlet矩并相加，得到协方差。它准确量化共同指导概率带来的依赖，不把强化解释为无条件独立。

\[ \operatorname{Cov}(G(A),G(B))=\frac{H(A\cap B)-H(A)H(B)}{\alpha+1},\quad \operatorname{Cov}(\mathbf1_A(X_i),\mathbf1_B(X_j))=\operatorname{Cov}(G(A),G(B))\quad(i\ne j). \]
