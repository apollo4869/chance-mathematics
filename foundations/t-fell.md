# T-FELL：闭集空间、拓扑与可测观察

返回[第51章](../chapters/51-random-closed-sets.md#sets-fell)。E始终为非空局部紧第二可数度量空间，闭集空间包括空集。只用T-RIESZ已构造的紧穷竭和截断，不预用Choquet表示。

## 1. 给无穷远一个位置

<a id="fell-compactification"></a>

T-RIESZ给连续φ，其下水平集紧。\(\rho(x,y)=d(x,y)+|\phi(x)-\phi(y)|\)仍相容，且每个闭有界球在φ的一个紧下水平集中闭，故紧。固定此proper度量。可数稠密中心、正有理半径的闭球及其有限并组成可数紧族R，添入空集。它对有限并封闭，并非要求对差封闭。任意紧K⊂开U可选L∈R，使K⊂int L⊂L⊂U：逐点选闭包在U内的小球，用稠密中心及有理半径缩调，再取有限内部覆盖。

递归可选Lₙ∈R，K⊂int Lₙ、Lₙ₊₁⊂int Lₙ、Lₙ⊂{ρ(x,K)≤1/n}，故Lₙ↓K；每步在上个内部与距离邻域交中覆盖K。对R内每个K预先固定一条这样的序列，只有可数条。

为证明紧化，不另借拓扑黑箱。取可数个[0,1]值紧支撑连续fⱼ，分离E的点并生成拓扑，且每点有一个fⱼ>0；相对紧可数基的截断与有理阈值给此族。将x映到立方体坐标(fⱼ(x))，把∞映到零。像加零紧：序列若在某个紧穷竭内有无限项，抽收敛子列；否则抽逃出每个紧集的子列，各紧支撑坐标趋0。立方体度量使X=E∪{∞}紧可度量。E上原拓扑由坐标恢复；∞的邻域恰含紧集的补。E紧时∞孤立，仍采用此约定。

## 2. 从Hausdorff度量到Fell拓扑

<a id="fell-polish"></a>

对X的非空紧集定义\(d_H(A,B)=\max\{\sup_{a\in A}r(a,B),\sup_{b\in B}r(b,A)\}\)，r为紧化度量。这是度量，且\(d_H(A,B)=\|r(\cdot,A)-r(\cdot,B)\|_\infty\)：三角不等式给一边，分别在A、B上取测试给另一边。

X的有限ε网的所有非空子集给紧集空间的有限ε网，故全有界。若Aₙ为Hausdorff-Cauchy，距离函数一致趋非负1-Lipschitz函数g。选aₙ∈Aₙ并抽紧子列可见g有零点。令A={g=0}。对每个x，选最近点aₙ∈Aₙ，抽至a∈A，得g(x)=r(x,a)；Lipschitz又给g(x)≤r(x,A)，所以g就是到A的距离。因此Aₙ→A，完备。全有界且完备给紧性，也给可分性。

\(F\mapsto F\cup\{\infty\}\)将\(\mathcal F(E)\)双射到含∞的非空紧子集，后者Hausdorff闭，故紧Polish。Hausdorff拓扑等于Vietoris拓扑：包含在开V的条件由紧集与V补的正距离保证为开，命中开V由一个命中点的小球保证为开；反向对紧集选有限ε/2网，要求各网球命中及全体包含在ε邻域，便得到Hausdorff ε球内的邻域。

在含∞的子空间，命中含∞的开集自动成立；其余就是命中E的开U。包含在开V中只需考虑∞∈V，此时K=X∖V是E的紧集。拉回拓扑因此恰由\(H_U=\{F:F\cap U\ne\varnothing\}\)与\(M_K=\{F:F\cap K=\varnothing\}\)生成，即Fell拓扑。空集对应{∞}。

## 3. 开命中与紧命中生成同一可测结构

<a id="fell-effros"></a>

紧命中\(H_K=M_K^c\)是Fell闭集。取\(U_n=\{x:\rho(x,K)<1/n\}\)，有\(H_K=\bigcap_nH_{U_n}\)：若F命中所有Uₙ，从一个紧邻域中的命中点抽子列，闭性给F∩K非空。故紧命中在开命中生成的Effros σ域内。所有Fell子基本集都在此域，第二可数使每个开集可写为可数个有限子基本交的并，故Fell Borel恰等于Effros。

更小的可数决定族是R的紧命中：开U的每一点属于某个K∈R、K⊂U的内部，所以\(H_U\)是这些\(H_K\)的可数并。反方向由刚才成立。这也证明随机闭集只需全部开命中事件可测，无需原概率空间标准Borel；其律是闭集Polish空间上的Borel概率。只给单点归属示性的可测性，不能冒充已给出全部开命中。

## 4. 序列与运算的边界

<a id="fell-sequences"></a>

Fₙ→F等价于：(i)每个x∈F有最终定义的xₙ∈Fₙ趋x；(ii)任意子列选点xₙⱼ∈Fₙⱼ若在E内收敛，其极限在F。必要性中开命中给(i)，逐个半径球即可选点；若(ii)失败，在F外极限附近选不交F的紧邻域，违反最终避让。充分性中(i)保证应命中的开集；若某个应避让的紧K仍无穷多次命中，在K抽子列就违反(ii)。空集极限的下界条件为空。

有限并连续：下界选点来自某个分量，上界子列再取来自同一分量的子列。交不连续：Aₙ={0}、Bₙ={1/n}都趋{0}，交却恒为空。若a:E→E连续且proper，a(F)闭且F↦a(F)连续：像中收敛序列的原像留在紧集，可抽子列，这同时证明闭性与上界；下界由连续性。缺proper时像可以不闭，不能无条件套连续映射定理。

## 5. 局部紧不能无声删去

<a id="fell-nonlocal"></a>

在无限维可分Hilbert空间，同样的开命中/紧避让拓扑不能分开∅和{0}。∅的基本邻域避让紧K；{0}的基本邻域命中有限个含0的开Uᵢ，并避让有限个不含0的紧Lⱼ。在⋂Uᵢ内取小球，它不可能包含在紧K∪⋃Lⱼ中，否则0有紧邻域。选球内y避开该紧并，{y}便属于两个邻域。因此该Fell拓扑非Hausdorff；一般Polish情形不能沿用本篇紧Polish定理。
