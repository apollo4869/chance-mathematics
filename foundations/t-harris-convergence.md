# 再生时钟、成功耦合与总变差极限

## 1. 一个不借混合定理的可数链引理

<a id="convergence-countable"></a>

设可数不可约链Q有不变概率ρ。所有\(\rho _i\)>0：从某个正质量状态到任一j的一条正概率路径，不变性会把正质量传给j。在ρ平稳路径上，Poincaré回归应用于{X₀=i}，给\(P_i\)(再次返回i无穷次)=1。再在i的反复返回处尝试一条通向j的固定有限路径，强Markov与几何失败界给从i最终到j的概率1。故所有状态常返。

还可得到精确平均返回时间，不用先引用收敛。双向平稳链由一致有限维分布构造，反向核\(\rho _j\)\(Q_{ji}\)/\(\rho _i\)仍不可约并保持ρ。对过去方向作同一Poincaré论证，几乎每条平稳路径有最近一次访问i。按这次访问发生在−n分割事件，得到下式；非负求和合法。对j求和给\(E_i\)\(\tau _i\)⁺=1/\(\rho _i\)。

\[ \rho_j=\rho_i E_i\sum_{n=0}^{\tau_i^+-1}\mathbf1_{\{X_n=j\}},\qquad E_i\tau_i^+=\frac1{\rho_i}. \]

不变律存在而不可约性失败时，这个推论不能跨越闭类。这里的引理只用于下面明确写出的可数时钟链，不假定一般Harris收敛。

## 2. 两个再生时钟怎样相遇

<a id="convergence-clocks"></a>

令L为正整数周期，μ=EL<∞，并假设gcd{l:P(L=l)>0}=1。定义剩余时钟Z：j≥1时下一步为j−1；在0时独立抽L，下一步为L−1。状态为S={j≥0:P(L>j)>0}。直接逐坐标验证\(\rho _j\)=P(L>j)/μ是不变概率；求和为1。所有j能降到0，0也能到任一j，所以不可约。

两个独立时钟的乘积核保持ρ⊗ρ。乘积不可约需要无周期条件，不能省略：0的回路长度是L支持的和。其最大公约数1由有限个支持长度已经达到。以其中一个a取模，非负组合的余数形成有限群的子半群，因此是全体可达余数组；选每个余数的一个非负代表，再加a，说明所有充分大的整数都是回路长度。接上固定进出路径，任意两个状态之间充分长的步数都有正概率。两时钟便有共同长度路径，故乘积不可约。

由上节引理，乘积从每一对剩余状态最终命中(0,0)，且命中时刻有限。随机初始延迟只需逐对条件化再积分，并不要求其期望有限。这个论证没有使用待证的总变差混合，也未循环调用一个未经建立的更新定理。

## 3. 时钟耦合怎样变成路径耦合

<a id="convergence-marks"></a>

先分别抽两份初始延迟，再让剩余时钟独立运行，直到第一次共同再生T，此后使用共同周期。不能把预先抽好的周期长度当作与周期起始状态独立：长度一般依赖起始状态。正确做法是对每个已完成长度l，从上专题的“给定长度的半开周期标记核”抽整段标记。标记包含起点而不含终点，所以相邻标记没有重叠坐标冲突。

T以前的长度抽取只用过去的长度，T是这些时钟的停止时刻；尚未抽取T以后周期长度。因此T处的新状态仍可取独立ν，令两坐标同值，然后用共同原始P核生成未来。单条边缘中，各周期长度及其条件标记重新组合后，正是原来独立周期的联合分布；初始前缀也按其延迟条件律抽取。标准Borel析取保证所有这些核存在且可测。

这是完整路径律的耦合，不必是两个当前状态的Markov耦合。T以后两条路径逐时相同。任取初态x及π初态，初始再生延迟均有限，由耦合不等式得到主结论。

\[ d_{\rm TV}(P^n(x,\cdot),\pi)\le \mathbb P_{x,\pi}(T>n)\longrightarrow0. \]

周期跨度为d>1时，时钟相位可能永不相遇，故不能删掉条件。对任意初始概率η，从每个x的结论和有界收敛还得ηPⁿ→π；不要求η有有限V矩。

## 4. 从边缘遗忘到平稳记录的混合

<a id="convergence-mixing"></a>

在双向π平稳P链上，过去到时刻0的条件未来只由X₀决定。时刻n以后的整条路径是从\(X_n\)出发的一份概率核，因此核收缩给下式。先对有限柱事件证明Markov条件恒等式，再以单调类扩到过去、未来σ域；可数生成性使总变差上确界可用一个可数决定代数表示，因而可测。

\[ \sup_{\substack{A\in\sigma(X_j:j\le0)\\B\in\sigma(X_j:j\ge n)}}|\mathbb P_\pi(A\cap B)-\mathbb P_\pi(A)\mathbb P_\pi(B)|\le\int \pi(dx)\,d_{\rm TV}(P^n(x,\cdot),\pi)\longrightarrow0. \]

所以得到强混合及遍历性，但没有统一速率。若一个平移不变事件A存在，以有限柱事件D作L¹逼近，再把D平移到远处，混合给P(A)=P(A)²；这是由混合推出不变σ域平凡的实际步骤。反向不成立，第41章的两点交换仍是反例。

## 5. 多步小集与证明边界

<a id="convergence-skeleton"></a>

若已给定m≥1，使Q=Pᵐ满足本章全部再生假设、有限平均周期及周期跨度1，则Q有唯一不变概率π。πP也为Q不变，因为P与Q交换；唯一性给πP=π。写n=mk+r，0≤r<m，总变差收缩给Pⁿ(x,·)→π。Q的一个再生周期对应原链mL步；不能把这份原时间的跨度m误当成P必然周期m，剩余r正由πP=π处理。

需要恢复中间m−1个状态时，第10章标准Borel条件核给P的有限桥，按骨架端点析取并填入；两个相等端点以后用共同P演化即可。这里对指定初始律下的路径及骨架记录析取，不假定任意参数桥的共同版本。这说明多步minorization不是任意省略中间路径的许可证。

本专题完整证明明确再生条件下的Harris收敛以及所给骨架推广。不把“任意抽象非周期Harris核自动具备所需全初态常返骨架”的一般提取定理算作已证；那是单独的可测空间结构问题，不能由一个minorization定义或本证明的链接替代。回到[第42章](../chapters/42-harris-coupling.md#harris-convergence)。
