# T-LOCAL-TIME：从凸逼近到整条占用密度

配套[第37章](../chapters/37-local-time.md#local-smoothing)。通常滤过，连续半鞅X=X₀+M+V，M从0出发、V连续有限变差从0出发；括号A=[M]。先局部化使初值、路径幅度、A和V的总变差有界，最后按整数时域及局部化时刻拼合。本页使用32章C² Itô、31章等距/括号、35章连续鞅高阶上界，不使用本章游程或38章一般Revuz。

## 1. 平滑绝对值实际产生什么

<a id="local-proof-tanaka"></a>

取非负对称C∞核ρ、支撑于(−1,1)、积分1，以ρᵋ卷积绝对值。导数绝对值≤1，二阶导数为2ρᵋ。对每个固定a，导数逐点趋sgn，且sgn(0)=0。对M部分由等距及Doob，误差的最大平方期望至多4E∫|导数差|²dA，DCT给0；对V部分用路径总变差支配，最大误差趋0几乎必然。函数本身一致误差≤ε。因此下面右侧定义的L对固定a是连续适应过程，卷积二阶项ucp趋于它。

\[ L_t^{a,\mathrm{sym}}=|X_t-a|-|X_0-a|-\int_0^t\operatorname{sgn}(X_s-a)dX_s,\qquad \int_0^t\rho_\varepsilon(X_s-a)dA_s\ \xrightarrow{\mathrm{ucp}}\ L_t^{a,\mathrm{sym}}. \]

每个逼近项非负且随t递增；从ucp抽一致几乎必然子列，得到同样性质。积分按参数a可联合选取：先以可预测简单过程逼近有界Borel函数(s,ω,a)↦sgn(Xₛ(ω)−a)，在有限a区间的乘积能量测度中延拓；Fubini及等距给联合可测版本，并在每个固定a与已有积分一致。下面更强的空间版本会消除逐点选择的不确定性。

## 2. 先证明占用公式，再处理单点括号

<a id="local-proof-occupation"></a>

对有界支撑的连续f，把上节卷积项关于a积分。确定积分的Fubini给∫₀ᵗ(f*ρᵋ)(Xₛ)dAₛ。局部化后，Tanaka右侧的p阶矩在紧a区间一致有界：绝对值项有界，V积分被总变差控制，M积分的括号≤A，由35章上界控制任意p≥2。相同界也控制平滑项。因此逐a的L¹收敛可再对a用DCT，左侧趋∫f(a)Lᵃᵗda；右侧由f一致连续趋∫f(X)dA。

\[ \int_{\mathbb R}f(a)L_t^{a,\mathrm{sym}}da=\int_0^tf(X_s)dA_s. \]

先对可数稠密的连续紧支撑测试及有理t取共同零集。连续性及局部可积性给所有t，再由有限测度唯一性在每条路径推广到任意非负Borel f。因此由X推前的括号占用测度逐路径绝对连续，特别地对全部水平a同时具有零单点质量。于是∫\(\mathbf1_{\{X=a\}}\)dM的括号为0，过程不可分辨地为0。这一步在占用公式之后，避免用待证的单点性质证明自身。

## 3. 右局部时及一般半鞅的空间跳跃

<a id="local-proof-regularity"></a>

若要在所有水平选取一致版本，应明确导数在尖点的约定。令sgn₋(0)=−1，其余点等于sgn；定义右局部时Lᵃ⁺为Tanaka右侧中以sgn₋替换sgn的过程。也可用二阶导数集中于(a,a+ε)的凸逼近，直接得到其非负、时间递增性。它与对称版本之差为∫\(\mathbf1_{\{X=a\}}\)dV。V推前总变差为有限测度，只有可数个非零原子，故两版本对几乎处处a相同，占用公式保持。

\[ L_t^{a,+}=|X_t-a|-|X_0-a|-\int_0^t\operatorname{sgn}_{-}(X_s-a)dX_s,\qquad L_t^{a,+}-L_t^{a-,+}=2\int_0^t\mathbf1_{\{X_s=a\}}dV_s. \]

空间正则性不能只说“取连续版本”。记Jᵃ=∫sgn₋(X−a)dM。对a<b，差为在[a,b)上的−2倍积分，端点不影响括号。占用及前述一致矩界给，对任意整数p≥2，

\[ E\|J^b-J^a\|_{C[0,T]}^{2p}\le C_pE\left(\int_a^bL_T^{y,+}dy\right)^p\le C_{p,K,T}|b-a|^p. \]

最后一步是积分Hölder：p次幂≤(b−a)^{p−1}∫(Lᵞ)ᵖdy。对C[0,T]值随机变量，23章的二进网格证明原样适用：邻点差阈值\(2^{-n\alpha}\)，并集概率可求和只需2pα<p−1；逐级连接给空间α-Hölder版本，任意α<1/2可由p任意大得到。J于是关于a连续，取值于连续时间路径空间。

有限变差部分对a右连续并有左极限，且在C[0,T]范数成立：aₙ↓a时被积符号逐点趋sgn₋，用总变差DCT；aₙ↑a时得到相反的尖点取值。两极限之差恰为上式。绝对值项本来连续，故L⁺在空间右连续有左极限、在时间连续，空间跳跃公式成立。先对有理a核对Tanaka，再用这份正则性延到所有a，所有身份都在同一零集之外。对M、V去局部化时，停止前Tanaka表达式唯一，版本相容。

若X为连续局部鞅，V=0，则L⁺空间连续，也等于对称局部时。特别对Brownian B，可取联合连续L。每个固定紧矩形上，联合连续性给窄带占用逼近一致：先对空间卷积用占用公式，再用连续函数在紧集一致连续。一般半鞅则只能直接断言单侧平均对每个a在C[0,T]中趋Lᵃ⁺；不能擅自把空间跳跃抹去。

\[ L_t^a(B)=\lim_{\varepsilon\downarrow0}\frac1{2\varepsilon}\int_0^t\mathbf1_{\{|B_s-a|<\varepsilon\}}ds,\qquad L_t^{a,+}(X)=\lim_{\varepsilon\downarrow0}\frac1\varepsilon\int_0^t\mathbf1_{\{a\le X_s<a+\varepsilon\}}d[M]_s. \]

## 4. 支持、反射与逆局部时间

<a id="local-proof-inverse"></a>

如果某闭时间段上X始终与a有正距离，窄曲率逼近项在该段为0，故局部时不增加。以可数有理时间段及水平的右连续性推广，dLᵃ⁺支撑于{X=a}。Brownian取a=0，Tanaka为|B|=β+L，其中β=∫sgn(B)dB。单点普通时间为0给[β]ₜ=t，由33章Lévy刻画β为Brownian。

确定Skorokhod引理可直接证明：对连续w、w(0)=0，若r=w+k≥0，k从0连续递增且只在r=0增加，则k(t)=supₛ≤ₜ(−w(s))⁺。非负性给≥；若严格大于该上确界，在首次产生多余增量以前r已严格正，与支持条件矛盾。故L=−minβ，且L∞=∞。Brownian在任何正时间段既有正值又有负值，由反射原理或26章的首达概率得到，因此从任一零点之后的局部时立刻增加。

\[ \tau_\ell=\inf\{t:L_t^0>\ell\},\qquad E e^{-\lambda\tau_\ell}=e^{-\ell\sqrt{2\lambda}},\qquad \ell\ge0,\ \lambda>0. \]

τ是右连续逆，有限且为停止时刻，Bτ=0、Lτ=ℓ；广义逆身份由L连续、无界和零集支持给出。固定ℓ时其规律由上述Skorokhod表示等于β首达−ℓ。解½h″=λh并在有界区间停止，或使用26章首达密度的Laplace积分，得到指数式。强Markov于τℓ及局部时的加性给τ在ℓ参数下独立平稳增量。加性直接来自Tanaka：平移时间后差满足同一表达式；先对有理时刻、停止时刻的网格逼近再用连续性，取得所需共同版本。

## 5. 变换公式与可预测性边界

<a id="local-proof-transform"></a>

若h是严格递增C²函数、h′>0，对Y=h(X)有[Y]=∫h′(X)²d[M]。两边占用公式及变量代换说明，作为密度，\(L^{h(a)}\)(Y)=h′(a)Lᵃ(X)对几乎处处a成立；在两边连续的范围由连续性延到全部a，右局部时范围则以单侧正则性延伸。对36章非退化SDE，有限变差部分在固定水平的积分为b(a)∫\(\mathbf1_{\{X=a\}}\)dt=0，因为σ在紧集有正下界、括号单点占用为0；故其局部时联合连续。

\[ \int_0^tf(X_s)ds=\int_I f(a)\frac{L_t^a(X)}{\sigma(a)^2}da,\qquad t<\zeta,\quad f\ge0. \]

普通时间的密度因而不是任意扩散的L本身，而是L/σ²。指标\(\mathbf1_{\{X=a\}}\)可预测，因为X连续适应、可预测σ-代数对Borel复合封闭。其对连续局部鞅的积分为0，却可对dL积分出L本身；这两份积分使用不同的积分测度，不构成矛盾。返回[正文的两个时钟](../chapters/37-local-time.md#local-two-clocks)。
