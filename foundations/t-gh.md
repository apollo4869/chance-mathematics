# T-GH：公共空间、对应与紧几何空间的完备性

本页完成[第55章](../chapters/55-metric-measure-limits.md#geometry-common)所需的确定性几何工具。对象均非空、紧；带根时等距必须保存根。没有引用后文的度量空间极限定理。

## 1. 先把不同的空间放到一起

<a id="gh-gluing"></a>

设X、Y分别等距嵌入Z₁、Z₂，且两份Y被识别。异侧点的距离取所有经过Y的路径长度的下确界。它不改变任一原空间的距离：任何离开原空间又返回的路段，其两个Y端点之间的长度至少是Y中的原距离，所以可以用原路段替换。三角不等式来自路径拼接。若Y闭而异侧两点的距离为0，则各自到Y的距离为0，它们均在Y且是同一点。故这是识别后的真度量。可分空间的此种有限或可数链式粘合仍可分，最后取完备化。紧空间两两粘合的结果紧。

\[ \rho(x,z)=\inf_{y\in Y}\{d_{Z_1}(x,y)+d_{Z_2}(y,z)\}. \]

公共空间可以总选为两份对象之并：从任意见证空间限制距离即可。因此紧对象的两空间比较不需要非可分背景。下文三角不等式都使用这一粘合，而不是要求所有空间原本已有统一坐标。

## 2. 对应与搭桥度量

<a id="gh-bridge"></a>

对应R是X×Y中向两侧都满射的关系。其失真是对应点对之间距离差的上确界。带根对应还要求根对属于R。以闭包替代R不改变满射性与失真，因为两侧紧且距离连续。令D为失真，选c>D/2，在X与Y的无交并上保留内部距离，定义如下交叉距离。

\[ \begin{aligned}\operatorname{dis}R&=\sup_{(x,y),(x',y')\in R}|d_X(x,x')-d_Y(y,y')|,\\
\rho_c(x,y)&=\inf_{(a,b)\in R}\{d_X(x,a)+c+d_Y(b,y)\}.\end{aligned} \]

只须检验会穿过两条桥的三角不等式。例如从x经Y中的y再到x′，若两桥使用(a,b)、(a′,b′)，该路径长度至少为dX(x,a)+2c+dY(b,b′)+dX(a′,x′)，又至少为dX(x,a)+dX(a,a′)+dX(a′,x′)，因为2c≥D。这不小于dX(x,x′)。另外两种混合三角式由下确界及原三角式直接得到。异侧距离至少c，故不产生零距离。每一对R中点的距离至多c，因此Hausdorff距离至多c；根对的距离也至多c。

## 3. GH距离的两种等价定义

<a id="gh-equivalence"></a>

\[ \begin{aligned}
d_{GH}(X,Y)&=\inf_{Z,\phi,\psi}d_H^Z(\phi X,\psi Y)
=\tfrac12\inf_R\operatorname{dis}R,\\
d_{rGH}(X,Y)&=\inf_{Z,\phi,\psi}
\max\{d_H^Z(\phi X,\psi Y),d_Z(\phi\rho_X,\psi\rho_Y)\}\\
&=\tfrac12\inf_{R\ \mathrm{rooted}}\operatorname{dis}R .
\end{aligned} \]

嵌入皆等距。搭桥论证给出“≤”。反向，在Hausdorff距离和根距都小于r的公共空间中，取所有交叉距离至多r的点对（或先稍加松弛），得到满射且包含根对的对应；两次三角式给失真至多2r。令r下降到定义中的下确界。粘合给三角不等式，对称性与非负性直接成立。

零距离需要真正证明等距。设误差rₙ趋0，固定X的一列稠密点xⱼ，含根；在第n个对应中选yₙⱼ，根的对应像明确选为Y的根。对j逐个用Y的紧性取对角子列，使每个yₙⱼ收敛。极限点之间的距离等于对应xⱼ的距离，因此这一定义扩张为X到Y的等距映射f。它满射：给y∈Y，选与y对应的xₙ，取X中收敛子列xₙ→x，再用稠密点近似x及失真趋0，得到f(x)=y。根由根对保存。无根情形同理而不指定首点。

## 4. 有限网如何近似整个空间

<a id="gh-nets"></a>

若A是X中的有限ε网，含根时将根加入A，则原空间中的嵌入立即给rGH(X,A)≤ε。有限实距离可以改为有理距离而不破坏三角式：取有理η>0，把每个非对角距离向上取整到η的整数倍。因为向上取整满足次可加不等式，所得仍为度量；每个距离变化小于η。按相同标号配对，GH误差不超过η/2。

\[ d^\eta(i,j)=
\begin{cases}\eta\lceil d(i,j)/\eta\rceil,&i\ne j,\\0,&i=j.\end{cases} \]

所有有限有理距离矩阵及根标号只有可数多个，且如上稠密。这既证明可分性，也说明有限近似需要保留点对距离，而不需要保留画图位置。

## 5. 完备性：为一条Cauchy列建立共同空间

<a id="gh-complete"></a>

从Cauchy列取子列，使连续两项的距离小于εᵢ=2⁻ⁱ。用见证嵌入逐次沿共同的第i项粘合，在一个完备可分Z中实现所有项，并使相邻Hausdorff距及根距小于εᵢ。其并全有界：给δ>0，选N使尾和小于δ/3，尾部各空间都在X(N)的δ/3邻域内，用X(N)的有限δ/3网即可；前N项的并也有有限δ网。因此并的闭包K紧。

K中的非空紧集Hausdorff完备性也可直接看出。若紧集Aᵢ为Hausdorff Cauchy，距离函数d(·,Aᵢ)一致Cauchy；极限q的零集A非空，由各选aᵢ和K的紧性可见。若Hausdorff距不趋0，一方向可选极限零集外的聚点矛盾；另一方向在A上用q的一致逼近。故Aᵢ→A。根形成Cauchy列，其极限在A中。整个原Cauchy列也由三角式收敛。于是紧空间等距类及带根等距类在各自距离下均为Polish空间。

## 6. 紧性判据及其可测读数

<a id="gh-compactness"></a>

一族紧空间在GH或带根GH下相对紧，当且仅当直径一致有界，且对每个r>0，覆盖全空间所需开r球数N(r)一致有界。必要性：从有限GH近似族转移其有限网；直径之差至多两倍GH距离。充分性：对固定误差η，取η网，点数一致有界且距离一致有界，向上有理取整后只有有限多个可能矩阵。于是该族全有界，完备性给相对紧。根加入网只多一个点，证明不变。

直径连续。事件N(r)≤m是开集：一个有限开r球覆盖紧X时，中心到点的最小距离的最大值严格小于r；足够小的GH误差转移中心后仍覆盖。因此这些读数Borel可测。由此紧性判据能够用于随机空间，而不只是确定性图形。回到[第55章的几何紧性](../chapters/55-metric-measure-limits.md#geometry-polish)。
