# T-PREDICTABLE-SYMMETRY：采样、可缩性与信息顺序

本专题证明无限序列的确定性子列不变与交换性的等价，以及明确可预测采样/变换下的保律结果。状态空间非空标准Borel；群作用联合可测。只使用第10章条件核、第41章Birkhoff、第43章实际de Finetti及先前离散滤过工具。返回[第45章](../chapters/45-invariance.md#sampling-question)。

## 1. 子列不变为什么已经很强

<a id="sampling-spreadable"></a>

称无限序列可缩，或spreadable，若任意确定性严格递增整数序列抽出的子列与原列有相同有限维分布。交换性立即蕴含此性质：任意有限递增指标组可以由一个有限置换把初始指标移过去。反向需要无限性。

在记录空间上，可缩性首先给左移不变，即平稳。令𝓘为该左移的不变σ代数。取任意有限个有界Borel函数f₁,…,fₖ。把前kN个位置分成k个依次排列、长度均为N的块；展开块平均乘积，每一项恰是一个递增指标的混合矩，所以其期望不随N变化。

\[ \mathbb E\prod_{j=1}^k f_j(X_j)=\mathbb E\prod_{j=1}^k\left[\frac1N\sum_{i=(j-1)N+1}^{jN}f_j(X_i)\right]. \]

第41章逐点遍历定理说明每一块平均趋于E[fⱼ(X₁)|𝓘]：第j块正好是j倍的前jN平均减去j−1倍的前(j−1)N平均。函数有界，乘积可用控制收敛。因此上式极限是这些条件期望的乘积的期望，显然不因调换fⱼ顺序而改变。矩形指标和π–λ遂给交换性。这里没有将平稳本身误当成交换性；关键是所有递增指标混合矩相同，才有块乘积恒等式。

由第43章，此交换列有唯一指导随机概率ν，给定ν后iid。还可识别ν(A)=E[\(\mathbf1_A\)(X₁)|𝓘]几乎处处：遍历极限和第43章经验极限对同一A相等，再在可数决定类上统一零集，由测度唯一性推广。取ν为实际概率值随机元，不把逐A选择的任意版本拼成一份测度。有限列没有任意长块，反向结论不能照搬。

## 2. 合法跳过观察，而不是挑中想要的答案

<a id="sampling-skipping"></a>

设Xₙ适应滤过𝓕ₙ，且对每个n，Xₙ在𝓕ₙ₋₁条件下的分布都是固定概率μ。允许滤过包含事前辅助随机性，但这项条件必须仍成立。取严格递增、几乎处处有限的整数时刻τⱼ，要求{τⱼ=n}∈𝓕ₙ₋₁。这比一般停止时刻更强：决定是否保留第n次，不能先看第n次结果。

\[ \mathbb E\prod_{j=1}^k f_j(X_{\tau_j})=\prod_{j=1}^k\mu(f_j)\quad(f_j\text{ bounded Borel}). \]

证明从最后一项展开。事件{τₖ=n}上，前面被选中的值都已出现在n以前；其乘积乘该事件指标属于𝓕ₙ₋₁。条件期望把最后fₖ替换为μ(fₖ)，再对n求和，利用τₖ有限把事件指标之和变成1。倒推k即得公式。对带符号测试，绝对值由有界乘积控制，可数求和合法。该证明同时说明为何仅说“随机时刻”远远不够。

例如公平硬币中首次出现1的时刻是几乎处处有限的停止时刻，却不是上述可预测选择；被选值恒为1。若τ有正概率为∞，再条件于“选择成功”，也可能改变指导律。具体地，交换混合硬币先看X₁，只在X₁=1时保留后续记录；条件于成功会把隐藏参数的分布乘以该参数再归一化。局部规则有定义，不代表条件后的抽样仍保原律。

## 3. 条件iid使同一证明适用于交换列

<a id="sampling-exchangeable"></a>

设ν是指导概率，在扩大的滤过σ(ν)∨𝓕ₙ₋₁下，新Xₙ的条件律为ν。取关于此滤过可预测且全部有限的递增采样时刻；通常只用观察过去及独立辅助随机性便满足信息要求。上节证明中把常数μ(f)改成σ(ν)可测的ν(f)，并在各步同时乘任意有界σ(ν)测试，得到选后记录在ν条件下仍iid ν。因此选后无限列与原交换列同律，指导律未被改变。

注意，这不是说任意包含未来信息的扩大滤过都可用。若把下一结果预先加入，条件iid前提已失效。反向鞅识别指导律与这里的事前采样证明解决不同问题，不可用“交换性”一词略过采样条件。

## 4. 允许依赖过去的群变换

<a id="sampling-transform"></a>

令G为标准Borel群，联合可测地作用于E，μ对所有g不变。若新Xₙ给定𝓕ₙ₋₁仍为μ，而gₙ是𝓕ₙ₋₁可测的G值随机元，则Yₙ=gₙXₙ给定过去仍为μ；所以整个Y列iid μ。核证明如下：先对矩形函数a(ω)b(x)验证条件积分，再用函数单调类推广到一切有界𝓕ₙ₋₁⊗B(E)可测函数，最后代入f(gₙ(ω)x)。

\[ \mathbb E[f(g_nX_n)\mid\mathcal F_{n-1}]=\int f(g_nx)\,\mu(dx)=\mu(f). \]

这是一个共同可测核的代入，不是把对每个固定g分别成立的几乎处处等式，未经证明地代入随机g。条件于ν，若ν几乎处处本身G不变，同一论证给交换列的可预测变换版本。均匀球面噪声的事前旋转、高斯向量噪声的事前正交变换都是实例；根据当前噪声再旋转到固定半球则不满足前提。一般混合正态序列的条件方差可以随机，事前旋转保留的是同一随机方差下的条件律，而不是强行变成无条件独立。
