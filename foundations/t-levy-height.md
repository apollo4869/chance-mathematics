# T-LEVY-HEIGHT：相容谱系、紧Lévy森林与高度识别的边界

回到[第58章](../chapters/58-multifurcation.md)。采用[T-CSBP-SEMIGROUPS](t-csbp-semigroups.md)的临界/次临界有限均值非线性机制及Grey条件。依据Duquesne–Winkel的[2007年公开论文](https://perso.lpsm.paris/~tduquesne/Documents/Duquesne_Winkel_PTRF_2007.pdf)第4–5节重建约化森林、紧性和质量。最后单列尚未补齐的经典Lévy路径高度识别，不将本文件标题误当全部完成证据。

## 1. 染色为何必须与谱系同时构造

<a id="lh-colour"></a>

固定b>0。令\(\mathcal F_\lambda\)有Poisson\((b v_\lambda)\)个祖先，各自独立，后代母函数\(g_\lambda\)，每条个体寿命边独立服从Exp\((c_\lambda)\)，共同连接在根。每棵树有限几乎必然；根可以在没有祖先时单独存在。给每片终端叶一个独立的[0,λ]均匀标记；只保留标记≤μ的叶及其祖先路径，压缩仅有一个保留孩子的顶点。压缩是边长相加，保留的是等距子树。

记一个祖先的树至少有一片保留叶的概率为q。若其叶数为L，则不保留概率\(r=E(1-\mu/\lambda)^L\)满足\(r=g_\lambda(r)-p_0\mu/\lambda\)。因为有限树几乎必然，此等式可先截代再单调取极限，取最小非负解。代入g得\(\psi(v_\lambda(1-r))=\mu\)，于是\(q=v_\mu/v_\lambda\)。

## 2. 保留树的后代与寿命核

<a id="lh-thinning"></a>

条件于至少一个保留孩子，原后代数的各孩子独立以概率q保留。一个有d≥2个保留孩子的分叉，其未归一化概率是\(q^d g_\lambda^{(d)}(1-q)/d!\)。有一个保留孩子的概率是\(q g_\lambda'(1-q)\)，叶端保留概率为\(p_0\mu/\lambda\)。除以q得条件分布；压缩一孩链后，再除以\(1-g_\lambda'(1-q)\)。因此压缩后零孩概率为

\[ \frac{p_0\mu/\lambda}{q(1-g_\lambda'(1-q))}
=\frac{\mu}{v_\mu c_\mu},\qquad
c_\lambda(1-g_\lambda'(1-q))=\psi'(v_\mu)=c_\mu. \]

d≥2的概率同样变成\(g_\mu\)的第d项。原寿命与繁殖独立，每段保留路径包含几何个Exp\((c_\lambda)\)寿命，终止概率\(1-g_\lambda'(1-q)\)。其Laplace变换为\(c_\mu/(c_\mu+s)\)，即Exp\((c_\mu)\)。繁殖标记与指数寿命的独立性以及分枝构造给出压缩后不同边、子树的独立性。祖先Poisson稀释后参数为\(b v_\mu\)。所以保留森林精确具有\(\mathcal F_\mu\)的律。

多级染色先用独立均匀标记，阈值的复合等于直接阈值，因此约化核满足复合律。有限平面树、正实边长、有限叶标记构成可数个欧氏空间的Borel并；每次约化及等距嵌入均可测。对整数λ的相容有限维律用第8章可数延拓，保留嵌入与标记，得到一个共同空间上嵌套的\(\mathcal F_1\subset\mathcal F_2\subset\cdots\)。也可先取所有正有理阈值；以下整数族已足够构造极限。

## 3. 高度有界不等于紧：必须数出长分支

<a id="lh-compact"></a>

令\(Z_\lambda(h)\)为高度h处存活的个体数。分枝首寿命方程给每个祖先的存活概率\(u_h(v_\lambda)/v_\lambda\)，因而森林最高点\(H_\lambda\)满足\(P(H_\lambda\le h)=\exp(-b u_h(v_\lambda))\)。同一耦合下高度递增，极限H的分布为\(\exp(-b v(h))\)，v由CSBP专题给出；v(h)↓0，故H有限几乎必然。

固定ε>0及j≥0，数出高度jε上仍有长度至少ε后裔路径的点。该数\(A_\lambda(j,\varepsilon)\)在嵌套下不减；在确定高度恰遇顶点的概率为零，可对可数j、ε和λ取共同零集。用分枝性质和均值\(E Z_\lambda(j\varepsilon)=b v_\lambda e^{-a j\varepsilon}\)，

\[ E A_\lambda(j,\varepsilon)
=b e^{-a j\varepsilon}u_\varepsilon(v_\lambda)
\le b e^{-a j\varepsilon}v(\varepsilon)<\infty. \]

单调收敛使各层极限计数有限几乎必然。若H≤R，则上述j≤R/ε的所有点与根构成联合森林的一个有限2ε网：任意高度大于2ε的点，向根退到前一个再前一个ε格点，其距离小于2ε，且该格点有至少ε的后裔。浅点由根覆盖。所有有理ε取共同事件，联合森林全有界。其完备化\(\mathcal F\)紧。

联合森林的任意两点已经处于某棵有限森林中，其唯一连接弧及距离不随λ改变。完备化仍是实树：近似端点、用四点不等式及紧性取连接弧极限，得到测地；四点不等式闭于距离极限，排除两条不同弧。该论证正是第57章线段生长完备化引理，所需条件在此已逐项验证。嵌套紧子树的并稠密，故\(d_H(\mathcal F_\lambda,\mathcal F)\to0\)；若不然存在固定ε外的点，其紧子列极限又被某个有限子树逼近，矛盾。

## 4. 质量不能由边长或均值直接猜出

<a id="lh-mass"></a>

令\(\xi_\lambda\)为终端叶各放一个单位的测度，\(L_\lambda=\xi_\lambda(\mathcal F)\)。单树叶数母函数的首分枝方程给\(\psi(v_\lambda(1-E s^L))=\lambda(1-s)\)，森林Poisson叠加于是给出

\[ E e^{-qL_\lambda/\lambda}
=\exp\{-b\,\phi(\lambda(1-e^{-q/\lambda}))\}
\ \longrightarrow\ e^{-b\phi(q)}. \]

极限在q=0连续，故\(L_\lambda/\lambda\)的律紧。临界时其期望可以无穷，不能用L¹有界鞅替代以下构造。把叶标记分成单位时间箱，令\(X_j=\xi_j-\xi_{j-1}\)。旧保留叶永远是新树的一片叶，故这是非负有限点测度。任意有限个时间箱的置换保持全部更细森林及染色的律，因为给定细树时各叶标记独立均匀。尤其箱计数可交换；第43章de Finetti及截断条件强律给\(L_N/N\to\Sigma\)几乎必然。若指导律的条件一阶矩为无穷，截断强律会使该比值趋无穷，与无条件紧性矛盾。因此Σ有限几乎必然，且Laplace为\(e^{-b\phi(q)}\)。

空间位置也要控制。固定整数m，把每个点投影到有限子树\(\mathcal F_m\)上最近的祖先点，记此1-Lipschitz投影为\(\pi_m\)。条件于全部前m箱信息，未来箱的投影点测度仍可交换。有限树的边地址与长度给其标准Borel编码，可用第43章随机测度版de Finetti；用可数个连续决定测试及截断强律，得到\((\pi_m)_*\xi_N/N\Rightarrow\nu_m\)几乎必然，\(\nu_m\)为有限测度，总质量Σ。这里只需可数m，故可取共同概率1事件。

对l≥m，投影复合恒等式给\((\pi_m)_*\nu_l=\nu_m\)。紧性证明又给\(\sup_{x\in\mathcal F}d(x,\pi_mx)\to0\)。因此在紧\(\mathcal F\)上，任意连续f的一致连续性使不同细度的\(\int f\,d\nu_m\)为Cauchy；Riesz表示给唯一有限测度m，并给\(\xi_N/N\Rightarrow m\)。具体地，先固定m控制投影后的弱极限，再令m→∞，误差至多Σ乘以f在投影距离下的模。构造对有限树坐标及可数测试可测；第55章带根GHP的测度可测结构遂使\((\mathcal F,m)\)为随机紧度量测度树。

有限质量空间的可测性还可以回到第55章的概率质量框架。Σ的Laplace变换在q→∞时趋零，所以P(Σ=0)=0。记录\((\Sigma,\mathcal F,m/\Sigma)\)；它属于正实数与带根概率GHP空间的乘积。共同空间中的Hausdorff收敛、总质量收敛与归一化弱收敛使它成为可测极限。

## 5. Poisson取样与质量支撑

<a id="lh-poisson"></a>

为使条件核中的测试函数与随机空间兼容，可保留有限树的平面顺序，但忘掉单位箱颜色。极限树的ε末梢修剪树是有限实树：不同末端各有一段长度ε的原树后裔，它们的端点两两至少距2ε，紧性保证有限。该修剪树的有限顶点和各边有理分点，按平面深度优先次序枚举；对ε=2的负整数次幂取并，得到不依赖箱颜色的可数稠密点。修剪树距原树至多ε；有限约化边的长度由有限个距离和最低共同祖先距离确定，枚举可由有理距离不等式取极限，故可测。用这些点的距离坐标把整树等距识别为一个可测的紧像。以下f取此坐标上的可数有界连续决定类；它们对所有\(\Theta_N\)可测，而不是偷偷把前m箱的某个叶标签留在条件域里。

固定整数t，令\(\Theta_N\)包含没有细分箱标签的最终森林以及所有\(\mathcal F_j,\xi_j\)，j≥N；不包含前N箱中的个别颜色。它们随N递减。给定\(\Theta_N\)，\(\xi_t\)是\(\xi_N\)的独立t/N稀释：从更细树的独立均匀标记先得有限条件结论，再用递增σ域条件期望极限保留该等式。对非负连续f，

\[ E(e^{-\xi_t f}\mid\Theta_N)
=\prod_{x\in\xi_N}\left[1-\frac tN(1-e^{-f(x)})\right]
\longrightarrow \exp\{-t\,m(1-e^{-f})\}. \]

取对数的二次误差被\(C_t L_N/N^2\)控制，几乎必然趋零。反向鞅定理识别左端的条件极限；m由未来经验读数确定，属于\(\Theta_\infty\)。故给定\(\Theta_\infty\)，\(\xi_t\)为强度tm的Poisson随机测度。可数决定类将此升级为共同核等式。每个\(\xi_t\)没有重合点，所以m无原子：若有原子，条件Poisson在该原子有至少两点的概率为正。每片标记叶在全部细树及完备化中仍为叶，否则可用有限树中的点逼近一个正距离后裔；这些点若为Cauchy，其两两共同祖先最终严格高于该叶，于是已有有限层出现它的后裔，矛盾。因此m集中于叶。

m还有满支撑。先固定一条粗树边的非空有理子区间J及ε>0。细树沿J中被压缩的一孩分叉形成速率\(c_\lambda-c_\mu\)的Poisson点：这是指数寿命事件按“一孩保留/其余”独立稀释的结果。在每个这类点至少有一个未保留孩子。给定一个孩子未保留，其直接终止且未染色的概率是\(p_0(1-\mu/\lambda)/(1-q)\)。又\(p_0\ge1/2\)：逐项用\(u\psi'(u)\le2\psi(u)\)，积分核的不等式由\(2(e^{-z}-1+z)-z(1-e^{-z})\ge0\)及其非负导数验证。故上述概率在λ大时有统一正下界；它的指数寿命小于ε的概率趋1。

Grey条件使\(c_\lambda\to\infty\)。独立分枝标记于是给“J附近ε内没有新增叶”的概率上界\(\exp[-C|J|(c_\lambda-c_\mu)]\to0\)。嵌套下，联合森林在每个这类邻域都有标记叶几乎必然。所有粗树边、J、ε可数，结合完备化稠密性，标记叶在整树稠密。条件Poisson及m的有限性又说明标记不可能落在m支撑之外；故m支撑整树。这个论证没有把骨架长度测度当作叶质量。

## 6. 稳定机制的分叉：细化时不会停在固定k

<a id="lh-degrees"></a>

取\(\psi(q)=q^\alpha,1<\alpha\le2\)。此时\(g_\lambda(s)=s+(1-s)^\alpha/\alpha\)与λ无关，\(c_\lambda=\alpha\lambda^{(\alpha-1)/\alpha}\)。固定粗层μ的一个分叉，保留孩子数为d≥2；细层λ的实际孩子数D满足

\[ E[z^{D-d}\mid d]=\frac{g_\lambda^{(d)}((1-q)z)}{g_\lambda^{(d)}(1-q)}
=\left(\frac{q}{1-(1-q)z}\right)^{d-\alpha},\qquad q=(\mu/\lambda)^{1/\alpha},\quad1<\alpha<2. \]

第一式由给定原孩子数后独立保留、按d次阶乘倾斜得到；分子逐项非负，归一化为1。第二式直接对\((1-s)^\alpha\)求d次导数。右端是负二项母函数。固定z<1时趋零，故D依概率趋无穷；在嵌套耦合中D非减，因此几乎必然趋无穷。粗层数与粗分叉可数，可取共同事件。

整树的任何非根分叉都在某棵粗树中已成为分叉：在它的三个开方向中各取一个稠密标记叶或根方向的有限树点；它们同处某个有限层，其连接弧交点就是该分叉。因此α<2的所有非根分枝点都有可数无穷度数。可分树的互不相交非空开分支最多可数。α=2时后代只能是0或2，任意有限层分叉保持二叉，稠密三点论证排除新增高阶分叉。森林公共根的人为祖先拼接须单独排除；这里说的是各个根分支内部的分叉。

## 7. 自相似尺度与并未宣称的归一化

<a id="lh-scaling"></a>

稳定机制中，原森林边长乘r及质量乘\(r^{\alpha/(\alpha-1)}\)，与初值参数\(b r^{1/(\alpha-1)}\)的同机制森林同律；用新标记率\(\lambda'=\lambda r^{-\alpha/(\alpha-1)}\)逐项验证：\(c_{\lambda'}=c_\lambda/r\)，\(b'v_{\lambda'}=b v_\lambda\)。相容有限核、紧完成及质量极限唯一，故这不只是量纲猜测。

已构造的是给定b的随机森林，其总质量Σ随机，Laplace为\(e^{-b q^{1/\alpha}}\)。它不是自动具有总质量1的单棵稳定CRT。要作单游程的持续时间条件化，必须先构造σ有限游程测度、作质量析取并核对高度规范；不能在概率零事件\(\{\Sigma=1\}\)上直接除法。本轮不把这项识别计为已完成。

## 8. Lévy路径高度：精确陈述未闭合的证明责任

<a id="lh-open"></a>

公开经典理论在其非单调的谱正Lévy过程及无限变差、临界/次临界条件下，以反向路径在上确界处的局部时间构造高度。常用规范是对每个固定t在概率意义下

\[ H_t=\lim_{\varepsilon\downarrow0}\frac1\varepsilon
\int_0^t\mathbf1_{\{X_s-\inf_{s\le r\le t}X_r<\varepsilon\}}\,ds. \]

[Duquesne–Le Gall, Astérisque281(2002)](https://arxiv.org/pdf/math/0509558)第1.2–1.4节构造该过程，并在Grey条件下建立连续版本与Ray–Knight联系；[2005年公开论文](https://www.imo.universite-paris-saclay.fr/~jean-francois.le-gall/Levy-final.pdf)研究所编码树。这里这条公式是有来源的外部结果，不是已由前文连续半鞅Tanaka公式证明的定义。谱正纯跳过程在记录集合上的局部时间，需要新的归一化和势估计。

本书仍未完整写成：反射过程局部时间的势构造、上述占用近似、共同连续版本、与本专题约化森林的同律识别、全层局部时间的CSBP/Ray–Knight结论，以及重尾条件GW高度与轮廓的函数极限。前八节的紧森林、质量、采样和分叉证明不调用这些未证识别。T-LEVY-HEIGHT因此只能登记“约化森林版本已完成，canonical高度与条件极限实质未闭合”，不能写成一般Lévy高度理论已证。Brownian时\(\psi(q)=q^2/2\)对应的经典高度为2倍标准游程；与本书\(e\)的距离必须减半，不能将λ参数或CSBP方差规范暗中换掉。
