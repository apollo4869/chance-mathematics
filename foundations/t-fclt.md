# T-FCLT：经验曲线、逆时间与函数型极限

本专题与[第25章](../chapters/25-donsker.md#donsker-theorem)共用一个证明起点：固定分布、独立同分布、有限二阶矩的折线部分和已满足Donsker。以下实际建立均匀经验过程、一般CDF在紧区间上的版本，以及正等待的有限方差更新函数极限。它们不调用未证的一般经验函数类理论、Brownian嵌入或Palm理论。

## 1. 指数间隔的有限样本等式

<a id="t-fclt-spacings"></a>

令N=n+1，E₁,…,E_N独立、密度为e⁻ˣ1_{x>0}，Rₖ为其部分和。在正正交象限中作一一光滑变换r=R_N，uᵢ=Rᵢ/r，i=1,…,n。新变量域为r>0、0<u₁<⋯<uₙ<1；设u₀=0、u_N=1，逆变换是Eᵢ=r(uᵢ−uᵢ₋₁)。

Jacobian可分两步核验。先从(r,u₁,…,uₙ)变到(r,E₁,…,Eₙ)：固定r后的差分矩阵下三角，对角线全为r，故行列式rⁿ。再把r替换成E_N=r−Σᵢ≤ₙEᵢ，绝对行列式为1。因此联合密度为e⁻ʳrⁿ。Tonelli允许先对r积分；分部积分归纳给∫₀∞e⁻ʳrⁿdr=n!，边界项为0，因为指数衰减快于任意固定多项式。

\[
f_{u_1,\ldots,u_n}(u_1,\ldots,u_n)
 =n!\,\mathbf1_{\{0<u_1<\cdots<u_n<1\}}.
\]

n个独立均匀点的无序联合密度为1，平局事件为零，每种严格次序对应一个坐标置换，故排序后密度正是n!。这证明向量等分布，而不仅是每个间隔的边缘公式。每个n都可在同一指数序列上这样实现，但没有宣称这种实现保留原均匀样本跨n的依赖。

## 2. 总长度归一化为何产生桥

<a id="t-fclt-bridge"></a>

令H_N为Eᵢ−1的√N归一折线，q_N为节点(k/N,Rₖ/R_N)间的线性插值。所有Eᵢ>0几乎必然，对全部N取可数交，q_N同时为[0,1]的递增同胚；零概率例外上统一令q_N=id。有限向量插值可测，逆也可测：在正间隔域内，节点与各段线性逆随参数连续。

\[
q_N(t)=\frac{Nt+\sqrt N\,H_N(t)}{N+\sqrt N\,H_N(1)},\qquad
 v_N(t):=\sqrt N(q_N(t)-t)
 =\frac{H_N(t)-tH_N(1)}{1+H_N(1)/\sqrt N}.
\]

指数变量有均值1、方差1，所以主章Donsker给H_N⇒B于C([0,1])。H_N的一致范数紧，故分母趋1依概率。令G_N=H_N−tH_N(1)，则G_N⇒B°由固定连续线性映射给出，且‖v_N−G_N‖∞≤2‖H_N‖∞|d_N−1|/|d_N|，其中d_N为分母。先把‖H_N‖∞限制在高概率有界集、|d_N|限制在1/2以上，便知差趋0依概率；这核验了含N的分母极限，而不是擅用一个随N变化的映射定理。

所以v_N⇒B°，并在C中紧；B°(t)=B(t)−tB(1)是第23章已经构造出的桥，协方差为min(s,t)−st。这里没有另外构造一个只在有限时刻存在的候选过程。

## 3. 逆函数的涨落不能只靠一句连续性

<a id="t-fclt-inverse"></a>

对任意递增连续同胚q及其逆r，换元u=q(t)即给‖r−id‖∞=‖q−id‖∞。在上面的随机情形中，右边是‖v_N‖∞/√N，因C紧性而趋0依概率。代入q_N(r_N(t))=t，得到精确关系：

\[
\sqrt N(r_N(t)-t)=-v_N(r_N(t)),\qquad
 \|\sqrt N(r_N-\mathrm{id})+v_N\|_\infty
 \le w(v_N,\|r_N-\mathrm{id}\|_\infty).
\]

最后的随机振幅确实趋0：对固定δ>0，其超过ε的概率至多P(‖r_N−id‖∞>δ)+P(w(v_N,δ)>ε)。先取N上极限，第一项为0，再令δ↓0，由共同C紧性使第二项趋0。无需r_N与v_N独立；它们实际上来自同一份数据。由稳定性结论，√N(r_N−id)⇒−B°于C。

## 4. 经验CDF的全部端点与误差

<a id="t-fclt-empirical"></a>

在指数实现中，令Gₙ为n个点R₁/R_N,…,Rₙ/R_N的经验CDF。当t∈[Rₖ/R_N,Rₖ₊₁/R_N)时，k=0,…,n，Gₙ(t)=k/n，r_N(t)介于k/N与(k+1)/N。两个端点误差分别为k/(nN)与(n−k)/(nN)，均不超过1/N；在t=1两者都为1。故有确定性一致误差界。

\[
\|G_n-r_N\|_\infty\le\frac1N,\qquad
 \left\|\sqrt n(G_n-\mathrm{id})-\sqrt n(r_N-\mathrm{id})\right\|_\infty
 \le\frac{\sqrt n}{n+1}\longrightarrow0.
\]

由于√(n/N)→1，上一节及紧范数控制给√n(r_N−id)⇒−B°于C。C到D的连续嵌入、上述一致误差与第24章稳定性遂给αₙ⇒−B°于D的J₁。中心Gaussian桥的对称性再给−B°等分布于B°。Gₙ为D值随机元素，因为每个阈值计数可测，D的Borel由坐标生成；其路径确为右连续有限阶梯。

第1节的有限向量等分布经“排序点→CDF”的Borel映射传成整个D值分布相同，所以这个结论确实适用于最初的独立均匀样本。最大绝对偏差可用连续近似直接传递：两者上确界之差不超过一致误差，因此√n‖Gₙ−id‖∞⇒‖B°‖∞。不需要在非可分ℓ∞空间里另作未经核验的可测性声明。

## 5. 一般CDF，包括原子的情形

<a id="t-fclt-general-cdf"></a>

设F为实线上任意CDF。对u∈(0,1)，Q_F(u)=inf{x:F(x)≥u}有限，且右连续性使F(Q_F(u))≥u：可从右侧选F≥u的点趋近下确界。因此Q_F(u)≤x当且仅当u≤F(x)。令Yᵢ=Q_F(Uᵢ)，便得到所需独立F样本及精确指标等式。

固定有限a<b。映射Φ_F:C([0,1])→D([a,b])，Φ_F(g)(x)=g(F(x))，输出有右连续与左极限；左极限是g(F(x−))。而‖Φ_F(g)−Φ_F(h)‖∞≤‖g−h‖∞，所以映射对J₁目标连续且Borel。将第4节连续近似过程送入Φ_F，其误差仍至多原一致误差，便证明下面的结论。

\[
\begin{gathered}
\sqrt n(F_n-F)\Rightarrow B^\circ\circ F\quad\text{in }D([a,b]),\\
 \operatorname{Cov}(B^\circ(F(x)),B^\circ(F(y)))
 =F(\min(x,y))-F(x)F(y).
\end{gathered}
\]

F有原子时，极限的跳跃发生在固定位置；这并不妨碍本证明，因为连续性要求作用在g这一输入变量上，而不是强迫F连续。未证明所有实线加权一致范数、一般指标函数类或多元经验过程，不把这一紧区间版本扩写成那些更强结论。

## 6. 更新计数的逆极限

<a id="t-fclt-renewal"></a>

设τᵢ>0独立同分布，均值μ>0、方差σ²∈(0,∞)。R₀=0，Rₖ=Σᵢ≤ₖτᵢ，N(t)=max{k:Rₖ≤t}。第12章可积强律给Rₖ/k→μ几乎必然，所以Rₖ→∞、N(t)有限，构造非爆炸。N是右连续阶梯，坐标事件{N(t)≥k}={Rₖ≤t}可测，因此是D值随机元素。

先证逆强律。对固定t>0、0<ε<t/μ，分别取kₙ±=⌊n(t/μ±ε)⌋，强律给R_{kₙ±}/n→t±με。因此最终kₙ⁻≤N(nt)<kₙ⁺，令ε↓0得到N(nt)/n→t/μ；t=0由正等待给N(0)=0。在强律的同一满概率事件上，可先对可数个网格时刻和有理ε统一这些结论。在有限网格上同时应用此结论，用N的单调性夹住网格之间的值；连续线性极限在网格格子内变化至多网格长度/μ。网格加密便得紧窗口上的一致收敛。

\[
\sup_{0\le t\le T}\left|\frac{N(nt)}n-\frac t\mu\right|\longrightarrow0
 \quad\text{almost surely}.
\]

接着控制随机下标。选C>T/μ，若R_⌊Cn⌋>nT，则N(nT)+1≤⌊Cn⌋；其补事件概率由强律趋0。在这个高概率事件上，年龄A(nt)=nt−R_{N(nt)}与剩余寿命V(nt)=R_{N(nt)+1}−nt均不超过前⌊Cn⌋个等待的最大值。有限二阶矩给：

\[
P\!\left(\max_{j\le\lfloor Cn\rfloor}\tau_j>\varepsilon\sqrt n\right)
 \le\frac C{\varepsilon^2}E[\tau_1^2\mathbf1_{\{\tau_1>\varepsilon\sqrt n\}}]\longrightarrow0,
 \qquad
 \frac1{\sqrt n}\sup_{t\le T}\{A(nt)\vee V(nt)\}\xrightarrow P0.
\]

令Hₙ(s)=(R_⌊ns⌋−μ⌊ns⌋)/√n，令Ḣₙ为相应折线。主章给Ḣₙ⇒σB于C([0,C])，且‖Hₙ−Ḣₙ‖_[0,C]→0依概率。对k=N(nt)，代入到达时刻的定义得到下面的精确等式；其余项不是随意忽略的取整符号，而是刚刚控制过的年龄。

\[
Z_n(t)=\frac{N(nt)-nt/\mu}{\sqrt n},\qquad
 \mu Z_n(t)=-H_n\!\left(\frac{N(nt)}n\right)-\frac{A(nt)}{\sqrt n}.
\]

在随机时间均落于[0,C]的高概率事件上，两次读数的差至多阶梯/折线误差，加上w(Ḣₙ, sup_{t≤T}|N(nt)/n−t/μ|)。对任意固定δ，概率由逆强律的坏事件与共同振幅坏事件控制，先取n极限再令δ↓0，便使其趋0。这个随机时间比较不要求计数过程与等待和独立。

\[
\left\|Z_n+\frac1\mu\bar H_n(\,\cdot\,/\mu)\right\|_{[0,T]}
 \xrightarrow P0,\qquad
 Z_n\Rightarrow-\frac{\sigma}{\mu}B(\,\cdot\,/\mu)
 \quad\text{in }D([0,T]).
\]

固定的时间缩放与线性倍乘是C空间连续映射；再用一致误差到J₁的稳定性，就得到最后结论。若把等待和与计数一起讨论，这个构造还保留二者的负相关极限。单独只看计数路径，√μ B(t/μ)是标准Brownian motion，加入负号仍同分布，所以可以改写为σμ⁻³ᐟ²乘另一标准Brownian；这是分布恒等，不是与原等待和的逐样本恒等。

此证不需要非算术性、Blackwell或关键更新定理；正等待、可积强律与有限方差已经足够。这一路线不依赖局部更新测度的选择或关键更新极限，只用独立和、逆时钟与共同振幅。方差为0时，等待恒为μ，计数误差至多1，√n涨落趋零。一般重尾更新、未缩放年龄余寿命与平稳观察的结论仍属各自不同的理论。
