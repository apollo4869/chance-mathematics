# T-MARKOV-BRANCHING：删叶一致性、分裂律与再生表示

本页证明[第57章](../chapters/57-regenerative-growth.md#growth-markov-branching)的有限与无限树表示。树先是无边长的非平面标号层级；根的唯一干边可另补，但不计入分裂。这里的再生指给定首次分裂后的子树条件独立并重用同一族律，不等于沿物理时间的更新过程。

## 1. 先把子树独立写成可检验的递归

<a id="mb-recursion"></a>

对n≥2，令qₙ为[n]的非平凡划分上的交换概率。给定根分裂π，逐块B独立生成同族T(B)，以递增标号将大小|B|的模型搬到B，再接到根；单标签树确定。这在有限n上递归终止，因为每块严格小于n，给唯一Markov branching律Pₙ。所有状态有限，所以条件概率和全部构造可测。反之，具有这种子树条件独立性的族由其根分裂q唯一决定。

## 2. 删除一个标签会让根消失

<a id="mb-deletion"></a>

对n≥3，令pₙ=qₙ({{n},[n−1]})。删除标签n时，如果根恰分成{n}与其余标签，根分叉被压掉，剩余整树按Pₙ₋₁生成；否则投影根分裂仍非平凡。交换性使n种单独剥离标签的根分裂等概率且互斥，故pₙ≤1/n<1。这里删除根指压缩失去分枝的顶点，不删除作为标记的根；若有干边，其长度另行合并。

\[ (r_{n-1})_*q_n\big|_{\mathcal P_{n-1}\setminus\{\mathbf1\}}=(1-p_n)q_{n-1},\qquad n\ge3. \]

这就是采样一致性的准确充要条件。必要性：假设树族一致，将删除后的根分裂分为根未塌陷与塌陷两项，后者权重pₙ、分裂律qₙ₋₁；移项即得。充分性用n归纳：给π，若n位于非单点块，归纳使该子树删叶后仍是同族，其他子树保持独立；若所在块为单点，则删去它。除根塌陷外，条件子树都是投影划分各块上的独立同族树；塌陷时剩余树本就有Pₙ₋₁律。显示身份使非塌陷部分也有根律qₙ₋₁，故全树为Pₙ₋₁。交换性再把删除n推广到任意标签及任意有限限制。

## 3. 从有限概率恢复一份局部有限速率测度

<a id="mb-rate-representation"></a>

\[ \gamma_2=1,\qquad\gamma_n=\frac{\gamma_{n-1}}{1-p_n},\qquad K_n=\gamma_nq_n\quad(n\ge2). \]

将Kₙ在平凡划分处补0。上节身份使其非平凡部分在删除标签下相容：若m<n，Kₙ投影到非平凡[m]划分等于Kₘ。设Bₘ为无限划分在[m]上非平凡的事件。固定m，对n≥m取Kₙ限制在投影落Bₘ的有限状态上；总质量γₘ，归一化后是相容概率。第8章可数延拓给Bₘ上的有限测度κᵐ。m增加时这些测度在小Bₘ上相同，由柱集唯一性；Bₘ递增且并为除平凡划分外的全部空间。

\[ \kappa(A)=\lim_{m\to\infty}\kappa^m(A\cap B_m),\qquad \kappa(B_m)=\gamma_m<\infty,\qquad (r_m)_*\kappa\big|_{\mathcal P_m\setminus\{\mathbf1\}}=K_m. \]

这个递增拼接是测度：对互不交Aⱼ，有限测度的可加性后交换两个非负递增极限即可。任意有限置换及有限非平凡柱集的值由Kₙ确定，而Kₙ交换；测度在Bₘ有限，π–λ唯一性推广到全部可测集，故κ交换。它在Bₘ上的有限柱值也证明唯一性。若不固定γ₂，唯一性是相差一个正时间倍数。反过来，任何非零交换κ、κ(Bₘ)<∞且不计平凡划分，给γₘ=κ(Bₘ)>0及qₘ=投影/γₘ。若γ₂=0，则所有指定标签对分开的κ质量为0，可数并会令κ=0，矛盾；所以归一化合法。限制身份恢复上面的递推。

## 4. 这确实生成一份无限分枝历史

<a id="mb-process"></a>

非平凡划分空间是紧划分空间去掉一点的标准Borel、局部紧空间，Bₘ是递增紧开覆盖。第48章可用σ有限强度dt κ(dπ) #dk构造Poisson原子，按56章的内部递增编号分细当前第k块。对[n]，只有k≤n且π∈Bₙ可能有效，率≤nγₙ，故全部有限路径非爆炸；共享原子给限制相容。这里不需要先把一般κ分解为ν与侵蚀。

一块含m≥2名可见成员时，下一次有效分裂等待Exp(γₘ)，条件分裂为qₘ；不同子块的有限生成项分离，给独立后续。最多n−1次有效细分后[n]成为单点，每段等待具有正有限率，所以这发生在有限时间几乎必然。收集这些分裂得到的有限谱系恰有Pₙ律。所有n的共同路径给一份交换无限层级。也可以直接把相容Pₙ送入56章紧逆极限，两种构造的有限限制相同，因而同律。

## 5. 宽广的具体分裂族与一个失败例

<a id="mb-examples"></a>

\[ q_n(\pi)=\frac{\int PB_s\{r_n\Pi=\pi\}\nu(ds)}{\int(1-\sum_i s_i^n)\nu(ds)},\quad \pi\ne\mathbf1,\quad c=0. \]

当56章可积分裂测度ν非零、分母正时，这个公式是上节κ的特例，因而给真正的采样一致Markov branching族；侵蚀也可加入其κ。相反，规定每个根把当前样本尽量均分：n=3根为1+2，而n=4根必2+2。删去四人中任一人给1+2，单这一步看似无碍；到n=5根为2+3，若从2侧删人则1+3，若从3侧删人则2+2。四人模型只允许2+2，故失败。条件子树独立和局部归一化没有修复这项冲突。

## 6. 二叉公式把根塌陷因子显露出来

<a id="mb-binary"></a>

\[ \left(1-\frac{q_n(1)+q_n(n-1)}n\right)q_{n-1}(i)=\frac{i+1}{n}q_n(i+1)+\frac{n-i}{n}q_n(i),\quad1\le i\le n-2. \]

这里qₙ(i)是随机左右定向后二叉根左侧大小i的概率，qₙ(i)=qₙ(n−i)；给大小后，标签子集均匀。这不是上一节具体划分概率qₙ(π)的同一坐标。两项来自左侧或右侧删除；前面的因子排除删去单独一侧后根塌陷。必要性由全树一致给出，充分性仍由独立子树归纳。省略塌陷项通常会把一个正确的条件分裂模型判成不一致。

## 7. 表示识别了什么，没有识别什么

<a id="mb-scope"></a>

本页完整表示的是交换、无边长、有限Markov branching树族与一份局部有限交换κ之间的对应，并构造相容无限层级。γ₂的选取是一只外加时钟；更换块质量相关时钟还可保留同一无时标谱系。κ的一般ν/c逆向分类未在这里证明，56章的该缺口仍开放。无限层级也不自动紧：等长星形有限样本都相容，但无限叶两两距离2，不可能紧。下一专题另证Brownian线段构造的紧性及质量，不能从本页的相容性跳过去。[返回正文](../chapters/57-regenerative-growth.md#growth-consistency)。
