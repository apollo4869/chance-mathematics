# T-SDE-WELLPOSEDNESS：从逼近到实际解

与[第35章](../chapters/35-sde-wellposedness.md)双向配套。Brownian积分使用第31章等距、Doob最大估计和停止；第32章提供连续Itô公式，第34章提供确定补偿Poisson随机测度的可预测L²积分。所有滤过通常，Brownian运动相对于所用整个滤过成立。有限T任意，初值与未来驱动独立；确定系数Borel可测。这里不使用一般好积分器逆向、局部时间、下一章尺度速度或一般SDE定理作为前提。

## 1. Picard、稳定性与完整的极限

<a id="sde-proof-picard"></a>

假设对0≤t≤T及全部x、y有正文的全局Lipschitz与线性增长界。先E|ξ|²有限。若Y连续适应且E sup|Y|²有限，则系数复合可预测，增长给两积分存在，且映射Γ(Y)仍在同一空间。漂移的最大平方由T∫|b|²控制；Doob与Itô等距使噪声最大平方由4∫||σ||²控制。以三项平方和界得到

\[ E\sup_{u\le t}|\Gamma(Y)_u|^2\le3E|\xi|^2+3(T+4)K\int_0^t(1+E|Y_s|^2)ds. \]

先不需要一个统一的迭代矩界：这个式子逐项保证每次迭代合法。相邻差记Dₙ(t)=E supᵤ≤ₜ|Xⁿᵤ−Xⁿ⁻¹ᵤ|²；两项平方界给C=2L²(T+4)以及Dₙ₊₁(t)≤C∫Dₙ。第一项D₁(T)≤A=C′T(1+E|ξ|²)有限。归纳得到Dₙ₊₁(t)≤A(Ct)ⁿ/n!。于是

\[ \sum_{n\ge0}\bigl(E\|X^{n+1}-X^n\|_T^2\bigr)^{1/2}<\infty,\qquad E\sum_n\|X^{n+1}-X^n\|_T<\infty. \]

第一式用第15章已补齐的Minkowski及L²完备性得到L²最大范数极限；第二式由Tonelli给几乎必然绝对一致收敛。连续适应过程的一致极限仍连续适应，完备化容纳公共零集。对漂移差再次用T L²∫E|Xⁿ−X|²，对噪声差用4L²∫E|Xⁿ−X|²，均趋0。故Γ(X)=X于最大L²中，连续性使过程等式不可分辨。

应用前述映射矩界于X本身并迭代积分不等式，得E||X||²_T≤C_T(1+E|ξ|²)。两解同一驱动作差给f(t)≤3E|ξ−η|²+C∫f，故f(T)≤3eᶜᵀE|ξ−η|²。零初始差时得到唯一性。对一般候选先停于两份状态幅度及两份积分能量的共同水平，使所有期望合法，再由Gronwall取零；共同停止趋∞，故不要求候选解事先具有总体二阶矩。

任意有限ξ用ξⁿ在|ξ|≤n时等于ξ、否则等于0。对Aₙ={|ξ|≤n}∈F₀，相乘1_Aₙ的差估计给Xⁿ与Xᵐ在Aₙ上一致（m≥n）；不必改用条件概率。于是按Aₙ拼合。过程可测、适应、连续，积分身份在每个Aₙ成立，故在其并集成立。对T取整数，唯一性再次保证相容，构造全半轴解。

同一估计还有系数稳定版本。若bₙ、σₙ共享L、K，并在有界集合上局部一致趋b、σ，则停止出球后的误差由初值误差和∫(|bₙ−b|²+||σₙ−σ||²)(s,Xₛ)ds控制。DCT与Gronwall给停止最大L²收敛；统一矩界去掉停止给ucp收敛。仅有依概率收敛时不自行升级成整列几乎必然收敛。

<a id="sde-proof-continuous-moments"></a>

后面使用的连续鞅高阶上界可在这里直接推出，不必依赖第34章尚待终审的一般有跳BDG。设连续向量局部鞅N₀=0，A=tr[N]，p>2。停至N与A有界，对|N|ᵖ用Itô并取期望，Hessian界给E|N_T|ᵖ≤C_p E[(N*ₜ)ᵖ⁻²A_T]。Doob的p阶不等式再给E(N*ₜ)ᵖ≤D_p C_p E[(N*ₜ)ᵖ⁻²A_T]。Young取足够小系数，把右侧一半最大矩吸回左侧，剩下C′_p E A_Tᵖᐟ²。放开停止用Fatou；p=2直接用Doob与等距。对N=∫H dW便得到E sup|∫H dW|ᵖ≤C_p E(∫||H||²ds)ᵖᐟ²。这个独立短证足以支持弱存在的四阶矩及下页流的任意高阶矩；不需要双向或有跳BDG。

## 2. 局部拼接、爆炸与Lyapunov

<a id="sde-proof-local"></a>

假设每个有限时间—紧状态区域上b、σ有界，且对x局部一致Lipschitz。选光滑截断χ_R，等于1于半径R球，等于0于半径R+1球外；系数χ_Rb、χ_Rσ全局Lipschitz并有线性增长。其解Xᴿ与Xˢ在两者离开半径R球的最小时刻以前满足相同停止方程，故唯一性使它们一致。离开时由连续性一致，退出时刻相同。

依这些相同的退出时刻定义X于t<ζ=limτ_R。这是由可数过程拼合的可测连续适应过程。若ζ≤T且limsupₜ↑ζ|Xₜ|有限，某个更大球的截断过程便把它延长到ζ以后，矛盾。局部唯一性也由同一停止比较得到。

取V≥0为C²、径向强制（|x|→∞时V→∞），并假设LₜV≤C_T(1+V)。先初值有界。停止Itô公式于τ_R及积分的L²局部化；在球内所有系数和导数有界，鞅项均值0。于是E V(Xₜ∧τ_R)≤EV(ξ)+C∫₀ᵗ(1+E V(Xₛ∧τ_R))ds。停止指标被非负项支配，故Gronwall合法。连续出球时V至少为球面下确界，得到正文的概率界。令R→∞再对整数T取并，ζ=∞几乎必然。一般初值先用F₀事件分片；若直接EV(ξ)<∞也可直接用该期望界。

## 3. Brownian与Poisson共同驱动

<a id="sde-proof-jump"></a>

假设N的补偿为dtν，ν在标准Borel标记空间上σ有限，W与N独立且对共同滤过保有Brownian/Poisson独立增量；ξ为F₀可测。对E₀要求正文联合平方Lipschitz界，以及|b(t,0)|²+||σ(t,0)||²+∫|g(t,0,z)|²ν(dz)≤K_T。Picard现在加第三份鞅积分。对三项差用3倍平方和，Poisson等距与Doob给

\[ E\sup_{u\le t}|X^{n+1}_u-X^n_u|^2\le3(T+8)L^2\int_0^tE\sup_{v\le s}|X^n_v-X^{n-1}_v|^2ds. \]

常数无需最优；阶乘收敛与第1节相同。每步càdlàg适应，左极限可预测。最大L²收敛有一致几乎必然子列，极限càdlàg，左极限的L²能量差同样趋0；等距通过方程。对终点跳使用(0,t]积分约定，不将Xₜ误当成事前输入。由同样差估计得路径唯一、矩界与非爆炸。

再设ν(E₁)<∞，h(t,x,z)联合Borel且有限于每个输入。E₁跳时刻Sₖ在紧时间内有限且不同时发生；E₀与E₁限制为独立Poisson测度，几乎必然不在同一随机时刻跳（先对有限标记带条件化，继以可数覆盖）。在Sₖ按x↦x+h更新，再解下一段小跳方程。

随机时刻后的Picard不需另引未经证明的强Markov定理。对有限F_S可测U，以U1_{S≤t}为基础过程，积分只在(S,t]上运行；每步仍适应、左输入仍可预测，同一最大估计在初始幅度|U|≤n的F_S事件上成立。对这些事件相乘的是1_A1_(S,∞)，为可预测规则，故可以拼合。这样在原空间上构造每次重启。无大跳的方程只在重启以后成立，S处的人工起始跳不再计入小跳积分。

有限次跳把有限状态映成有限状态；每段全局小跳解非爆炸，所以每个有限T内的拼接非爆炸。若h没有ν平方矩，E sup|X|²可能为∞，不影响上述按状态分片的路径构造。局部Lipschitz的小跳系数则在出球前同样构造最大解；大跳可直接跳出球，退出包括越界，不可把最后状态误称有界。

## 4. 一维模条件的完整平滑论证

<a id="sde-proof-modulus"></a>

设b局部Lipschitz，|σ(t,x)−σ(t,y)|≤ρ(|x−y|)，ρ连续非减、正于正半轴、ρ(0)=0且∫₀₊ρ⁻²=∞。选a₀=1及aₙ↓0使∫ₐₙ^ₐₙ₋₁ρ⁻²=n。存在光滑ψₙ支撑于(aₙ,aₙ₋₁)，积分为1，且0≤ψₙ(u)≤2/(nρ(u)²)：先在该区间把ρ⁻²截去短端点，保留积分大于n/2，再以光滑下逼近并归一化。定义偶C²函数

\[ \phi_n(z)=\int_0^{|z|}\!\int_0^y\psi_n(u)\,du\,dy,\quad |\phi_n^\prime|\le1,\quad |z|-a_{n-1}\le\phi_n(z)\le|z|,\quad\phi_n^{\prime\prime}(z)\rho(|z|)^2\le2/n. \]

对同驱动同初值的两份连续解，停于τ_R=inf{|X|∨|Y|≥R}。Itô及局部化使鞅均值为0；漂移项≤L_R∫₀ᵗE[1_{s≤τ_R}|Xₛ−Yₛ|]ds，二阶项≤t/n。φₙ以有界差趋绝对值，不需要φₙ单调；DCT可用，因为停止路径差≤2R。于是f_R(t)=E|Xₜ∧τ_R−Yₜ∧τ_R|≤L_R∫₀ᵗf_R(s)ds。Gronwall给0，连续性取有理时间共同零集，再放开R，得到直到共同寿命的路径唯一。

## 5. 连续系数的弱存在，不偷换紧性与构造

<a id="sde-proof-weak"></a>

先b、σ有界连续、时间齐次、X₀=x确定。网格δ上定义冻结Euler解Xᵟ=x+∫b(Xᵟ_η(s))ds+∫σ(Xᵟ_η(s))dW，η(s)=δ⌊s/δ⌋。逐段显式递推得到连续适应过程。连续鞅p=4估计给E|Xᵟₜ−Xᵟₛ|⁴≤C_T|t−s|²（漂移的四次方用|t−s|⁴，噪声括号≤C|t−s|）；常数与δ无关。Kolmogorov紧性及Prokhorov给连续路径弱极限Q。

冻结误差满足E∫₀ᵀ|Xᵟₛ−Xᵟ_η(s)|²ds≤C_Tδ。其最大振幅也依概率趋0，可由共同紧性及δ→0的振荡控制得到。对f∈C_c∞，Itô给鞅，其中生成元系数在冻结位置、导数在当前位置。系数在紧集上一致连续，出紧集概率由统一矩界控制，所以这一积分与∫Lf(Xᵟₛ)ds的差趋L¹的0。

固定有理s<t，把鞅增量乘任意有界连续的过去有限坐标函数。被积的路径泛函有界连续（Lf有界连续），故弱收敛通过期望；误差趋0，得到Q下的鞅检验。函数单调类把过去圆柱函数推广到坐标Fₛ；连续路径再将有理s、t推广到全部时刻。于是Q解决鞅问题。下一专题的伪逆构造配上Brownian噪声，才得到弱解；这里没有以该弱解反过来证明紧性。

有线性增长而非有界时，Euler过程的四阶最大矩在确定初值下由BDG、Hölder与Gronwall统一控制。具体地，E supᵤ≤ₜ|Xᵟᵤ|⁴≤C(1+|x|⁴)+C∫₀ᵗE supᵥ≤ₛ|Xᵟᵥ|⁴ds；增量四阶仍≤C_T|t−s|²。因此同样紧。对生成元检验使用紧支撑f，漂移及a只在导数非零的紧集出现，Lf仍有界连续；冻结误差先限制两位置在大球内，再用矩界控制离球尾。识别与Brownian重构不变。随机初值可先固定给定初始规律做相同Euler，按初始幅度截断矩界；这给固定初始规律的弱存在，而不是未经证明的可测选解。

## 6. Tanaka方程的三个不同结论

<a id="sde-proof-tanaka"></a>

令s(x)=1于x≥0、−1于x<0。先B为标准Brownian，定义W=∫s(B)dB。能量为t，由Lévy刻画W为相同滤过中的Brownian；结合律给∫s(B)dW=∫s(B)²dB=B，故弱存在。任一弱解X也有[X]=t，因而为Brownian，给分布唯一。路径唯一性失败：在上述共同空间，B与−B都由同一W驱动，因为∫1_{B=0}dt=0。后式由Tonelli及P(Bₜ=0)=0于t>0得到，不借局部时间。

为排除另一种隐蔽的强构造，需要联合律唯一。取有界连续sₙ→s于x≠0且|sₙ|≤1；Gaussian与Tonelli给E∫|sₙ(X)−s(X)|²dt→0。对每个n，∫sₙ(X)dX由确定网格左和依概率逼近，因为sₙ(X)连续；再取对角子列，得到W=∫s(X)dX作为X路径的Borel泛函，定义在Wiener满测集合上。所有弱解X的规律相同，因此(X,W)联合规律相同。

Brownian反号保持Wiener规律，且上述积分在反号后不变，所以(X,W)与(−X,W)同律。于是对任意有界可测h(W)，E[Xₜh(W)]=−E[Xₜh(W)]=0，E[Xₜ|W]=0。强解要求Xₜ对(ξ,W)的过去可测，这里ξ=0，故也对整条W可测，迫使Xₜ=0，矛盾。分布唯一、弱存在、无强解三个断言均已建立。
