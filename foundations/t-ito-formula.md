# T-ITO-FORMULA：连续路径的变量变换与积分约定

本专题实际证明第32章采用的连续半鞅公式，不使用一般SDE存在定理、跳跃积分或未来的非光滑公式。基础是[T-ITO-BRACKET](t-ito-bracket.md)已构造的连续局部鞅积分、确定网格平方和的ucp极限、协变差及停止身份。通常条件始终成立；局部鞅和有限变差部分从0出发。ucp指每一有限区间上的一致依概率收敛。这里是完整工作证明，作者与独立数学终审仍开放。

## 1. 带权平方和为什么收敛

<a id="t-ito-weighted"></a>

设M连续局部鞅，A=[M]。固定T，取确定网格\(\pi_n\)，最大格距趋0，不要求嵌套。令\(\widehat Q_n\)在完成一格时才加上该格平方，尚未完成的格贡献0。它是递增阶梯函数；包含当前部分格的\(Q_n\)与它的差的最大值不超过\(\omega_M(|\pi_n|)^2\)。因此\(\widehat Q_n\)一致依概率趋A，\(\widehat Q_n\)(T)紧。ω表示给定紧区间的路径振荡。所有这些事实来自31章，不使用本专题公式。

给任意连续随机权重g，以下陈述是路径Stieltjes极限，不需要g适应。先把每个格左端的g换为该格右端的g；误差一致至多为\(\omega_g(|\pi_n|)\widehat Q_n(T)\)，依概率趋0。对固定粗网格\(u_j\)，以g(\(u_j\))构造分段常数\(g^k\)。对每一个这样的粗函数，两个积分之差至多为2Σ\_j|g(\(u_j\))|‖\(\widehat Q_n\)−A‖∞，所以依概率趋0。任意g与\(g^k\)的积分差统一由下式控制。随机但有限的系数可以先限制在任意高概率事件上，不需要期望界。

\[ \sup_{t\le T}\left|\int_0^t(g-g^k)\,d\widehat Q_n\right|+\sup_{t\le T}\left|\int_0^t(g-g^k)\,dA\right|\le\omega_g(|u^k|)\{\widehat Q_n(T)+A_T\}. \]

先令n趋无穷，再加细粗网格。右侧由紧性和路径一致连续性趋0；当前未完成格至多再产生‖g‖∞\(\omega_M(|\pi_n|)^2\)。这证明正文的带权平方和ucp结论，而非仅终点收敛。对M,N用极化，把交叉和写成M+N与M−N平方和之差，即得连续权重的交叉和极限∫g d[M,N]。有符号极限测度的总变差受Stieltjes Cauchy–Schwarz约束，见31章。

若V连续有限变差，则Σ(ΔV)²≤\(\omega_V(|\pi_n|)\operatorname{Var}(V)\)趋0，路径上成立且一致于截止时间。交叉和由有限和CS受√(ΣΔM² ΣΔV²)控制，故ucp趋0。于是X=X0+M+V具有[X]=[M]，向量的所有交叉和同理；Σ‖ΔX‖²在有限区间上紧。这些是后面余项估计真正需要的共同控制。返回[正文32.3](../chapters/32-ito-formula.md#ito-weighted-variation)。

## 2. 左端和、有限变差积分及局部化

<a id="t-ito-localization"></a>

设X为d维连续适应半鞅，X=X0+M+V，X0为几乎处处有限的F0可测向量，M连续局部鞅，V连续适应有限变差。对连续适应H，定义∫H dX=∫H dM+∫H dV；第一项采用31章局部积分，第二项为路径Lebesgue–Stieltjes积分。H在紧区间局部有界，因而两项经局部化存在。V的变差过程连续适应：其变差由有理分割的可数上确界给出，适应性及可测性随之成立。随机Stieltjes积分的可测性先对可预测矩形验证，再用函数单调类推广，与31章随机时钟测度的论证相同。

完整的局部化如下。先在F0事件\(E_R=\{\|X_0\|\le R\}\)上计算；将各M分量首次达到绝对值R、以及各V分量总变差之和首次达到R时停止，必要时再与既有局部化时刻相交。连续性没有越界；停止M有界，故平方可积，\(E([M^\tau]_T)=E((M^\tau_T)^2)\)有限。停止后X在确定紧集，所有连续系数及所用导数可有界化。\(E_R\)之外乘0，最后让R趋无穷并去掉这些停止。原始有限变差、连续性与局部化保证任意固定T被这些事件和停止覆盖的概率趋1。

若H是任意连续适应过程，还须将初值事件缩为\(E_R\cap\{|H_0|\le R\}\)，并把公共停止时刻与H首次满足\(|H_t|\ge R\)的时刻相交；在公共停止过程上取H的停止版本。这样H也有确定界，且这些初值事件和停止仍覆盖每个有限区间。仅在H是紧集上有界的确定连续函数作用于(t,X)时，先前对X的控制才已足够。两种停止积分身份由T-ITO-BRACKET第5节给出。

在这个有界阶段，\(H^n_s=H_{t_i}\)（\(t_i<s\le t_{i+1}\)）为简单可预测过程，路径上一致趋H。等距及Doob估计给下式；其右侧以常数乘\([M]_T\)控制，期望有限，故由DCT趋0。有限变差部分误差至多\(\omega_H(|\pi_n|)\operatorname{Var}(V)_T\)，路径上趋0；此处H与总变差都有确定界，DCT也给该项的L²最大收敛。这证明左端和在局部化后S²、一般情形ucp收敛。对向量逐分量相加即可；最后一格必须截在当前t，不能在公式中偷偷使用未来完整增量。

\[ E\sup_{t\le T}\left|\int_0^t(H^n_s-H_s)\,dM_s\right|^2\le4E\int_0^T|H^n_s-H_s|^2\,d[M]_s\longrightarrow0. \]

## 3. 从Taylor恒等式完成一维与多维公式

<a id="t-ito-general"></a>

定理：对上节的X及F∈C¹,²([0,∞)×R^d)，下式作为连续过程不可分辨身份成立。C¹,²表示一次连续时间导数与二次连续空间偏导，连同函数本身联合连续；不要求二次时间或混合时间空间导数。\(C_{ij}=[M^i,M^j]\)为连续局部有限变差过程，不假定存在dt密度。

\[ F(t,X_t)-F(0,X_0)=\int_0^t F_s(s,X_s)\,ds+\sum_i\int_0^t F_i(s,X_s)\,dX^i_s+\frac12\sum_{i,j}\int_0^t F_{ij}(s,X_s)\,dC_{ij}(s). \]

证明。先采用上节的局部化，对确定分割逐格拆成两步：在新空间位置\(X_{t_{k+1}}\)改变时间，再在旧时间t\_k改变空间。时间差为\(\int_{t_k}^{t_{k+1}}F_s(u,X_{t_{k+1}})\,du\)，它与∫\(F_s\)(u,X\_u)du的总差不超过T乘\(F_s\)在紧集上的空间连续模，距离为\(\omega_X(|\pi|)\)，路径上趋0。空间差令h=ΔX，使用沿线段的一维积分余项，得到准确的下式。

\[ F(t,x+h)-F(t,x)=\sum_i F_i(t,x)h_i+\frac12\sum_{i,j}F_{ij}(t,x)h_ih_j+r(t,x,h),\qquad |r(t,x,h)|\le\frac12\omega_{D_x^2F}(|h|)\|h\|^2. \]

一阶和由第2节收敛到所声明的积分。每个二阶和由第1节的连续随机权重\(F_{ij}\)(s,X\_s)收敛到∫\(F_{ij}\) d\(C_{ij}\)。余项总和一致至多½ω\_{D²F}(\(\omega_X(|\pi|)\))Σ‖ΔX‖²；前因子路径上趋0，后因子紧，所以ucp趋0。向量范数引起的固定维数常数可吸入连续模。包含当前部分格时同样估计成立，时间误差也一致于t≤T。于是整个恒等式在ucp意义下取极限。解除局部化，两个连续过程的差在每个T上的最大值为0几乎必然；对整数T取可数并集，得到全时间的不可分辨身份。没有断言任意分割逐路径几乎必然收敛。

令F与时间无关、d=1即得连续半鞅的一维C²公式；令X=B即得Brownian版本。有限变差坐标的所有二阶项为0，故经典公式确实作为特殊情形恢复。取F(x,y)=xy即得乘积公式，也可直接从有限乘积相减及第1节证明，二者没有逻辑循环。

还需识别变换后的共同波动。若f,h为C²，刚证公式把f(X)的局部鞅部分明确给为Σ∫f\_i(X)dM^i，其余连续有限变差。31章已经独立证明积分的混合括号变换；所以以下身份成立。它不是用本专题的乘积公式倒过来定义协变差。返回[正文32.7](../chapters/32-ito-formula.md#ito-continuous-formula)。

\[ [f(X),h(X)]_t=\sum_{i,j}\int_0^t f_i(X_s)h_j(X_s)\,d[M^i,M^j]_s. \]

## 4. 端点对称积分的定义域与链式法则

<a id="t-ito-stratonovich"></a>

先设H,X均为连续半鞅。每格端点平均和等于左端和加上½ΣΔHΔX，因此由第1、2节ucp收敛；包括当前部分格时恒等式仍精确。定义H∘dX为这一极限，就得到∫H∘dX=∫H dX+½[H,X]。没有把任意连续H都放进这个定义域，更没有假设对称和是鞅。

C²链式法则还要小心一个正则性问题：f∈C²只保证f′∈C¹，不能未经证明就说f′(X)是半鞅。实际需要的扩展可以直接证明。设g∈C¹(R^d)，逐格写Δg(X)=Σ\_j \(g_j\)(\(X_{\mathrm{left}}\))ΔX^j+ρ，|ρ|≤ω\_Dg(\(\omega_X(|\pi|)\))‖ΔX‖。乘ΔX^i再求和，误差由连续模乘Σ‖ΔX‖²控制，ucp趋0。第1节给出下式。∫g(X)dX^i因连续适应局部有界而已存在；因此端点平均和也收敛，我们仅在这个已证明的复合域扩展对称积分。

\[ \sum_k\Delta_k g(X)\Delta_k X^i\xrightarrow{\mathrm{ucp}}\sum_j\int_0^\cdot g_j(X_s)\,dC_{ji}(s). \]

时间—空间版本取确定函数g(t,x)，只要求g及\(D_xg\)联合连续，不必存在时间导数。将每格时间差换成\(q_k=g(t_{k+1},X_{t_k})-g(t_k,X_{t_k})\)。\(q_k\)为\(\mathcal F_{t_k}\)可测，且局部一致趋0。Σ\(q_k\)ΔM^i是简单可预测积分；经第2节有界化，用等距和Doob，其最大平方期望趋0。Σ\(q_k\)ΔV^i以sup|q\_k|Var(V^i)控制。原来在\(X_{t_{k+1}}\)取值的时间差与q\_k之差，再用空间积分的一阶公式，至多为\(\omega^{\mathrm{time}}_{D_xg}(|\pi|)\)‖ΔX‖；乘ΔX后求和也趋0。当前部分格的q可单独以时间连续模乘\(\omega_X(|\pi|)\)控制。因此上面的交叉极限同样对g(t,\(X_t\))成立。

将上段的统一收敛写成显式估计：在局部化后的空间紧集K上，令\(\beta(\delta)=\sup_{|u-v|\le\delta,\,x\in K}|g(u,x)-g(v,x)|\)，时间取[0,T]，则β(δ)趋0。用整格系数\(q_k\)定义包含当前部分格的简单积分J，等距与Doob给下式。真正部分格的时间差与整格\(q_k\)的差再乘鞅增量，最大绝对值至多\(2\beta(\delta)\omega_{M^i}(\delta)\)，趋0；有限变差部分以β(δ)乘总变差控制。D_xg的时间模数乘平方和控制剩余替换误差。因此这里确实是ucp结论，而不只是网格终点的收敛。

\[ E\sup_{t\le T}|J_t|^2\le4\beta(\delta)^2E([M^i]_T)\longrightarrow0. \]

取g=F\_i，其中F∈C¹,²。上面的条件恰好成立；各端点对称积分中的½协变差正好吸收第3节Hessian项。这证明C¹,²的Stratonovich链式法则，不额外假设F\_i是半鞅。若给定连续SDE的\(\sigma_{kj}\)(x)属于C¹，先用31章积分括号变换得[X^k,W^j]=∫\(\sigma_{kj}\)(X)ds，再用刚证复合协变差，得到∫\(\sigma_{ij}\)(X)∘dW^j=∫\(\sigma_{ij}\)(X)dW^j+½Σ\_k∫∂\_k\(\sigma_{ij}\)(X)\(\sigma_{kj}\)(X)ds。它只转换已有解的方程，不证明一般解的存在。返回[正文32.12](../chapters/32-ito-formula.md#ito-stratonovich-domain)。

## 5. 时间中点不一定把平方时钟平分

<a id="t-ito-midpoint"></a>

给出正文反例的完整核验。取0<p<1且p≠½；独立三进制数字为0的概率p，为2的概率1−p，所得Cantor概率\(\nu_p\)的分布函数记\(c_p\)。在第n层，每个允许三进区间的质量q为\(p^k(1-p)^{n-k}\)，最大值≤max(p,1−p)^n趋0。所以单点质量为0，\(c_p\)连续，\(c_p\)(0)=0，\(c_p\)(1)=1；区间中间三分之一上时钟不动。令\(M_t=B_{c_p(t)}\)，t≥1时\(c_p\)=1；采用31章证明的通常增广时间变换滤过，有[M]=\(c_p\)。

把[0,1]等分为3^n格，取每格时间中点\(m_i\)。有质量\(q_i\)的格内，中点已经跨过左子区间、尚未进入右子区间；因此\(a_i=M_{m_i}-M_{t_i}\)的方差p\(q_i\)，\(b_i=M_{t_{i+1}}-M_{m_i}\)的方差(1−p)\(q_i\)。所有这些变量是独立的中心Gaussian；无质量格的增量为0。于是时间中点和比左端和多出的正是\(C_n=\sum_i a_i(a_i+b_i)\)。独立性与Gaussian四阶矩给下面的精确计算。

\[ EC_n=p\sum_i q_i=p,\qquad \operatorname{Var}(C_n)=\{2p^2+p(1-p)\}\sum_i q_i^2\le2\max_i q_i\longrightarrow0. \]

左端积分的能量E∫M\_s² d\(c_p\)(s)=∫\(c_p\)(s)d\(c_p\)(s)=½；连续分布函数的Stieltjes链式法则给最后等号。简单左端逼近的能量误差为Σ∫\_{格i}(\(c_p\)(s)−\(c_p\)(t\_i))d\(c_p\)(s)≤max\_i \(q_i\)，故左端和在终点的L²极限是∫M dM=½(\(M_1^2\)−1)。端点平均和却对每个n都精确等于½\(M_1^2\)。因此时间中点和在固定终点的L²极限是½(\(M_1^2\)−1)+p；p≠½时与端点平均不同。本反例只声明已证明的固定终点L²，不升级为其他网格或其他系数的一般结论。返回[正文32.13](../chapters/32-ito-formula.md#ito-midpoint-clock)。

## 6. 线性方程的显式解与证明责任

<a id="t-ito-linear-models"></a>

设M连续局部鞅、V连续适应有限变差且都从0出发，Z=exp(M+V−½[M])。第3节先证明dZ=Z dM+Z dV；再对负指数应用同一定理，得d(Z^{-1})=−Z^{-1}dM−Z^{-1}dV+Z^{-1}d[M]。若连续适应X满足dX=X dM+X dV，31章积分括号给[X,Z^{-1}]=−∫XZ^{-1}d[M]。乘积公式各项抵消，XZ^{-1}=X0。所有计算都可在|X|、Z、Z^{-1}和总时钟的退出时刻内有界化再解除停止，因而没有预设X严格正，也无需对log X用公式。这里同时给构造与这类方程的路径唯一性。

令M=σB、V=μt，即得正文几何Brownian公式。一般有限F0可测初值通过F0有界事件局部化处理；若初值绝对可积，Gaussian指数矩与独立增量给E[\(X_t\)|F0]=X0 exp(μt)，不把任意非负局部鞅都当成真鞅。若V=0，一般Z只是非负局部鞅；由停止后的鞅及条件Fatou只能先得超鞅。换测度定理和真鞅判据不在本证明范围。

OU公式的确定性积分因子e^{θt}与X的协变差为0，乘积公式给\(d(e^{\theta t}(X_t-m))=\sigma e^{\theta t}\,dB_t\)。正文的显式积分因此存在并满足方程。两个解之差满足\(D_t=-\theta\int_0^tD_s\,ds\)，故逐路径D=0，经典ODE论证即可。未来积分从简单确定被积函数的Gaussian线性组合L²逼近得到Gaussian，且独立于\(\mathcal F_s\)：先对简单函数的特征函数验证联合独立，再以L²收敛及有界特征函数取极限。因此正文的条件均值、方差及平稳Gaussian初值的协方差均有实际依据，而非仅形式求解。

这里的条件规律不依赖“所有SDE解都是Markov过程”这种未经建立的断言。对有界Borel函数f，未来Gaussian积分独立于\(\mathcal F_s\)，直接给\(E[f(U_t)\mid\mathcal F_s]=K_{t-s}f(U_s)\)。令\(a_u=e^{-\theta u}\)、\(v_u=\sigma^2(1-e^{-2\theta u})/(2\theta)\)，核\(K_u\)为均值\(m+a_u(x-m)\)、方差\(v_u\)的Gaussian。两次Gaussian积分使中心化均值的衰减因子相乘，并把缩放后的过去方差与新方差相加，具体给\(a_{u+v}=a_va_u\)、\(v_{u+v}=a_v^2v_u+v_v\)，所以\(K_uK_v=K_{u+v}\)。这实际建立OU的时间齐次Markov转移与有界Borel观测上的半群，不借第35章一般SDE结论。

对f∈C²且紧支撑，Lf与σf′有界；有限时间上的噪声积分平方可积、均值0。Fubini由Lf有界保证，得正文32.18的期望积分身份。确定初值x时，U_s趋x路径上成立，Lf连续有界，DCT再给该处的点态导数。第28章28.3、28.5区分C₀-Feller强连续性与其生成元的上确界范数定义域，本段没有用点态导数替代这些要求；若系数时变，Itô漂移记L_t，不能自动给单参数半群。一般有限但不可积初值下，上述均值、方差说的是条件Gaussian核的矩；L¹条件期望身份另须相应可积性。
