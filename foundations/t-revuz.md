# T-REVUZ：对称Hunt过程的连续有界势对应

配套[第38章](../chapters/38-feynman-kac.md#revuz-class)。本页实际证明一个非Brownian专用的双向定理，不把最广右过程理论冒充已证。Hunt指右连续强Markov且准左连续；准左连续指递增停止时刻Tₙ↑T、Tₙ<T时，在T<ζ上X_{Tₙ}→X_T。下面只需其càdlàg实现、Markov性和所声明的核条件；不以尚未建立的Dirichlet形式存在定理构造过程。

## 1. 准确的过程类、测度类和等价关系

<a id="revuz-proof-class"></a>

假设E为紧度量空间，m为有限满支撑Borel测度，X为保守m-对称Feller Hunt过程，使用规范路径空间和通常滤过。Pₜ1=1及对称性给m不变。对每个λ>0，假设resolvent有在E×E联合连续的有限非负对称核rλ，Rλf(x)=∫\(r_\lambda(x,y)\)f(y)m(dy)。紧性使核有界。该条件确实限制了过程类，二维及更高维Brownian的对角Green奇点不满足；不能悄悄把它省略。

\[ U_1^A(x)=E_x\int_0^\infty e^{-s}dA_s,\quad R_1\mu(x)=\int_Er_1(x,y)\mu(dy),\quad \mu\in\mathcal M_+(E),\ \mu(E)<\infty. \]

PCAF为适应、从0连续递增、有限时间有限且\(A_{s+t}\)=A_s+A_t∘θ_s的泛函，身份在一个对各起点概率1的移位不变集合上成立。本定理的泛函类明确要求U₁ᴬ有有界连续版本，并且定义在所有起点；两个泛函若对每个x不可分辨即视为等价。结论：有限正μ与此类PCAF一一对应，U₁ᴬ=R₁μ。对应还满足下一节的全部测试身份，而不只一个小时间极限。

紧区间上的反射Brownian是一个非空例子：余弦展开给\(r_\lambda(x,y)\)=1/(λl)+(2/l)∑ₖ≥₁ cos(kπx/l)cos(kπy/l)/(λ+(kπ/l)²/2)，级数一致绝对收敛；27/28章的半群或折叠Brownian构造给过程。有限可逆连续时间链也是例子。无限状态、非对称、仅准连续势以及所有平滑测度的最广定理，不由这些例子自动推出。

## 2. 从空间测度实际构造路径累积

<a id="revuz-proof-construction"></a>

令u=R₁μ∈C(E)，取整数n≥2，\(f_n=nR_n\mu\)，uₙ=R₁fₙ=\(nR_nu\)。最后的交换由resolvent核的半群积分及Tonelli证明：先对f m验证算子恒等式，再利用核的联合连续性和m满支撑把几乎处处的核恒等式延到全部y，才可对奇异μ积分。Feller强连续性使uₙ→u一致。fₙ连续有界非负，Aₙ(t)=∫₀ᵗfₙ(Xₛ)ds是现成的规范PCAF。

\[ E_x\left(\int_0^\infty e^{-s}f(X_s)ds\right)^2=2R_2(fR_1f)(x),\quad |R_1f|\le\varepsilon\ \Longrightarrow\ E_x\left|\int_0^\infty e^{-s}f(X_s)ds\right|^2\le2\varepsilon R_2|f|(x). \]

对有界带符号f，把平方分成s<t两块、条件化于s；时间对角Lebesgue为0，给第一式。取f=fₙ−fₖ，R₂|f|≤R₁(fₙ+fₖ)≤2‖u‖∞，所以右侧随‖uₙ−uₖ‖∞趋0。闭鞅为条件期望Mₜ=∫₀ᵗ\(e^{-s}\)f(Xₛ)ds+\(e^{-t}\)R₁f(Xₜ)。Doob L²给折扣积分的最大范数Cauchy；去折扣用普通分部积分，在[0,T]最多乘2eᵀ。故Aₙ于每个有限T在L²最大范数收敛，估计对x一致。

选同一子列，使在[0,j]的平方误差上确界期望≤2^{-j}；Borel–Cantelli对每个x给规范路径上的局部一致极限A。定义集合Λ为这条子列在所有整数时域上一致Cauchy的路径集，它是Borel且PₓΛ=1。因为每个Aₙ精确加性，ω∈Λ自动使θ_sω∈Λ，对全部实s≥0成立；所以极限是同一个移位不变版本，不是逐起点另选不相容零集。极限连续递增、适应且有限。Λ的补集对所有起点均为零测，通常增广将它放入初始σ代数，故在其上设A=0不破坏适应性。

对折扣尾部，Eₓ∫ₜ∞\(e^{-s}\)dAₙ=\(e^{-t}\)Pₜuₙ≤\(e^{-t}\)‖u‖∞。有限时域L²收敛加该一致尾界给U₁ᴬ=u。若f,g连续非负，则Stieltjes积分∫f(X)dAₙ趋∫f(X)dA：X的跳点至多可数，A连续不收费，故弱测度收敛的有界非连续测试准则适用；Aₙ(t)的L²一致界给期望UI。

\[ \int_Eg(x)E_x\int_0^t f(X_s)dA_s\,m(dx)=\int_0^t\int_E(P_sg)(y)f(y)\mu(dy)ds. \]

逼近情形由m对称性直接成立。测度fₙm=nRₙ^*μ弱趋μ，因为∫h fₙdm=∫nRₙh dμ且nRₙh→h一致；其总质量=μ(E)。对每个s连续测试fPₛg取极限，再以该质量界DCT穿过时间。函数单调类把f,g推广至非负Borel，得到上式。小时间极限对连续g由Pₛg→g一致推出，这才是Revuz读数。

## 3. 从一份已有PCAF恢复测度

<a id="revuz-proof-reverse"></a>

现在A属于第1节声明的类，\(u_A\)=U₁ᴬ有界连续。E_mA₁≤e∫\(u_A\) dm有限。以m为初始测度时过程平稳，加性使随机收费测度f(Xₛ)dAₛ的期望在时间平移下不变；因此E_m∫₀ᵗf(Xₛ)dAₛ=t\(\mu_A\)(f)，其中\(\mu_A\)(f)=E_m∫₀¹f(Xₛ)dAₛ。对指示函数用MCT，\(\mu_A\)是有限Borel测度；紧度量空间上有限Borel测度Radon，此正则性由8章紧逼近结论得到。

要把平稳平均变回起点x的势，不能假定dA独立于过去。令\(\nu_h\)(dx)=h^{-1}EₓA_h m(dx)，总质量恒为\(\mu_A\)(E)。对连续f，在[0,T]分成长度h的小格，把∫f(Xₛ)dAₛ替换为左端f(\(X_{kh}\))乘A增量。路径càdlàg而A无原子给逐路径收敛，绝对界2‖f‖∞A_T可积。平稳性使这些左端和的期望为Nh\(\nu_h\)(f)，剩余不足h的区间期望≤h‖f‖∞\(\mu_A\)(E)。所以\(\nu_h\)弱趋\(\mu_A\)。这一整段平均论证避免了对A_h/h未经证明的一致可积假设。

在同一网格再乘g(X₀)。给定\(X_{kh}\)，未来A增量由Markov与加性决定；m对称性把起点g传到\(P_{kh}g\)，故期望和为h∑ν_h(f\(P_{kh}g\))。对连续f,g，Feller强连续性使s↦fPₛg在C(E)范数连续；ν_h质量有界、弱收敛，故网格和趋∫₀ᵀ\(\mu_A\)(fPₛg)ds。具体地先把s按固定粗网格逼近，误差由一致连续性控制，再对有限多个连续测试取弱极限。左侧由上述Stieltjes/DCT论证收敛，得到第2节的双变量身份。

\[ \int_Eg\,u_A\,dm=\int_E R_1g\,d\mu_A=\int_Eg\,R_1\mu_A\,dm,\qquad u_A=R_1\mu_A. \]

对时间Laplace积分及f=1使用Tonelli，给第一行。m满支撑、两边连续使m几乎处处身份延到所有x。若A,B有同一势u，Dₜᴬ=∫₀ᵗ\(e^{-s}\)dAₛ满足Dₜᴬ+\(e^{-t}\)u(Xₜ)=E[∫₀∞\(e^{-s}\)dAₛ|Fₜ]，B同样。相减后Dᴬ−Dᴮ为连续有限变差真鞅；31章结论使其恒0。因此泛函不可分辨。这个唯一性还证明从μ构造再恢复所得就是μ，不只拥有相同总质量。

## 4. 归一化、奇异测度和未完成的最广版本

<a id="revuz-proof-boundary"></a>

若m换成cm而过程不变，rλ换成rλ/c，同一A的Revuz测度变成cμ。参考dx时一维Brownian的Lᵃ对应δₐ；参考速度2dx时对应2δₐ。对反射Brownian，调节量K=½L^{0,+}；其零边界小带占用密度与内部的对称L必须分别计算，不能在边界直接照抄内部因子。这里不用未经核验的边界δ公式完成定理。

最广的标准表述允许局部紧状态空间、m-对称Hunt过程及与正规Dirichlet形式相联系的容量；平滑μ不收费于容量零集，并有闭巢Fₙ使μ(Fₙ)<∞且巢补集的容量在每个紧集内趋0。PCAF只需在适当例外起点集之外定义，按共同不可分辨版本识别。此处“平滑”是容量/巢条件，不是具有光滑密度。一般非对称右过程还需要指定过分参考测度及相应例外集理论。

本页没有完成从任意这类平滑μ到有限能量巢的逼近、准连续势的共同版本与拼接，也没有证明任意PCAF自动具有本页的连续有界势。因此这些广版本仍是实质证明缺口，单独登记为T-REVUZ的开放范围；它们不是“只差独立终审”。本页完整建立的是第1节明确类中的双向定理，其构造、唯一性和测试身份均已实际写出。正文使用它时只采用已证范围；一维全空间显式Radon局部时构造另由37章成立，不从紧空间定理偷渡。
