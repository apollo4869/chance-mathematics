# T-ARRAYS：共享指标、条件独立与有限阶表示的完整证明

本专题证明：任意固定有限阶、非空标准Borel取值的联合交换关系数组，都有按指标子集共享独立均匀数的表示，包括重复指标与对角。先证同时带全部低阶标记的无序子集版本，再编码有序关系。二维分别交换由T-ARRAY-VARIANTS另证。只用第8章可数实验、第9章L²投影、第10章标准Borel核/随机化与T-DIRECTING-MEASURE的概率参数空间；不借第47章划分或第49章一般随机测度。返回[第46章](../chapters/46-arrays.md#arrays-proof-mechanism)。

## 1. 准确陈述以及实际需要的可测工具

<a id="arrays-proof-statement"></a>

固定整数r≥0，给非空标准Borel空间S₀,…,Sᵣ。对所有有限a⊂N、|a|≤r，有\(S_{|a|}\)值随机元Zₐ；包括一项Z∅。联合交换指每个有限置换π使整族(Zπa)与(Zₐ)同律。存在Borel函数fₗ，各自对局部顶点重新编号不变，使整族具有下列同一概率律。所有\(U_b\)独立Uniform(0,1)，一个子集b只使用一个\(U_b\)，不因它出现在不同a内而重抽。

\[ (Z_a)_{|a|\le r}\ \stackrel d=\ \left(f_{|a|}\big((U_b)_{b\subseteq a}\big)\right)_{|a|\le r}. \]

有限局部输入以a的任意枚举识别到[|a|]的子集；函数不变性使结果不依赖该枚举。r=0时，单个Z∅由一个均匀数随机化，结论成立。以下归纳步不把条件独立当作已知。

第10章的核随机化可统一选成\(\Gamma_S\):P(S)×(0,1)→S。具体将S双向Borel编码到[0,1]的Borel子集，以有理CDF评价构造分位数，越出编码集时用固定点修复。每份概率上的越界只占均匀数零集；函数在全部参数上Borel。P(S)的评价σ代数标准Borel性已在[T-DIRECTING-MEASURE](t-directing-measure.md#directing-proof-space)实际证明。在均匀数端点取固定值可把随机化延到闭区间，不改变任何概率。因此后面Γ只取决于一份概率本身，而不取决于描述这份核的其他方式。

## 2. 条件期望的范数怎样检测额外信息

<a id="arrays-proof-projection"></a>

若𝓖⊂𝓗、V∈L²，投影的Pythagoras恒等式如下。因此两个条件期望的L²范数相同，便足以证明它们作为随机变量相同。

\[ \|\mathbb E[V\mid\mathcal H]-\mathbb E[V\mid\mathcal G]\|_2^2=\|\mathbb E[V\mid\mathcal H]\|_2^2-\|\mathbb E[V\mid\mathcal G]\|_2^2. \]

还会比较不在同一σ代数内、但由同分布资料生成的投影。其范数只依赖(V,Y)的联合律，因为平方误差最优预测可写为下式。Y可为可数资料向量；其值空间仍标准Borel，Doob–Dynkin分解适用。

\[ \|\mathbb E[V\mid\sigma(Y)]\|_2^2=\sup_{h\text{ bounded Borel}}\{2\mathbb E[Vh(Y)]-\mathbb E[h(Y)^2]\}. \]

上界由配方得到；把真正条件期望的可测版本截断，便达到该上确界。因此下面通过重新编号得到的范数相等不是形式上的“信息量相同”，而是可核算的投影恒等式。

## 3. 留出无限背景，并消除编码中的编号偏向

<a id="arrays-proof-reservoir"></a>

归纳假设已经处理r−1。把指标集重新分成两个可数无限集合N与R。以原指标的一个双射构造全体资料；任意有限目标指标的边际仍是原律，因为有限单射都可延拓为有限置换。这同时证明了任意指标单射保持全族的分布：逐个有限柱集验证，再用可数乘积唯一性。

独立附加iid连续标记Rᵢ∼Uniform(0,1)，作为第1阶标签的一部分；本归纳步仍用S₁记扩大的一级值空间，最后投影回原标签。所有标记两两不等的事件有概率1，这是可数对的零集并。本证明的σ代数包含关系按模P理解，必要时加入全部环境零集；排序在此共同满概率集上进行，L²投影不受其外版本影响。对每个a⊂N、|a|<r，构造背景档案Yₐ：记录所有\(Z_c\)，其中|c|≤r且c∩N⊂a，并记录R中的全部辅助标记以及a内标记。a内的顶点按这些辅助标记从小到大排列，背景R使用固定可数枚举。

严格说，|a|=l时，记录坐标由b⊂[l]与有限d⊂R、|b|+|d|≤r索引，坐标值是相应\(S_{|b|+|d|}\)，加上l个排序标记与背景标记列。其值空间\(T_l\)只限制有限排序条件，是可数标准Borel乘积的Borel子空间；不把所有可实现档案的像未经证明当作Borel。并列的零概率输入用固定标签补全。使用辅助标记的目的只是让Yₐ成为不带外部编号的随机元：若重排N，标记随顶点移动，内部排序不变，所以整族(Yₐ)为通常的子集交换族，而不是携带一个未经说明的坐标置换作用。

在r≥2时，单点档案给每个具名顶点自己的标记，故给定(\(Y_b\))对b⊊e，能从排序记录中恢复全部\(Z_c\)，只要c∩N是e的真子集；反向每份档案当然只使用这些资料。r=1时局部资料只有Y∅，正好是纯背景。另有固定Borel投影从Yₐ取回原Zₐ，因为它是“全部l个正指标、没有背景指标”的那一格。这些细节保证下一节的σ代数包含关系真实成立。

## 4. 把其余顶点放进背景的范数夹逼

<a id="arrays-proof-independence"></a>

固定r集e⊂N，V=f(\(Z_e\))，f有界实Borel。令𝓖由(Yₐ:a⊊e)生成；𝓗由全部低阶Yₐ以及任意有限多个不同于e的r阶\(Z_b\)生成。显然𝓖⊂𝓗。把R分为T和R∖T两个无限集，选单射γ：固定e逐点，R双射进T，N∖e双射进R∖T。全族单射不变性使V与𝓗中资料在变换前后具有同一联合分布。

记变换后的资料σ代数为𝓙。每个背景档案Yₐ用的正顶点至多r−1个，所以其像中仍有至少一个e的顶点缺席；其他r集b≠e的像也不能等于e。于是所有像资料只涉及“在e内的真子集，加上一些R指标”。排序需要的辅助标记也已在𝓖里。因此𝓙⊂𝓖，而不是未经证明地宣称𝓙与𝓖相等。

\[ \|\mathbb E[V\mid\mathcal G]\|_2\le\|\mathbb E[V\mid\mathcal H]\|_2=\|\mathbb E[V\mid\mathcal J]\|_2\le\|\mathbb E[V\mid\mathcal G]\|_2. \]

等号由上一节的联合律与投影范数公式给出。Pythagoras于是证明E[V|𝓗]=E[V|𝓖]。对任意有限个不同r集，依次剥去最后一项并用塔式性质，得到：给定全部低阶档案后，r阶变量条件独立，而且\(Z_e\)的条件律只依赖局部档案(Yₐ:a⊊e)。剥去时，其他因子的条件核已经是全部档案的可测函数，所以同一条件期望身份仍可使用。

\[ \mathbb E\left[\prod_{e\in A}h_e(Z_e)\,\middle|\,(Y_a)_{|a|<r}\right]=\prod_{e\in A}K_{h_e}\big((Y_a)_{a\subsetneq e}\big),\qquad A\text{ finite}. \]

## 5. 从条件期望到一份共同的可测核

<a id="arrays-proof-kernel"></a>

对标准目标e=[r]，第10章给局部资料v=(\(Y_b\):b⊊[r])到Sᵣ的正规条件核K(v,·)。局部资料空间是有限标准Borel乘积；它的律以及与\(Z_{[r]}\)的联合律在r个局部顶点的任意置换下不变。将K对这有限群平均，得到处处为概率的Borel核K*，并且K*(σv,A)=K*(v,A)对所有参数、所有置换和所有Borel A成立。

平均仍是同一个条件律版本：对局部资料的有界测试逐个换元，再使用联合不变性验证积分身份。给任意e选一个顶点枚举，交换性使同一个K*可用。每个Sᵣ有可数生成代数；在这些测试、全部r集及有限r集族上共同删去一个零集，再以两次单调类推广到全部Borel测试。这给出一份真正的共同条件乘积律，而不是为不可数测试各选不同版本。

## 6. 完成归纳，且保持同一子集使用同一噪声

<a id="arrays-proof-induction"></a>

低阶档案族(Yₐ:|a|<r)本身满足归纳假设，故可在独立\(U_b\)、|b|<r上同时表示。对每个r集e，从这些函数生成它的局部档案\(v_e\)，再使用独立\(U_e\)，定义\(Z'_e=\Gamma(K^*(v_e),U_e)\)。给定全部低阶均匀数，它们具有上节的条件乘积律；对低阶均匀数积分，便恢复原全部档案与r阶资料的联合律。原低阶Zₐ由档案的固定投影取回。

K*的局部不变性、归纳函数的不变性以及Γ只依赖概率本身，使新顶层函数在所有输入上也局部不变。原辅助标记并列的集合在原律为零；表示保留其律，故也可在同一个可数共同零集外正确解码。最后忘掉独立附加的标记，便完成r步归纳。所有函数均由Borel投影、有限排序、核积分与可测随机化组合而成。

反向也有证明：给任意有限置换π，整族(\(U_{\pi b}\))仍是一族独立均匀数；局部函数不变性把变换后的输出准确变为\(Z_{\pi a}\)。因此构造必定给联合交换族。定理是“任意这样的交换律都能表示”与“此种构造总是交换”两个方向，而不是只验证后者。

## 7. 有序关系与重复指标的完整解码

<a id="arrays-proof-ordered"></a>

现给有限d及联合交换数组\(X_{i_1,\ldots,i_d}\)，允许指标重复。再附加独立连续标记Rᵢ。对每个a、1≤|a|=l≤d，按标记排序其顶点a₁,…,\(a_l\)，存下所有满射v:[d]→[l]对应的\(X_{a_{v(1)},\ldots,a_{v(d)}}\)，作为一个\(S_l\)值标签Zₐ；满射集合有限。l=1同时存下该顶点标记。空标签可为单点。这个多层子集标记族联合交换，值空间为有限标准Borel乘积。

应用刚证明的定理。给一条目标有序元组，先取其支持集a；表示中的单点标签提供每个具名顶点的Rᵢ，排序并定位元组所对应的满射坐标，然后从表示的Zₐ取出该格。并列时统一取固定值。因原Rᵢ两两不同，表示律中解码也几乎处处正确；所有元组可数，共同零集合法。这实际证明了每种相等模式都由其支持集的全部子集噪声决定，未把有序方向或对角项略为“类似”。

\[ X_{ij}=F(U_\varnothing,U_{\{i\}},U_{\{j\}},U_{\{i,j\}})\ (i\ne j),\qquad X_{ii}=D(U_\varnothing,U_{\{i\}}). \]

二维时，这就是完整的有向、带对角Aldous–Hoover表示；反向边使用同一个无序对噪声，交换前两个顶点输入即可。若原数组对称，可让成对标签只存一个值；所得F对两个顶点输入对称。若边独立但只在给定顶点后才独立，表示依然使用同一组顶点输入，不为每条边重抽它们。

## 8. 范围与不能附加的结论

<a id="arrays-proof-scope"></a>

已证任意固定有限阶的联合交换标准Borel关系族及全部重复模式，也可同时处理有限多个关系种类，取有限乘积标签即可。没有断言不可数关系种类、非标准Borel目标或一般无限元关系都由同一证明覆盖。表示为同一数组的概率律，不声称原空间本来就存在这些独立U，亦不声称表示函数或各潜变量能从观测唯一恢复。分别交换的多类型构造、极端性与函数识别分别在后续三个实际专题证明。
