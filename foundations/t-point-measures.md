# T-POINT-MEASURES：点测度的状态空间

返回[第48章](../chapters/48-point-processes.md#points-state)。E始终采用T-RIESZ的局部紧第二可数度量空间假设，取其度量、紧穷竭和局部截断函数。

## 1. 整数值测度为什么真是一批点

<a id="point-space-atoms"></a>

记Mₚ(E)为在紧集上有限、对每个相对紧Borel集取非负整数值的Radon测度。它们恰为Σmⱼδₓⱼ，其中不同xⱼ、正整数mⱼ，且每个紧集只含有限总重数。证明并不需要原子分解定理：若μ在某个点附近没有任何原子，却有正质量，局部有限性与μ({x})=0让每点都有质量<1的邻域。这些邻域的测度必须为0，可数基给零质量可数覆盖，矛盾。每个非零单点质量为正整数；紧窗口只能有有限个这样的点，穷竭便给全部原子。对余下非原子部分重复上述论证，质量为0。

## 2. 可数连续测试与vague度量

<a id="point-space-tests"></a>

取0≤χₘ∈\(C_c\)，χₘ≥1于Kₘ。各紧窗口中连续函数可分：利用度量上的有限网及分割单位，分段插值有理网值，再将网格大小缩小，得到可数一致稠密族。以χₘ截断，在\(C_c^+\)中取可数族(fⱼ)，使每个非负紧支撑连续函数可在同一个较大紧集内被它们一致逼近；将χₘ及所有非负有理线性组合加入族。用下式度量Mₚ。

\[ d(\xi,\eta)=\sum_{j\ge1}2^{-j}\bigl(1\wedge|\xi f_j-\eta f_j|\bigr),\qquad \xi f=\int f\,d\xi. \]

这些测试分离测度，故d确为度量。d收敛使各χₘ积分有界，从而紧窗口质量一致有界；一致函数逼近便把坐标收敛推广到所有\(C_c\)测试。反向由各坐标收敛与级数尾界成立。这正是vague收敛，不是总质量或全部有界连续测试的收敛。

## 3. 有界局部计数怎样产生紧性

<a id="point-space-compact"></a>

若ξₙ(Kₘ)≤aₘ对所有n,m成立，先对可数测试逐次抽子列，得到全部坐标极限。任意固定支撑的测试由局部质量界延拓到极限正线性泛函L；线性、正性从序列保留，一致逼近误差≤局部计数界乘上确界误差。T-RIESZ给唯一Radon极限μ。它仍为整数测度，证明如下。

在相对紧开球B上，若μ(∂B)=0，连续内外截断证明ξₙ(B)→μ(B)，所以μ(B)为整数。对每个球心，除了可数个半径以外，球面μ质量为0：不交球面在一个有限质量大球内不可能有不可数个正质量。因此每点有任意小的这种球。若μ({x})<1，足够小的连续性球质量<1，遂为0；所有非原子点可被可数个这种零球覆盖。剩余单点质量由递减连续性球的整数极限得到整数。故μ∈Mₚ，抽取所得确为点测度极限。给定逐窗口界的集合因而相对紧，其闭包紧。

若序列是d-Cauchy，各坐标为实数Cauchy，从χₘ得到局部质量界。上一论证给收敛子列，Cauchy性使全序列收敛，故d完备。有限多重配置放在E的可数稠密点集上是稠密的：先截断到一个足够大的窗口，再将有限多个位置各自移近，检验有限多个测试，最后控制度量尾。因此Mₚ是Polish空间。这里证明的是整数测度的最小拓扑，不是预先使用第49章一般随机测度定理。

## 4. 评价σ代数与可测枚举

<a id="point-space-measurable"></a>

每个ξ↦ξfⱼ在评价σ代数内可测，故vague Borel包含于评价σ代数。反向，对开U取递增\(C_c\)非负函数趋\(\mathbf1_U\)（紧穷竭及距离截断给出），ξ(U)为可测上确界。要推广到所有Borel集，先在相对紧开窗口V内使用有限量ξ(V)：已知开子集评价，可用补集减法与不交并构成Dynkin类，π–λ给V内所有Borel评价。再对可数窗口穷竭取极限。因此两种σ代数相同，也都由可数测试坐标生成。

标记构造还需可测地枚举每一个点的出现，而非只枚举支撑。把E分成可数个相对紧Borel片Dₘ，每片点数有限；例如Kₘ∖Kₘ₋₁。选标准Borel编码b:E→B⊂(0,1)。在每片按b值排列，重复位置按重数重复。第j小编码由有理q上的计数ξ(Dₘ∩{b≤q})≥j恢复，因而可测；有限个编码保证所得确在B，逆编码可测。j超出点数时放墓地点。可数个(m,j)给所需枚举。此排序只是构造工具，不给点增加固有身份。
