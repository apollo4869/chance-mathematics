# 小集分裂、周期测度与Harris常返

## 1. 把假设逐点写清

<a id="regen-assumptions"></a>

本专题的主线在标准Borel空间E上。P为概率核，C为非空可测集，ν为概率，0<ε<1，且对每个x∈C、每个可测A有P(x,A)≥εν(A)。此外从每个x出发，链访问C无穷多次的概率为1。ε=1可通过改取ε/2而归入本约定。这是明确的再生假设，不把“不可约”误当作这一不等式的证明。

在C上令\(R_x\)=(P(x,·)−εν)/(1−ε)，C外令\(R_x\)=P(x,·)。每一步先在x∈C时抽一个新Bernoulli(ε)硬币δ；成功则下一状态从ν抽，失败从\(R_x\)抽。C外δ=0，下一状态从P抽。用核随机化与独立均匀序列实际构造，或对这份可测联合核应用T-SEQUENTIAL。对硬币求和后的转移严格等于P。

记录硬币发生在离开\(X_n\)之前；再生时刻是成功转移的终点n+1，不是成功硬币所在的n。给定成功以前的整段信息与成功时刻，\(X_{n+1}\)的律都是ν。访问C无穷次时，前k次尝试全部失败的概率为(1−ε)ᵏ，所以首个以及每个后继再生时刻都有限。

## 2. 半开周期与停止信息

<a id="regen-cycles"></a>

从一个再生终点X₀∼ν开始，L是下一个再生终点。周期标记为(L,X₀,…,\(X_{L-1}\))，不包含下一个终点\(X_L\)。它落在可数不交并\(\bigsqcup _{l\ge 1}\)({l}×Eˡ)中，仍为标准Borel。成功终点独立于前一个半开周期，故此后这些标记独立同分布。任意x只增加一个几乎必然有限的初始延迟。

再生是扩大的信息流中的停止构造；原始链的强Markov性质只在已有合法停止时刻使用。特别是不能先观察下一状态，再在不校正条件律的情况下宣布硬币独立。本段的顺序抽样避免了这个错误。给定L=l的周期标记核由标准Borel析取得到，只对P(L=l)>0的整数需要指定；其余任取。

## 3. 周期占用是一份不变测度

<a id="regen-measure"></a>

\[ m(A)=E_\nu\sum_{n=0}^{L-1}\mathbf1_A(X_n),\qquad \mu=E_\nu L=m(E)\in[1,\infty]. \]

这是可数可加测度，来自非负求和与Tonelli。令\(S_n\)={L>n}；它只知道前n次转移还没有再生，不知道第n次新硬币。因此E[\(\mathbf1_{S_n}\)f(\(X_{n+1}\))]=E[\(\mathbf1_{S_n}\)Pf(\(X_n\))]。对指标f求和，右边等于mPf，左边把半开周期向前平移一格，移走X₀并补入\(X_L\)。两端的分布同为ν，故mP=m。即使mf=∞，也是两个非负级数的恒等式，移去或加入的端点期望至多1，不作∞−∞运算。

每访问一次C就尝试一次，直到成功；因此m(C)=1/ε。令\(A_{jk}\)={x:Pʲ(x,C)≥1/k}，j≥0、k≥1。所有x都能到C，这些集合覆盖E。不变性给m(\(A_{jk}\))≤k mPʲ(C)=k/ε，所以m为σ有限，且非零。这个覆盖是不能省略的测度论步骤：有限周期长度几乎必然并不意味着期望周期长度有限。

若m(A)>0，则一个ν周期访问A的概率严格为正。独立重复周期使A在所有初态下被无穷多次访问。因此链对ψ=m是Harris常返。这里Harris意指每个固定正ψ集合以概率1无穷次被访问，零集可依A而变；不是声称某条路径同时访问所有不可数多的集合。

## 4. 正常返与零常返的分界

<a id="regen-positive"></a>

若μ<∞，π=m/μ为不变概率。其唯一性不需要先证明非周期收敛：周期报酬强律给每个有界f的时间平均趋πf，从任意初态成立。若η也是不变概率，在η初态下对有界f用有界收敛取期望，ηf=πf。可数决定类或直接对各指标给η=π。

若μ=∞，不能归一化m。下面也证明不存在另一份不变概率。用上节可数有限测度覆盖构造处处正、至多1、且m(g)<∞的可测g，例如枚举覆盖\(B_j\)后取Σ 2⁻ʲ\(\mathbf1_{B_j}\)/(1+m(\(B_j\)))。独立周期长度的截断强律给\(R_k\)/k→∞，所以已完成周期数N(n)/n→0。周期g报酬可积，最后一个完整周期报酬\(Y_k\)满足\(Y_k\)/k→0（尾概率可求和）；于是总g报酬/n→0。初始有限延迟不影响结论。

若有不变概率η，有界收敛将迫使ηg=0，与g处处正矛盾。这说明再生范围内“有不变概率”恰对应有限平均周期；Harris常返本身只保证周期有限，不保证平均有限。完整报酬/余项步骤见[T-HARRIS-RATIO](t-harris-ratio.md)。

## 5. 多步小集的实际提取

<a id="regen-small-extraction"></a>

还可以在标准Borel空间证明一个实质性的提取引理：若P为ψ不可约，则存在m≥1及ψ(C)>0的m步小集。它并不把Pᵐ在全部初态上的Harris常返或非周期性自动包括进来；后面仍须核验那项骨架条件。

取与ψ等价的概率λ。对每个k≥1，将联合测度λ(dx)Pᵏ(x,dy)相对于λ⊗λ作Lebesgue分解，AC密度记\(r_k\)(x,y)。奇异余项的第一边缘受λ控制；标准Borel析取及一个可数决定代数使Pᵏ(x,dy)=\(r_k\)(x,y)λ(dy)+\(S_k\)(x,dy)对λ几乎所有x同时成立。联合奇异集N的λ截面几乎处处为零，而\(S_k\)集中于\(N_x\)，所以\(S_k\)(x,·)与λ奇异。这实际证明了需要的逐行分解，而不是预设一个未来的一般带参数定理。

令R=\(\sum _{k\ge 1}\)2⁻ᵏPᵏ。不可约性给λ≪R(x,·)，这里命中取正时刻n≥1。可数个奇异余项仍奇异，故\(r_R\)=Σ2⁻ᵏ\(r_k\)在λ⊗λ几乎处处严格正。因此至少一个k的行密度\(r_k\)(x,·)在正λ集合上非零。L¹(λ)可分：可数生成代数的有理简单函数稠密。行映射可测，因为到这些简单函数的L¹距离可测。选其分布支撑内一个非零非负g；每个L¹球{‖\(r_k\)(x,·)−g‖₁<δ}都有正λ质量。

对某个l≥1，\(h_l\)(y)=∫g(z)min(\(r_l\)(z,y),1)λ(dz)在一个正λ集合上正；否则对l求和将与\(r_R\)>0及g非零矛盾。选δ>0和正λ集合B使\(h_l\)>2δ，令C为上述半径δ球的逆像，并去掉已知行分解例外集。则每个x∈C都有如下测度下界。

\[ P^{k+l}(x,dy)\ge\left[\int r_k(x,z)\min(r_l(z,y),1)\lambda(dz)\right]\lambda(dy)\ge\delta\,\mathbf1_B(y)\lambda(dy). \]

第一步用行分解和核复合；第二步用‖\(r_k\)(x,·)−g‖₁<δ及截断函数min(\(r_l\),1)≤1。取ν=λ|B/λ(B)，ε≤δλ(B)，便得到m=k+l的小集。由于C有正ψ质量，原Harris链会反复访问C；但这些访问不一定已经被证明落在指定模m的时刻，不能直接跳过骨架常返的检验。

## 6. 真正构造错时耦合

<a id="regen-shift"></a>

从x、y分别生成各自第一再生以前的半开前缀与终点时刻R、S。终点尚未抽取；两份前缀之后的终点都应独立服从ν。现在只抽一次Z∼ν，令\(X_R\)=\(Y_S\)=Z，随后用共同的P核随机化生成未来。终点独立前缀保证每条边缘路径完全正确，且R、S有限。这个证明允许μ=∞以及周期性。
