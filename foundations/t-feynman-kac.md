# T-FEYNMAN-KAC：从条件分解到经典解、边界与测度源

配套[第38章](../chapters/38-feynman-kac.md#fk-discovery)。所有过程用通常增广滤过，退出后放入墓地、测试函数在墓地取0。随机积分仅使用31–35章已建版本；局部时间使用37章的对称Brownian归一化。以下各定理的过程类别分别声明，不能互相扩大。

## 1. 先在短时间后重新结算

<a id="fk-proof-dynamic"></a>

令X为强Markov过程，τ为开集D的退出时刻，q≥0有界Borel，f有界，g为有界终端或边界报酬。Qₜ=∫₀ᵗq(Xₛ)ds。先处理有限时域T；终端函数h有界。Markov性和普通Fubini给以下逐次结算身份，对停止时刻S≤T同样成立。积分项绝对值≤T‖f‖∞，故条件期望与积分交换合法。

\[ u(t,x)=E_x\left[e^{-Q_t}h(X_t)+\int_0^te^{-Q_s}f(X_s)ds\right],\quad u(t,x)=E_x\left[\int_0^Se^{-Q_s}f(X_s)ds+e^{-Q_S}u(t-S,X_S)\right]. \]

只把S换成确定小时间还不能推出可微性。若X解35章非爆炸SDE，系数时间齐次且局部Lipschitz，且v∈\(C^{1,2}\)有界、终端v(0)=h、满足∂ₜv=Lv−qv+f，则对\(e^{-Q_s}\)v(t−s,Xₛ)用32章乘积与Itô公式。在离开大球及随机积分能量达到n时停止，漂移只剩−\(e^{-Q_s}\)f。取期望后，让n趋∞；v、f有界使边界项DCT，得到v=u。这是经典解的验证及唯一性，不是假设期望表达式已经\(C^{1,2}\)。本节声明为时间齐次运动及势；一般时变系数应改用带起始时间与终端时间的后向方程，不能从此处正向时间记号直接推出。

## 2. 真正构造一类经典抛物解

<a id="fk-proof-parabolic"></a>

现在取Rᵈ上的标准Brownian，Pₜ为Gaussian卷积。令h,q,f及它们到二阶的空间导数有界一致连续，q≥0，f与时间无关。记这些函数的Banach空间为C²_bu，范数是各阶导数上确界之和；其完备性由逐导数一致极限及线段积分基本定理证明。Gaussian卷积是此空间的收缩，且Pₜv→v于此范数，直接来自一致连续及Gaussian尾界。

\[ u(t)=P_th+\int_0^tP_{t-s}(f-qu(s))ds. \]

在C([0,T];C²_bu)逐次代入右侧；乘法v↦qv的算子范数有限。第n次差被C(C_qT)ⁿ/n!控制，所以所有T上收敛且唯一。二阶导数可穿过时间积分，因该Banach范数收敛。热半群恒等式Pₜv−v=½∫₀ᵗPₛΔv ds由Gaussian分部积分或Itô验证，对C²_bu成立。将差商用于温和方程，强连续性给∂ₜu=½Δu−qu+f，时间导数在C_bu中连续。因此确实得到\(C^{1,2}\)解，上一节才把它与路径期望识别。

若只给有界Borel h，Gaussian在t>0平滑并不保证t=0经典连续：h=1_{x>0}时u(t,0)=1/2，h(0)=0。这不是Feynman–Kac失效，而是初值的实现只能在相应弱或几乎处处意义下讨论。一般退化SDE也不能照搬Gaussian平滑。

## 3. 任意有界域中的调和性

<a id="fk-proof-dirichlet"></a>

令D⊂Rᵈ有界开，τ=τ_D，g为有界Borel边界函数。Brownian连续性保证退出点在∂D。把D包在半径R的球内，停止|B|²−dt给Eₓτ≤4R²/d，故τ有限。h(x)=Eₓg(Bτ)在D有界。对任何闭包包含于D的小球V，强Markov给h(x)=Eₓh(BτV)。从球心出发的退出方向由旋转不变性为球面均匀分布，故h有球面均值性质。

这也证明正则性而非假设它：选支撑在小球的光滑径向概率核η，把各半径的球面均值积分得h=h*η。右侧光滑，故h在内部C∞；均值公式在半径r做二阶展开给Δh=0。反过来有界C²调和函数在紧球停止的Itô鞅给同一均值性质；若它连续实现边界g，D内球域耗尽、τₙ↑τ和有界DCT给其等于h。

边界另需条件。若z∈∂D存在局部正的连续超调和屏障b，b(x)→0于z且在远离z的局部人工边界下界c>0，停止超鞅给Pₓ先逃离z附近再退出D≤b(x)/c。连续g的振幅分成近z小振幅及远端至多2‖g‖∞，所以h(x)→g(z)。外切球提供这样的屏障：\(d\ge3\)用ρ^{2−d}−|x−c|^{2−d}，d=2用log(|x−c|/ρ)，一维用线性距离；必要时把邻域缩小。局部球与D只在z相切，保证人工边界正下界。

若一个外球在其他邻近边界也相切，单个径向屏障未必严格隔离z；使用严格外球条件即可，上述结论不偷偷覆盖所有外锥域。反例为\(d\ge2\)的穿孔球D={0<|x|<1}：0是边界孤点，令g(0)=1、外球面g=0，g在边界连续。径向调和函数给从r出发先达ε再达1的概率：二维为log(1/r)/log(1/ε)，高维为(\(r^{2-d}\)−1)/(\(\varepsilon^{2-d}\)−1)，趋0。故点0极性，h≡0，不能实现g(0)=1。内部解合法，并不保证指定边界值合法。

## 4. 源项的概率解，为什么内部可微

<a id="fk-proof-elliptic"></a>

在上一节D内令f,q有界局部α-Hölder，0<α<1，q≥0，g有界Borel。定义u=E[e^{-Qτ}g(Bτ)+∫₀τ\(e^{-Q_s}\)f(Bₛ)ds]。退出均值界使u有界。强Markov给球V内的同一结算式；把指数中的q展开，用条件期望和Fubini，可消去折扣得到u=H_Vu+G_V(f−qu)。绝对可积界为C Eτ_V，二次积分有Eτ_V²<∞；后者由球内退出均值一致有界及Markov给几何尾。

所需Green正则性可直接核查。基本解Φ满足−½ΔΦ=δ：\(d\ge3\)时为2|x|^{2−d}/((d−2)|S^{d−1}|)，d=2为−log|x|/π，d=1为−|x|。径向求导及小球通量验证常数。对紧支撑有界w，Φ*w的梯度核在原点可积，故它局部连续并局部Lipschitz。球Green势只差一个光滑调和修正。此身份先对光滑紧支撑w证明：对v=Φ*w用Itô停止，得v(x)−Eₓv(BτV)=Eₓ∫₀τVw(Bₛ)ds。两侧作为w的积分泛函定义局部有限测度，光滑测试稠密及测度唯一性把核身份延到全部有界Borel w；非负情形用MCT，带符号情形用退出均值界。这样识别Green核并未预先假设一般u可微。因此上式先证明u局部连续且局部Lipschitz，随后w=f−qu局部α-Hölder。二阶核以w(x−y)−w(x)抵消奇点，近0的绝对积分受∫₀ʳs^{α−1}ds控制；截断积分分部及小球通量给−½Δ(Φ*w)=w。于是u∈C²(D)、½Δu−qu=−f。这里两次使用不同强度的正则性，不能一步假定期望C²。

球的调和修正取基本解势在球边界上的退出平均；其内部光滑性已由第3节均值性质与径向卷积证明，无需再调用另一条未证的Poisson核定理。一维用端点线性插值。若z有严格外球屏障，源项贡献由Eₓτ_D→0消失：先用屏障控制离开小邻域的概率，再用τ_D的统一二阶矩做Cauchy–Schwarz，邻域内退出时间由小球界控制。因此u实现连续g。

无界域必须另查终端项和一致可积性。例如在(0,∞)，h(x)=x是经典调和、边界0；Brownian首达0有限，但Eₓh(Bτ)=0≠x。停止在n再取极限时，远端极小概率携带n的值，停止族不UI。不能把有限停止的Itô恒等式直接送到无穷退出时刻。

## 5. 奇异收费给出的弱方程

<a id="fk-proof-singular"></a>

取有界区间I=(a,b)、有限正Radonμ、\(f\in L^2(I)\)，给定有限端点值gₐ,g_b。令H为绝对连续、端点0、导数L²的函数空间；‖v‖∞≤√(b−a)‖v′‖₂给Poincaré及点值连续。H完备：导数L²极限积分恢复v，端点约束通过积分保持。以B(v,w)=½∫v′w′dx+∫vw dμ为内积，其范数与H范数等价。令h为端点g的线性函数，右侧ℓ(w)=∫fw dx−B(h,w)连续。Hilbert投影证明Riesz表示：在连续线性泛函核的正交补取单位向量即可，因此唯一v∈H满足B(v,w)=ℓ(w)，u=h+v。

\[ \frac12\int_Iu^\prime\varphi^\prime dx+\int_Iu\varphi\,d\mu=\int_If\varphi\,dx,\quad\varphi\in H,\qquad \frac12u^{\prime\prime}=u\mu-f\,dx\quad\hbox{as distributions}. \]

u连续有界，右侧为有限带符号测度，故u′有BV版本，u是两凸函数之差：二阶测度正负部分分别积分(x−y)⁺即可构造，剩余为线性函数。这不是假定u∈C²。将37章Tanaka对二阶测度积分，随机Fubini由局部时矩界和测度总变差保证，得广义Itô：u(Bₜ)=u(x)+∫u′₋(Bₛ)dBₛ+½∫Lₜʸu″(dy)。停止在退出I，u′在闭区间有界，积分能量的期望由Eτ有限保证。

Aₜ=∫L_{t∧τ}ʸμ(dy)连续有限，且dLʸ只支撑B=y，所以乘积e^{-A}u(B)中的uμ项精确消去。取期望并令停止时刻增加到τ，f项用E∫|f(B)|ds=∫G_I|f|dx有限控制，边界项有界。得到以下概率表示。原弱解唯一，故两种构造确实同一；没有先假设概率式属于H。

\[ u(x)=E_x\left[e^{-A_\tau}g(B_\tau)+\int_0^\tau e^{-A_s}f(B_s)ds\right],\quad \mu=\gamma\delta_c\ \Longrightarrow\ u^\prime(c+)-u^\prime(c-)=2\gamma u(c). \]

点收费产生导数跳跃而不是普通函数q(c)的选择。若写q=0几乎处处，便错误地丢失整颗原子。与37章速度原子也不同：速度原子改变运动时钟，这里的μ在原Brownian时钟上改变权重。两者使用同一个局部时，却承担不同的数学职责。

## 6. 加性代价的算子恒等式

<a id="fk-proof-resolvent"></a>

对连续PCAF A，定义Pₜᴬf=Eₓ[\(e^{-A_t}\)f(Xₜ);t<ζ]。加性及Markov立即给半群；非负f用Tonelli得到其Laplace resolvent。若A=∫q(X)ds，q≥0有界，则1−\(e^{-A_t}\)=∫₀ᵗq(Xₛ)e^{-(Aₜ−Aₛ)}ds，先条件化后得Duhamel，Laplace交换给Rλᴬ=Rλ−Rλ(qRλᴬ)。乘法与算子的次序不能交换。对一般连续A，同样以Stieltjes积分替代qds；有界f、λ>0时由非负分拆或绝对界‖f‖∞/λ成立。
