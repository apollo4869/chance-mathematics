# T-ERGODIC-DECOMPOSITION：标准Borel遍历分解

本页完成[第41章§41.13](../chapters/41-ergodic-theory.md#ergodic-decomposition)。设(E,B)标准Borel，T:E→E为Borel映射，P为T不变概率。使用Borelσ域构造核，再按P完成化解释条件期望。结论是P几乎处处的核分解，不是对所有初始点的无例外分类。

## 1. 把不变信息变成一个可条件化的参数

<a id="decomposition-proof-parameter"></a>

取可数生成代数A={A_j}，含E且封闭有限并交补。对每个j选h_j=E[1_{A_j}|I]的Borel代表，值在[0,1]；模零I可测变量总有Borel代表，因为完成化只增添零集。令H=(h_j)映到[0,1]ᴺ，G=σ(H)。每个h_j不变模P，故G⊂I模P。

反过来，对B∈I，用A简单函数g_n在L²(P)逼近1_B。此稠密性由指标单调类与有限测度逼近证明，不假设B在代数内。条件收缩使E[g_n|I]→1_B于L²；每个条件平均都是h_j的有限线性组合，故极限有G可测代表。因此I与G模P相同。这个论证没有断言任意σ代数在点集意义可数生成。

## 2. 条件核的三个共同零集

<a id="decomposition-proof-kernel"></a>

第10章标准Borel条件核给K(z,dx)作为给定H的正则条件概率，令P_ω=K(H(ω),·)。对所有A_j，P_ω(A_j)=h_j(ω)同时在一个共同满测集成立；积分给P(A)=∫P_ω(A)P(dω)，先代数再π–λ。

此外P_ω{H(x)=H(ω)}=1几乎处处。具体地，给定H以后，每个h_j是否落在一个有理端点区间已经确定，所以条件核在这些可数测试上给同样的0或1。取共同零集，再用区间分离不同实数，得到所有j的相等，而非只得到同分布。

对A_j与C∈I，保测给∫_C1_{T⁻¹A_j}dP=∫_C1_{A_j}dP。因此P_ω(T⁻¹A_j)=P_ω(A_j)几乎处处。可数取交后，两份概率P_ω∘T⁻¹与P_ω在代数上相同，π–λ使它们在B上相同。所有保留下来的P_ω确为T不变概率；没有逐个Borel集合选不同的例外ω。

## 3. 为什么每份条件核真的遍历

<a id="decomposition-proof-ergodicity"></a>

Birkhoff对可数个1_{A_j}给一个满P集Nᶜ，在其中所有时间平均趋h_j(x)。因P(N)=0，分解身份使P_ω(N)=0几乎处处。再与上一节的共同集合相交，给P_ω几乎每个x上Aₙ1_{A_j}(x)→h_j(ω)，即对x为常数。

在概率P_ω下有界收敛也给L²收敛。上一页的均值遍历适用于这份已证不变的概率，因此E_{P_ω}[1_{A_j}|I(P_ω)]是常数。代数简单函数在每份L²(P_ω)中稠密；投影连续性使所有I(P_ω)可测变量只能为常数。特别是不变事件指标，故P_ω遍历。这个论证处理了一个常见缺口：P_ω下的不变事件未必是原P下同一个模零不变事件，不能直接在两份完成化之间转移事件。

## 4. 积分变量、唯一性与任意空间的可数因子

<a id="decomposition-proof-scope"></a>

对指定f∈L¹(P)，Tonelli使P_ω|f|有限几乎处处；核积分P_ωf给E[f|G]=E[f|I]的版本。对可数个指定f可统一零集。若另一个关于同一G的核也给条件概率，可数代数上的条件期望唯一使两核共同几乎处处相等，再以π–λ推广。分解参数可以重新标记，零测起点上的核可不同，均不改变这份测度论唯一性。

任意概率空间若只需研究可数族f_j及其所有前向平移，映射Φ(ω)=(f_j(Tᵏω))_{j,k}进入实数可数乘积，满足Φ∘T=S∘Φ。其推前概率标准Borel且保测，所研究变量都能在这个因子上恢复。因此次可加定理可以先在可数记录因子证明后拉回，不必声称原空间本身具有正则条件分解。这是后页使用分解时的合法范围。[返回正文](../chapters/41-ergodic-theory.md#ergodic-subadditive)。
