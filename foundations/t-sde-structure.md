# T-SDE-STRUCTURE：规律、输入与共同随机空间

与[第35章](../chapters/35-sde-wellposedness.md)配套。前置为第10章标准Borel核分解，第24章连续路径弱收敛，第31–32章连续积分及Itô，第33章连续局部鞅的Lévy刻画，T-SDE-WELLPOSEDNESS 1直接证明的连续鞅p阶上界。基本构造已在[T-SDE-WELLPOSEDNESS](t-sde-wellposedness.md)写出；这里不借一般Bichteler–Dellacherie逆向或未来局部时。

## 1. 从鞅问题构造Brownian驱动

<a id="sde-proof-mp"></a>

设b:Rᵈ→Rᵈ、σ:Rᵈ→Rᵈˣᵐ为局部有界Borel，a=σσᵀ。在C([0,∞),Rᵈ)上的概率Q若使每个f∈C_c∞的正文读数成为坐标自然滤过下的局部鞅，便称解决连续鞅问题。初始分布给定；假定路径取有限值于全部有限时刻，不含爆炸。局部有界性使每条紧路径上的漂移与能量局部有限。

正向由Itô公式与较大球内截断得到。逆向取χ_R等于1于半径R+1球；测试χ_R xᵢ和χ_R xᵢxⱼ，停止于τ_R。测试函数在球内与坐标及乘积完全相同，故Mᵢ=Xᵢ−X₀ᵢ−∫bᵢ(X)ds为连续局部鞅。对坐标乘积，代入连续半鞅乘积公式，读出MᵢMⱼ−∫aᵢⱼ(X)ds为局部鞅。连续有限变差局部鞅恒定，给[Mᵢ,Mⱼ]=∫aᵢⱼ。放开R，各紧路径被某球容纳，身份相容。

先将坐标滤过作通常增广。右连续化保留连续局部鞅：对有界停止的M，sₙ↓s时条件期望对递减σ代数收敛，E[Mₜ|Fₛ₊]=limMₛₙ=Mₛ；完备化只增加零集。再扩大空间乘独立m维Wiener空间，原鞅仍是鞅，由独立矩形检验与单调类可知。其与独立Brownian的共同括号为0：乘积为局部鞅，再用乘积公式。

\[ \sigma^+(x)=\lim_{n\to\infty}\sigma(x)^\top(a(x)+n^{-1}I_d)^{-1},\quad P(x)=\sigma^+(x)\sigma(x),\quad Q(x)=\sigma(x)\sigma^+(x). \]

奇异值分解逐点证明极限有限，P、Q为相应像空间的正交投影，σ⁺a(σ⁺)ᵀ=P。该公式也证明Borel可测性，无需先选可测特征向量。因为X连续适应，Borel函数复合可预测；∫tr(σ⁺a(σ⁺)ᵀ)ds≤mT，尽管伪逆可能无界，其积分可在第31章随机时钟方法的向量能量延拓中构造。

这里必须使用向量协方差能量，不能从总二次型有限直接断言每个分量积分各自有有限能量。先停M到L²窗口，对有界矩阵简单H，条件正交与混合括号给E|∫H dM|²=E∫tr(HaHᵀ)ds。令Hₙ=σ⁺1_{||σ⁺||≤n}；其有界可预测积分由第31章逐分量构造。两截断之差的联合能量是∫tr(P)1_{截断带}ds，由mT支配并趋0，所以最大L²极限定义完整向量积分，再放开M的停止。平方能量及混合括号按同一截断极限传递。这补足了在退化相关坐标间可能存在抵消时的构造。以下有界局部σ的积分结合律也先在这些截断上成立，再以共同协方差能量取极限。

\[ W_t=\int_0^t\sigma^+(X_s)dM_s+\int_0^t(I_m-P(X_s))d\overline W_s,\qquad [W^i,W^j]_t=\delta_{ij}t. \]

Lévy刻画使W成为扩大通常滤过中的Brownian运动，特别包括其增量独立于F₀。另一方面∫σdW=∫QdM，因σ(I−P)=0；M−∫QdM的括号为∫(I−Q)a(I−Q)ᵀds=0，故差恒0。得到弱SDE。平方根的选择不唯一，但弱SDE路径规律与a有关；这一构造不声称原坐标滤过必须包含所需全部Brownian方向。

## 2. 因果条件核与Yamada–Watanabe

<a id="sde-proof-yw"></a>

考虑确定Borel b(t,x)、σ(t,x)的连续Brownian SDE，在固定初始规律μ、非爆炸且满足局部漂移/平方能量条件的弱解类别中。假设至少一份弱解存在且路径唯一。输入空间Y=Rᵈ×C₀([0,∞),Rᵐ)，输出空间S=C([0,∞),Rᵈ)，二者Polish。第10章给条件核K(y,dx)，输入规律ν=μ⊗Wiener。对每个有理t及输出过去事件A，K(y,A)有只依赖y到t的版本。

证明这个最后断言：未来Brownian增量独立于原Fₜ，而A及输入过去均在Fₜ。对过去输入函数u及未来增量函数v，有E[1_Au v]=E[1_Au]E[v]。令kₜ=E[1_A|ξ,W≤t]，也有E[kₜu v]=E[1_Au]E[v]。过去与未来输入圆柱生成整个输入σ代数，单调类给E[1_A|Y]=kₜ。只需在可数的有理坐标生成类上取共同零集，再推广到所有过去事件。

给两份弱解的核K₁、K₂构造Π(dy,dx₁,dx₂)=ν(dy)K₁(y,dx₁)K₂(y,dx₂)。对两个输出过去圆柱A₁、A₂及输入过去函数u，条件乘积K₁(y,A₁)K₂(y,A₂)u只依赖输入过去。因此它与任何未来增量函数因子v分离，W未来仍独立于扩大过去。由单调类对所有扩大过去成立。右连续化/完备化如第1节处理，W仍为Brownian。两份初值等于共同ξ。

积分方程也保留，不能只保留(Xᵢ,W)的分布却忽略新滤过。令H=σ(t,Xₜ)，先停止使能量有界并截断H，再用向后时间平均n∫_(t−1/n)₊^t Hₛds作连续适应逼近；在dt×P的L²中收敛。对每个连续逼近，用确定网格左值的简单积分逼近，Doob与等距给ucp收敛。取对角序列使两份边缘规律下误差同时趋0，这是一列只依赖(X,W)的Borel路径泛函。新空间上的积分由同一等距逼近定义，所以边缘律相同便使方程继续成立。漂移是普通可测积分，直接由边缘律保留。放开停止，得到两个真正的弱解。

先K₁=K₂=K，路径唯一性给Π(X₁=X₂)=1。因此对ν几乎每个y，K(y,·)⊗K(y,·)集中于对角。取S的可数分离代数Bₖ，有K(y,Bₖ)(1−K(y,Bₖ))=0；若概率不是一点质量，则两个不同支撑点有不相交开邻域及正质量，与这一0–1性矛盾。这里Polish概率紧性保证支撑有满测度，可由可数开基直接构造。故K(y)=δF(y)。

点的可测选择可以显式完成：对S作嵌套可数Borel分区，直径≤2⁻ⁿ，选唯一质量1的格子及其中预定代表；嵌套代表形成Cauchy列，极限就是F。S完备，极限可测；在零集任取固定路径。对输出到有理t的每个生成事件，1_{F(Y)∈A}=K(Y,A)仅依赖输入过去。因此F(Y)的有理坐标适应；任意t从右侧有理时刻取连续极限，在输入通常增广滤过中适应。

(X,Y)的联合律等于(F(Y),Y)，故在任何给定输入规律ν上，F(Y)以刚才的积分泛函定义满足方程，是真正强解。再将K₁、K₂作交叉耦合，路径唯一性给δF₁(y)=δF₂(y)几乎处处，故联合律乃至X的律唯一。本证明针对固定μ；不未经另外可测参数论证就宣称一个对所有μ、所有初值共同的逐路径函数。

## 3. 计数检验与鞅问题的适定性

<a id="sde-proof-tests"></a>

局部鞅问题的“每个测试函数”可由可数类控制：在每个紧球上，C_c∞函数及至二阶导数的统一范数具有可数稠密子集，取所有整数球的并。局部有界系数使生成元误差被二阶统一误差控制；停止出球及时间T后，鞅检验有界且UI，故稠密极限通过条件期望。过去测试也只需有理坐标的可数生成代数，再由单调类扩展。

在全局有界连续系数下，Euler弱存在已证。若SDE路径唯一，则第2节与第1节的两向实现给鞅问题分布唯一。若初值xₙ→x，解路径的统一四阶增量界及有界初值给紧性；任一极限通过第1个专题相同的有界连续鞅检验，解初值x的鞅问题。唯一性迫使整列Qₓₙ⇒Qₓ。因此x↦Qₓ弱连续，特别是Borel核。这个论证也适用于全局Lipschitz线性增长系数，使用统一矩界局部化。

## 4. 停止以后仍是同一条局部规则

<a id="sde-proof-markov"></a>

先全局Lipschitz、时间齐次。Picard在输入初值与Wiener路径上的简单积分逼近给一个联合Borel解泛函；对随机初值可先用有限值近似，稳定估计将泛函关系传递到极限。确定s后Brownian增量独立过去，停止积分身份使后段满足从Xₛ启动的同一SDE。路径唯一性与独立输入核给正文Markov等式。

Pₜf连续于有界连续f：xₙ→x的最大L²稳定性给Xˣⁿₜ→Xˣₜ依概率，有限维读数的有界性给期望收敛。若还需C₀不变，必须另有控制无穷远进入紧集的条件，本节不以C_b-Feller冒充完整C₀-Feller。对有界停止S，取Sₙ=2⁻ⁿ(⌊2ⁿS⌋+1)。格点分片给E[f(Xₛₙ₊ₜ)|Fₛₙ]=Pₜf(Xₛₙ)。对A∈F_S⊂Fₛₙ积分，路径连续与Pₜf连续使两侧DCT通过极限。故停止Markov等式对C_b成立，再由函数单调类推广到B_b。有限S截断于整数并取并；过程未来的多时刻分布由条件迭代得到，才是强Markov。

还可不指定强解泛函，直接对上一节的适定鞅问题证明。范围限全局有界连续系数，或已有统一局部矩控制的全局Lipschitz线性增长情形。固定有界S，对停止后的连续路径取给定F_S的正则条件核；先在未增广的标准Borel坐标路径空间取给定停止过去的核，完备化只改变零集。可数鞅检验及有界抽样证明该核几乎处处解初值X_S的同一鞅问题：测试S+r、S+t，先离散逼近S，再用连续性及有界/停止支配；过去圆柱事件成为条件核下的检验。可数类保证同一个例外零集，稠密性恢复全部f。唯一性于是使条件核等于Q_{X_S}。x↦Q_x的Borel性已证，不依赖未说明的可测选择。这证明该准确范围的鞅问题强Markov性。

## 5. 共同连续的C¹前向流与Jacobian

<a id="sde-proof-flow"></a>

假设时间齐次b、σ∈Cᵦ³(Rᵈ)，σ列为σₖ。对0≤s≤t≤T定义Φₛ,ₜ(x)，并在t<s时延拓为x。对任意p≥2，连续BDG和Hölder给以下工具：若系数差由L|U−V|支配，E sup|U−V|ᵖ≤C(E|起始差|ᵖ+E|残差|ᵖ的相应积分)。具体地，漂移用Tᵖ⁻¹∫|差|ᵖ；噪声用C_p Tᵖᐟ²⁻¹∫||差||ᵖ，余下用Gronwall。

\[ E\sup_{t\le T}|\Phi_{s,t}(x)-\Phi_{r,t}(y)|^p\le C_{T,p,K}\bigl(|x-y|^p+|s-r|^{p/2}\bigr),\qquad |x|,|y|\le K. \]

对不同起始时刻，先把从较早时刻到较晚时刻的短增量估计为C|s−r|ᵖᐟ²，再在共同后段用差估计；在两时刻之间同一短增量界成立。取p任意大，对参数(s,x)使用值于C([0,T])最大范数空间的Kolmogorov网格证明：维数d+1，邻接网格差的p矩≤Cδᵖᐟ²，选择p/2>d+1，再对坏边Markov估计及Borel–Cantelli求和。得到局部Hölder的C路径值版本，故(s,t,x)共同连续。对整数T、K可数拼合。

沿Φ构造矩阵线性SDE J=I+∫Db(Φ)Jdu+∑∫Dσₖ(Φ)JdWₖ。随机系数适应且有界，Picard差估计不要求系数确定，故仍给唯一连续J，所有p阶最大矩局部一致有界。J参数差中，Db(Φˣ)−Db(Φʸ)由有界二阶导数控制，Hölder用2p矩，得到与上一式同型的p阶参数差界。因此J也有共同连续版本。

取方向v，差商Dʰ=(Φ(x+hv)−Φ(x))/h。积分形式的均值定理使其系数为沿两状态线段的Db、Dσ平均。与Jv作差，二阶导数界给系数误差≤C|Φ(x+hv)−Φ(x)|；前述2p矩给E||Dʰ−Jv||ᵖ_T≤C|h|ᵖ|v|²ᵖ。为把平均可微变为逐路径可微，先在Lᵖ(C路径)中沿一条有限线段分割求和：每个小段的误差范数≤C|段长|²，全部误差随网格趋0；J的连续性给Riemann和极限。于是

\[ \Phi_{s,t}(y)-\Phi_{s,t}(x)=\int_0^1J_{s,t}(x+\theta(y-x))(y-x)d\theta. \]

先对有理s、x、y取共同零集，再以共同连续性扩展至所有参数。该身份给x↦Φ的经典C¹性且导数J；没有将仅固定x的Lᵖ差商收敛直接冒充路径C¹。流关系先对有理s≤u及有理x由路径唯一性得到，因为从u起两过程具有相同初值并满足同方程。共同连续性扩展到所有s≤u≤t、x。

\[ dK=K\left(-A+\sum_kB_k^2\right)dt-\sum_kKB_kdW^k,\quad K_{s,s}=I,\quad A=Db(\Phi),\quad B_k=D\sigma_k(\Phi),\quad d(KJ)=0. \]

K的线性方程同样可构造，参数连续性也由有界导数和矩估计得到。乘积公式中交叉项−∑KBₖ²J恰好抵消额外漂移，于是KJ=I，先在可数参数上再同时延拓。有限维逆函数定理给每张Φ为局部C¹微分同胚。但局部非奇异本身不足以保证全局双射；还需要排除无穷远的状态挤进一个有限区域。

这一步在Cᵦ³条件下也可补全。令D(s,t,x)=Φₛ,ₜ(x)−x。系数有界给E||D(s,·,k)||ᵖ_T≤C_T,p，不依赖整数格点k。空间差与起始时刻差的前述界也不依赖k。对每个单位立方体k+[0,1]ᵈ，在参数(s,x)上逐层用二进网格；第j层至多C2ʲ⁽ᵈ⁺¹⁾条边，每边差的Lᵖ(C路径)范数≤C2⁻ʲᐟ²。因此该层最大边差的Lᵖ范数≤C2⁻ʲ⁽¹ᐟ²⁻⁽ᵈ⁺¹⁾ᐟᵖ⁾，取p>2(d+1)使层和有限。Minkowski与网格连续延拓得到E sup_{s≤t≤T,x∈k+[0,1]ᵈ}|D|ᵖ≤C_T,p，对全部k同一常数。

Markov不等式使这个立方体上的最大位移超过|k|/2的概率≤C|k|⁻ᵖ；对整数格点可求和，Borel–Cantelli说明仅有限个坏立方体。因此在同一个概率1集合上，|x|→∞时inf_{s≤t≤T}|Φₛ,ₜ(x)|→∞。每张映射适当（紧集的逆像紧），且这个性质在时间参数上共同成立。

最后核验从局部到全局的拓扑步骤。固定s、t，像集由局部逆为开；若像中yₙ→y，适当性使其原像有收敛子列，所以像也闭，非空即为全部Rᵈ。每个y的原像离散又紧，故有限。每份局部逆可随(s,t,y)连续变化：用基点处J的逆矩阵，把求Φₛ,ₜ(x)=y改写成小球上的压缩映射；共同连续导数保证邻近参数仍压缩。适当性排除邻近参数突然出现远处的新原像，因此原像个数局部恒定。沿t从s连续变化，这个整数始终等于t=s时的1。故每张Φ全局一一且满，局部C¹逆拼成全局C¹逆；共同参数连续性与逆导数也由上述局部构造给出。这样实际建立了Cᵦ³系数下的C¹随机微分同胚流，而没有借未来逆时间随机微积分。
