# 局部共同质量、漂移与定量Harris定理

## 1. 何时局部共同质量能够反复发挥作用

<a id="drift-assumptions"></a>

设E标准Borel，V:E→[1,∞)处处有限，PV≤γV+K，0<γ<1、K≥0。取R>max(1,2K/(1−γ))，C={V≤R}，且已验证对C有P(x,·)≥εν，0<ε<1。R、ε和ν是明确给定数据，不是由“噪声存在”自动推出。

令d=(1−γ)R−K>0。C外一步条件漂移≤−d，有限停止求和给\(E_x\)(\(\tau _C\)∧n)≤V(x)/d；单调收敛得\(E_x\)\(\tau _C\)≤V(x)/d。对从C离开的下一步再用此界，得到有限平均返回。分裂失败后的下一状态V均值至多(γR+K)/(1−ε)，成功后的νV至多(γR+K)/ε。几何次数的尝试配合这些统一界使ν再生周期均值有限。

所以小集会被反复访问，本章再生测度可归一化并给Harris正常返。下面另一个直接压缩证明还给非周期的几何收敛，不需要先证明某个隐含的周期跨度。

## 2. 加权距离不是增加一个无关范数

<a id="drift-metric"></a>

\[ w(x)=1+\beta V(x),\quad d_\beta(x,y)=\mathbf1_{\{x\ne y\}}\bigl(2+\beta V(x)+\beta V(y)\bigr),\quad \|\mu-\eta\|_w=\int w\,d|\mu-\eta|. \]

这是真正的度量：若x≠z，经过不同的y时三角不等式右边比左边多2+2βV(y)，重合情形直接成立。共同部分a=min(dμ/dλ,dη/dλ)λ可放在对角线；剩余互相奇异。其耦合的平均dβ恰为∫w d|μ−η|。任意耦合平均代价不小于这个值，因为其对角质量不超过共同部分。因而加权变差既是对有界于w的观测函数的最坏误差，也是最佳加权耦合代价。

## 3. 远处与近处的两个估计

<a id="drift-contraction"></a>

设S=V(x)+V(y)，x≠y。若S≥R，用任意独立下一步耦合，有期望代价≤2+βγS+2βK。与当前2+βS相比，因R>2K/(1−γ)，其比值统一小于1。若S<R，两点同在C；用共同εν部分使下一步以至少ε的概率相等，剩余部分得到期望代价≤2(1−ε)+βγS+2βK。选β>0使β(γR+2K)≤ε，后者至多2−ε。

\[ r=\max\left\{\gamma,\frac{2+\beta\gamma R+2\beta K}{2+\beta R},1-\frac{\varepsilon}{2}\right\}<1,\qquad E\,d_\beta(X_1,Y_1)\le r\,d_\beta(x,y). \]

在x=y时取对角核。所有分支都可测，先对初始μ、η作共同部分最优耦合，再条件使用上面的转移耦合，得\(\|\mu P-\eta P\|_w\)≤r\(\|\mu -\eta \|_w\)。这里不能只用两个过程各自回到C：必须控制两点同时所处的区域。S的分区正是为此而设。

## 4. 完备性、存在性与所有初态

<a id="drift-existence"></a>

有限w矩概率在此范数下完备：乘以w把有限带权有符号测度等距映到有限变差测度；后者由L¹密度或级数证明完备。极限仍非负、总质量1，且w积分有限。P由漂移保持此空间。于是迭代\(\delta _x\)Pⁿ为压缩Cauchy序列，极限π不变，且πV≤K/(1−γ)由有限矩下积分漂移得到。

\[ d_{\rm TV}(P^n(x,\cdot),\pi)\le\frac{r^n}{2}\bigl(2+\beta V(x)+\beta\pi V\bigr). \]

若η是不满足有限V矩的另一份不变概率，仍可逐点积分上式的总变差上界与1的较小者，用有界收敛得到ηPⁿ→π，故η=π。任何初始概率也收敛，但不由此得到对所有初态统一的几何常数。

## 5. 可计算的Gaussian例子与返回

<a id="drift-ar"></a>

对\(X_{n+1}\)=a\(X_n\)+σ\(Z_{n+1}\)，|a|<1、σ>0、独立标准正态Z，取V=1+x²，PV=1+a²x²+σ²≤γV+K，选a²<γ<1及足够K。C为紧区间；在任一固定紧目标区间D=[−b,b]，Gaussian转移密度在C×D有正的共同下界c。令ν为D均匀律，ε可取小于min(1,2bc)，便验证minorization。故存在唯一不变律并有上节定量界。

独立正态和或特征函数直接验证N(0,σ²/(1−a²))不变，唯一性识别π。若两条路径只使用同一Z，差恰为aⁿ(x−y)；当a≠0且x≠y时永不精确相遇。于是同一模型中，总变差遗忘成立，而这个特定的同步耦合不成功。换一份耦合可以成功，并不改变任何单条路径律。

回到[第42章漂移判据](../chapters/42-harris-coupling.md#harris-drift)。这是给定漂移与小集数据的完整几何Harris充分定理，不是断言所有正常返系统都有几何速度。
