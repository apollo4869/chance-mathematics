# T-ERGODIC：保测平均、最大引理与逐点极限

本页为[第41章](../chapters/41-ergodic-theory.md#ergodic-birkhoff)给出完整的概率保测版本。T可测且P∘T⁻¹=P，不要求可逆；函数先为实值，复值按实虚部处理。I按模P不变事件定义。以下的a.s.零集可同时覆盖一份指定的可数测试族，不无条件覆盖全部L¹。

## 1. 空间分解、条件投影与有界稠密类

<a id="ergodic-proof-mean"></a>

对指标的保测积分恒等式，先用简单函数再用单调收敛，得Eφ∘T=Eφ；可积有符号φ分别取正负。故U在L²为等距，\(U^*\)U=I。D₀=ran(I−U)的正交补为ker(I−\(U^*\))。若\(U^*\)h=h，‖Uh−h‖²=2‖h‖²−2〈Uh,h〉=0；若Uh=h，则\(U^*\)h=\(U^*\)Uh=h。因此D₀的闭包恰为Fix U的正交补。

对余边界Aₙ(I−U)g=(g−Uⁿg)/n，其L²范数至多2‖g‖₂/n。不变函数不变；Aₙ为收缩，所以正交分解给Aₙf→Pf于L²。Fix U=L²(I)，第9章投影定理识别P=E[·|I]。将不变h截断仍不变，将g截断使(I−U)g在L²逼近，得到有界不变函数加有界余边界组成的D在L²稠密。L²逼近蕴含L¹逼近，加上对一般L¹函数先截断，D在L¹也稠密。D每个元素的平均逐路径收敛，且在L¹收敛。

## 2. 有限最大递推与全部观察长度

<a id="ergodic-proof-maximal"></a>

\[ S_kf=\sum_{j=0}^{k-1}U^jf,\quad F_0=0,\quad F_N=\max(0,S_1f,\ldots,S_Nf)=(f+UF_{N-1})^+. \]

F_N可积，因为F_N≤Σⱼ<N Uʲ|f|。E_N={F_N>0}上f=F_N−UF_{N−1}；补集上0≥−UF_{N−1}。积分后∫_{E_N}f≥EF_N−EF_{N−1}≥0。E_N递增，|f|控制指标乘积，故∫_{E∞}f≥0。取f=|r|−λ，E_N={maxₖ≤N Aₖ|r|>λ}，得到λP(E_N)≤∫_{E_N}|r|，再令N→∞即弱型(1,1)。

还要建立强型界。先令r有界，M_N=maxₖ≤N Aₖ|r|。将上述事件内积分界乘pλ^{p−2}并对λ>0积分，非负Tonelli与Hölder给下面的不等式。M_N有界，所有运算有限；约去‖M_N‖ₚ^{p−1}，再截断r并令N增加，单调收敛得到常数p/(p−1)。

\[ EM_N^p\le\frac p{p-1}E(|r|M_N^{p-1})\le\frac p{p-1}\|r\|_p\|M_N\|_p^{p-1},\qquad \left\|\sup_n A_n|r|\right\|_p\le\frac p{p-1}\|r\|_p. \]

## 3. 完整的L¹逐点定理及极限识别

<a id="ergodic-proof-pointwise"></a>

弱型界给supₙAₙ|f|<∞几乎必然：超出K的概率至多‖f‖₁/K。对h_j∈D趋f于L¹，定义振荡O(f)=limsup Aₙf−liminf Aₙf；因h_j收敛，有O(f)≤2supₙAₙ|f−h_j|。每个ε>0的超出概率随j趋0，故O(f)=0；取可数ε给有限极限L(f)。对两个函数，Fatou与Aₙ收缩给‖L(f)−L(g)‖₁≤‖f−g‖₁。以h_j同时逼近平均及极限，得limsupₙ‖Aₙf−L(f)‖₁≤2‖f−h_j‖₁，故L¹收敛。

由∑ₙP(|f|>εn)≤E|f|/ε，保测与第一Borel–Cantelli给Uⁿf/n→0几乎必然。T⁻¹也保留零集，故可在f的收敛集及其逆像上比较UAₙf−Aₙf=(Uⁿf−f)/n，得到UL(f)=L(f)。因此极限I可测。若A∈I，1_A Uᵏf=Uᵏ(1_A f)模零，积分等于∫_A f。L¹极限给∫_A L(f)=∫_A f，所以L(f)=E[f|I]。

对p≥2，有界f的L²收敛和确定的统一界给Lᵖ收敛；1≤p<2用概率空间的范数包含。再以有界函数在Lᵖ中的稠密性及两侧收缩延到全部1≤p<∞。这给后页所用的Lᵖ均值遍历，不声称p=∞范数收敛。

## 4. 遍历、混合与返回的量词

<a id="ergodic-proof-examples"></a>

若I平凡，I可测实变量的有理水平事件均为0或1，故其分布集中一点；积分确定该点为Ef。反向取不变事件指标即证。对独立坐标移位，有限圆柱事件在足够大平移后独立；圆柱代数逼近任意事件A、B的误差小于ε，而交概率与各概率乘积的总误差至多4ε，得强混合。对不变A取B=A，强混合又给P(A)=P(A)²，所以遍历。两点交换的偶奇计算给逆向失败。

令B=A∩∩ₙ≥1T⁻ⁿ(Aᶜ)，即在A却不再返回。T⁻ʲB两两不交，否则较早一次B的轨道将再次进入A。保测给P(B)=0。有限次访问A的点在某次迭代进入B，落在可数并∪T⁻ʲB中。再由逐点定理，频率为q=E[1_A|I]；在A中q>0几乎必然，因为P(A∩{q=0})=E[q1_{q=0}]=0。这里不需把所有正概率集合的返回共同化到一个不可数零集。

## 5. 联合可测保测半流的连续时间版本

<a id="ergodic-proof-flow"></a>

设θ为联合可测保测半流，f∈L¹。Tonelli给每个有限时间区间上的绝对积分有限，先对整数端点取共同零集。F=∫₀¹f∘θ_s ds、G=∫₀¹|f∘θ_s|ds均可积。离散定理对θ₁与F给整数n处的平均收敛到L。可积尾和及保测给G∘θ_n/n→0几乎必然。对n≤t<n+1，最后一段积分的绝对值至多G∘θ_n，分母的变化则由已收敛的整数平均控制，因此所有实t趋∞都有同一有限极限。

固定任意r≥0。平移r只在首尾增加长度r的积分。尾段由H_r∘θ_n控制，其中H_r=∫₀^{r+1}|f∘θ_s|ds可积，故H_r∘θ_n/n→0。比较原收敛集与θ_r逆像，得L∘θ_r=L模零；此论证对每个r分别成立，已足以说L对I_flow可测。对A∈I_flow，Fubini与保测使∫_A t⁻¹∫₀ᵗf∘θ_s ds=∫_A f。

最后证明L¹收敛：连续平均都是L¹收缩，Fatou使其极限算子也是收缩；对有界f逐点收敛加DCT给L¹，再截断一般f，误差在平均端与极限端各不超过‖f−f_K‖₁。所以上一积分身份通过极限，L=E[f|I_flow]。不要求θ₁本身遍历，不能把它的不变σ域误当作全流的不变σ域。
