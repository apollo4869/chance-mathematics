# T-REAL-TREE-CODE：连续游程商空间的完整实树证明

本专题补全[第54章](../chapters/54-brownian-crt.md#crt-pseudo)的确定性构造。不使用第55章的GH闭性、任何随机树极限或Brownian特殊性质。

## 1. 假设、最低值与伪距离

<a id="real-code-pseudo"></a>

设h为[0,1]上连续非负函数，h(0)=h(1)=0；允许内部零点及恒零函数。以下区间总取两端之间的闭区间。记m(s,t)为区间上h的最小值，定义d。

\[ m(s,t)=\min_{[s\wedge t,s\vee t]}h,\qquad d(s,t)=h(s)+h(t)-2m(s,t). \]

非负性、对称性及d(s,s)=0立即成立，但三角不等式须核对第三个时间可能落在何处。区间[s,t]总包含在[s,u]与[u,t]的并内，故m(s,t)≥min(m(s,u),m(u,t))。又h(u)≥max(m(s,u),m(u,t))，于是

\[ m(s,u)+m(u,t)-h(u)\le\min\{m(s,u),m(u,t)\}\le m(s,t),\qquad d(s,t)\le d(s,u)+d(u,t). \]

连续性还给d(s,t)≤2ωₕ(|s−t|)，其中ωₕ为一致模连续。这里的区间最低值是普通实数最小值，不存在另外选择版本的零集问题。

## 2. 零距离与紧商空间

<a id="real-code-quotient"></a>

定义s∼t当且仅当d(s,t)=0。三角不等式给传递性，故是等价关系。若s∼s′、t∼t′，两次三角不等式给d(s,t)≤d(s′,t′)及反向。因此商集Tₕ的距离不依赖代表元，且商上不同点距离严格正。记p为投影、ρ=p(0)=p(1)。

\[ T_h=[0,1]/\!\sim,\qquad d_h(p(s),p(t))=d(s,t),\qquad d_h(\rho,p(t))=h(t). \]

投影由模连续界连续，满射像Tₕ因而紧、连通、可分且完备。但连通或紧性都不证明没有环路，下一步须实际构造弧。

## 3. 祖先线不是任意挑一条回程

<a id="real-code-ancestors"></a>

对x=p(t)、0≤a≤h(t)，令rₜ(a)为t以前最后一次达到高度a的时间。由中间值定理，这个非空闭集有最大值。rₜ(a)以后到t之间h≥a；否则要从更低处回到h(t)必再次经过a。若a<b≤h(t)，必rₜ(a)≤rₜ(b)，其间最小值为a。因此a↦x(a)=p(rₜ(a))是从ρ到x的等距映射。

\[ r_t(a)=\max\{u\le t:h(u)=a\},\qquad d_h(x(a),x(b))=|a-b|. \]

代表元无关也要证明。若s≤t且p(s)=p(t)，则h(s)=h(t)=m(s,t)=H。对a<H，两时刻之间高度始终>a，因此t以前最后一次达到a与s以前相同；a=H时两终点本就等价。故x(a)只依赖商点x。

## 4. 共同祖先与两点间的等距线段

<a id="real-code-lca"></a>

取s≤t、x=p(s)、y=p(t)，令m=m(s,t)。对a<m，区间[s,t]始终在a之上，两条祖先线在a处相同；在a=m处，任一最低时间u∈[s,t]与两线在高度m的点零距离。因此高度≤m的初段共同。若两线在某高度a共同，则连接其代表时间并经过s,t的各段高度均≥a，推出m≥a。共同初段恰为[0,m]，末点b称最近共同祖先。

\[ x\wedge y=b=x(m)=y(m),\qquad |x\wedge y|=m,\qquad d_h(x,y)=|x|+|y|-2|x\wedge y|,\quad |x|=d_h(\rho,x). \]

从x沿祖先线降到b，再沿y线升到y。不同分支上高度为a、c的两点，其共同祖先仍是b，所以距离为a+c−2m；同一分支上则为高度差。故拼接是一条长度dₕ(x,y)的等距线段，不是仅长度正确的一条可求长曲线。记其像为[x,y]。

## 5. 唯一测地不足以排除其他弧

<a id="real-code-arcs"></a>

本专题采用的实树定义有两项：任意两点有等距线段；任意连接这两点的单射连续弧，其像只能是该线段。第二项不可由第一项的唯一性冒充，欧氏平面也唯一测地。以下证明每个线段内部点都是把两端隔开的割点。

共同祖先高度函数q(x,w)=(|x|+|w|−dₕ(x,w))/2连续。三条祖先线给出一个基本事实：q(x,w)、q(x,v)、q(w,v)的最小值至少出现两次。若q(x,w)<q(x,v)，x与v在较低的分叉处仍同支，w已分开，故q(w,v)=q(x,w)；另两种次序同理。这个事实由共同初段的精确刻画得来。

设z=x(a)、a<|x|，并令O={w:q(x,w)>a}。这是开集且含x。若w∉O、w≠z，而v∈O，上述三点事实给q(w,v)=q(w,x)；当q(w,x)=a时也成立，因为q(v,x)>a。因此

\[ d_h(w,v)=|w|+|v|-2q(w,x)\ge |w|+a-2q(w,x)=d_h(w,z)>0. \]

所以O在Tₕ∖{z}中既开又闭。任一位于[x,y]内部的z，至少在x或y的一条祖先线上且严格低于该端，选择相应O便把两端分开；若z为共同祖先本身也同样成立。连续路径从一端到另一端必须经过z。

若γ是单射连续弧，其像因紧域及Hausdorff值域与[0,1]同胚。割点论证说明它包含[x,y]。这个线段连通，γ的连续逆将它送为[0,1]中含两端的连通子集，只能是全区间。因此γ的像恰为[x,y]。两项实树公理全部成立；连带得到唯一测地，而非把唯一测地当作全部证明。

## 6. 有限子树及其恢复

<a id="real-code-reduced"></a>

有限根跨度R(x₁,…,xₖ)=∪[ρ,xᵢ]为紧实树。逐次加xᵢ时，祖先线与旧树相交成一个闭初段：每条旧祖先线给一个初段，有限并仍为最长的初段。于是新部分只是一条线段，粘在唯一一个旧点。删除无标记的二度点后得到有限组合树及其正边长；若新点已经在旧树上，不增加边。

按时间s₁<⋯<sₖ采样，设xᵢ=h(sᵢ)、yᵢ=m(sᵢ,sᵢ₊₁)。任何非相邻两时刻的最低值是相邻y的最小值。因此x与y恢复全部采样距离。若y互异且0<yᵢ<min(xᵢ,xᵢ₊₁)，递归选最小y分割左右样本，得到二叉平面约化形状，根的初始边长为全局最小y；k=1时只有长度x₁的根边。每次添加新样本所添长度为xᵢ−yᵢ₋₁，所以总长L=Σxᵢ−Σyᵢ。

## 7. 假设的边界与回到正文

<a id="real-code-boundaries"></a>

连续性不能只在最后才补。取h=1在[1/3,2/3)上、其余0，公式的商仅有距离1的两个点，没有长度1的线段，不是实树。反之，连续函数允许内部零点、平段或多叉最低值，仍由上述证明得到紧实树；Brownian的二叉性不是确定性编码定理的前提。

若把区间最低值换成两端高度较小者，所得距离为|h(s)−h(t)|，会把不同枝上等高点压在一起。这仍可能给一个合法线段，却不再恢复原来分枝。某些非非负或不闭合的连续函数也能编码树，但本专题的根高等式与闭合遍历约定不自动适用；没有证明一般函数一定失败。[返回第54章的实树结论](../chapters/54-brownian-crt.md#crt-real-tree)。
