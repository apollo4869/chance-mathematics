# T-GW-TREES：完整谱系、探索与规模

本专题补全[第52章](../chapters/52-discrete-trees.md#trees-gw)的概率构造。后代分布先只要求是非负整数上的概率，不预设有限均值，也不预设整树有限。编码双射见[T-TREE-CODING](t-tree-coding.md)，计数关键见[T-CYCLIC-DWASS](t-cyclic-dwass.md)。

## 1. 可数潜在地址上的完整家族

<a id="gw-tree-space"></a>

\[ p=(p_k)_{k\ge0},\qquad \xi_u\overset{\mathrm{iid}}{\sim}p\quad(u\in\mathcal U),\qquad \mathcal U=\bigcup_{h\ge0}\mathbb N_+^h. \]

第8章的可数乘积给出所有实验；取其乘积域即可，不需要为有限树重新指定归一化常数。根一定出生；一个词出生当且仅当其每一步孩子编号都未超过前缀节点的后代数。这是有限多个坐标不等式，故每个地址的出生指示可测，整树作为可数二值族也可测。概率1上每个坐标有限，取可数交后整树局部有限。

\[ P(\mathcal T=t)=\prod_{u\in t}p_{k_t(u)}\qquad(t\text{ a finite plane tree}). \]

事实上，事件整树恰为给定有限树，等价于树内每个地址的后代数等于指定孩子数。叶子的零后代条件已经阻止树外其他地址出生，故不必再对无穷多个未出生地址施加条件。独立坐标给出乘积公式。任一因子为零时该树概率为零；把所有有限树概率相加只得到灭绝概率，不一定为1。

给定根有k个孩子，去掉各孩子地址前缀后，所用坐标族两两不交，也与根坐标独立。因此这k棵完整子树独立，且各自具有原树律。这是树值分枝性质，比只知道下一代人数的条件分布更强。每代人口由同一构造取层大小，恰为第20章的Galton–Watson过程；这里保留了该投影所删去的全部父子关系。

## 2. 自适应探索为什么仍读到独立后代数

<a id="gw-tree-exploration"></a>

按先序待访问列表逐个揭示后代数。下一地址取决于已揭示结果，所以不能只说“原坐标独立”便略过随机索引。固定一个有限探索历史：它指定已读地址及各自读数，且列表算法由这些有限信息唯一决定。若列表非空，下个地址未读过；在这个历史事件上，它的坐标仍具有原分布，并独立于已读有限坐标。

所有可能的有限历史只有可数多个。在每个历史事件上将一个有界过去可测函数乘以下次读数的有界函数，先用坐标独立性积分，再对历史求和，得到下次读数给定过去的分布恒为p。探索结束后另接独立的新实验，可得到一条无限iid序列，其到结束前的读数正是实际探索。这项补接不改变已完成的树。

\[ S_j=\sum_{\ell=1}^{j}(\xi_\ell-1),\qquad N=|\mathcal T|\ \overset d=\ \tau_1:=\inf\{j\ge0:1+S_j=0\},\quad \inf\varnothing=\infty. \]

等式包括无穷值。有限树在恰好所有节点被访问后列表归零；若在有限步归零，列表算法已经构造整棵有限树，不可能还留未访问分枝。所以未归零恰对应无限树。这里仅使用探索前有限历史，而没有声称普通先序在有限时间内能列出无限树的每个节点。

## 3. 森林、停止后的新实验与无限树边界

<a id="gw-tree-forest"></a>

\[ N^{(m)}=\sum_{a=1}^{m}|\mathcal T^{(a)}|,\qquad \tau_m=\inf\{j\ge0:m+S_j=0\},\qquad N^{(m)}\overset d=\tau_m. \]

对m棵独立有序树，列表初始放m个根。访问头一棵的全部后代再访问下一棵；同一探索证明给出上述等分布。合法有限森林路径恰满足终点为−m、此前严格大于−m、每步至少−1；逆向列表构造从m个根开始，证明与单树相同但初始槽位不同。因此n个节点的森林有n减m条边。

在有限首次下降时刻以后，iid读数仍从新开始：对任意停止时刻的有限取值r，停止事件及过去只用前r个坐标，后续有限串与它独立；逐r求和便得停止后有限串仍为乘积分布，并独立于停止前信息。这证明所需的专用离散停止分片，不借连续时间强Markov。若停止时刻无穷，不定义“其后的第一个读数”。

无限树的警告是实质性的：根有两个孩子，第一个孩子延续一条无限单孩子链，第二个孩子是叶子。递归先序永远走第一条链，无法在某个有限指标访问第二个孩子。其完整树仍由地址族合法定义，总规模也确为无穷，但不属于有限编码双射。本章不把这种遍历障碍藏进“同理推广”。

## 4. 有限总规模、最小母函数与条件子树

<a id="gw-tree-size-pgf"></a>

\[ f(z)=\sum_{k\ge0}p_kz^k,\qquad q_n=P(N=n),\qquad G(s)=E[s^N;N<\infty]=\sum_{n\ge1}q_ns^n,\quad 0\le s\le1. \]

只对有限规模求和，所以即使树可无穷大，定义也没有约定不清的无穷次幂。根分解、非负求和及子树独立给出下式。要确定是哪一个解，令初值为0并迭代右端；第d次迭代正是只保留高度小于d的有限树的加权和。局部有限树有限高度就只有有限个节点，故单调收敛给出全部有限树。任何非负不动点都逐次压住这些迭代，因此极限是最小解。

\[ G(s)=s f(G(s)),\qquad G(s)=\min\{z\in[0,1]:z=s f(z)\},\qquad G(1)=P(N<\infty). \]

条件化也可以精确计算。给根有k个孩子，并给定正整数子树规模，联合概率为

\[ P\bigl(k_{\mathcal T}(\varnothing)=k,\ |\mathcal T_1|=n_1,\ldots,|\mathcal T_k|=n_k\bigr)=p_k\prod_{a=1}^{k}q_{n_a}. \]

再条件于总规模为n，只保留子规模和等于n减1的项，并除以正的总规模概率。对可行的根度数和子规模条件，各子树形状仍独立，分别具有对应规模条件下的GW律：将有限树乘积概率除以各自规模概率即可证明。只给总规模而不给子规模时，子树规模受和约束，一般不独立。条件事件概率为零时，不使用这份除法定义条件模型。

## 5. 可计算模型与树的不同均匀律

<a id="gw-tree-examples"></a>

以下应用[T-CYCLIC-DWASS](t-cyclic-dwass.md#dwass-formula)已独立证明的公式，不反过来用本节识别循环引理。几何后代分布的一个特别结果来自树概率乘积：

\[ p_k=(1-a)a^k\ (0<a<1)\quad\Longrightarrow\quad P(\mathcal T=t)=(1-a)^n a^{n-1}\quad(|t|=n). \]

因此条件于规模n，所有平面树等概率；这对参数全区间成立，即使无条件树可能无限。它不是在所有带不同标签的树中均匀，也不是在无序形状中均匀，因为忘记孩子次序后各形状有不同数目的平面实现。

\[ p_0=1-b,\ p_2=b\ (0<b<1):\quad P(N=2j+1)=\frac{1}{2j+1}\binom{2j+1}{j}b^j(1-b)^{j+1},\quad P(N=2j)=0. \]

全二叉树的每个内部节点有两个孩子，因此节点总数只能为奇数。公式来自独立后代数之和恰为节点数减1；其系数等于第j个Catalan数。若后代为参数λ的Poisson变量，独立和仍为Poisson，得到

\[ p_k=e^{-\lambda}\frac{\lambda^k}{k!},\quad \lambda>0:\qquad P(N=n)=\frac{e^{-\lambda n}(\lambda n)^{n-1}}{n!}. \]

超临界参数下这些有限规模概率之和小于1，余量属于无限树；不能为了称它为分布而擅自再归一化。零参数时只有根。

## 6. 临界总规模的格点常数与尾部

<a id="gw-tree-critical-tail"></a>

\[ E\xi=1,\quad 0<\sigma^2=\operatorname{Var}\xi<\infty,\qquad d=\gcd\{k\ge1:p_k>0\}. \]

这些条件排除恒为1的后代律，并迫使零后代概率为正。因此后代分布的最大格点跨度正是上述整数。规模可行性见循环专题；以下沿正概率的规模序列。第13章格点局部CLT在均值附近一点的结论给出

\[ P\!\left(\sum_{i=1}^n\xi_i=n-1\right)\sim\frac{d}{\sigma\sqrt{2\pi n}},\qquad q_n\sim\frac{d}{\sigma\sqrt{2\pi}}\,n^{-3/2}\quad(n\equiv1\!\!\!\pmod d). \]

偏离均值只有−1，标准化后趋零，故Gaussian指数因子趋于1；再用Dwass除以节点数，就得到第二式。循环专题证明所有充分大的正确余数规模都可行，其他余数概率为零。第20章临界非退化灭绝定理保证整树有限a.s.，故尾部就是这些有限规模概率之和。

\[ P(N\ge n)\sim\frac{\sqrt{2/\pi}}{\sigma}\,n^{-1/2}. \]

具体地，在足够大的可行规模上，以任意小相对误差夹住第二式；等差数列上的递减函数求和由左右积分夹住，节点间距为d，故幂次为−3/2的和等价于2除以d再乘节点阈值的−1/2次幂。前式的d恰好抵消。有限个初始例外不影响尾和。这不是忽略奇偶性，而是先保留局部格点因子，再在尾部求和时消掉它。

另由非负求和交换，期望总规模等于各代期望人数之和。有限均值μ小于1时为几何级数；μ不小于1时发散。这与临界树有限a.s.而平均总规模无穷并不矛盾。上述结论只涉及规模，不证明条件树的轮廓极限。回到[第52章](../chapters/52-discrete-trees.md#trees-critical-size)。

\[ EN=\sum_{h\ge0}EZ_h=\sum_{h\ge0}\mu^h=\begin{cases}(1-\mu)^{-1},&0\le\mu<1,\\ \infty,&1\le\mu<\infty.\end{cases} \]
