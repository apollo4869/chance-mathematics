# T-SCALE-SPEED：停止、Green核与速度归一化

与[第36章](../chapters/36-scale-speed.md)双向配套。I=(ℓ,r)，b、σ局部Lipschitz，σ>0；a=σ²/2。最大解来自第35章，使用通常滤过和停止Itô；不借局部时间、一般时间变换或第38章Feynman–Kac。c为固定内部参考点，p、S、m按正文归一化。

## 1. 紧区间退出有限：不预设命中公式

<a id="scale-compact-exit"></a>

固定ℓ<α<x<β<r。p为正C¹，S为严格增C²，m′=1/(ap)正连续。在[α,β]均有界，且有正下界。先纯粹用确定性公式定义下页的G及u(x)=∫_α^βG(x,y)m′(y)dy。G≥0且在端点为0，故u≥0连续有界；直接微分证明u∈C²及Lu=−1，这个步骤不使用随机占用结论。

令τ为首次到α或β。Itô到t∧τ，鞅系数u′σ在紧区间有界，所以该有限时间积分平方可积、均值0。于是E(t∧τ)=u(x)−E u(Xₜ∧τ)≤u(x)。单调收敛使Eτ≤u(x)<∞，故τ有限几乎必然。连续性和最大解在紧区间可延长性保证退出恰在α或β。再让t→∞，u的端点值与DCT给Eτ=u(x)。

S(Xₜ∧τ)是有界局部鞅，故真鞅；可先对积分局部化再用常数支配验证。τ有限后DCT给S(x)=S(α)P(\(\tau_\alpha<\tau_\beta\))+S(β)P(\(\tau_\beta<\tau_\alpha\))，两概率相加1，解得正文命中公式。对任意内部起点，命中另一个内部点在适当紧区间内有正概率；这是本页使用的内部regular性，不是端点的regular类别。

## 2. Green核的微分、停止与Borel推广

<a id="scale-green"></a>

\[ D=S(\beta)-S(\alpha),\quad G(x,y)=\frac{(S(x\wedge y)-S(\alpha))(S(\beta)-S(x\vee y))}{D},\quad u_f(x)=\int_\alpha^\beta G(x,y)f(y)m^\prime(y)dy. \]

先f连续。写A(x)=∫_αˣ(S(y)−S(α))f(y)m′dy，B(x)=∫ₓᵝ(S(β)−S(y))f(y)m′dy，则u_f=((Sβ−Sx)A+(Sx−Sα)B)/D。乘积微分的两个端点项相消，得到\(u_f^\prime\)/p=(B−A)/D，其导数为−f m′。因此\(Lu_f\)=(1/m′)(\(u_f^\prime\)/p)′=−f，且u_f端点为0。这个计算同时核对了斜率跳−1与归一化因子。

停止Itô给\(u_f\)(x)=E \(u_f\)(Xₜ∧τ)+E∫₀ᵗ∧τ f(Xₛ)ds。|f|有界且Eτ有限，DCT使t→∞时得到占用公式。对固定x，左右两侧在f=1时总质量有限，定义[α,β]上的有限Borel测度；它们在全部连续函数上一致。可用连续帽函数递增逼近开集指标，再由测度唯一性得到相等，继以MCT推广任意非负Borel f。有符号f需相应绝对积分有限。

取f=\(\mathbf1_{\{y_0\}}\)，m无原子给E∫₀ᵗ∧τ\(\mathbf1_{\{X_s=y_0\}}\)ds=0；非负性使时间积分为0几乎必然。对可数紧区间穷尽及整数T取并，得到任一固定y₀在整个寿命内的普通占用时间为0。没有对不可数y₀同时相交零集，也没有据此断言路径从未到y₀。

## 3. 区间扩张及单边返回公式

<a id="scale-exhaustion"></a>

取αₙ↓ℓ、βₙ↑r，τₙ为对应首次退出。τₙ递增到寿命ζ。对f≥0，∫₀^τₙf随n递增到∫₀^ζf，故其期望由MCT取极限。Gₙ(x,y)也逐点递增：在扩大区间的新增边界上原核为0，新核非负；在旧区间内，两核的差关于x为L调和且边界非负，按尺度线性性非负。延零后仍成立。因此极限\(G_I\)可定义为Gₙ↑，可能∞，与所选穷尽无关：任何一个穷尽中的固定紧区间最终都被另一个穷尽容纳，核的单调性给两方向的极限比较，即使极限为∞也成立。

若固定α而S(r)=∞，则命中α的概率为1：\(P_x\)(\(\tau_\beta<\tau_\alpha\))→0，且每个紧区间退出有限。因而τ_α<∞几乎必然（到不了α的路径必须先到每个β；这些事件概率趋0）。核极限为S(x∧y)−S(α)，得到

\[ E_x\int_0^{\tau_\alpha}f(X_t)dt=\int_\alpha^x(S(y)-S(\alpha))f(y)m(dy)+(S(x)-S(\alpha))\int_x^r f(y)m(dy). \]

公式允许∞。左端镜像：若S(ℓ)=−∞，从x<β到β的核为S(β)−S(x∨y)，定义于(ℓ,β)。这些身份随后计算入口返回界与完整往返周期，不把∞期望误当∞实际时间。

## 4. 折扣Green核与速度对称性

<a id="scale-resolvent"></a>

固定λ>0及紧区间(α,β)。线性ODE Lh=λh的连续系数在紧区间可用二维一阶积分方程的Picard构造唯一解。取u(α)=0、u′(α)/p(α)=1，及v(β)=0、v′(β)/p(β)=−1。积分式(u′/p)′=λum′显示u在(α,β]严格正且增；从右反向同理v严格正且减。若存在第一个失去正性的点，之前导数严格保持相应符号，矛盾。

\[ w_\lambda=\frac{u^\prime v-uv^\prime}{p}>0\text{ is constant},\qquad G^\lambda_{\alpha,\beta}(x,y)=\frac{u(x\wedge y)v(x\vee y)}{w_\lambda}. \]

微分Wronskian，利用h″=(λh−bh′)/a及p′/p=−b/a，导数恰为0。核的尺度导数跨过y跳−1，其余位置满足(L−λ)G=0。对连续f，\(u_f^\lambda\)=∫Gλ f dm于是满足(λ−L)u=f、端点0。对e⁻λᵗu(Xₜ)停止Itô并取t→∞，得到\(R_\lambda^{\alpha\beta}\)f=\(E_x\)∫₀^τe⁻λᵗf(Xₜ)dt。Borel推广与第2节相同；|Rλ f|≤||f||∞/λ。

Gλ(x,y)=Gλ(y,x)直接给速度测度对称性：对非负f、g，∫gRλf dm=∫fRλg dm，Tonelli允许∞。穷尽区间时，非负路径积分单调趋最小过程的Rλ，故对称性保留。这是后面不变测度证明真正使用的对称性，不是只写一个形式分部积分。

## 5. 尺度改变与因子核验

<a id="scale-normalization"></a>

若S换为AS+B，A>0，则p换为Ap，m换为m/A，G换为AG；命中概率和Gm都不变。生成元a=σ²/2，故标准Brownian为S=x、m=2dx；将第2节核积分于2dy，得(x−α)(β−x)，可直接二次微分核对½u″=−1。

自然尺度坐标Y=S(X)在寿命内满足dY=α(Y)dW，α(y)=p(S⁻¹y)σ(S⁻¹y)>0，局部Lipschitz。坐标速度密度为2/α(y)²；变回x时恰为m′(x)dx，因为dy=p(x)dx。这里只使用确定C²变换，没有从此宣称一般奇异速度的随机时间变换已经构造。返回[正文Green核](../chapters/36-scale-speed.md#diffusion-green)。
