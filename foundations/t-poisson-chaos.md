# T-POISSON-CHAOS：重合点、多重积分与L²解耦

返回[第48章](../chapters/48-point-processes.md#points-multiple)。固定标准Borel E上的σ有限μ及已构造的Poisson计数N；下面是确定性核的完整L²多重积分与chaos展开，包括μ有原子的情形。所选解耦结果是L²精确等式，不宣称一般Lᵖ或尾概率解耦。

## 1. 同一个单元的重复出现需要新多项式

<a id="poisson-chaos-polynomials"></a>

\[ e^{-\lambda t}(1+t)^k=\sum_{r\ge0}\frac{t^r}{r!}C_r(k,\lambda),\quad C_0=1,\ C_1=k-\lambda,\ C_2=(k-\lambda)^2-k. \]

这定义实多项式Cᵣ；对固定整数k左侧是整函数。若K∼Poisson(λ)，直接对其级数求和给两个生成函数的乘积期望等于exp(λst)。在s,t的小复邻域内绝对值受常数乘aᴷ控制，而Poisson有全部指数矩，所以可逐项微分并比较系数。

\[ \mathbb E[C_r(K,\lambda)C_s(K,\lambda)]=\mathbf1_{\{r=s\}}r!\lambda^r. \]

特别是二重积分不能无条件取中心计数的平方；还需减去K，才能使均值为零并与一阶正交。这里减去的是同一次出现被重复使用的贡献，不是简单删掉空间对角。若μ有原子，不同出现也可处在同一点，空间对角仍可能承载合法二重项。

## 2. 有限分割上的定义及精确等距

<a id="poisson-chaos-step"></a>

取不交有限强度单元A₁,…,Aₖ。对总次数r的多重指标a=(a₁,…,aₖ)，|a|=r，以sym表示对r个坐标的平均对称化，令fₐ=sym(⊗ᵢ\(\mathbf1_{A_i}\)的aᵢ次张量)。定义Iᵣ(fₐ)=∏ᵢ\(C_{a_i}\)(N(Aᵢ),μ(Aᵢ))。不同多重指标的核正交，其范数平方是(∏aᵢ!/r!)∏μ(Aᵢ)^{aᵢ}；计数独立及上一节给相应随机变量范数平方∏aᵢ!μ(Aᵢ)^{aᵢ}。线性组合于是有下式。

\[ \mathbb E[I_r(f)I_s(g)]=\begin{cases}r!\langle f,g\rangle_{L^2(\mu^{\otimes r})},&r=s,\\0,&r\ne s.\end{cases} \]

## 3. 分割改变不会改变积分

<a id="poisson-chaos-refine"></a>

若一个单元拆为两个，生成函数相乘给Cᵣ(K+L,λ+ρ)=\(\sum_{j=0}^r\) binom(r,j)Cⱼ(K,λ)Cᵣ₋ⱼ(L,ρ)。这恰与张量中每个坐标选择落在哪个子单元的展开相同。有限次细分后定义一致；任意两份有限分割可取共同细分，所以定义不依赖表达。有限强度矩形简单函数在L²(μ的r重积)中稠密：有限窗口截断后，对乘积Borel域用单调类逼近指标，随后简单函数逼近。对称化为收缩，故这些对称简单核在对称子空间稠密。等距及第15章前已补全的L²完备性唯一延拓Iᵣ到全部对称L²核。一般核定义为其对称化的积分。

## 4. 为什么这些阶数没有遗漏L²随机输出

<a id="poisson-chaos-complete"></a>

记𝓗ᵣ为Iᵣ的闭像，𝓗₀为常数。先对有限分割上的有界h、有限强度支撑，计算随机指数𝓔(h)=exp(−μh)\(\prod_{x\text{ occurrence in }N}\)(1+h(x))；取−1<h≤0即可。各单元生成级数在L²中收敛，因为正交项平方范数之和为exp(∫h²dμ)。其和与逐样本整函数级数一致（取L²收敛子列与逐点级数比较），故有下式。

\[ \mathcal E(h)=\sum_{r=0}^\infty\frac1{r!}I_r(h^{\otimes r}),\qquad \mathbb E\mathcal E(h)^2=\exp\{\mu(h^2)\}. \]

若F∈L²(σ(N))正交于所有𝓗ᵣ，它就与这些𝓔(h)正交。置h=e⁻ᶠ−1，得到E[F e⁻ᴺᶠ]=0，对所有有限强度片上非负简单f成立。对任意有限个有限强度集合，这使以F的正、负部分加权的计数向量有限测度有相同Laplace变换；总质量也相同，因EF=0。向量唯一性给对全部有限计数柱集\(\mathbb E[F\mathbf1_A]\)=0。σ有限分片的计数生成σ(N)，π–λ推广到全部事件，取{F>0}与{F<0}便得F=0。因此正交和完备，每个F唯一地展开如下。

\[ F=\mathbb EF+\sum_{r\ge1}I_r(f_r),\qquad \operatorname{Var}F=\sum_{r\ge1}r!\|f_r\|_2^2. \]

## 5. 独立副本的L²解耦范围

<a id="poisson-chaos-decoupling"></a>

取r份独立PRM N¹,…,Nʳ，强度均μ。对积核f=f₁⊗⋯⊗fᵣ定义Jᵣ(f)=∏ᵢI₁^{(i)}(fᵢ)。独立性及单重等距给E[Jᵣ(f)Jᵣ(g)]=〈f,g〉；有限和、稠密性与完备性延拓到全部L²积核。这是把不同坐标交给独立噪声副本的精确定义。对对称f，与前述耦合多重积分比较得到下式。

\[ \mathbb E|I_r(f)|^2=r!\,\mathbb E|J_r(f)|^2=r!\|f\|_2^2. \]

这是一项二阶范数解耦，不是两随机变量等律。单窗口例子中I₂由同一个Poisson计数的C₂产生，而J₂由两个独立中心计数相乘，显然不是同一构造。未证明一般Lᵖ解耦、尾界比较、随机核多重积分或完整乘积公式；它们不计入本专题的已证范围。
