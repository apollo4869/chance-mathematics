# T-PAINTBOX：交换划分、频率与唯一混合的完整证明

本页处理N的划分，不预设块数有限或无dust。只用第8章可数构造、第12章条件强律、第43章标准Borel de Finetti及概率核。返回[第47章](../chapters/47-partitions.md#partitions-paintbox)。

## 1. 先把划分放进一个真正的可测空间

<a id="paintbox-proof-space"></a>

以0/1关系矩阵记录划分：自反、对称、传递。每个条件只涉及有限坐标，所以所有划分组成可数立方体的闭子集P∞；有限限制rₙ取值于有限集合Pₙ。这是紧可度量标准Borel空间，Borel域由所有有限限制生成。块按最小成员编号，只是一个可测枚举约定，不是大小顺序。

交换性指每个有限置换推送后整份划分同律。相容且在Pₙ上交换的有限律，确实给唯一无限交换律：把限制序列放进有限空间的可数乘积，第8章按有限相容律构造；相邻限制相容的事件可数，概率1，其上唯一确定等价关系。有限群不变性逐柱集延伸到全域。单独一份有限交换律不保证存在这样的无限相容族。

## 2. 给块贴独立标签，究竟保留了什么

<a id="paintbox-proof-labels"></a>

在独立积扩张上，给按最小成员枚举的每个块贴一个Uniform(0,1)标签Zⱼ，令Xᵢ为i所在块的标签。块编号是可测的，因为“i是第j个最小代表”由前i个关系决定；Xᵢ也可测。可数独立连续标签几乎处处两两不同，故原划分恰由Xᵢ=Xⱼ恢复。

给定划分，任意有限个X的条件联合律，只由这些指标之间的等价关系决定：同块共用一个均匀数，异块用独立数。重编号可能改变块的出现次序，却不改变这份核。将核对交换划分积分，证明X是无限交换序列。第43章于是给可测随机概率μ，使给定μ时整列X的条件律为其可数积。这里没有假设一般交换图有条件iid的边。

\[ \Pi=\operatorname{Eq}(X),\qquad \mathcal L(X\mid\mu)=\mu^{\otimes\mathbb N}. \]

## 3. 同时取得所有块的频率，并识别零频率块

<a id="paintbox-proof-frequencies"></a>

固定一份μ。给定Xᵢ=x，除第i项外的指标1{Xⱼ=x}是成功率μ({x})的iid列；强律及对x积分给i所在块的渐近频率。对可数i取共同满概率集。正质量原子至多可数；每个这样的原子几乎必然被抽到，因为一直漏掉它的概率为零。故这些块的正频率恰是μ的所有原子质量，连重数也保留。

\[ F_i=\lim_{n\to\infty}\frac1n\sum_{j=1}^n\mathbf1_{\{i\sim j\}}=\mu(\{X_i\})\quad\text{a.s. simultaneously for all }i. \]

μ({x})联合可测：在[0,1]上，它是μ对递减有理网格邻域的评价极限，或直接由可测对角的核积分得到。任意固定i≠j，二者相等却位于零质量点的概率是∫1{μ({x})=0}μ({x})μ(dx)=0。可数对取共同零集，所有零频率块都是单点。它们可以有正的总体密度，却不能组成一块频率为零的无限类别。

令Jᵢ表示i是其块的最小成员。bᵢ=JᵢFᵢ给每块只记一次频率。有限多个互不交块的频率和不超过1，再取上确界得Σbᵢ≤1。非原子部分的抽样指标也满足强律，故零频率单点的密度是d=1−Σbᵢ。不能把每个单点的零频率相加来否定这份正质量。

## 4. 排序、参数可测性与paintbox核

<a id="paintbox-proof-kernel"></a>

在所有频率存在的Borel集合上，把b按大小排序为s；在坏集合统一取全零。对q>0有至多1/q个bᵢ>q，故第j大值可写成下面的可数上确界，约定空集上确界为0。它证明排序可测，并无须为相等质量选择唯一标签。

\[ s_j=\sup\{q\in\mathbb Q\cap(0,1):\sum_i\mathbf1_{\{b_i>q\}}\ge j\},\qquad \Delta_\downarrow=\{s_1\ge s_2\ge\cdots\ge0:\sum_i s_i\le1\}. \]

Δ↓是可数立方体中由有限部分和与排序条件定义的闭集。对s取独立均匀Uᵢ，以相邻区间长度sⱼ指定正质量块；落在剩余区间的人各自成为不同单点，而不是共同组成“dust块”。每个有限相等关系是(s,U)的Borel函数，所以其概率Qₛ构成P∞上的概率核：先证有限柱集评价可测，再用单调类。

## 5. 有限模式的准确公式，包括dust

<a id="paintbox-proof-eppf"></a>

给定一个具体的[n]划分π，其k个块大小为n₁,…,nₖ。J₁是其中大小为1的块编号集合。选择D⊂J₁表示恰好由dust产生的块；其余块必须落在互不相同的正质量区间。独立抽样与非负可数求和给如下公式。它是一个指定划分的概率，不乘额外的块排列数。

\[ p_s(n_1,\ldots,n_k)=\sum_{D\subseteq J_1}d^{|D|}\!\sum_{\substack{j_\ell\ge1\ (\ell\notin D)\\j_\ell\ \text{all distinct}}}\prod_{\ell\notin D}s_{j_\ell}^{\,n_\ell},\qquad d=1-\sum_j s_j. \]

空乘积与没有非dust块的内和均取1；d⁰=1。每项非负且总和至多1，因为对应互斥的抽样事件；因而公式同时证明Borel性，不依赖带符号无穷求和交换。它对块大小对称。一般混合划分的EPPF为E \(p_S\)。

## 6. 存在性不只是一份公式：完整的表示与唯一性

<a id="paintbox-proof-representation"></a>

对任意固定μ，前面的条件强律证明Eq(X)的排序频率等于μ的排序原子质量，且有限模式概率只由这些质量与剩余非原子质量决定。参数可测性还可不经原子选择来证明：定义hⱼ(μ)=∫Sⱼ(Eq(x))μ的可数积(dx)。积核可测，所以hⱼ可测；对每份固定μ，强律使该积分恰等于其第j大原子质量。这同时给全部μ的Borel质量编码。

于是辅助标签空间上S=h(μ)几乎必然。给定μ，有限模式的条件概率为\(p_{h(\mu)}\)，再对σ(S)用塔式，得到\(Q_S\)的有限柱集身份。所有柱集可取可数决定类，统一零集后概率唯一性给整个划分的条件律。把辅助标签积分掉，这就是原划分的表示，S本来就是原划分的可测函数。

\[ \mathcal L(\Pi\mid S)=Q_S,\qquad \mathcal L(\Pi)=\int_{\Delta_\downarrow}Q_s\,\nu(ds),\qquad \nu=\mathcal L(S). \]

反向，每份paintbox显然交换；对每个固定s，独立强律与可数共同零集使其恢复的排序频率就是s。因此若另一混合ν′产生同一划分律，把可测频率映射推送过去，必有ν′=ν。唯一的是排序质量的混合律，不是颜色、区间位置或按出现次序的名字。

## 7. 出现顺序的偏置与有限观察的边界

<a id="paintbox-proof-order"></a>

给定s，第1个人属于第j个正质量块的概率是sⱼ，属于一个dust单点的概率是d。因此“首先看见的块”是按质量偏置的抽取，不是最大块。无dust时，发现了若干不同正块以后，下一尚未见块按其剩余质量归一化抽取：在独立抽样中，先等到落在未见区间，再按条件概率分配。若有dust，单点会不断插入，这份无dust的排列描述不能原样使用。

只有观察整条无限划分才得到几乎必然频率识别。一个固定n的样本即使全是单点，也可能来自全dust，或来自极多很小正块；并不能据此判定d=1。无穷多原子也不等于有dust，例如sⱼ=2⁻ʲ总和为1。交换性很关键：确定地把平方数放在同一块、其他数各为单点，含一块无限零密度类别，却不交换。

甚至没有dust也能在小样本上不可区分：s=(1/2,1/2)与t=(2/3,1/6,1/6)的二人碰撞概率均为1/2，但三人同块概率分别为1/4与11/36。两人全部划分律相同而排序质量不同，第三人已经提供真正的新信息。
