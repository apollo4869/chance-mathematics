# T-DIFFUSION-TIME：奇异速度、边界时钟与Revuz的可证范围

配套[第37章](../chapters/37-local-time.md#local-speed-clock)。局部时按T-LOCAL-TIME归一化，速度按36章\(L=D_mD_S\)；因此时钟前必须有½。先给开区间内、无内部杀死的连续正则扩散，再在有限正则端点讨论连续局部边界规则；不包含边界跳入内部的非局部过程。一般右过程的全部PCAF/Revuz双射仍由38章T-REVUZ承担。

## 1. 任意满支撑Radon速度的实际构造

<a id="time-proof-construction"></a>

取开区间J、其上Radon测度m，每个非空开子区间质量正。Brownian从x∈J出发，H为首离J，局部时在H停止。下式定义连续加性时钟；在H以前每段路径取值于紧集，局部时连续有界且m局部有限，所以时钟有限连续。若u<v<H，∫(Lᵃᵥ−Lᵃᵤ)da=v−u>0；被积函数连续非负，在某开区间正，满支撑给Aᵥ>Aᵤ。因此A严格增加，其逆T连续，Y在寿命\(A_H\)以前是连续路径。

\[ A_s=\frac12\int_JL_{s\wedge H}^y(B)m(dy),\qquad T_t=\inf\{s:A_s>t\},\qquad Y_t=B_{T_t},\quad t<A_H. \]

Tₜ为Brownian停止时刻，因为{Tₜ<s}={Aₛ>t}。局部时加性给\(A_{T_t+s}-A_{T_t}=A_s\circ\theta_{T_t}\)，从而\(T_{t+u}=T_t+T_u\circ\theta_{T_t}\)。Brownian强Markov遂给Y的Markov性。对Y停止时刻S，\(T_S\)也是Brownian停止时刻：先对S的上方二进近似验证，再以右连续滤过取极限。相同加性公式于是给强Markov。局部有界停止Brownian的抽样给Y为自然尺度连续局部鞅，括号T。

\[ \int_0^tf(Y_u)du=\frac12\int_Jf(y)L_{T_t}^y(B)m(dy),\qquad E_x\int_0^{\tau_{a,b}(Y)}f(Y_u)du=\int_a^bG^{S=\mathrm{id}}_{a,b}(x,y)f(y)m(dy). \]

第一式是Stieltjes换时du=dAₛ、Tonelli及dLᵞ支撑于{B=y}。第二式用Brownian到a或b以前E Lᵞ=2G，来自36章Green与本章连续占用密度；这里亦可直接对|B−y|取停止Tanaka期望，得到E Lᵞ=E|B退出−y|−|x−y|=2G，Eτ有限保证鞅可积；因此是每个y的身份，而非仅几乎处处。它直接核对速度就是m。方向命中仍为普通距离比，因为严格换时不改变路径经过各水平的顺序。

这份构造确实包括奇异速度，而不要求m有Lebesgue密度。初值连续性亦可验证：用Bˣ=x+W耦合，Lₛᵞ(Bˣ)=\(L_s^{y-x}\)(W)。在共同紧停止以前，联合连续性及m的局部有限性使时钟随x局部一致收敛，严格时钟的逆也一致收敛。Brownian对固定内部退出水平的首达时刻在该水平处几乎必然连续，故停止路径律随初值连续。由连续路径和紧集覆盖得到局部Feller性质；可先在紧区间杀死表述，不强加无穷远的C₀条件。

## 2. 恢复原SDE及自然尺度表示的逆向

<a id="time-proof-converse"></a>

若m有连续严格正密度2/α²，则Aₛ=∫₀ˢα(Bᵤ)⁻²du，由普通积分换元，Tₜ=∫₀ᵗα(Yᵤ)²du。定义Wₜ=∫₀ᵗα(Yᵤ)⁻¹dYᵤ，括号为t，故为Brownian；结合律给dY=α(Y)dW。36章令Y=S(X)，α(y)=p(S⁻¹y)σ(S⁻¹y)，再以S⁻¹的Itô公式恢复原b、σ，因子恰为m′=2/(σ²p)。

逆向的准确类别如下：X为连续强Markov过程，无内部杀死，紧子区间退出有有限均值；已选自然尺度，即所有内部a<x<b的上端命中概率为(x−a)/(b−a)。最后条件在36章由S变换得到，在本节构造中也已验证。我们不把一个未指定尺度的任意Markov过程称作这类扩散。

在(a,b)内，X停于退出后等于其退出值的条件平均，因而为有界鞅。逐区间拼合给连续局部鞅。设u(x)=Eₓ\(\tau_{a,b}\)。对内部c<x<d，强Markov给u(x)−弦插值u(c),u(d)=Eₓ\(\tau_{c,d}\)>0，故u是有限凹函数。其右导数单调不增，定义Radon测度m=−du′。不同大区间的u在共同内部之差为仿射函数，所以该测度相容；没有开子区间质量0，否则对应退出均值为0。

凹函数的广义Itô式这里可以由Tanaka实际推出：在任一更小紧区间，把u写成一个仿射函数减½∫|x−y|m(dy)，二阶分布导数均为−m，相差仿射项；这个表示也可由右导数的Stieltjes积分逐次积分验证。对Tanaka式积分，确定项用Fubini，随机项由局部有限m及等距/局部化通过，得到u(X)减其鞅项等于−½∫L_Xᵞm(dy)。

另一方面强Markov及\(\tau_{a,b}\)可积使u(X停止)+停止时间为闭鞅。相减后，时间减½∫L_X m是连续有限变差局部鞅，必恒为0，故t=½∫Lₜᵞ(X)m(dy)。33章DDS给X=B_[X]；局部时的占用身份给Lₜᵞ(X)=L_[X]ₜᵞ(B)，因此A_[X]ₜ=t，正是前节逆时钟。速度唯一性来自−du′，而整条过程律由Brownian及m的可测时钟确定。

## 3. 原子速度与真正的粘滞

<a id="time-proof-sticky"></a>

先在半轴反射。由Skorokhod引理取R=x+β+K≥0，K只在R=0增加；它与36章|x+B|同律。内部局部时在a↓0时趋2K，故定义右端点值\(L_R^{0,+}\)=2K。在内部取m=2dy，另加θδ₀，θ≥0，时钟与换时过程为

\[ A_s=s+\theta K_s,\quad Y_t=R_{T_t},\quad t=T_t+\theta K_{T_t},\quad \int_0^t\mathbf1_{\{Y_u=0\}}du=\theta K_{T_t}. \]

最后一个等式用du=ds+θdK及R的零集普通时间0。θ>0时边界可以占用正普通时间；这不是在0停一段独立指数时间再出发，因为A严格增加、T连续，路径没有这样的有限平坦等待段。它把无Lebesgue时间的接触集合展开为有时间权重的集合。θ=0恢复即时反射。一般内部Radon速度可同样加入有限端点原子，A=½∫_{(0,b)}L_R m+θK。

到内部上界b前，若0为正则端点，m((0,b))有限且尺度长度b有限。Green均值给从x↓0到0以前的时间趋0，达到固定ε以前先离零点方向的机会≤x/ε。因此从内部初值逼近0，停止路径律连续地趋上述零起点构造；结合内部时钟的初值连续性，得到该有限区间模型的Feller性质。没有把自然/出口端点强行设为反射入口。

## 4. 连续局部边界规则的范围与识别

<a id="time-proof-boundaries"></a>

在有限自然尺度端点0、本地化上界b以前，考虑无内部杀死、路径连续的Feller强Markov扩张。0可以直接杀死或成为陷阱；除此以外假设它仍可进入内部。以下边界再生从X₀=0表述；内部初值先等首达0，之前的规律已确定。路径连续指寿命以前，死亡进入墓地。其连续局部规则由θ≥0的边界时间和κ≥0的局部时杀死率决定：在前节时钟上，再于K首次超过独立Exp(κ)变量时杀死。κ=0意为不杀死。下面给必要性机制，排除把这仅当作一份模型清单。

把墓地坐标记0、b到达后吸收，在[0,b]的坐标过程是有界次鞅。理由是到0或b以前为自然尺度鞅，从0以后坐标期望非负、从b以后恒为b；以强Markov分解条件期望即得次鞅不等式。30章Doob–Meyer给X=M+K，K连续递增，且只在0增加，因为每个内部紧区间中X已为鞅，分解唯一性使其补偿不增加。连续性由可预测补偿的跳跃条件平均及ΔX=0得到。

对非负X用正部Tanaka，单点鞅积分为0，给K=½\(L_X^{0,+}\)；所以K有路径可测且可加的版本，不是另外假设补偿可加。DDS和确定Skorokhod引理把X在二阶时钟中写成反射Brownian，K成为它的反射调节量；未结束的括号可用独立Brownian补足。每次K的逆到达一个确定l，X=0，强Markov使尚存活的未来接触、游程和边界时间在l轴重新开始。对高度≥ε的有限批标记，其首次标记或死亡的局部时具有无记忆性，因此为指数间隔，且类型、形状与间隔独立；这是T-EXCURSIONS 2相同的半直线条件化证明，死亡作为额外标记类型。

标记速率不是任意常数。记达ε标记率为\(r_\varepsilon\)、死亡率κ，停止于二者先发生者，则K终值均值1/(\(r_\varepsilon\)+κ)，而E X终值=ε\(r_\varepsilon\)/(\(r_\varepsilon\)+κ)。M停止后由|M|≤ε+K终值一致可积，故两均值相等，得到\(r_\varepsilon\)=1/ε。这里b只作上方局部化：命中b是一次达到b的内部游程终止标记，强度1/b，不计入κ：ε<b时先产生达ε标记，随后先到b而非0的条件概率ε/b，乘\(r_\varepsilon\)=1/ε即得1/b。不同ε下零边界死亡事件相容，死亡率κ不变。有限标记独立稀释给死亡阈值与其余游程独立；低高度极限仍保留此独立性。零起点Feller强连续性排除在K=0以非平凡概率瞬时死亡的混合，立即杀死需另列为Dirichlet边界。

扣除内部游程用时，剩下的边界普通时间作为K参数的函数连续递增：逆K的跳跃是内部游程，其间边界时间不变。它具有独立平稳增量，来自相同逆K处的强Markov重启。存活概率在l轴上乘法分解为\(e^{-cl}\)；将有限维的存活次概率核除以该因子，卷积与投影相容，得到一份完整概率律。各有限窗条件于活到窗尾的路径连续，所以归一化律下也连续。这使它成为连续递增Lévy过程，27章的连续部分刻画使它只能是θl：Gaussian部分不能单调，跳跃部分已无跳，剩下确定漂移。因此边界时间只能为θK。若0根本不能离开，则为陷阱，已单列。内部游程的时钟由第2节唯一确定，故θ、κ及内部m确定整个本地化规律。

这里需要排除有限但非零的整段停住后再出发。若从0首次离开时间D>0而有限，D是停止时刻且X_D=0；在D处强Markov会重新给同样正等待，与D以后任意近的时刻已经离开相矛盾。零点的强Markov零一律把即时离开或永久陷阱分开。它可由Feller强连续性直接证明：对F₀⁺事件用ε时刻Markov及Pεf→f，得到它与全部未来圆柱独立，因而概率0或1。粘滞的正时间占用因此不能解释成一次普通holding interval。

在光滑密度内部，取内部C²、到0为C¹且Lf连续延到0的紧支撑测试，Ito乘e^{−κK}给可验证的生成元边界条件。时间原子贡献θAf(0)dK，边界微分贡献f′(0)dK，死亡贡献−κf(0)dK，故下式。它包括Neumann、Robin、粘滞及结合形式；杀死与陷阱另对应f(0)=0及Af(0)=0。这里只对有限正则、连续局部边界作上述识别；边界跳入、内部杀死、一般右过程不在该分类中。

\[ f^\prime(0)=\theta Af(0)+\kappa f(0). \]

## 5. 奇异速度的边界检验怎样继承

<a id="time-proof-feller"></a>

在自然尺度，把36章Σ=∫m((c,y))dy、N=∫(y−c)m(dy)及左端镜像原样用于Radon速度。Green已经在本页证明，因此Σ有限的可达充分性不变。必要性所需v=1+λ∫(x−y)v(y)m(dy)可由局部Volterra迭代构造；v连续、右导数BV、二阶Stieltjes测度λv m。第2节由Tanaka得到的广义Itô，使e^{−λt}v(Yₜ)为局部鞅：½∫L v″=λ∫v(Y)dt。于是36章同一概率上界排除Σ无限的有限到达。

不可达端点N有限的入口构造也可闭合，而不假设奇异模型有Lipschitzσ。为从xₙ↑r取得有序过程，依次放入独立内部路径，首次遇到此前任一路径后随该路径同行；连续性保证不交叉，强Markov保证每个边缘规律正确，已有较低编号路径不被改动。故得到可数单调耦合。36章的Green返回均值及正时间上界不变。

正时间紧性现在不用系数矩界：先按该上界把δ时刻的初值及以后路径限制于内部紧集，再用第1节时钟构造所得的紧初值族连续路径律。连续初值映射使该族在C路径空间紧；强Markov于δ使随机初值的混合仍紧。其后有理坐标重建、单调子列一致收敛和首次到a时间传递与36章相同；内部规律由Feller核的连续性及Markov圆柱检验通过极限，而不是传递一个不存在的σ-SDE。必要性仍用命中Laplace的广义ODE及Tonelli，得到N有限。

还须排除出口端点从外侧成为即时起点，不能只证明不可达端点的必要性。假定从右端r存在能即时进入内部的连续局部扩张，令u(x)为该扩张首达c的折扣变换。路径相遇后同行的耦合使u非增；紧区间停止的广义ODE验证给u″=λu m。入口处首达a的时间随a↑r趋0，强Markov使d=lim u(a)=u(r)>0。w=u′于是非正且递增。

若r有限，由w′=λu m及u≥d得到m尾部有限，故N≤(r−c)m((c,r))有限。若r无穷，w的极限必须为0，否则u最终变负；Tonelli给1−d=λ∫(y−c)u(y)m(dy)≥λdN，仍得N有限。因此N无穷的出口和自然端点均不能作为这种即时入口；N有限而Σ有限的正则端点由反射/粘滞构造进入，N有限而Σ无穷的端点由前段构造进入。

这样四种积分类型、不可达端点入口及正则端点连续局部规则在所声明的尺度—Radon速度类别中衔接。未声称所有一般右过程可由这个一维表示覆盖，也未把非局部边界条件纳入。

## 6. 本章实际证明的Revuz联系

<a id="time-proof-revuz"></a>

先只取标准Brownian及参考测度dx。对正Radon测度μ，定义Aᵗμ=∫Lₜᵃ μ(da)。Brownian在紧时间的范围紧、L联合连续，故它有限、连续、递增、适应；局部时加性给连续加性泛函。dA支撑于路径所接触的μ支撑；μ若集中在Lebesgue零集，A仍可能非零，而该集合的普通时间为0。

\[ \int_{\mathbb R}g(x)E_x\!\int_0^tf(B_s)dA_s^\mu\,dx=\int_0^t\!\int_{\mathbb R}f(a)(P_sg)(a)\mu(da)ds,\qquad \lim_{t\downarrow0}\frac1t\int g(x)E_x\!\int_0^tf(B_s)dA_s^\mu dx=\int fg\,d\mu. \]

取f≥0连续紧支撑、g≥0有界连续。证明用dLᵃ的支持、Tonelli及EₓdLₛᵃ=pₛ(a−x)ds；后式从占用期望与连续密度得到。Gaussian对称性将x积分识别为Pₛg(a)。在f的紧支撑上Pₛg→g且有统一界，μ局部有限，DCT给极限。这就把该显式泛函的Revuz测度识别为μ；μ也由全部fg测试唯一决定。

特别Lᵃ对应δₐ，普通时间∫q(B)ds对应q(a)da。若参考改为36章Brownian速度2dx，左侧加倍，Revuz测度也加倍；不能漏掉参考测度的归一化。这里已证Radonμ到显式Brownian泛函的构造与识别，不证明任意PCAF必有该表示、不处理一般右过程的例外集合或平滑测度。那些精确一般性仍登记在38章T-REVUZ，不能将本节记成全双射已证。返回[正文Revuz联系](../chapters/37-local-time.md#local-revuz)。
