# 随机权重、stick-breaking与Dirichlet识别

## 1. 切剩余部分，为何总质量恰为1

<a id="stick-proof-mass"></a>

固定α>0。取独立Vⱼ∼Beta(1,α)，密度α(1−v)ᵅ⁻¹，0<v<1；另取独立于全部V的iid标签Zⱼ∼H。第8章乘积空间实际容纳这些变量。Pⱼ是第j次从当时剩余部分切下的质量，不是每次从原来的1切Vⱼ。

\[ R_m=\prod_{j=1}^m(1-V_j),\qquad P_j=V_j\prod_{i<j}(1-V_i),\qquad \sum_{j=1}^mP_j=1-R_m. \]

直接积分给E(1−V)=α/(α+1)。独立性给ERₘ=(α/(α+1))ᵐ。Rₘ递减到非负R∞，有界收敛给ER∞=0，故R∞=0几乎必然，同时Rₘ→0于L¹。所有权重正、总和1在同一概率1集合上成立；这是实际无剩余质量证明，不以“不断切割”直觉替代。

## 2. 每个样本点上的概率与评价可测性

<a id="stick-proof-measure"></a>

\[ G=\sum_{j\ge1}P_j\delta_{Z_j}. \]

在上述好集合上，这个式子对每个样本点定义可数可加概率：对不交Aₖ，双重非负级数可以交换，所以G(并Aₖ)=ΣG(Aₖ)。坏集合只依赖权重且可测，在那里统一设G=δe₀。每个G(A)是可测级数极限，故G是评价σ代数下P(E)值随机变量。标准Borel空间中单点可测，因此G确实集中在一份至多可数的随机集合上。

权重与标签独立、Tonelli及ΣPⱼ=1还给EG(A)=H(A)。H若无原子，这不妨碍每份G都是离散概率：期望把随机原子的位置平均了，不是把每条实现本身变成连续密度。

## 3. 一个有限维不动点的精确识别

<a id="stick-proof-fixedpoint"></a>

对分区\(A_1,\ldots,A_d\)，设hⱼ=H(Aⱼ)、aⱼ=αhⱼ。删去第一个独立权重及标签后，剩余序列经归一化仍是独立同律的原构造。因此其分区质量向量Y满足下列分布恒等式，V、J、Y′相互独立，P(J=j)=hⱼ。先删除hⱼ=0的坐标；它们原质量为0。只剩一个坐标时结论确定成立。

\[ Y\overset d=V e_J+(1-V)Y^\prime,\qquad V\sim\operatorname{Beta}(1,\alpha). \]

现在独立验证Dir(a)也是不动点，不先假设Sethuraman表示。取独立Gamma(aⱼ,1)变量Uⱼ，S=ΣUⱼ，D′=U/S；再取独立Gamma(1,1)变量T。T-POLYA-DIRICHLET已证明S与D′独立，所以V=T/(T+S)为Beta(1,α)且与D′独立。固定J=j时，V eⱼ+(1−V)D′把Uⱼ换成Uⱼ+T再除总和，律为Dir(a+eⱼ)。

\[ f_{a+e_j}(y)=\frac{\alpha}{a_j}y_jf_a(y),\qquad \sum_j h_j f_{a+e_j}(y)=\sum_j y_jf_a(y)=f_a(y). \]

第二式的混合正是J的概率，故Dir(a)确为不动点。密度在正参数的单纯形面上理解，不能在aⱼ=0处除以aⱼ。

## 4. 为何不动点唯一，因而这确是DP

<a id="stick-proof-unique"></a>

若ρ与ρ′都是单纯形上的不动点律，迭代m次，用共同的V₁,…,Vₘ、J₁,…,Jₘ，最后分别接上任意独立尾向量U、U′，其律为ρ、ρ′。迭代身份使两输出仍分别具有这两种律，而差只在剩余Rₘ上。

\[ \left\|\sum_{j=1}^mP_je_{J_j}+R_mU-\sum_{j=1}^mP_je_{J_j}-R_mU^\prime\right\|_1\le2R_m,\qquad ER_m\longrightarrow0. \]

对任意连续f，单纯形紧性给一致连续，所以上述耦合使两输出的f期望之差趋0。两边律不随m改变，故连续积分相等。用连续函数max(0,1−r dist(x,C))递减逼近闭集C的指标，再用π–λ，得到ρ=ρ′。因此构造向量的律必为Dir(a)，对每个分区成立。T-DIRICHLET-PROCESS的评价柱集唯一性遂给G∼DP(α,H)。没有调用后文划分分类。

## 5. 编号、合并与两种构造的职责

<a id="stick-proof-order"></a>

P₁、P₂,…按切割顺序编号，通常不递减。事件V₁<1/10、V₂>1/2具有正概率，且在那里P₂>P₁。标签也不必互异：有原子的H可能使多个正权重落在同一点，应相加为该点总质量。不能把切割序号直接等同于按大小排序的原子，或未经论证等同于观察中出现的新类别。
