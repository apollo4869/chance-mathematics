# 耦合、共同质量与时间对齐

## 1. 同一边缘不等于同一路径

<a id="coupling-measure"></a>

设E为标准Borel空间。两份概率μ、η的耦合是E×E上的概率Γ，两个边缘分别为μ、η。采用下列总变差约定；其中第三项的上确界对所有可测实函数取。

\[ d_{\rm TV}(\mu,\eta)=\sup_A|\mu(A)-\eta(A)|=\frac12\int|p-q|\,d\lambda=\frac12\sup_{|f|\le1}|\mu f-\eta f|,\quad \lambda=\mu+\eta,\ p=\frac{d\mu}{d\lambda},\ q=\frac{d\eta}{d\lambda}. \]

令a=min(p,q)λ，a(E)=1−dTV。共同部分放在对角线：以质量a(E)抽取a/a(E)，两坐标取同值；剩余以μ−a和η−a的归一化乘积抽取。两个剩余测度支撑于{p>q}与{q>p}，所以不会相等。质量为0或1的情形分别去掉无用分支。这给最大耦合，且任一耦合都有下式，因为两个指标函数只有在坐标不同处才可能不同。

\[ d_{\rm TV}(\mu,\eta)\le \Gamma\{(x,y):x\ne y\}. \]

给任意Markov核K同时作用在两份测度上，|Kf|≤1，因此总变差收缩。若E×E核Q的边缘分别是P(x,·)、P(y,·)，并且在对角线上以后总使用相同的随机化，则顺序核构造给两条合法P链。它们首次相遇后保持相等，τ为耦合时间。

\[ d_{\rm TV}(\mathcal L(X_n),\mathcal L(Y_n))\le\mathbb P(\tau>n). \]

可测的共同随机化使用第10章标准Borel核随机化；对角线为Borel集。这个构造没有断言原来独立实现的两条路径会相遇。

## 2. 共同质量与统一遗忘

<a id="coupling-global"></a>

若对所有x有P(x,·)≥εν(·)，0<ε<1，残差\(R_x\)=(P(x,·)−εν)/(1−ε)是概率核。用同一个Bernoulli(ε)硬币，成功时两坐标都从ν取同一值，否则分别用残差；相遇后锁定。故τ尾部至多(1−ε)ⁿ，总变差至多同值。ε=1时一步遗忘。

存在性也不能省略。概率测度在总变差下完备：Cauchy序列相对于λ=Σ2⁻ʲ\(\mu _j\)有L¹密度极限，非负且积分1。映射μ↦μP是严格压缩，于是迭代的相邻差可求和，极限π满足πP=π；同一压缩给唯一性。并非先假设存在π才得到结论。

## 3. 两种时间对齐

<a id="coupling-shift"></a>

成功的同时间耦合要求有限τ后\(X_n\)=\(Y_n\)。错时耦合只要求存在几乎必然有限的整数R、S，使所有k≥0有\(X_{R+k}\)=\(Y_{S+k}\)。后者不能推出逐时总变差收敛：确定性交替链从相反相位出发，错开一步后完全重合，同一时刻的总变差却始终为1。

后文的再生构造会给真正的错时耦合。正常返再加非周期性，才使两个再生时钟能够在同一整数时刻对齐。由这种构造得到的耦合不必相对于两个原始滤过同时适应；需要的是两条完整路径各自具有正确的概率律。
