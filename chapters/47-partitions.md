# 第四十七章：随机划分如何生长、合并与演化？

一张关系表中，两个人被记为同类。第三个人又与其中一人同类。若表格表达的真是分类，剩下那一格已经不能自由抛硬币了：它也必须记为同类。

这个小小的传递要求，改变了整张随机表的问题。现在不知道的不是每条边如何产生，而是这些彼此一致的关系，是否来自一些能够逐渐被辨认的类别质量。

## 47.1 三条边不能再各自作决定

<a id="partitions-transitivity"></a>

第46章的独立公平边模型当然允许12相连、23相连而13不连。这件事概率为1/8；作为一般关系没有问题，作为“同类”却不合法。我们不能只在原来的数组表示中换几个变量名，就声称已经表示了随机分类。需要让概率律集中在等价关系上。

把N分成互不相交、并为N的非空块，记为Π。块没有固有名称；说某块是第一块，暂时只指它的最小成员最先出现。交换性要求任何有限标签置换都不改变Π的概率律。它允许两个指定人同类，却没有给这个类别规定一个外在名字。

这不是削弱上一章，而是利用附加结构缩小问题：任意数组还需要分析成对噪声；一份传递关系则可能把这些信息收束为共同类别。能否从观察到的同类关系中恢复类别有多大，必须另证。

## 47.2 有限交换表不一定能不断延长

<a id="partitions-finite"></a>

在三个人中均匀选一对同类，第三人单独一类。这是一份完全交换的有限划分。若能无限延拓，每个三人样本都应恰为“一对加一个单点”。但这要求任何类别最多两人，否则取出同块三人；又要求类别最多两个，否则取出三类各一人。全体人数于是最多四，不能容纳N。

因此本章的无限性不是语言上的方便。需要一族有限限制Πₙ，删除最后一个标签以后与Πₙ₋₁同律，且各层都交换。这种采样一致性才使第8章的构造适用。具体的随机划分则还要满足各层限制在同一条样本上相容，而不只是碰巧有类似公式。

## 47.3 名字可以忘掉，比例不能靠猜

<a id="partitions-frequency-question"></a>

看见一个类别在前n人中出现多少次，最自然的读数是除以n。但在任意确定划分中，这个比例未必有极限；即使有，某个无限块也可能密度为零，例如平方数组成的块。交换性究竟能否排除这些情形，是频率概念出现以前必须解决的困难。

另一方面，无穷多个正频率相加可能等于1，也可能小于1。剩余质量不能简单叫作“另一个小类别”：若其中每个人都只出现一次，它是一批单点的总体比例。我们需要同时识别块频率与没有正频率类别承接的质量。

## 47.4 先给类别贴颜色，再把颜色忘掉

<a id="partitions-labels"></a>

一个看似绕远的做法，恰好让旧理论变得可用。独立给每个块贴一个连续均匀标签；同块的人读到同一个标签，不同块使用独立标签。可数标签几乎必然互异，因而记下Xᵢ以后，只要检查Xᵢ=Xⱼ就能准确恢复Π，没有损失分类信息。

重编号会改变块的发现次序，但独立同分布标签不在乎这个次序。给定Π的有限标签核只看等价关系；与交换的Π积分后，X成为真正的无限交换序列。第43章现在可以合法使用：存在随机概率μ，给定μ时X为iid。不同于对一般数组逐行套定理，这里已经证明整个需要表示的对象就是一列标签。

\[ \Pi=\operatorname{Eq}(X),\qquad \mathcal L(X\mid\mu)=\mu^{\otimes\mathbb N}. \]

这一步不是把μ当作预先假定的总体参数。它由交换律反向得到。辅助颜色最终会被积分掉；保留下来的，是相等关系能够识别的那部分μ。

## 47.5 原子质量怎样变成同类频率

<a id="partitions-frequencies"></a>

给定μ及Xᵢ=x，其他人是否与i同类，就是成功率μ({x})的独立指示列。条件强律给下面的极限；i只有可数多个，所以可在一个共同满概率集合上对所有i成立。任意正质量原子几乎必然最终被抽到，故没有一个正质量类别被无限观察永远漏掉。

\[ \frac1n\#\{j\le n:j\sim i\}\longrightarrow F_i=\mu(\{X_i\})\quad\text{a.s. for all }i. \]

这已经回答了原先对频率存在的疑问，而不只是给它一个名字。等式左侧完全由划分本身计算，右侧则把其存在原因解释为独立抽样中的原子质量。不同i同属一块时读到同一个频率，不能把它们重复加进总质量。

## 47.6 dust不是一块无穷小的共同类别

<a id="partitions-dust"></a>

两次独立μ抽样在零质量点上相等的概率为零。对所有人对取可数共同零集，零频率块便只能是单点。这是无限交换性给出的严格限制；前面的平方数块不交换，因此不是反例。

把不同块的正频率按降序排为S₁≥S₂≥…，和不超过1。剩余d=1−ΣSⱼ称dust质量。若μ有非原子部分，抽到它的人互不相等，强律却给这批单点的总体密度d。每个单点频率为0与全部这类人的密度为d，并不是可以互换次序的两个求和极限。

例如Sⱼ=2⁻ʲ有无穷多块而没有dust；全部人单独成类则S全零、dust为1。只有区分块数与总频率，才能描述这两个极端。

## 47.7 paintbox：从质量重造整份分类

<a id="partitions-paintbox"></a>

现在反向作一次实验。给定递减非负序列s且Σsⱼ≤1，在[0,1]画出长度sⱼ的相邻区间。每人独立均匀选点；落在同一个正长度区间才同类，落在剩余区间的每个人各为单点。剩余区间不能涂成一种共同颜色，否则它会错误地产生一个正质量块。

这个构造称paintbox。Kingman表示定理的精确内容是：每份无限交换划分，都唯一地是这些paintbox律关于排序质量S的混合；给定S，整份划分的条件律就是相应paintbox。存在性来自刚才的随机标签与de Finetti，不是因为我们已经验证候选模型可交换。

\[ \mathcal L(\Pi\mid S)=Q_S,\qquad \mathcal L(\Pi)=\int Q_s\,\nu(ds),\quad \nu=\mathcal L(S). \]

技术上还需让排序、μ的原子质量和Qₛ都可测。无需为每个μ神秘地选出一列原子：以其iid积核积分“样本等价划分的第j大频率”，就得到一个Borel函数，其值由强律等于第j大原子质量。[T-PAINTBOX](../foundations/t-paintbox.md#paintbox-proof-representation)完整建立这一步及共同零集，再以有限柱集唯一性证明整份条件律。

## 47.8 为什么排序混合唯一，而发现顺序偏向大块

<a id="partitions-order"></a>

在一份固定s的paintbox中，强律会恢复原来的每个正区间长度，最后排序仍是s。因此任何产生同一无限划分律的混合，都必须在“取排序频率”这一可测映射下给同一分布。这证明唯一性，却不让颜色名称或区间位置变得唯一。

第1个人落入第j块的概率为sⱼ，而不是每块等可能。无dust时，接下来首次发现的新块也按尚未发现的剩余质量抽取。这解释了第44章GEM的出现次序与这里降序质量的区别：大块较早被看见，但首先被看见的不一定最大。排序后的坐标也不保留原Beta切割的独立性。

## 47.9 一份具体划分的概率，究竟在计数什么

<a id="partitions-eppf"></a>

对[n]的一个指定划分，交换性使其概率只看块大小n₁,…,nₖ，且对这些大小对称，记p(n₁,…,nₖ)。这是EPPF，不是“这些大小出现”的总概率。两个具体划分即使块大小相同，仍是两个互斥事件；最后求块数分布时必须把它们都计入。

\[ p(n_1,\ldots,n_k)=\sum_{j=1}^k p(n_1,\ldots,n_j+1,\ldots,n_k)+p(n_1,\ldots,n_k,1). \]

新标签或者进入一个旧块，或者新开块，给出这个递推。反过来，非负、对称、p(1)=1且满足递推的p，会逐层产生归一化相容有限律，再构造无限交换划分。因此EPPF同时是一种概率读数和一致性条件，不是随意挑选的对称函数。

## 47.10 频率如何给出全部有限采样概率

<a id="partitions-sampling"></a>

若没有dust，让指定的k个块分别选择互不相同的正质量类别，便有下式。这里是可数非负求和，可直接以Tonelli或互斥事件解释。它显示样本中同类事件的概率，是总体质量的幂与交叉幂，而非仅由平均类别数决定。

\[ p_s(n_1,\ldots,n_k)=\sum_{j_1,\ldots,j_k\ \mathrm{distinct}}s_{j_1}^{n_1}\cdots s_{j_k}^{n_k}\qquad\left(\sum_j s_j=1\right). \]

有dust时，只有大小1的指定块可以来自剩余区间。逐个选择哪些单点来自dust，每个贡献d，其他块仍落在互异正质量区间；[完整公式](../foundations/t-paintbox.md#paintbox-proof-eppf)把这些有限选择求和。特别地，两个人同类的概率始终为EΣSⱼ²，dust不贡献碰撞。

## 47.11 Ewens公式新增的是哪一层解释

<a id="partitions-ewens"></a>

统一用θ>0记第44章的集中量，不再与下面的折扣α混用。该章已证明CRP的指定划分概率θᵏ∏(nⱼ−1)!/θ的n阶上升阶乘。本章不用重讲餐馆，而问：若只数每种大小的类别，公式怎样改变？

设Aⱼ为大小j的块数。规定aⱼ后，标签划分数为n!除以∏(j!)的aⱼ次方及aⱼ!。前者忘掉块内顺序，后者忘掉同长块之间的排列。乘原EPPF、消掉阶乘，得到Ewens采样公式。

\[ \mathbb P(A_j=a_j,1\le j\le n)=\frac{n!}{\theta^{\uparrow n}}\prod_{j=1}^n\frac{\theta^{a_j}}{j^{a_j}a_j!},\qquad \sum_j j a_j=n. \]

paintbox使这个有限组合公式获得了逆向解释：它是某份随机质量的抽样规律。第44章GEM质量降序后称PD(0,θ)，其和为1；本章的表示与唯一性说明，这份随机排序质量不是额外猜测，而能由无限CRP划分恢复。若另贴有原子标签，异桌可能同名，实际相等值划分便不能直接使用这个公式。

## 47.12 改变强化以后，哪些规则仍能交换

<a id="partitions-two-parameter"></a>

普通CRP把进入旧块的权重取为它的全部人数。若每个旧块都扣去同一个α，并把扣出的总权重交给新块，局部归一化仍成立：旧块权重nⱼ−α，新块权重θ+αk。真正需要检查的是改变顾客顺序以后整条路径概率是否保持。

在0≤α<1、α=0时θ>0、α>0时θ>−α的范围，所有概率合法。乘路径概率，新块因子只看已经开了多少块，旧块因子只看最终人数，得到对称公式，因此确实交换。只说“归一化了”不能代替这一步。

\[ p_{\alpha,\theta}(n_1,\ldots,n_k)=\frac{\prod_{i=1}^{k-1}(\theta+i\alpha)\prod_{j=1}^k(1-\alpha)^{\uparrow(n_j-1)}}{(\theta+1)^{\uparrow(n-1)}}. \]

这不是所有交换划分的分类，只是paintbox一般结构中的一族可计算预测律。合法却不交换的顺序核反例见[T-PARTITION-PREDICTION](../foundations/t-partition-prediction.md#partition-proof-boundaries)：前两人不同后，确定让第3人追随第1人，会把名字偷偷留在模型里。

## 47.13 删除一个类别，为什么参数也要改变

<a id="partitions-stick"></a>

第一块已有n₁人、其外r人时，不进第一块的权重为θ+α+r。条件于不进，余下类别正好服从参数(α,θ+α)的同类餐馆。独立生成初始质量(1−α,θ+α)的二色Pólya，再把另一份独立残余餐馆插入蓝色位置，有限路径核逐项相同，证明独立分解，而非从边缘概率猜独立。

\[ V_j\sim\operatorname{Beta}(1-\alpha,\theta+j\alpha)\ \text{independently},\qquad P_j=V_j\prod_{i<j}(1-V_i),\quad \sum_jP_j=1\quad\text{a.s.} \]

残余子序列的密度每次乘上1−Vⱼ，给出现次序质量。总和1仍需证明：α>0时ΣEVⱼ发散而ΣEVⱼ²有限，第12章中心级数判据使ΣVⱼ发散，剩余乘积不超过exp(−ΣVⱼ)而趋零；α=0用强律。完整Beta计算与所有参数条件在[配套证明](../foundations/t-partition-prediction.md#partition-proof-total-mass)。排序得到PD(α,θ)，不是把排序后的坐标继续当作独立Beta。

## 47.14 同一份对称，尚未规定时间怎样经过

<a id="partitions-dynamics"></a>

一个静态paintbox可以一直保持不动；也可以让已有类别开始合并。两种过程在初时拥有同一交换划分，未来却不同。甚至选定某种合并规则后，将所有速率乘2，交换性仍保持，等待时间全部改变。静态表示不可能独自决定这些时钟。

因此我们另外提出一个具体动力学：任何两条当前祖先线等机会合并，每对速率1。这里把时间向过去推进，类别表示在该时间深度已经拥有共同祖先的样本。它是一个可研究的数学模型；交换性本身没有证明真实人口必然使用这份规则。

## 47.15 有限样本可以先把时钟真正造出来

<a id="partitions-finite-coalescent"></a>

n个单点开始。当前b块时，等待参数b(b−1)/2的指数时间，再均匀选一个块对合并。每次用新独立变量；至多n−1跳，不会爆炸。指数竞争说明每对速率恰为1。与“从b个人中抽两个人”不同，我们选的是当前谱系块，不按块含多少样本加权。

\[ L_nf(\pi)=\sum_{\{B,C\}\subseteq\pi}\left[f(\operatorname{merge}_{B,C}\pi)-f(\pi)\right]. \]

这定义了有限Kingman coalescent。其标签交换性从构造直接成立。还不够的是：不同n造出的链能否作为同一个无限过程的有限记录？答案需要处理看不见的合并。

## 47.16 删去一个人以后，为什么时钟没有被破坏

<a id="partitions-projection"></a>

把一个较大样本只保留[n]。每个可见块都来自唯一完整块，所以两个可见块的合并仍只对应一个率1的完整块对。完整块若在[n]中没有成员，它与可见块合并可能发生许多次，却不改变限制划分。这些不可见事件不能被误当成限制的额外跳跃。

\[ L_N(f\circ r_n)=(L_nf)\circ r_n,\qquad P_t^N(f\circ r_n)=(P_t^nf)\circ r_n. \]

有限矩阵的第二个身份由第一个身份逐幂求和得到。再对完整过去条件化、用塔式，限制过程本身就是生成矩阵Lₙ的Markov链，所有时间联合分布相容。只匹配某个时刻的块数，远不足以得到这一结论。[完整分块证明](../foundations/t-kingman-coalescent.md#kingman-proof-consistency)保留了这一步。

## 47.17 无限谱系存在，不靠一只无穷快的总时钟

<a id="partitions-infinite-process"></a>

若直接把无穷块的所有率1时钟放在一起，“下一次等待”的总速率无穷；这没有定义出从0开始的普通跳链。可行路线是先保存每个有限限制在有理时间的记录。它们是可数个有限值随机元，第8章把相容记录放在同一空间。

每个有限记录以概率1只粗化，只有有限次改变，而且在有理点右连续；这是可数可测条件。对所有n共同成立后，向右取有理极限便得到每个实时刻的有限限制。各限制相容，确定整份Π(t)。以有限限制度量先控制有限头部、再控制尾和，得到无限划分空间中的càdlàg路径，0处仍是单点划分。

这是路径存在的证明，不只是将有限维分布命名为过程。[T-KINGMAN-COALESCENT](../foundations/t-kingman-coalescent.md#kingman-proof-path)实际给出好记录集合、可测延拓、左极限及唯一律；不以尚未写成的第56章作基础。

## 47.18 未来合并可以作用于现在的块

<a id="partitions-coagulation"></a>

对当前π，把块按最小成员编号；另取一份独立Kingman划分Ξ(t)，将编号在同一Ξ块中的旧块合并。这是Coag(π,Ξ(t))。检查有限个原标签只需有限个块编号，故操作可测；它给无限状态空间上的真正转移概率核。

该核的每个有限限制就是已经构造的有限链。有限半群身份与条件期望逐柱集延伸，证明Π的Markov性质。这里“只记住现在”指现在的整份划分，而非只记块数；若还要追踪谁与谁同祖先，块数并不是足够状态。

## 47.19 无穷多个祖先怎样在正时间变成有限个

<a id="partitions-coming-down"></a>

记Nₙ(t)为前n人的块数，N(t)=supₙNₙ(t)。首次只剩不超过b块的时间\(T_b^{(n)}\)随n递增。有限链经过j块时的等待为独立Exp(j(j−1)/2)，所以从n降到b的期望可望远镜求和。

\[ \mathbb ET_b^{(n)}=\sum_{j=b+1}^n\frac2{j(j-1)}=2\left(\frac1b-\frac1n\right),\qquad \mathbb ET_b=\frac2b. \]

令n增大，用单调收敛得到\(T_b\)极限，而非先假设无限跳链存在。因为{N(t)>b}等于{\(T_b\)>t}，概率不超过2/(bt)，再令b增大，任何t>0的块数都有限。先在有理t共同成立，再用只合并不分裂的单调性，推广到全部正时间。

0处仍有无穷单点，并不与上述结论矛盾。任何固定有限样本都有正的首次等待；但是放大观察人数以后，越来越早的合并可以在更精细的尺度上发生。

## 47.20 为什么下降速度是2除以时间

<a id="partitions-speed"></a>

只证明正时刻有限，还没有量出初始的剧烈变化。\(T_b\)的律等于独立指数尾和，方差至多C/b³，平均为2/b。因此\(bT_b\)在平方数b=m²上的偏差概率可求和；Borel–Cantelli给极限2，再以单调性补到所有整数b。

\[ bT_b\to2\quad\text{a.s.},\qquad T_{N(t)}\le t<T_{N(t)-1},\qquad tN(t)\to2\quad(t\downarrow0)\ \text{a.s.} \]

有限限制在0的右连续性使N(t)随t↓0趋无穷，所以上面的反演合法。速度常数是本章速率约定的产物：每对率c时变为2/c。该论证量化的是时间边界附近的谱系数，不是Ewens模型中样本量增大时的类别数。

## 47.21 dust消失，为什么路径仍右连续

<a id="partitions-time-frequencies"></a>

每个正有理时刻，有限块的交换划分不可能有dust：否则paintbox抽样会产生无穷单点。各块频率正且总和1。对这些有理时刻共同取好集，任意更晚时刻的块只是有限个旧块的并，所以频率同时在所有正时刻存在，无需求交不可数个零集。

\[ \sum_iS_i(t)=1\quad(t>0),\qquad \mathbb E\sum_iS_i(t)^2=1-e^{-t}. \]

第二式只需二人限制：两人在率1指数时间后合并。最大块质量的平方被ΣSᵢ²控制，又随合并单调，因此t↓0时最大质量趋0几乎必然。排序频率逐坐标趋全零，但ℓ¹总质量一直是1。有限样本、逐坐标频率和总质量是三种不同的观察；把它们混用，才会制造出表面上的悖论。

## 47.22 合并质量不等于抽取两个人

<a id="partitions-mass-rates"></a>

正时间的有限个块可以直接用质量表示。质量sᵢ、sⱼ的块一旦合并便成为sᵢ+sⱼ，随后重新排序。但触发这一合并的速率仍是1，并非sᵢsⱼ。后一因子来自按总体质量抽取两个个体，与等机会选择谱系对不是一个实验。

独立Coag核说明，未来质量合并不依赖块的旧名称；在有限块正时间状态上，质量过程具有相应合并生成机制。这是静态频率与动态划分之间实际建立的结构联系，但并未证明所有质量合并模型都能用同一速率族投影一致地实现。

## 47.23 一个两人公式相同，三个样本就会揭穿区别

<a id="partitions-not-ewens"></a>

无突变Kingman中，二人时刻t仍不同的概率是e⁻ᵗ；三人全不同是e⁻³ᵗ。Ewens(θ)中二者是θ/(θ+1)与θ²/[(θ+1)(θ+2)]。若只匹配二人，就可能误以为t与θ之间有简单等价。

可是代入e⁻ᵗ=θ/(θ+1)，三人等式要求θ(θ+2)=(θ+1)²，这不可能成立。两份对象都交换，并没有让它们成为同一族概率。若要建立Ewens与谱系的联系，必须另加并证明相应机制。

## 47.24 在祖先线上寻找首次突变

<a id="partitions-mutation"></a>

保留每对谱系合并率1，给每条活跃祖先线另放一个率θ/2的独立突变时钟。向过去追溯，某条线遇到首次突变，就给它覆盖的样本一个新类型并冻结；不同突变使用不同类型。我们记录的是最近突变所决定的类别，不是任意时间深度的共同祖先块。

\[ q_b^{(\theta)}=\binom b2+\frac{b\theta}{2}=\frac{b(b-1+\theta)}2. \]

b条活跃线的下一事件是某对合并或某条冻结。每次活跃数少1，有限n经过n个事件后全部冻结。也可在有限Kingman树的独立Poisson突变中实现：越过最后共同祖先仍接一条根支，θ>0保证向过去遇到首次突变。忽略已定类型谱系的不可见事件后，同一有限生成矩阵给上述冻结过程；[配套证明](../foundations/t-coalescent-mutation.md#mutation-proof-construction)核对这个投影，而不靠生物图像替代。

## 47.25 首次事件怎样把Ewens公式逼出来

<a id="partitions-mutation-proof"></a>

指定一个终端类型划分π。首次若为i突变，i必须在π中单独一类；若i,j先合并，它们必须在π中同类。删掉已冻结的单点或压缩已合并的一对，都变为n−1谱系的同一问题。令u(π)为终端概率，按事件速率得到严格递推。

\[ q_n^{(\theta)}u(\pi)=\frac\theta2\sum_{i:\{i\}\in\pi}u(\pi\setminus i)+\sum_{i<j:\ i\sim_\pi j}u(\pi^{ij}). \]

代入CRP的Ewens候选。删单点的概率比是(θ+n−1)/θ；大小m块中合并一对的概率比是(θ+n−1)/(m−1)，而可选对有m(m−1)/2个。所有单点与非单点人数相加恰为n，右侧总因子变成n(θ+n−1)/2，即左侧速率。n=1初值相同，归纳证明u恰为Ewens EPPF。

限制标签的活跃/冻结生成矩阵也相容；有限终端以有界收敛取得相容无限类型划分。因此“同一公式”是两份不同构造经证明产生同一静态律，不是说向前加顾客和向后合祖先具有相同的转移过程。每对率c、每线突变率μ时，参数是θ=2μ/c。

## 47.26 有限样本能辨认什么，不能辨认什么

<a id="partitions-information"></a>

观察越来越多标签，paintbox频率几乎必然可恢复；但固定有限样本只给有限模式的一个实现。全部单点不能证明总体全是dust，少数大类别也不能证明其余质量为零。不同质量混合可能在有限阶测试上相同，只有全部有限限制共同确定无限律。

同样，某个时刻的交换划分没有决定其未来合并机制。Kingman规定每对合并率，突变模型另外规定类型阻断；若允许多块同时合并、碎裂或嵌套层级，需要重新证明有限限制一致性与路径构造。多重合并、碎裂与层级的更一般构造将在第56章研究，不能从这里的二元速率规则自动推出。

## 47.27 名称无关紧要，不等于结构不存在

<a id="partitions-insight"></a>

传递性最初只是不许三格关系各自决定，却让一般关系表示变成一份唯一的排序质量混合。dust又提醒我们，总体质量不能只按每个可见类别逐项想象；一批互不相等的单点仍能占据非零比例。数学消去的是任意命名，不是分类本身。

当类别开始合并，额外的速率规则才赋予时间。静态表示、样本增长与后向谱系可以相遇，却只有在明确机制与完整证明下才能认作同一分布。读者现在能够追问的不只是“是否对称”，还包括对称作用于什么对象、哪些信息被共享、哪些观察尺度能够恢复它们，以及运动还需要什么独立的规则。

如果观察对象不再是已经编号的人，而是空间中实际出现的一批随机位置，“有多少个”和“位于哪里”会同时成为随机结果。分类经验告诉我们应先辨认对象及其可测观察，再讨论表示；计数与位置的相互作用将要求另一种空间。

## 47.28 史料、完整证明与适用范围

预测与两参数结构的学术参照是Pitman的[作者讲义](https://www.stat.berkeley.edu/~aldous/206-Exch/Papers/pitman_CSP.pdf)，本章独立给出删除、Beta因子和剩余质量的论证，不将文献链接当作证明。完整专题为[T-PAINTBOX](../foundations/t-paintbox.md)、[T-PARTITION-PREDICTION](../foundations/t-partition-prediction.md)、[T-KINGMAN-COALESCENT](../foundations/t-kingman-coalescent.md)、[T-COALESCENT-MUTATION](../foundations/t-coalescent-mutation.md)。
