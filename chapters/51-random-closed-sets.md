# 第五十一章：一个随机集合怎样拥有概率规律？

在单位正方形里，等机会选择一个高度，画一条贯穿左右两边的水平线。对任何预先钉好的一个点，这条线经过它的概率都是零。可是每张实验记录上都有一条完整的线。

若把所有位置的归属概率排成一张表，得到的会是一片零。这张表甚至不能区别“画了一条线”和“什么也没画”。遗漏的不是某个更精确的小数，而是一次实验中不同位置怎样共同组成一个形状。

## 51.1 没有一点被预先选中，仍然可以有一整条线

<a id="sets-stroke"></a>

取U均匀于[0,1]，令\(F_U=[0,1]\times\{U\}\)。对固定(x,y)，P((x,y)∈Fᵤ)=0；但P(Fᵤ≠∅)=1。不能把不可数个零概率事件的并当成零概率。换成一个竖向高度从a到b的观察窗口，命中概率却是b−a。窗口保留了点式观察没有提供的信息。

这里不必先决定给线赋多少长度、怎样沿线分配质量，或把它切成多少个点。先问一个更少承诺的问题：这次画出的闭集合，是否碰到了某个区域？若这种观察足够，我们就能先建立形状的概率，再决定是否需要在形状上加质量。

## 51.2 开窗口为什么看不见未补上的极限点

<a id="sets-closedness"></a>

不能对任意子集直接照搬这套观察。实线中的有理数集与整条实线，命中的非空开集完全相同，却并非同一个集合。开窗口无法判断一个极限点是否已经被纳入；它看到的是闭包。闭性因此不是为了证明方便而附加的装饰，而是当前观察方式能够识别的对象边界。

对闭F，若x不在F，总有一个与F不交的开邻域；在可数基中仍能找到这样的邻域。所有避让邻域的并恰是F的补，故开命中记录可以恢复每个闭集。随机情形还要证明这些记录相容、可测，并能决定联合概率；确定性可辨认只是第一步。

## 51.3 先给所有可能形状一个共同空间

<a id="sets-state"></a>

以下E为局部紧、第二可数的度量空间，取全部闭子集组成\(\mathcal F(E)\)，包括∅。这沿用48–49章的空间条件，但对象已从质量变成集合。对开U与紧K记

\[ H_U=\{F:F\cap U\ne\varnothing\},\qquad M_K=\{F:F\cap K=\varnothing\}. \]

随机闭集是取值于这个空间的映射，要求每个开命中事件可测。这叫Effros可测结构。它对原实验概率空间没有标准Borel要求；我们将证明形状空间本身有足够好的Borel结构，才谈它的概率律与极限。空集保留“没有留下任何形状”的实验，不能在定义时无声删去。

## 51.4 为什么避让紧集，而不要求避让所有开集

<a id="sets-fell"></a>

实线上的{n}逐渐离开每个有界观察区域，局部记录应趋空集；若要求它最终避让整条实线，这个极限就不可能成立。反过来，{1/n}应趋{0}，必须保留附近位置对极限点的逼近。所需拓扑同时允许“将有的点被邻近点逼近”和“本不该有的点不在有限区域残留”。

以开命中\(H_U\)和紧避让\(M_K\)为子基本开集，得到Fell拓扑。只用开命中不足以控制多余位置；把避让条件扩大得过强，又会不许形状逃向无穷远。这个选择与第49章vague拓扑有相似的局部性，但不是由测度拓扑自动继承，因为此时尚未指定任何测度。

## 51.5 把无穷远加入形状，得到一个紧空间

<a id="sets-hyperspace"></a>

将E紧化为\(X=E\cup\{\infty\}\)，把F记录为\(F\cup\{\infty\}\)。包括空F时，这始终是X的非空紧集。X可取紧度量r；在其紧子集间使用Hausdorff距离

\[ d_H(A,B)=\max\left\{\sup_{a\in A}r(a,B),\sup_{b\in B}r(b,A)\right\}. \]

这份紧集空间确实紧，而非图像上的猜测：有限ε网给它有限ε网；Hausdorff-Cauchy列的距离函数一致收敛，其极限恰为到一个非空紧集的距离。因此完备且全有界。含∞的紧集是闭子空间，故也紧、完备、可分。拉回后的开条件恰是上一节的开命中与紧避让，所以Fell空间是紧Polish。[T-FELL](../foundations/t-fell.md#fell-polish)给紧化和全部度量细节。

## 51.6 紧窗口的命中为什么也是可测事件

<a id="sets-measurability"></a>

对紧K取逐渐收紧的开邻域Uₙ，全部闭包留在一个紧邻域内，交为K。闭F命中每个Uₙ时，可从命中点抽收敛子列，极限在F∩K。因此

\[ H_K=\bigcap_nH_{U_n},\qquad H_K=M_K^c. \]

紧命中因此属于Effros域，且是Fell闭集。Fell子基本集均Effros可测；由第二可数性，每个拓扑开集是可数个有限子基本交的并。故Effros域恰等于Fell Borel域。更进一步，有限并的可数紧邻域族就能生成它；以后核对概率律只需这一份可数记录，不必逐个挑选不可数位置的零集。

## 51.7 容量记录命中，而不是计算区域的质量

<a id="sets-capacity"></a>

对随机闭集F定义容量泛函\(T(K)=P(F\cap K\ne\varnothing)\)，K为紧集，T(∅)=0。水平线例子的状态空间是单位正方形，以下K取其中的紧子集，得到

\[ T(K)=\operatorname{Leb}\bigl(\pi_yK\bigr),\qquad F=[0,1]\times\{U\}. \]

投影\(\pi_yK\)紧，故此式合法。取两条位于不同横坐标、覆盖相同高度区间的竖线段K₁,K₂，它们不交，却总是同时被命中。并集的容量与每条相同，而非两倍。所以T不是空间中的可加概率测度；它是形状空间中一族事件的概率。两层空间若混淆，后面的表示条件就会显得莫名其妙。

## 51.8 知道并集的命中，能恢复共同命中吗

<a id="sets-identification"></a>

若只给若干事件各自的概率，通常不能恢复联合律。但紧窗口的并仍是紧窗口，容量同时给出了它的读数。两个窗口的共同命中因而满足

\[ P(H_{K_1}\cap H_{K_2})=T(K_1)+T(K_2)-T(K_1\cup K_2). \]

任意有限次共同命中及避让，也可由并集容量用容斥恢复。可数紧决定族的全部有限联合律因此被T确定，而它们生成Fell Borel，π–λ便识别整份随机闭集律。这是容量的完整识别能力，绝非“只记录一阶平均”。它同时解释为什么仅知道单点容量远远不够。

## 51.9 不可能出现负概率的观察表

<a id="sets-alternation"></a>

设要避让A，又命中K₁,…,Kᵣ。逐项展开其事件，得到一个对所有r都必须成立的约束：

\[ \sum_{I\subset\{1,\ldots,r\}}(-1)^{|I|}T\!\left(A\cup\bigcup_{i\in I}K_i\right)=-P\left(H_A^c\cap\bigcap_{i=1}^rH_{K_i}\right)\le0. \]

这叫完全交替性。一次差给单调，二次差涉及两个命中的依赖；更高次差不能省。在三点空间，把每个单点容量设为1/2，任何两点或三点容量设为1，所得T单调又次可加，却给“三个点全被命中”的概率−1/2。形式上像概率的数字表，仍可能不是任何实验的概率。

## 51.10 有限表相容还不够，极限点也要被落实

<a id="sets-continuity"></a>

紧Kₙ下降到K时，若F命中全部Kₙ，闭性及紧性使它必命中K。因此T(Kₙ)必须下降到T(K)。没有此条件，有限表仍可能一致，极限记录却无法成为闭集。

例如在[0,1]令无限紧集容量1、有限紧集容量0。因为有限并无限恰当至少一个成员无限，它满足完全交替；但{0}∪{1/k:k≥n}下降到{0}，容量始终1而极限单点容量0。若真有随机闭集，每个单点的零命中又会使这个可数紧集的命中概率为0。缺失的连续性不是一个无关紧要的技术补丁。

## 51.11 哪些容量恰好来自随机闭集

<a id="sets-choquet"></a>

现在才有充分理由提出表示定理。LCSC度量E上，紧集泛函T来自一份唯一随机闭集律，当且仅当：值在[0,1]，空集值0，完全交替，且沿递减紧列连续。允许随机空集；没有额外要求每次实验留下非空形状。这是本章的Choquet随机闭集表示定理。

必要条件已由实际命中事件证明。充分性真正困难的部分，是把一致的有限0/1表变成一个空间对象；第8章只能先给无限记录，不能自动保证记录画得出一个闭集。接下来完成这一步，[T-CHOQUET](../foundations/t-choquet.md)保留所有共同零集与任意紧集延拓。

## 51.12 先构造一份可数的命中记录

<a id="sets-records"></a>

取可数稠密中心和有理半径的紧闭球，再取有限并，得族R。它足以从内部探测所有开集，也能从外部逼近任意紧集。对每种有限记录，把要避让的窗口并成A，要命中的窗口记Kᵢ。令q=1−T，则其概率必须是

\[ p(A;K_1,\ldots,K_r)=\sum_{I\subset\{1,\ldots,r\}}(-1)^{|I|}q\!\left(A\cup\bigcup_{i\in I}K_i\right). \]

完全交替使它非负。将某位“命中”与“避让”的两项相加，容斥中新增项消去，得到少一位的概率；逐位相加最后是q(∅)=1。因此这些表真正一致，8章给{0,1}ᴿ上的概率与命中位H(K)。有限表还保证单调性、并集位等于各位最大值；指标可数，所以能统一到同一满测度集合。

## 51.13 从零记录挖出开补集

<a id="sets-realization"></a>

若一个紧邻域被记录为避让，它的内部当然不该含形状。把所有这些内部挖掉，定义

\[ F=E\setminus\bigcup_{\substack{L\in R\\H(L)=0}}\operatorname{int}L. \]

这给闭集，却还要核对它没有篡改记录。若H(K)=0，取R内外逼近Lₙ↓K、K⊂int Lₙ。容量递减连续与单调命中位，使H(Lₙ)最终为0，所以整个K被挖去。反过来，若F避让K，K被那些零记录的内部覆盖；紧性给有限子覆盖，并集位为0，单调性迫使H(K)=0。故在同一满测度集合，R内全部记录都被精确实现。

每个开命中是R中相应紧命中的可数并，因而F可测。最后对任意紧K选R的外逼近，再用闭集的递减连续性，便恢复P(F命中K)=T(K)。存在性完成；之前的容斥识别再给唯一性。有限概率的一致、空间的闭性与概率的连续性，各自解决了不同的构造困难。

## 51.14 空形状的概率也在容量中

<a id="sets-empty"></a>

对递增紧穷竭Kₘ，任意非空闭F必命中某个Kₘ，所以

\[ P(F=\varnothing)=1-\lim_{m\to\infty}T(K_m). \]

因此不能在T的定义中随手补上“总量1”来排除空形状。容量不是空间质量，不需要模仿一份空间概率的总量；它已经在形状空间给出总概率1，并明确计算非空部分。

## 51.15 这个表示与势论容量是什么关系

<a id="sets-history"></a>

Choquet在1954年的《Theory of capacities》中发展集合函数及无限阶交替性，并研究其积分表示；Fell在1962年的论文中研究局部紧空间闭子集的一种Hausdorff拓扑。这些是可核实的数学史节点。本章用可数命中表组织构造，是现代重建，不把它写成两位作者共同经历的一条发现路线。

第38章的势论容量与这里的命中容量有关，但不是同一份未经条件核对即可互换的定义。本章定理识别的是满足明示条件的闭集命中概率，值≤1；一般解析容量可能没有这个归一化，也可能需要另证连续性或表示条件。名称相同不能替代数学比较。

## 51.16 形状收敛，需要同时保留与排除哪些点

<a id="sets-sequences"></a>

Fell收敛有可复核的路径判据：极限F的每个点都由Fₙ中的点逼近；任何从Fₙ子列选出、在E内收敛的点，其极限都必须在F。第一项不许极限凭空多出未被逼近的位置，第二项不许前列在有限区域留下不属于极限的残余。

证明直接来自开命中与紧避让。若后一项失败，极限点在F外有紧邻域，可与F分开；若某个应避让紧集仍无穷多次命中，紧性又会抽出违反第二项的子列。{n}趋空集与{1/n}趋{0}由此同时合法；“所有点都去哪里了”必须连同状态空间的无穷远约定回答。

## 51.17 随机收敛不能要求每个紧窗口读数都收敛

<a id="sets-convergence"></a>

现在令Fₙ、F为随机闭集。分布收敛指Fell空间上的弱收敛。24章Portmanteau对开命中与闭命中分别给出

\[ \liminf_nP(F_n\cap U\ne\varnothing)\ge P(F\cap U\ne\varnothing),\qquad\limsup_nT_n(K)\le T(K). \]

若F命中K却不命中int K的概率0，两边夹出Tₙ(K)→T(K)。一般紧集却不能如此要求：确定的Fₙ={1/n}已经Fell趋{0}，但在K={0}上的命中概率从来不是1。一个恰落在窗口边界上的点，会让0/1读数跳变，而集合本身仍然很好地收敛。

## 51.18 足够多的连续窗口，仍能确定全部极限

<a id="sets-capacity-limit"></a>

准确判据是：对给定F，只要在所有满足\(T(K)=P(F\cap\operatorname{int}K\ne\varnothing)\)的紧K上有Tₙ(K)→T(K)，便有Fₙ⇒F；必要性也成立。不能只靠“容量唯一”跳过证明。Fell空间紧，所以任意子列有弱极限Q；需证Q的容量确为T。

用proper度量将任意紧K扩成紧邻域Kʳ。除可数个半径外，F到K的随机距离不在r有原子，故Kʳ是合法连续窗口。对子列极限用Portmanteau，上界与下界分别通过Kʳ和int Kʳ夹住Q在K的读数；再让合法r下降到0，两份闭集律的递减连续性给Q(\(H_K\))=T(K)。容量唯一性这时才完成识别。[T-CLOSED-LIMITS](../foundations/t-closed-limits.md#closed-capacity-convergence)给全部不等式方向与可数例外半径的证明。

## 51.19 并集可以连续，交集却未必

<a id="sets-operations"></a>

有限并在Fell空间连续，因而联合收敛的随机形状可以用连续映射定理合并。只知道两个边缘各自收敛，不等于知道它们怎样联合。交集即使确定也会失败：{0}与{1/n}分别趋{0}，它们的交始终为空，却不同于两个极限的交。

连续且proper的空间映射a将闭集送到闭集，并诱导连续的形状映射；proper性使像中留在紧区域的点，其原像也有紧子列。没有这个条件，闭集像本身可能不闭。所谓“把图形变换一下”，必须先确认输出仍属于同一个状态空间。

## 51.20 测度的支撑可测，却可能在极限中保留幽灵

<a id="sets-examples"></a>

给Radon μ取支撑。对开U，\(\operatorname{supp}\mu\cap U\ne\varnothing\Longleftrightarrow\mu(U)>0\)；支撑补是可数个零质量基开集的并，证明了反方向。49章评价可测性因此给随机支撑的Effros可测性。

\[ \mu_n=(1-1/n)\delta_0+(1/n)\delta_1\Rightarrow\delta_0,\qquad\operatorname{supp}\mu_n=\{0,1\}\quad(n\ge2). \]

右边的支撑不趋{0}。即使总质量都是1、没有逃向无穷远，消失的小质量也能留下一个始终存在的位置。测度收敛询问积分读数，支撑收敛询问存在性；不是将某个已有收敛定理换一个名称。

## 51.21 整数点为何排除了这个小质量反例

<a id="sets-point-support"></a>

对局部有限整数点测度，支撑映射vague→Fell却连续。极限中的点有一个正的连续测试读数，保证前列在每个邻域最终有点；应避让的紧K可用极限积分0、在K上≥1的连续截断检测，前列读数小于1时整数性就迫使K内无点。任意小权重造成的幽灵在此不可能存在。

于是48章Poisson点过程支撑的容量为\(T(K)=1-e^{-\mu(K)}\)，Cox支撑容量为\(T(K)=1-Ee^{-\Lambda(K)}\)。但闭形状仍忘掉重数：\(\delta_U\)与2\(\delta_U\)的形状完全相同。我们既证明了测度产生形状的合法途径，也看见这个映射具体丢掉了什么。

## 51.22 一条路径留下的范围，需要多长的观察时间

<a id="sets-paths"></a>

连续路径在[0,t]的范围紧，且\(d_H^\rho(\gamma_n[0,t],\gamma[0,t])\le\sup_{s\le t}\rho(\gamma_n(s),\gamma(s))\)。所以有限时间的一致路径收敛推出范围Fell收敛，随机情形再用连续映射定理。

无限时间不同。路径1/(1+s)的像为(0,1]，须取闭包才能进本章状态空间。闭包范围命中开U，等价于路径在某个有理时刻进入U，因而可测；但局部一致收敛不保证无限范围收敛。让γₙ在n以前为0、下一单位时间升到1再保持，所有闭范围都是[0,1]，路径却局部一致趋零。第24章建立的路径拓扑在有限时窗控制运动，不会自动控制尚未到来的全部时间。

## 51.23 随机颗粒的并集何时真是一片闭区域

<a id="sets-coverage"></a>

再让Poisson父点各带一个紧颗粒，把所有平移颗粒并起来。它不只是点测度换个图标：颗粒之间可重叠，最后结果不保存覆盖次数。需要先保证每个紧窗口只遇到有限个颗粒。若σ有限父强度a、独立颗粒律Q满足

\[ I_K=\int a(dx)\int\mathbf1_{\{(x+G)\cap K\ne\varnothing\}}Q(dG)<\infty. \]

标记Poisson构造给命中颗粒数均值\(I_K\)，因而有限a.s.；可数紧穷竭统一零集，使并集局部为有限闭并，故闭。无颗粒命中K的Poisson概率又给\(T(K)=1-e^{-I_K}\)。实线上固定颗粒[−r,r]、齐次父率κ，在[a,b]有I=κ(b−a+2r)。可测颗粒空间、无限并闭性及完整计算见[T-RANDOM-SHAPES](../foundations/t-random-shapes.md#shapes-boolean)。

条件不能只删不问：在各位置1/n处放独立Poisson(1)个零半径颗粒，无穷多标签出现a.s.，并集不含0却向0聚集。取闭包可以定义另一个对象，但确实增加了一个位置。无限并、闭包和原始出现记录并不是同一个操作。

## 51.24 局部紧性不是可任意搬走的背景

<a id="sets-space-boundary"></a>

本章在闭集空间中得到紧Polish性，依赖空间E局部紧且第二可数。无限维Hilbert空间若仍用开命中与紧避让，空集和{0}竟无法被不交邻域分开：有限个紧集不能填满0附近的小球，总能挑一个单点同时通过两边的有限观察条件。详见[T-FELL](../foundations/t-fell.md#fell-nonlocal)。

这不表示一般Polish空间上无法研究随机闭集，而是本章的拓扑构造和表示范围不能无条件搬用。每次换空间，都要重新检查紧邻域、可数决定族、边界与实际收敛的关系。

## 51.25 从零读数到一份完整形状概率

<a id="sets-insight"></a>

开头每个固定点的零归属概率，至此仍然是正确计算。错误的是把它当成整份形状概率。窗口的联合命中记录不仅能区分水平线与空集；只要满足完全交替和递减连续，便能从头构造一份唯一闭集律。条件中的每一部分都承担具体责任：有限表不能含负概率，极限命中不能丢失应有的接触，记录必须在同一空间对象中同时实现。

容量不是另造一份空间质量，而是把形状空间中的相容事件组织为概率。支撑、路径范围和随机覆盖的反例也说明：存在性、质量大小、时间范围及闭包都各有自己的极限。我们现在能对没有预定单位质量的随机形状提问，并知道哪些答案足以成为一个合法的随机世界。

## 51.26 形状之外，什么还没有被记录

<a id="sets-sources"></a>

一棵画出的树当然可以看成闭集合，但仅有图形，并未说明哪个点是祖先、边有多长、怎样沿亲缘关系到达另一个点。两个相同的外部形状可以承载不同的关系。下一个问题不是再给窗口增加一个命中数字，而是为谱系本身选择一个能够保留这些关系的随机对象。

本章完整证明位于[T-FELL](../foundations/t-fell.md)、[T-CHOQUET](../foundations/t-choquet.md)、[T-CLOSED-LIMITS](../foundations/t-closed-limits.md)及[T-RANDOM-SHAPES](../foundations/t-random-shapes.md)。史料参见Choquet的[1954年原刊](https://numdam.org/articles/10.5802/aif.53/)与Fell的[1962年论文](https://doi.org/10.1090/S0002-9939-1962-0139135-6)。本章证明LCSC度量版本；一般非局部紧空间的其他闭集拓扑和更广Choquet表示不由上述论证自动覆盖。
