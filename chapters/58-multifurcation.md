# 第五十八章：从二叉树走向多叉随机几何

一棵有限树的每个内部节点都有三个孩子，似乎应当留下一棵三叉的连续树。图画很容易支持这个判断：把枝画得越来越细，三条子枝看起来仍然在那里。

但是，缩放极限比较的不是纸面上的分叉符号。它比较距离、根和质量。三个孩子可以各自存在，却没有三个方向都在所选尺度上保留可辨认的长度。要判断什么会留下来，必须先给出树的概率律，而不能从孩子数替整棵随机树作决定。

## 58.1 三叉的离散树，二叉的连续极限

<a id="mf-counter"></a>

取一个极其具体的繁殖规则：个体以概率2/3没有孩子，以概率1/3恰有三个孩子。平均后代数为1，方差为2。它不是一棵无限规则三叉树；它是一棵会灭绝的临界GW树。现在只保留恰有n个节点的实现。

若内部节点数为I，边数既等于3I又等于n−1，所以n=3I+1。每个可行n下，所有完整三叉平面树的概率相同。第55章的定理现在适用：距离乘以\(\sqrt2/(2\sqrt n)\)，节点质量归一化后，得到标准Brownian CRT。后者的每个非根分枝点只有两个子方向。

这不是“图画太粗糙”的解释，而是已有空间极限定理的直接推论。固定有限的繁殖度数不决定连续树的分叉类型。值得研究的对象因此从一个整数变成一组条件：我们怎样选树，怎样条件化，怎样缩放，又怎样在树上选取典型样本？

## 58.2 把所有固定k放进同一个严格反例

<a id="mf-gw"></a>

\[ P(\xi=0)=1-\frac1k,\quad P(\xi=k)=\frac1k,\quad E\xi=1,\quad \sigma^2=k-1,\qquad k\ge2. \]

给定节点总数n，沿\(n=1+kI\to\infty\)，有

\[ \left(T_n,\frac{\sqrt{k-1}}{2\sqrt n}d,\rho,\frac1n\sum_{v\in T_n}\delta_v\right)
\Rightarrow(\mathcal T_e,d_e,\rho_e,\mu_e). \]

这里k固定，不能把k随n增长的三角阵列也纳入结论。每个条件事件有正概率，跨度k已体现在可行规模上；均匀节点质量也不是均匀选内部节点。完整验证见[T-KARY-UNIVERSALITY](../foundations/t-kary-universality.md)第1–2节，实际输入是第53–55章已经建立、仍待独立终审的有限方差条件树定理。

同样的连续极限不是说有限模型完全相同。方差进入尺度，允许的规模不同，有限树的组合概率也不同。普遍性说的是：在这些假设与这些尺度下，某些差异不再出现在极限的距离—质量规律中。

## 58.3 一个分枝点究竟有几条路

<a id="mf-degree"></a>

对实树中的点b，最不依赖画法的定义，是删除b后连通分支的数目，记为\(\deg(b)\)。若b不是根，其中一个方向通向根，剩余方向才是朝向后代的方向。于是Brownian CRT的“二叉分枝”对应无向度数3。

有限抽样又会漏掉没有被样本选中的方向。一个无穷度数分枝点，在三叶约化树里至多只显示三个方向。不能从一张有限约化树的三叉图，反推原树只有三个连通分支。

反过来，若质量满支撑，一个无限iid样本稠密。假如整树某点有四个开方向，各方向都能选到一个样本，某棵有限约化树就必然显示四个方向。第54章所有有限约化树的二叉律因此排除了这种点。这个可数稠密论证把有限抽样结论升级为全树性质，补上了仅看图片所缺的一步。

## 58.4 分叉的条数并没有给出质量比例

<a id="mf-mass"></a>

同一个三方向接点可以把质量分成接近\((1/3,1/3,1/3)\)，也可以分成接近\((0.98,0.01,0.01)\)。距离结构没有自动给出哪一种更常见；还必须说明接点怎样被选中。

在标准Brownian CRT上，取根和两个独立质量样本，它们连接的唯一接点b给出一个明确抽样规则。三个方向按根及两个样本标号，其质量满足

\[ (M_0,M_1,M_2)\sim\operatorname{Dirichlet}(1/2,1/2,1/2). \]

证明不从一份未知的“分枝点均匀分布”开始。有限约化树的新增样本在全部边上均匀插入，一个方向若有a片标签叶，就有2a−1条边；添一片叶会增加两条边。三个方向因此形成初值1、强化2的Pólya urn。第44章的预测积分给Dirichlet极限；实际树上的条件强律又把它识别为方向质量。专题第4节保留完整证明。

这个例子说明质量分裂可以被严格识别，但识别结果依赖抽样规则。名字同样叫“分枝点质量”，并不足以比较两篇论文中的概率公式。

## 58.5 另一种k叉树不是另一个名字

<a id="mf-growth"></a>

现在把“先独立繁殖，再固定总规模”换成逐步生长。从一条根边开始，每一步均匀选一条边，插入顶点，并从这里长出k−1条新边。插入后新顶点有k个子方向；n步后有kn+1条边、\((k-1)n+1\)片叶。

这是Haas–Stephenson公开研究的k叉增长模型。它与前面的条件GW树拥有相同的内部孩子数，却没有因此拥有同一概率律。增长会反复细分旧路径；单位边长也会随细分改变旧端点距离，不能把有限树直接当作嵌套等距子树。

[2015年原文](https://archive.numdam.org/articles/10.1214/14-AIHP622/)定理1.1建立\(n^{-1/k}\)尺度的k叉碎裂树极限，与有限方差GW的平方根尺度不同。这项整树极限定理在本章作为有明确来源的外部结果介绍；本书尚未补齐它的全部空间紧性证明。以下先证明一个不需要借用整树极限、却能清楚区分模型的质量结论。

## 58.6 跟踪一个持久节点：强化在哪里出现

<a id="mf-urn"></a>

固定第一次插入的节点v。它有k+1个无向方向，包括指向根的那个方向。初始每个方向一条边；每次在一个方向里操作，该方向边数增加k。若已经选过该方向\(N_i\)次，下次仍选它的条件概率就是

\[ \frac{1+kN_i}{\sum_{j=0}^k(1+kN_j)}. \]

预测规则已经把全树中的一个统计量变成可解的urn。将权重除以k，得到初参数1/k的Dirichlet混合。因此各方向的渐近叶比例为

\[ (D_0,\ldots,D_k)\sim\operatorname{Dirichlet}(\underbrace{1/k,\ldots,1/k}_{k+1}). \]

根方向初始没有叶，其余方向各一片；分别计算叶数后再除以总叶数，仍得到这组极限。[T-PUBLIC-KARY-GROWTH](../foundations/t-public-kary-growth.md)给出方向词的精确Gamma概率、条件独立核和强律证明。

k=2时有三个参数1/2，与前面的Brownian三分质量相接；k≥3时这只是指定离散持久点的经验质量极限。它既不是任意连续k叉树的通用公式，也没有单独证明该持久点在某个GHP极限中如何对应。

## 58.7 什么时候原来的平方根尺度不够

<a id="mf-tail"></a>

固定k的GW反例具有有界后代数，所以无论k看起来多大，它仍有有限方差。要离开Brownian普适类，改变“允许三个还是四个孩子”未必触及关键条件；改变尾部才可能触及。

第14章区分了有限方差求和与稳定吸引域。对谱系来说，重尾意味着少数个体可以产生极大的家族。人口总量仍可缩放为连续质量，但仅有一个新的一维极限定律不够：我们还必须说明这些质量怎样拥有共同祖先。

先把人口问题与谱系问题分开解决。若初始质量x和y的家族独立繁殖，合在一起的未来应与初始质量x+y的过程同律。这个分枝要求使Laplace变换具有指数形式；但形式正确并不意味着它已经是一份概率核。

## 58.8 从繁殖规则建立连续状态人口

<a id="mf-csbp"></a>

\[ \psi(q)=a q+\beta q^2+\int_0^\infty(e^{-qr}-1+qr)\pi(dr),\qquad
\int(r^2\wedge r)\pi(dr)<\infty,\quad a,\beta\ge0. \]

本章选临界或次临界、有限均值机制，非线性且满足\(\int_1^\infty dq/\psi(q)<\infty\)。最后这个条件先用于有限高度灭绝，随后还要用于谱系紧性。记\(v_\lambda=\psi^{-1}(\lambda)\)，\(c_\lambda=\psi'(v_\lambda)\)。下式不是随意的母函数：它让离散人口的Laplace演化精确对齐同一个ODE。

\[ g_\lambda(s)=s+\frac{\psi(v_\lambda(1-s))}{v_\lambda c_\lambda},\qquad
\partial_tu_t(q)=-\psi(u_t(q)),\quad u_0(q)=q. \]

展开后常数项正、一次项为零，其余系数由非负Lévy积分给出，总和1。每个个体以速率cλ结束寿命并繁殖。以\(\lfloor x v_\lambda\rfloor\)个祖先出发，人口除以vλ后在单时刻的Laplace变换趋于

\[ E_xe^{-qZ_t}=\exp[-x u_t(q)]. \]

专题[T-CSBP-SEMIGROUPS](../foundations/t-csbp-semigroups.md)实际证明概率核存在、可测、满足Chapman–Kolmogorov及分枝性质，再验证\(C_0\)强连续性，用第28章实现càdlàg过程。没有从一条形式ODE直接宣布随机路径存在。

## 58.9 灭绝的高度和稳定人口的尺度

<a id="mf-extinction"></a>

\[ P_x(Z_t=0)=e^{-x v(t)},\qquad
\int_{v(t)}^\infty\frac{dq}{\psi(q)}=t. \]

令Laplace参数趋无穷，就得到有限时刻恰为零的概率。Grey积分有限保证每个正t的v(t)有限。这与只知道均值下降不同：\(\psi(q)=aq\)给确定性衰减\(Z_t=xe^{-at}\)，永远不在有限时间到零。

稳定机制\(\psi(q)=q^\alpha,1<\alpha\le2\)则给

\[ u_t(q)=\left(q^{1-\alpha}+(\alpha-1)t\right)^{-1/(\alpha-1)},\quad
v(t)=((\alpha-1)t)^{-1/(\alpha-1)}. \]

人口的尺度关系可直接从这里核对。然而一个人口过程仍没有记录哪两份质量分享祖先。要得到树，我们需要在不同采样密度下保持一致的全部约化谱系。

## 58.10 为什么让叶子接受染色

<a id="mf-colouring"></a>

把刚才的指数寿命当作真实边长。先取Poisson\((b v_\lambda)\)个祖先，各自生成有限GW实树，连接在共同根。若每片叶独立以概率μ/λ保留，只留下保留叶与根之间的路径，理想情形是：这棵较小的森林恰好具有参数μ的同一种律。

这比要求人口平均一致强得多。一个粗样本看见的每条祖先路径，都必须与细样本中的距离相容。被删去的旁枝可以消失，被压缩的一孩链的长度却必须相加，不能重新抽一个任意长度。

上述\(g_\lambda,c_\lambda\)恰好满足这个要求。一个家族至少保留一片叶的概率是\(v_\mu/v_\lambda\)；压缩链后寿命速率从cλ变为cμ，后代母函数从gλ变为gμ。专题[T-LEVY-HEIGHT](../foundations/t-levy-height.md)第1–2节逐项计算条件核、几何和指数寿命以及Poisson祖先稀释。这是Duquesne–Winkel公开构造的核心一致性，不是为最后一章新提出的模型。

## 58.11 有限谱系怎样长成真正的紧实树

<a id="mf-compact"></a>

相容染色在共同概率空间上产生嵌套的有限实树森林。取并、再完备化，仍需防止出现无限多条固定长度的枝。仅有高度有界不够：无穷星形可以高度1而不紧。

固定ε，把高度切成ε格点，数每层仍有至少ε长后裔的点。它们的期望至多为

\[ b e^{-a j\varepsilon}v(\varepsilon)\quad\text{at level }j\varepsilon. \]

有限上界与嵌套单调性保证每层极限只有有限个这样的点。森林极限高度有限几乎必然，所以有限多层的这些点构成一个有限2ε网。由此得到全有界性，再完备化得到紧实树。不同ε的共同零集、连接弧的保留和Hausdorff收敛都在专题第3节证明。

这里的紧性来自灭绝高度和长分支的共同控制，不是从有限树各自紧直接推出。

## 58.12 终端叶的极限质量不是骨架长度

<a id="mf-leafmass"></a>

令ξλ在每片终端叶放一个单位。采样变密时叶数增加；正确的质量归一化为ξλ/λ，而不是除以某个预先知道的确定叶数。其总质量的Laplace变换满足

\[ E\exp[-q\,\xi_\lambda(\mathcal F)/\lambda]
\longrightarrow \exp[-b\,\psi^{-1}(q)]. \]

这个极限只证明总量不会逃向无穷，还没有给出质量在哪里。专题把标记强度分成单位箱，利用未来箱的交换性，把点投影到每棵粗树上，对可数连续测试作条件强律，再用粗树到整树的一致距离误差拼接为一份有限随机测度m。临界情况下总量期望可能无穷，所以这一步没有误用L¹有界鞅。

再次改变取样密度时，给定极限环境，保留叶形成强度tm的Poisson样本。这个条件核反过来识别m为无原子、集中于叶而满支撑的质量。骨架上每条弧的长度可以正，m对那条弧却为零；距离和质量保留的是不同结构。

## 58.13 稳定机制为何产生无穷叉

<a id="mf-stable"></a>

对\(\psi(q)=q^\alpha\)，后代母函数化为\(s+(1-s)^\alpha/\alpha\)。α=2时只有0和2个孩子。1<α<2时，则允许所有大于等于2的后代数。单看这个无界支持，仍不能宣布极限有无穷度数；每棵有限树的节点度数都有限。

真正的判断来自同一个分枝点在采样细化时的行为。若粗树上已有d≥2个保留子方向，细树中实际子方向数D的条件母函数为

\[ E[z^{D-d}\mid d]
=\left(\frac{q}{1-(1-q)z}\right)^{d-\alpha},
\qquad q=(\mu/\lambda)^{1/\alpha},\quad1<\alpha<2. \]

固定z<1，λ→∞时右端趋零，所以D趋无穷；嵌套单调性把依概率结论升级为几乎必然。稠密有限样本又保证整树每个非根分枝点在某层已经出现。于是稳定机制α<2的非根分枝点全部为可数无穷度数，而α=2仍二叉。专题第6节给出阶乘倾斜的条件分布和共同零集论证。

这是真正不同的分叉机制，却不是“α对应一个固定k”。连续无穷叉与离散固定k叉不属于同一分类标签。

## 58.14 稳定树的尺度还包含质量

<a id="mf-scaling"></a>

稳定森林的有限约化核同时给出长度和质量的尺度关系：长度乘r，质量应乘\(r^{\alpha/(\alpha-1)}\)，祖先参数b相应变为\(b r^{1/(\alpha-1)}\)。通过改变标记强度、核对寿命率与Poisson祖先数，专题第7节证明整个紧森林及质量同律，而不只比较总高度。

这里构造的森林总质量随机，Laplace为\(e^{-b q^{1/\alpha}}\)。它不能直接被叫作总质量1的单棵稳定CRT。单游程及按持续时间析取的理论还有独立证明责任；这一区别对于与标准e的尺度比较尤其重要。

## 58.15 Lévy跳跃并不就是树的高度

<a id="mf-height"></a>

第52章已提醒我们，Łukasiewicz路径和高度过程不是同一个编码。前者记录待处理的后代，后者记录祖先链的长度。这个区别进入连续极限后仍然存在。

如果直接把谱正Lévy路径X的跳跃画成树的高度，就会把一大批待分配后代误当成一次垂直祖先距离。经典Lévy高度理论转而考察：在时刻t回看，哪些过去时刻仍然位于当前个体的祖先线上？这对应区间后向下确界，而不是Xₜ本身。

\[ \frac1\varepsilon\int_0^t
\mathbf1_{\{X_s-\inf_{s\le r\le t}X_r<\varepsilon\}}\,ds. \]

在准确假设和局部时间规范下，这个近似产生经典高度H；Grey条件控制其连续版本。[Duquesne–Le Gall的2002年专著](https://arxiv.org/pdf/math/0509558)第1.2–1.4节给出完整经典理论。它不是本章前面人口ODE的推论，也不能把第37章连续半鞅Tanaka公式原样搬来。

必须如实保留本书的边界：本轮已经完整重建约化Lévy森林及其质量、稳定机制的分叉和尺度；从X的反向记录局部时间到同一森林的完整识别、Ray–Knight及重尾条件树函数极限仍未全部写成。专题最后一节把所缺步骤逐项列出。这些是尚未闭合的证明，不仅是已证结果等待专家签字。

## 58.16 另一种无穷叉来自反复接到同一个地方

<a id="mf-icrt"></a>

无穷度数也不唯一决定稳定树。还可以让某些接点以正概率被反复选中。ICRT的一种公开构造把分散接枝和固定枢纽分开记录。

取非负参数\(\theta_0^2+\sum_{i\ge1}\theta_i^2=1\)，正指标可按非增次序排列。标准ICRT参数域还要求\(\theta_0>0\)或\(\sum_{i\ge1}\theta_i=\infty\)。分散部分在\(0<y<x\)上放强度\(\theta_0^2 dx\,dy\)的Poisson点：x为切点，y为接点。每个θᵢ>0又产生速率θᵢ的独立Poisson时钟；第一次出现只指定枢纽，第二次及以后每次都切出新枝、接回同一枢纽。

[Aldous–Pitman，PTRF118(2000),455–482](https://www.stat.berkeley.edu/~pitman/525.pdf)第2节给出这一模型。不能把“每次选同一个枢纽”的机制与稳定树“同一粗分枝在细化中显示无穷方向”的机制直接等同；两者的参数、有限约化律和质量理论都需要各自建立。

## 58.17 无限多个时钟为什么仍可逐枝操作

<a id="mf-localfinite"></a>

下面的时钟与局部有限性计算只需平方可和，因而也能在比标准ICRT更宽的参数域中操作；这不取消上一节的标准参数条件。平方和有限在这里有精确作用。第i个时钟在[0,R]产生的切点数，是总出现数减去第一次出现，其期望不超过\(\theta_i^2R^2/2\)。全部切点在每个有限窗口内因此有限，能够依次排列。接点总在对应切点以前，有限接枝不会要求连接到一个尚不存在的位置。

\[ P(\eta_1>t)=e^{-\theta_0^2t^2/2}\prod_{i\ge1}(1+\theta_i t)e^{-\theta_i t}. \]

第一次切点公式来自各时钟至多出现一次；无限乘积的对数由θ的平方和控制。[T-ICRT-POISSON](../foundations/t-icrt-poisson.md)完整证明局部有限性、有限接枝、完备实树和枢纽无穷度数。

当只有θ₀=1时，切点强度为rdr，对应第57章常见的2e规范。标准e的边长小一半，对应4rdr。相同的“Brownian CRT”名称不能消除这个因子2。

## 58.18 合法无限接枝仍然可能不紧

<a id="mf-star"></a>

现在故意放宽标准参数域，取θ₁=1而其余为零；它同时违反θ₀>0和正指标之和发散的条件，不属于标准ICRT族。按同一接枝算法，每条新枝都接到同一个枢纽，枝长为独立指数间隔。几乎必然无穷多条长度超过1。距枢纽1处的点彼此距离2，无法用有限个小球覆盖。

这给出放宽参数后的合法完备接枝实树，却不是紧树；它不是标准ICRT族内部的非紧反例。公开ICRT理论的参数域和质量构造因此不能删掉；即便已构造计数时钟，也没有自动得到一份适合紧GHP空间的随机概率树。专题清楚区分这里实际完成的接枝与一般ICRT的质量和紧性分类。

## 58.19 怎样比较这些模型而不抹去差别

<a id="mf-compare"></a>

现在可以准确对照四条路线。固定有限k的条件GW树，依靠有限方差和总规模条件，属于标准Brownian极限。公开选边k叉增长，靠不同的Markov增长律，可出现\(n^{1/k}\)高度尺度与k叉碎裂极限。稳定Lévy机制在更细谱系中揭示无穷分枝，参数α描述尾部和尺度而不是孩子数。ICRT则把分散噪声和持续枢纽分开编码。

有些树可以共享某个统计量，甚至共享“无穷度数”这个性质，却不共享同一律。也有些离散孩子数完全不同的树，共享同一Brownian空间极限。要声称两个模型相同，必须比较具有决定能力的有限约化分布及一致性，并验证它们确实重建同一种带质量无限对象。一个Dirichlet边缘公式没有这份决定能力。

## 58.20 哪些条件改变后，原结论真正停止适用

<a id="mf-boundaries"></a>

让k随规模变化，已超出固定后代律定理；改变总规模条件为高度或叶数条件，也必须重建条件路径估计。放弃有限方差，并不会自动满足某个稳定吸引域。只保留质量比例、不控制细枝长度，可能得到GP信息而没有GH紧性。只保留有限约化树的概率一致性，也不自动给出紧的完备化。

这些限制没有否定推广。它们给出可以实际研究的任务：选定新模型后，需要验证哪一份路径极限，哪一个长度控制，哪一种质量构造，以及哪一类有限读数足以识别全树。已有经典答案与本书尚未补完的证明必须分别记录；未在这里证明，不意味着它是数学界的开放问题。

## 58.22 极限保留的不是分叉符号

<a id="mf-understanding"></a>

开头的三叉树没有消失在一句“尺度不同”里。我们已经写出了它的概率律、可行规模、方差和距离归一化，并严格得到二叉Brownian极限；又从另一套公开增长规则中算出了不同的强化与质量比例。随后，相容有限谱系的构造说明连续分枝必须经过距离、紧性和质量三个检验，不能只画出一条跳跃曲线。

微观分枝和连续几何之间没有逐字翻译。某些差别在极限尺度下消失，另一些通过尾部、持久枢纽或分裂核留下来。能够作出这些判断，依靠的不是哪个模型的名字更像一棵树，而是哪一组有限概率、路径估计和一致性能够共同建立一个真实的随机几何对象。

当一个新生长规则被提出时，第一步因而不该是给它取一个新的CRT名字。应先计算它保存的约化律，检验它允许的采样，寻找细枝的长度控制，并证明质量从何而来。只有这些工作完成，新的连续形状才成为一个可以比较、可以识别、也可以继续提出精确问题的数学对象。
