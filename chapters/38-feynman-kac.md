# 第三十八章：随机运动与偏微分方程的再次相遇——Feynman–Kac与势论

一颗粒子在区间中运动。每多走一秒，就产生一秒的保管费用；走到边界，账户停止。另一个人不看任何一条轨迹，只想知道：从位置x开始，平均要付多少？这份平均值是一个确定函数。路径的无规则性没有消失，却可能被它满足的方程重新组织。

## 38.1 先算一份会停止的账

<a id="fk-discovery"></a>

取标准Brownian B，在I=(0,1)首次退出时τ停止。第36章Green核已经让我们计算平均占用，这里只取每个位置每秒收费1。若u(x)=Eₓτ，先从已知核积分，得到u(x)=x(1−x)。它的二阶导数恰好等于−2。这个计算值得保留的不是一个多项式，而是：随机退出时间的平均值竟能由一个局部微分条件和两个边界值确定。

\[ u(x)=E_x\tau=x(1-x),\qquad -\frac12u^{\prime\prime}=1,\qquad u(0)=u(1)=0. \]

如果费用随位置改变，或者走到左右边界得到不同结算，这个巧合还能成立吗？我们已有足够的随机路径和积分工具，可以检查它成立的真正原因，不必猜一个新微分方程。

## 38.2 短时间后的剩余账单

<a id="fk-local-equation"></a>

让每秒收益为f(Xₛ)，终端收到g(Xτ)。无折扣时，走过一小段S以前的收益，加上\(X_S\)处未来的平均收益，必须等于原来的平均。这里S可取局部退出时刻，避免离开状态区间；强Markov性真正负责将“从这里重新算”变成数学。

\[ u(x)=E_x\left[\int_0^S f(X_s)ds+u(X_S)\right],\qquad Lu=-f\quad\hbox{if }u\hbox{ has the required regularity}. \]

若u已经足够光滑，Itô把最后一项的短时平均变化读成Lu，立即解释了负号：尚未收取的总收益，随着眼前收益被支付而减少。但这行推导尚未证明u光滑，也尚未证明边界值能够达到。把这两件事保留下来，才不会把漂亮的形式计算误当成存在定理。

## 38.3 沿途付出的代价怎样改变权重

<a id="fk-cost"></a>

若每到一个位置都有即时失效速率q(x)≥0，一秒以后是否仍在结算，要由整段路径决定。取独立均值1指数阈值E，累计q直到超过E才失效；给定路径，其存活概率为exp(−Qₜ)。无记忆指数在21章已建立，这次的新对象是依赖整条路径的累计危险，而不是重新讲固定Poisson时钟。

\[ Q_t=\int_0^tq(X_s)ds,\qquad P(E>Q_t\mid X)=e^{-Q_t},\qquad Q_{s+t}=Q_s+Q_t\circ\theta_s. \]

同一指数也可作折扣，而不作真实死亡解释。若q为有下界的带符号函数，在有限时域可提取确定指数再化为非负势；无穷时域则必须另查可积性。我们不会把有限时域的界自动搬到无限未来。

## 38.4 一般公式先从重新结算长出来

<a id="fk-dynamic"></a>

在固定期限t内，设到期支付h，沿途收益f。短时间S过后，已经发生的成本固定，剩余账户乘以同一个存活因子。这给出完整的动态关系；从中寻找能被微分读出的函数，比先背下一条公式更有信息。

\[ u(t,x)=E_x\left[e^{-Q_t}h(X_t)+\int_0^te^{-Q_s}f(X_s)ds\right],\qquad u(t,x)=E_x\left[\int_0^S e^{-Q_s}f(X_s)ds+e^{-Q_S}u(t-S,X_S)\right]. \]

对候选光滑u，乘积公式给时间项−∂ₜu、运动项Lu、成本项−qu以及收益f。使账户在重新结算时没有额外漂移，恰要求∂ₜu=Lu−qu+f。Feynman–Kac联系的是这份结算结构，不是“随机性平均以后总会得到任意一条PDE”。[推导与条件期望交换](../foundations/t-feynman-kac.md#fk-proof-dynamic)逐步给出。

## 38.5 验证一个解，与证明有解不同

<a id="fk-verification"></a>

准确的验证定理是：对非爆炸、时间齐次且局部Lipschitz系数的SDE，若有界v∈\(C^{1,2}\)满足上述方程及初值h，且q≥0、f,h有界，则v等于上一节路径式。证明是在大球和积分能量处停止，对\(e^{-Q_s}\)v(t−s,Xₛ)用Itô，取期望再移去停止。它同时给这类经典解的唯一性。

第35章已提醒，写出规则不等于对象存在。这里同样如此：验证定理不能从“若v存在”跳成“期望表达式已经可微”。接下来必须真的建立一个可微解。

## 38.6 Gaussian核不只给表示，也给正则性

<a id="fk-classical-existence"></a>

对Rᵈ上的Brownian，取h,q,f及到二阶导数有界一致连续，q≥0。先求下面的温和方程，而不把它叫作经典解。Gaussian卷积Pₜ保持二阶导数的有界一致连续性；反复代入，连续两次误差被(Ct)ⁿ/n!控制，因此在每个有限时间区间收敛。

\[ u(t)=P_th+\int_0^tP_{t-s}(f-qu(s))ds,\qquad \partial_tu=\tfrac12\Delta u-qu+f. \]

同一Banach范数控制二阶导数，热半群的强连续性又给时间导数，所以这次确实得到\(C^{1,2}\)解。然后验证定理才识别它与随机式。[完整收敛及求导证明](../foundations/t-feynman-kac.md#fk-proof-parabolic)保留在专题。若h只是1_{x>0}，t>0的解虽平滑，t↓0在x=0却趋1/2而非h(0)=0；一个边界或初值的单点指定，不会自动服从平滑后的读数。

## 38.7 边界的随机结算，为什么调和

<a id="fk-dirichlet"></a>

把期限改成离开有界域D的时刻。没有沿途收益也没有成本时，h(x)=Eₓg(BτD)。任何内部小球的退出后都可重新结算，于是h等于球面上的平均。平均性质不是调和性的比喻：把所有半径的均值叠加成光滑径向卷积，得到h本身光滑；再对小半径展开，严格推出Δh=0。

对带有界局部Hölder源f、成本q≥0的情形，动态关系在小球中化为u=H_Vu+G_V(f−qu)。Green核的一阶奇点可积，先给连续及局部Lipschitz；随后二阶核的抵消与Hölder误差才给C²。最终−½Δu+qu=f。[专题3–4](../foundations/t-feynman-kac.md#fk-proof-dirichlet)不把这两次正则性步骤藏在一个“标准PDE结果”之中。

## 38.8 正确的内部方程，也可能到不了边界值

<a id="fk-irregular-boundary"></a>

路径式自动知道从内部真正能看见哪些边界。若z有严格外切球屏障，停止超鞅控制先逃离z附近的概率，连续边界数据便能被实现。但在二维穿孔单位圆盘，Brownian从内部以概率1避开中心点0，最后从外圆退出。给中心边界值1、外圆值0，得到的期望仍处处0。

\[ P_r(T_\varepsilon<T_1)=\frac{\log(1/r)}{\log(1/\varepsilon)}\longrightarrow0\quad(d=2),\qquad 0<\varepsilon<r<1. \]

这组边界数据本身连续，因为0是边界中的孤点。失败的是该点对内部路径的正则性，不是数据写得不够平滑。Dirichlet问题因此同时包含内部微分关系和边界可达的限制，后者不能从方程符号中删除。

## 38.9 为什么无穷远仍须单独结算

<a id="fk-infinity"></a>

在半直线，u(x)=x调和、u(0)=0；Brownian最终却到达0，终端值期望为0。两者不矛盾，因为u不有界，停止到大水平n的族不一致可积。极小的远端概率携带极大的函数值，移去n时不能只看几乎必然终点。这次旧有UI思想承担的是无界Dirichlet表示的合法性，而不是再讲一次尖峰序列。

## 38.10 尚未支出的收益形成过分函数

<a id="potential-excessive"></a>

从一个位置出发的未来总收益U，到了t以后只剩下一部分。若收费非负，U≥PₜU；有折扣α时则U≥\(e^{-\alpha t}\)PₜU。我们因而需要比“局部平均不变”更宽的对象。称非负u为α-过分，如果这个不等式对所有t成立，并且t↓0时右边回到u。极限条件挑选与运动相容的版本。

\[ U(x)=E_x\int_0^\zeta e^{-\alpha s}dA_s,\qquad U(x)-e^{-\alpha t}P_tU(x)=E_x\int_0^{t\wedge\zeta}e^{-\alpha s}dA_s\ge0. \]

这个定义直接来自收益的时间分割，不是把调和函数换个名称。对连续局部有界u，\(e^{-\alpha t}\)u(Xₜ)是局部化后的超鞅；调和对应尚未消耗的平均完全不变，势对应已经在路径上发生的累积。[完整条件及抽样](../foundations/t-potential.md#potential-proof-excessive)说明了这里没有使用一般Borel过分函数的未证精细版本定理。

## 38.11 Green核把沿途时间搬回空间

<a id="potential-green"></a>

回到有界区间，被杀Brownian的Green核相对于dx为下式。Gf是普通时间收益的期望；把f(y)dy替换为测度μ，37章的局部时又使Gμ成为真正的随机累积，而不只是一个形式积分。

\[ G_I(x,y)=2\frac{(x\wedge y-a)(b-(x\vee y))}{b-a},\qquad G_I\mu(x)=E_x\int_I L_\tau^y\mu(dy). \]

第36章用Green回答平均停留多久；这里新增的认识是，空间上的源可以由核叠加，且不同的收费测度给出不同的势。固定同一个运动，改变源并不是改变生成元；若改变速度测度，才是在改变运动本身。

## 38.12 一份过分函数中，哪些是源，哪些是边界

<a id="potential-riesz"></a>

这里固定被杀于区间端点的Brownian运动，并取α=0：连续有限非负0-过分函数必凹：停止在任意小区间的两端，u不小于端点值的线性插值。凹函数的二阶导数不必是函数，却有负Stieltjes测度。这份曲率就是内部源。端点极限则留下线性调和函数h。

\[ u=h+G_I\mu,\qquad \mu=-\tfrac12u^{\prime\prime}\ge0,\qquad h(x)=\frac{b-x}{b-a}u(a+)+\frac{x-a}{b-a}u(b-). \]

这是本章完整证明的0-过分情形一维Riesz分解；α>0时要保留折扣项，不自动具有这里的凹性与线性调和余项。先在内部紧区间用二阶测度积分得到身份，再让区间增加；Green核单调极限控制可能在边界附近无限的源质量。二阶曲率唯一决定μ，边界极限唯一决定h；h还是u最大的非负调和下界。[全部步骤](../foundations/t-potential.md#potential-proof-riesz)没有把一般Hunt过程的分解偷换成这个一维证明。

## 38.13 长度为零，仍然可能承受非零势

<a id="potential-capacity"></a>

一个点的长度为0，但一维Brownian确能命中它并在那里积累局部时。只用Lebesgue测度决定哪些集合重要，已不足够。我们改问：把某集合上的势抬到至少1，最少需要多少能量？在I上取零端点绝对连续v，以½∫|v′|²作能量，就得到相对容量。

\[ \operatorname{cap}_I(K)=\inf_{v\in H_0^1(I),\,v\ge1\ \text{on }K}\frac12\int_I|v^\prime|^2dx,\qquad \operatorname{cap}_I(\{c\})=\frac{b-a}{2(c-a)(b-c)}>0. \]

点c的最优形状是两边线性搭成的帐篷，Cauchy–Schwarz直接证明其最小能量。一般非空紧K的平衡势则从0升到minK上的1，在minK与maxK间保持1，再下降；它恰等于先命中K的概率，平衡测度是两端的曲率原子，总质量等于容量。这里的能量、命中与源强度不是三种类比，而是[同一个明确计算](../foundations/t-potential.md#potential-proof-capacity)。

## 38.14 扫掠不是删除源，而是保留它在某处的作用

<a id="potential-sweeping"></a>

如果只在K上观察，一份散布在区间内部的源能否移到K而不改变这些观测？让每个源点y按运动先命中K的分布重新落点；未命中就退出的那部分质量不留下。得到的μᴷ称扫掠测度。

\[ \mu^K(C)=\int P_y(B_{T_K}\in C,T_K<\tau)\mu(dy),\qquad G_I\mu^K(x)=E_x[G_I\mu(B_{T_K});T_K<\tau]. \]

强Markov把Green占用分成命中前后，对称性再把x与y交换，严格给出第二式。扫掠势不超过原势、在K与原势一致、在K外调和。一个局部观察所保留的，不是原始源的所有位置，而是它通过运动传到观察集合上的作用。[证明](../foundations/t-potential.md#potential-proof-balayage)保留了核对称性和非负Tonelli的使用位置。

## 38.15 给一个点收费，方程怎样知道

<a id="fk-singular"></a>

令I内点c每积累一单位局部时就收取γ，Aₜ=γLₜᶜ。成本不会消失：Brownian在c的普通时间虽为0，A仍可增加。定义到退出前的折扣收益u。若把这笔费用强写成普通q(x)dt并令q在c之外为0，几乎处处信息就会错误地把它抹掉。

\[ -\tfrac12u^{\prime\prime}+u\mu=f\,dx,\quad \mu=\gamma\delta_c,\qquad u^\prime(c+)-u^\prime(c-)=2\gamma u(c). \]

点代价被保留为导数的跳跃。此时u通常连续却不是跨越c的C²函数，不能要求它满足处处经典的方程。源的数学类别改变，解的类别也必须随之改变。

## 38.16 弱解不是把证明放松

<a id="fk-weak"></a>

对有限正Radonμ及\(f\in L^2(I)\)，把方程乘零端点测试φ并分部积分。零边界数据时，未知u属于H₀¹(I)；非零端点数据g时，取线性提升h满足h(a)=g(a)、h(b)=g(b)，求u=h+v、v∈H₀¹(I)。此时B(v,φ)=∫fφdx−B(h,φ)，其中B是下面的能量形式；不能沿用同一源项的零边界解再直接加h，μ项也作用于提升。能量形式½∫u′φ′+∫uφdμ有明确意义，因为一维H¹函数连续。它控制导数范数，Hilbert表示定理便实际构造唯一弱解，再从分布二阶导数的测度性得到广义Itô。

\[ \frac12\int u^\prime\varphi^\prime dx+\int u\varphi\,d\mu=\int f\varphi\,dx,\qquad u(x)=E_x\left[e^{-A_\tau}g(B_\tau)+\int_0^\tau e^{-A_s}f(B_s)ds\right],\quad A_t=\int L_{t\wedge\tau}^y\mu(dy). \]

[完整证明](../foundations/t-feynman-kac.md#fk-proof-singular)先构造弱解，后以Tanaka积分证明它等于路径式。弱在测试方式，不在论证质量。经典解、分布解、能量弱解与概率表示的联系，都必须由相应的正则性和唯一性论证建立。

## 38.17 局部平均能够恢复什么，又会遗漏什么

<a id="potential-differentiation"></a>

抽象RN密度的存在还不等于能够从小球平均恢复它。这里必须补上局部恢复的论证，因为奇异源不能再被含混地写成普通密度。五倍球覆盖给最大平均弱型估计，连续函数的局部平均显然收敛，再用L¹逼近及弱型控制误差，才得到Lebesgue微分。

\[ \nu=f\,dx+\nu_s\quad\Longrightarrow\quad\frac{\nu(B(x,r))}{|B(x,r)|}\longrightarrow f(x)\quad\hbox{for Lebesgue-a.e. }x. \]

奇异ν_s的密度几乎处处为0，却可能仍有全部非零质量。δ_c就是最小例子。这也解释了前面为什么必须保留测度方程。[覆盖、函数与测度三个步骤](../foundations/t-differentiation.md)实际证明该结论；它不声称在每一点收敛，也不以RN定理的名称代替微分证明。

## 38.18 怎样识别不同路径上的同一种累积

<a id="revuz-additive"></a>

时间收益和局部时间有共同的加性：先走s再走t，两段账单相加等于总账单。但仅有每条路径递增，还不够。例如Aₜ=t²没有重新开始后只看未来路径的加性；把当前总时长偷偷带入第二段，就改变了状态信息。PCAF要求连续、非负递增、适应、从0开始及真正的移位加性。

\[ A_{s+t}(\omega)=A_s(\omega)+A_t(\theta_s\omega). \]

第37章从μ出发构造了Brownian的A。现在反过来问：给定一份这样的随机累积，能否用一份空间测度识别它？如果只记录EₓAₜ，一个固定x的观察可能看不见全空间。我们要同时平均所有起点，并记录收费发生在哪里。

## 38.19 Revuz读数需要一份参考测度

<a id="revuz-reference"></a>

取参考测度m，用f记录收费位置、g记录初始权重。小时间内的每单位时间平均，才有希望读出一种空间收费强度。m并非无关紧要的书写习惯：同一个A若改用cm起点平均，读数也乘c。

\[ \lim_{t\downarrow0}\frac1t\int g(x)E_x\int_0^t f(X_s)dA_s\,m(dx)=\int f(y)g(y)\mu_A(dy). \]

对一维Brownian，参考dx时Lᵃ对应δₐ；若参考速度2dx，便对应2δₐ。37章的时钟半因子与这里的参考变化都必须保留。小时间身份是一个识别条件；只写出它，还没有证明每份允许的测度都有PCAF，也没有证明唯一性。

## 38.20 对称性把起点权重送到收费位置

<a id="revuz-correspondence"></a>

若过程对m对称，完整身份比小时间极限更有用。先看A=∫q(X)ds，交换起点积分与转移核，g被送成Pₛg；这提示同样的结构应对奇异测度成立。完整身份将一份路径累积与一个确定性核作用精确联系。

\[ \int g(x)E_x\int_0^t f(X_s)dA_s\,m(dx)=\int_0^t\int (P_sg)(y)f(y)\mu_A(dy)ds. \]

这次重访半群有了新的增量：Pₛ不只是把未来函数平均到起点，也能通过对称性把起点的观察权重传到一份奇异收费上。非对称过程需要对偶半群或过分参考条件，不能把上式原样照搬。

## 38.21 先声明真正能够证明的对应范围

<a id="revuz-class"></a>

为使存在、版本和唯一性都可独立核查，我们选定如下过程类：紧度量E，有限满支撑m，保守m-对称Feller Hunt过程；每个λ>0的resolvent具有有限联合连续对称核rλ。测度取有限正Borelμ，泛函取具有连续有界1-势U₁ᴬ的PCAF。在这两个准确的类之间，存在双射，且U₁ᴬ=R₁μ。

\[ U_1^A(x)=E_x\int_0^\infty e^{-s}dA_s=R_1\mu(x). \]

这不只适用于一个Brownian公式：紧区间反射Brownian和有限可逆连续时间链都在其中。核连续是实际假设；高维Brownian的对角奇点提醒我们不能随手删去它。[专题1](../foundations/t-revuz.md#revuz-proof-class)给精确路径、等价类及非空实例。

## 38.22 用空间平滑构造真正的随机累积

<a id="revuz-construction"></a>

给μ，令u=R₁μ；用resolvent把它平滑成密度\(f_n=nR_n\mu\)。普通时间积分Aₙ=∫fₙ(X)ds已合法，而其势uₙ=\(nR_nu\)一致趋u。只知道势收敛还不够，路径累积本身必须收敛；关键是把两个候选收费之差的平方平均写成resolvent。

\[ E_x\left(\int_0^\infty e^{-s}f(X_s)ds\right)^2=2R_2(fR_1f)(x). \]

若R₁f很小，右边被势的误差控制。Doob最大不等式再把终值误差变成整段时间的L²最大误差。选择同一子列，在规范路径空间上取局部一致极限，连续性、递增性和全部时间移位加性一同留下。[完整构造](../foundations/t-revuz.md#revuz-proof-construction)处理了奇异测度的核交换、无原子Stieltjes极限及共同移位不变版本，未以“存在一个加性泛函”跳过过程构造。

## 38.23 反向识别与一般理论的真实边界

<a id="revuz-reverse"></a>

反向从A出发，m平稳性使E_m∫₀ᵗf(Xₛ)dAₛ对t线性，定义有限\(\mu_A\)。要恢复每个起点的势，需要在小网格上以左端状态读取未来A增量，利用Markov与对称性，再取Stieltjes极限；不能假设随机收费独立于过去。最后\(u_A\)=R₁\(\mu_A\)，且同势的两个A之差给连续有限变差鞅，只能恒0。[反向与唯一性](../foundations/t-revuz.md#revuz-proof-reverse)由此闭合上述类的对应。

更广的平滑测度不是指有光滑密度，而是不得收费于容量零集，并具有适当有限测度巢。一般Hunt或右过程还涉及准连续势、例外起点集与巢拼接。本章不把连续有界势版本冒充这些最广版本的证明；任意平滑测度的巢逼近和一般PCAF的版本技术仍是[明确的未闭合范围](../foundations/t-revuz.md#revuz-proof-boundary)。一维局部时的全部Radon显式构造则已由37章另行成立。

## 38.24 改变路径权重，也改变演化算子

<a id="fk-additive-semigroup"></a>

连续加性代价A给Pₜᴬf=Eₓ[\(e^{-A_t}\)f(Xₜ)]。加性使它仍是半群，却通常不保质量：它描述带杀死的运动。若A来自qdt，原生成元L变成L−q；Laplace resolvent满足下面的有序恒等式。

\[ R_\lambda^A=R_\lambda-R_\lambda(qR_\lambda^A),\qquad P_{s+t}^A=P_s^AP_t^A. \]

q作为乘法算子，不能越过Rλ随意换序。对奇异A，算子不再由一个普通有界q表示，但路径半群仍有意义；在一维，它对应前面的测度弱方程。随机积分、加性泛函和确定性算子在这里通过实际恒等式相连，而非仅共享“累积”一词。

## 38.25 边界收费与内部点收费仍有区别

<a id="fk-robin"></a>

取0反射、1停止的Brownian R=x+W+K。沿K以速率κ杀死时，对\(e^{-\kappa K}\)u(R)用Itô，边界漂移为(u′(0)−κu(0))dK。要使账户正确结算，需u′(0)=κu(0)。内部仍是同一个½u″，边界却由反射Neumann变成Robin。

这不是内部δ源跳跃条件的简单改名：边界只有一侧导数，K的归一化也不同。36–37章已说明同一个内部算子未必确定过程；现在又看见，边界上的累积如何在确定性方程中留下可计算的条件。普通时间、局部时和边界调节量各有自己的角色。

## 38.26 同一结构的两种读法，仍各有条件

<a id="fk-insight"></a>

最初那份随机账单已经不再只是一个退出时间的例子。时间分割产生动态关系，Itô把它读成方程；Green把累积移到空间，Riesz分开内部源与边界信息，容量识别哪些零长度集合仍可影响运动，扫掠保留源在特定观察处的作用。奇异收费又迫使我们保留测度和弱解，不能把所有问题压成处处光滑的函数。

逐次运动与确定性方程可以是同一结构的两种读法，但等价由条件支撑：经典正则性、边界正则性、停止的一致可积性、参考测度及泛函类别都不能省略。我们得到的新能力，是知道一份公式究竟保留了哪些路径信息，哪里还需另一种语言才能看见。

还有一个具体困难。Gaussian平均可以把不连续数据变平滑，而一般随机方程的输出未必如此。如果目标不是表示一个期望，而是判断随机输出是否具有光滑密度，我们能否改变驱动噪声、观察输出怎样响应？对空间的微分已给了我们方程；对随机性的扰动又能读出什么，成为一个不同而值得研究的问题。
