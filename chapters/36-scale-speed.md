# 第三十六章：一维扩散如何决定自己的命运？——尺度、速度与边界

一颗粒子不断受到向右的推动。若只看漂移箭头，似乎应该不断向右；但随机振荡仍可能先把它送到左边的障碍。即使两个模型向左、向右的命中机会完全相同，它们抵达障碍所需的时间，也可能一个有限、一个无限。方向的机会与运动的时钟，还没有被我们分开。

## 36.1 向右推动，为什么仍会先到左边

<a id="diffusion-question"></a>

先研究最朴素的模型：dX=μdt+σdW，μ>0、σ>0。从a与b之间的x出发，我们想知道先到b还是先到a。用均值x+μt不能回答，因为抵达时刻本身随机；把停止时间直接代入均值，又会绕回第16章已经辨清的抽样条件。

如果能找到一种新的位置读数h，使它在粒子运动时没有可预测漂移，那么停止以前的平均读数就保持不变。把读数在a设为0、在b设为1，停止以后它只记录究竟到达哪一端。命中问题于是要求我们寻找一个合适的坐标，而不是猜测时间。

## 36.2 先说明我们追踪的是哪一条路径

<a id="diffusion-setting"></a>

本章主线为开区间I=(ℓ,r)上的时间齐次SDE。端点允许为无穷。假设b、σ在I内局部Lipschitz、σ(x)>0；因而在每个紧子区间上系数有界且σ有正下界。第35章给直到离开I的最大连续强解及路径唯一性。其滤过满足通常条件，W相对于它为Brownian运动。

\[ dX_t=b(X_t)dt+\sigma(X_t)dW_t,\qquad Lf(x)=a(x)f^{\prime\prime}(x)+b(x)f^\prime(x),\qquad a=\sigma^2/2>0. \]

用紧区间退出时刻的递增极限定义寿命ζ。在ζ以后，最小过程进入墓地状态；本章的内部方程只在t<ζ成立。有限端点的抵达和无穷端点的有限时逃逸都可能结束寿命。反射、吸收或从端点开始的入口，需要另给规则，不暗含在这份开区间SDE里。

## 36.3 让位置变成公平读数

<a id="diffusion-scale-discovery"></a>

对C²函数h应用已经建立的Itô公式。读数的漂移是Lh。于是所需条件为ah″+bh′=0。这个方程的未知量可以先降成h′：它的对数变化率必须抵消b/a。

\[ p(x)=\exp\!\left(-\int_c^x\frac{b(z)}{a(z)}dz\right),\qquad S(x)=\int_c^xp(y)dy,\qquad LS=0,\qquad c\in I. \]

p严格正，所以S保持位置顺序。它不是把实际漂移从原路径中抹去，而是选择一个读数，让同一条运动在这个坐标里成为连续局部鞅。尺度函数因此从一个明确的停止任务中产生：把方向的不对称改写成坐标的不均匀。

\[ dS(X_t)=p(X_t)\sigma(X_t)dW_t\quad(t<\zeta),\qquad \widetilde S=AS+B\ (A>0)\text{ is an equivalent scale}. \]

## 36.4 一个停止恒等式，变成命中概率

<a id="diffusion-hitting"></a>

固定ℓ<a<x<b<r，令τ=τₐ∧τᵦ。S(X)停于τ后有界，因而是真鞅。还必须证明τ有限，才能让停止时间趋∞；[证明1](../foundations/t-scale-speed.md#scale-compact-exit)以解Lu=−1的非负函数给出统一期望界，没有预设命中结论。

\[ P_x(\tau_b<\tau_a)=\frac{S(x)-S(a)}{S(b)-S(a)},\qquad P_x(\tau_a<\tau_b)=\frac{S(b)-S(x)}{S(b)-S(a)}. \]

分子分母不是普通距离，而是尺度距离。连续性使退出值只可能为a或b，没有跳跃越界；有界鞅及有界收敛使期望合法。若换成有跳过程，最后一步已经不再成立，不能把这个公式照搬。

## 36.5 常数漂移的箭头，要和波动一起衡量

<a id="diffusion-drift-example"></a>

回到μ、σ模型，尺度密度为exp(−2μx/σ²)，相差正常数无关紧要。计算得到

\[ P_x(\tau_b<\tau_a)=\frac{1-e^{-2\mu(x-a)/\sigma^2}}{1-e^{-2\mu(b-a)/\sigma^2}}\quad(\mu\ne0),\qquad P_x(\tau_a<\infty)=e^{-2\mu(x-a)/\sigma^2}\quad(\mu>0,x>a). \]

第二式让b趋∞；若一条路径曾在有限时间到a，之前的紧时间路径有界，因而会在某个b以前到a，事件递增穷尽。向右漂移并未消灭向左命中，只把机会按漂移与波动平方的比率压低。μ趋0时恢复普通距离比。

## 36.6 方向的机会相同，时钟却可以不同

<a id="diffusion-two-structures"></a>

把b、a同时乘同一个正函数q，b/a不变，全部紧区间命中概率不变。但是运动的二阶变化速率改变了。特别是零漂移时，普通Brownian运动与dX=X dW都处于尺度S(x)=x上；在正半轴里，前者可以碰到0，后者却永不在有限时间碰到0。相同的区间方向机会，没有决定边界时间。

需要一个与尺度互补的量。将生成元重新整理为两次不同的微分，恰好出现这个量。

\[ m(dx)=m^\prime(x)dx,\qquad m^\prime(x)=\frac1{a(x)p(x)}=\frac2{\sigma(x)^2p(x)},\qquad L=\frac d{dm}\frac d{dS},\quad \frac{df}{dS}=\frac{f^\prime}{p}. \]

## 36.7 速度测度为什么越大，运动反而越慢

<a id="diffusion-speed"></a>

称m为速度测度，不应把它误读成粒子的速度。它是生成元中第二次微分所用的空间权重。固定尺度，a减小会使m增大；同一尺度区域因而需要更多普通时间才能穿过。下面的占用公式将把这句话变成精确期望。

我们的归一化让标准Brownian运动有m(dx)=2dx，而非dx，因为其生成元是½d²/dx²。将S乘A时，m必须除以A；Green核则乘A，使最终概率与时间公式不变。不同书的因子2若不随生成元一起核对，会让全部平均时间错一倍。

## 36.8 一座折线，如何记录全部占用

<a id="diffusion-green"></a>

仍停在(a,b)。若以每单位时间f(Xₜ)累计读数，其平均总量u应满足Lu=−f，并在退出端点为0。在尺度坐标里，点源的解由两段直线拼成：除了源点没有曲率，在源点让尺度斜率向下跳一个单位。

\[ G_{a,b}(x,y)=\frac{\{S(x\wedge y)-S(a)\}\{S(b)-S(x\vee y)\}}{S(b)-S(a)},\qquad u_f(x)=\int_a^bG_{a,b}(x,y)f(y)m(dy). \]

这座折线对x、y对称。直接微分核的两段，尺度导数在x=y处的跳为−1；对连续f积分便得到C²函数\(u_f\)，且\(Lu_f\)=−f。停止Itô公式于是证明，而不只是猜测，

\[ E_x\int_0^{\tau_a\wedge\tau_b}f(X_t)dt=\int_a^bG_{a,b}(x,y)f(y)m(dy),\qquad f\ge0\text{ Borel}. \]

先连续f、再用有限测度唯一性与单调类推广；非负f允许值∞。有符号f需对|f|的同一积分有限，才能相减。[证明2](../foundations/t-scale-speed.md#scale-green)给出端点、可积性与推广步骤。

## 36.9 命中位置与抵达时间，终于分开

<a id="diffusion-mean-exit"></a>

令f=1便得到平均退出时间。Brownian运动的S=x、m=2dx代回去，积分为(x−a)(b−x)。将系数整体加速q而尺度不变，Green核不变，速度测度却除以q；它精确改变每个区域对总时间的贡献。

\[ E_x(\tau_a\wedge\tau_b)=\int_a^bG_{a,b}(x,y)m(dy),\qquad L_{\rm BM}=\tfrac12\partial_{xx}:\ E_x\tau=(x-a)(b-x). \]

向端点扩张区间时，退出时刻递增。对非负f，时间积分也递增，单调收敛给整个寿命以前的Green势。这个极限可能无穷；不能把无穷端点直接塞进一个出现∞/∞的商，更不能从期望无穷直接断定路径永远不退出。

## 36.10 一份平均密度，还不是逐路径的停留记录

<a id="diffusion-occupation"></a>

对固定y，速度测度在{y}上的质量为0，因此任一紧区间停止前，粒子恰在y的总时间几乎必然为0。然而命中y的概率可以为1。命中一个位置与在该位置占有正的普通时间，是两件不同的事。

Green公式给的是随机占用测度的期望。它还没有为每一条样本路径构造关于空间的密度，也没有同时对所有y选择一份局部时间。我们先用这份可靠的平均信息研究边界，稍后再追问逐路径究竟留下什么。

## 36.11 靠近边界，不等于能在有限时间抵达

<a id="diffusion-access"></a>

看右端r，固定c<x<r。若S(r)=∞，命中公式立即说明在先到c以前，达到越来越高尺度的概率趋0。若S(r)<∞，向右的机会却可能保留。仍需知道：一串越来越靠近r的到达时刻，会累积到有限时间，还是拖到无穷。

\[ \Sigma_r=\int_c^r\{m((c,y))\}\,dS(y)=\int_c^r\{S(r)-S(y)\}\,m(dy)\quad\text{when }S(r)<\infty. \]

第一种非负迭代积分总有意义；S(r)=∞时它必为∞。第二种写法只在S(r)有限时使用，来自Tonelli。改变内部参考点c不会改变有限或无穷的判断。左端则把方向反过来。

## 36.12 为什么检验期望还不够

<a id="diffusion-feller-test"></a>

本章证明：右端在有限时间、先于c可达，当且仅当Σᵣ有限。充分性可由Green期望界和尺度概率一起得到；必要性需要更强的工具。一个有限随机时间可以有无穷期望，因此不能只说“Green积分发散，所以到不了”。

寻找正的λ调和读数v，Lv=λv、v(c)=1、v′(c)=0。其两次积分形式显示，Σ有限时v有界；Σ无穷时v趋∞。对e⁻λᵗv(Xₜ)停止，便用一个真正的概率上界排除有限时间到达。

\[ v(x)=1+\lambda\int_c^x\{S(x)-S(y)\}v(y)m(dy),\qquad P_x(\tau_b\le T,\tau_b<\tau_c)\le e^{\lambda T}\frac{v(x)}{v(b)}. \]

这一步区分了“时间的平均太大”和“有限时间事件的概率为0”。[边界证明1](../foundations/t-feller-boundaries.md#boundary-access)完成Volterra界、寿命极限与退出方向；没有借用未来的一般扩散时间变换。

## 36.13 边界能否成为起点，是另一个方向的问题

<a id="diffusion-entrance"></a>

一个端点从内部到不了，不表示从它开始的路径一定没有意义。三维Brownian运动从原点出发，它的半径立即为正；从任一正半径出发，它却永不碰到0。空间中同一个点，在两个方向上承担不同角色。

为了检验右端能否向内部送出运动，交换刚才两次积分的顺序，得到另一份量。它衡量从很远的位置返回内部所需的时钟，而不是从内部赶到边界。

\[ N_r=\int_c^r\{S(y)-S(c)\}m(dy),\qquad N_\ell=\int_\ell^c\{S(c)-S(y)\}m(dy). \]

对于不可达的右端，Nᵣ有限当且仅当存在连续即时入口，先停于内部点c来表述。证明不是只给一个积分名字：[边界证明2](../foundations/t-feller-boundaries.md#boundary-entrance)把初值x推向r，用同一Brownian噪声的单调耦合构造入口，并用返回时间界控制正时间的紧性；逆向则用命中c的Laplace读数排除Nᵣ无穷。

## 36.14 四种边界，来自两份不同的检验

<a id="diffusion-boundary-table"></a>

对左端，\(\Sigma_\ell=\int_\ell^c m((y,c))\,dS(y)\)，与右端保持镜像。Feller基本分类由Σ与N是否有限给出。这里regular boundary指端点类别，不是另一个用法“每个内部点之间可达”的regular diffusion。

|Σ|N|类别|本章可直接读取的区别|
|---|---|---|---|
|有限|有限|regular，正则|内部可达；到达后仍须选择边界规则|
|有限|无穷|exit，出口|内部可达，入口检验失败|
|无穷|有限|entrance，入口|内部不可达，但可从该端点连续即时进入|
|无穷|无穷|natural，自然|内部不可达，也没有上述连续即时入口|

表格准确规定基本积分类型，并配上前两节已证的可达性与不可达端点入口定理。所有正则端点的反射、粘滞、杀死等延拓及一般奇异速度测度的完整构造，不由这张表自动完成；其一般证明按蓝图在第37章局部时间/时间变换后接续。本章下面实际构造可核算的代表，严格区分分类检验与所有边界过程的构造。

## 36.15 把四种可能放在具体模型里

<a id="diffusion-examples"></a>

Brownian运动在(0,1)的两端均正则：p=1、m′=2，两份积分有限。零漂移平方根扩散dZ=2√Z dW在(0,∞)的0端为出口：尺度为x、m′=1/(2x)，Σ有限而N无穷。从0延用同一个平方根SDE只能得到零过程，第35章的模唯一性给出证明。

三维Bessel半径的内部方程是dR=dβ+R⁻¹dt。取p=x⁻²、S=−1/x、m′=2x²，0端有Σ无穷、N有限，因此为入口。令R=|B⁽³⁾|实际构造从0的运动；对正时间的Itô计算及0附近漂移可积性见[边界证明3](../foundations/t-feller-boundaries.md#boundary-examples)。

几何Brownian运动dX=X dW的0端则自然：p=1、m′=2/x²，两份检验都发散。它能随t→∞趋近0，却不在有限时刻抵达；从0用同一SDE出发也不能自行进入正半轴。这不是把“非常慢”当作“不可能”的语言修饰，而是两个不同的时间命题。

## 36.16 更大的噪声，可能阻止向上的爆炸

<a id="diffusion-explosion-example"></a>

比较正半轴上的两条方程，漂移都为x²。确定性方程会有限时爆炸，但两种噪声给不同命运。

\[ dX=X^2dt+X\,dW:\quad p(x)\asymp e^{-2x},\quad m^\prime(x)\asymp e^{2x}/x^2;\qquad dY=Y^2dt+Y^2dW:\quad p(x)\asymp e^{2/x},\quad m^\prime(x)\asymp e^{-2/x}/x^4. \]

第一条在∞有有限尺度，并且(S(∞)−S(x))m′(x)为常数倍x⁻²，故Σ∞有限，存在先于某个内部下界的有限时向上爆炸。第二条在∞的尺度无穷，在0的尺度为负无穷，两端均不可达，所以它在正半轴内保有无限寿命。不能仅凭相同漂移箭头、或者“噪声更大”判断爆炸。这里的比较是两份命运的比较，不是下面的同噪声路径排序定理。

## 36.17 同一个内部算子，可以有不同的边界未来

<a id="diffusion-boundary-rules"></a>

在半轴内部，普通Brownian运动的生成元都是½f″。到0就杀死、到0后停在0，以及碰到0后反射回来，却是不同过程。前两种由停止直接构造；第三种可以取|x+B|。绝对值后的未来规律只依赖当前绝对值，因为Brownian增量关于0对称，所以它确为Markov过程，不需提前使用Tanaka公式。

\[ p_t^{\rm ref}(x,y)=\frac1{\sqrt{2\pi t}}\left[e^{-(y-x)^2/(2t)}+e^{-(y+x)^2/(2t)}\right],\qquad x,y\ge0. \]

若f′(0)=0，偶延拓f(|z|)为C²，Itô给反射模型的Neumann条件；杀死模型的连续测试则取Dirichlet条件f(0)=0。吸收模型在状态0的生成元值为0，和保留端点后的状态空间一起说明。内部微分表达式未变，定义域与边界规则却改变了全部未来。[证明4](../foundations/t-feller-boundaries.md#boundary-rules)核验核、强Markov及边界计算。

## 36.18 比较定理究竟在比较什么

<a id="diffusion-comparison"></a>

若两方程使用同一个Brownian运动、同一个局部Lipschitz扩散系数σ，而b₁≤b₂、初值x₁≤x₂，则在共同寿命以前有X¹≤X²。不同初值、相同系数时，连续路径要交换顺序必须先相遇；路径唯一性使相遇后不再分开。不同漂移则要进一步控制两解正差的二阶贡献。

这里用第35章已建立的光滑绝对值逼近，构造正部逼近，对停止后的差应用Itô和Gronwall；不借第37章Tanaka。完整估计在[长期证明1](../foundations/t-diffusion-longtime.md#diffusion-order)。若σ也不同，从0出发的W与2W已会随W的符号交换顺序，不能保留这份排序。

## 36.19 有限区间的命中，怎样决定无限时间的去向

<a id="diffusion-recurrence"></a>

对两端均不可达的最小过程，寿命无限。若S(ℓ)=−∞、S(r)=∞，令命中公式的一端逐渐远去，得到任一内部点从另一内部点最终被命中的概率为1。强Markov性使这些往返反复发生，形成一维的常返。

若两端尺度都有限，S(X)为有界鞅，收敛到端点尺度。它不能收敛到内部尺度，因为那会把路径最终留在一个非退化紧区间，平方时钟无限增长，与有界鞅的收敛相矛盾。于是

\[ P_x(X_t\longrightarrow r)=\frac{S(x)-S(\ell)}{S(r)-S(\ell)}\qquad\text{if both scales are finite and }\zeta=\infty. \]

若只有右端尺度有限而左端为−∞，用S(r)−S(X)的非负局部鞅收敛得到X→r几乎必然；另一方向镜像成立。这里只讨论已明确保守的内部过程，不能把反射或被杀死后的模型混进同一结论。[长期证明2](../foundations/t-diffusion-longtime.md#diffusion-recurrence-proof)给出时钟论证。

## 36.20 速度测度什么时候能成为平稳概率

<a id="diffusion-invariant"></a>

若m(I)有限且两端不可达，将m归一化便得到不变概率。这不能只从形式关系L*π=0宣告。我们先在紧区间构造带折扣的Green核，证明它相对于m对称；再扩张区间，用保守性Rλ1=1/λ识别积分，最后由Laplace唯一性恢复每个时间的平稳性。

\[ \pi(dx)=\frac{m(dx)}{m(I)},\qquad \int_I P_tf(x)\pi(dx)=\int_I f(x)\pi(dx). \]

在两端尺度无穷的常返情形，不变概率若存在必是这份π：紧支撑测试给平稳分布的常流方程，解为(C+JS(x))m(dx)；S覆盖整个实轴、密度非负迫使J=0。因此m总量无穷时，常返并不产生一份可归一化的平稳概率。[长期证明3](../foundations/t-diffusion-longtime.md#diffusion-invariance-proof)包含测度形式的方程与唯一性。

## 36.21 一条路径的长期平均，怎样回到速度权重

<a id="diffusion-time-average"></a>

选择内部两点a<b，把a→b→a看成一个完整返回周期。强Markov使各周期独立同分布。Green公式分别计算去程与回程，合起来恰好消去折线两侧，留下速度测度本身。

\[ E_a\!\int_{\rm cycle}f(X_t)dt=\{S(b)-S(a)\}\int_If(y)m(dy),\qquad E_aT_{\rm cycle}=\{S(b)-S(a)\}m(I). \]

当m有限，独立周期的大数定律给有界Borel f的路径时间平均趋πf。最后未完成周期的误差由可积周期长度控制；这一步在[长期证明4](../foundations/t-diffusion-longtime.md#diffusion-cycle-proof)实际写出，不提前调用第41章遍历定理。若m无限但尺度两端无穷，紧支撑有界非负f的周期收益仍可积，而周期均值无穷，时间平均趋0。常返与正比例地停留在一个区域，终于被区分开。

## 36.22 OU、Brownian与趋向零的几何运动

<a id="diffusion-longtime-examples"></a>

OU方程dX=−θXdt+σdW（θ>0）有p=exp(θx²/σ²)，m′=(2/σ²)exp(−θx²/σ²)。尺度两端无穷、速度总量有限，归一化给方差σ²/(2θ)的中心Gaussian。第32章显式解还给从固定初值向这份分布的收敛；本章新增的是由尺度与速度直接解释常返及路径占用比例。

普通Brownian运动尺度两端无穷，但m(R)=∞，因而常返却没有不变概率，在每个固定有界区域的时间比例趋0。零漂移几何Brownian运动则尺度左端有限、右端无穷，路径趋向0而从不在有限时间抵达。三个模型分别展示：返回、长期占用与边界到达，不能由一个“稳定”概括。

## 36.23 路径的命运，已经能够分成可计算的关系

<a id="diffusion-insight"></a>

我们没有从一根漂移箭头读出未来。先选择使读数公平的尺度，再以速度测度恢复普通时间，才把方向机会与停留时间分开。两份边界积分进一步区分有限时抵达与从端点开始；反射例子则说明，内部规则正确而唯一，仍不意味着边界未来已经规定。

这些认识由命中恒等式、Green核、边界概率检验和返回周期的计算支持。更强噪声未必更易爆炸，常返未必有平稳概率，逐渐接近一个点也未必能在有限时刻碰到它。决定这些差别的，是漂移、波动、尺度、时钟和边界规则怎样组合，而非其中任何一项孤立的大小。

不过，速度公式仍然只告诉我们平均占用。若想在一条具体路径上，把时间分解到每个空间位置，单点时间为零的事实立刻成为新的困难。下一种工具必须能记录“经过一个位置的累积强度”，同时不把它误当成在该点停留的普通时间。

完整证明分别为[T-SCALE-SPEED](../foundations/t-scale-speed.md)、[T-FELLER-BOUNDARIES](../foundations/t-feller-boundaries.md)与[T-DIFFUSION-LONGTIME](../foundations/t-diffusion-longtime.md)。一般奇异尺度/速度、正则端点全部Markov延拓、粘滞与局部时间构造仍由第37章接续；一般Harris/mixing及最广遍历理论不计为本章已经完成。
