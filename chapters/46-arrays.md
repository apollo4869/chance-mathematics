# 第四十六章：当可交换的对象不再排成一列

我们调查一群人之间的关系，每两个人之间只记0或1。不记录姓名，重新编号以后概率不变。若逐人阅读调查表，每一行都可能像独立抛出的公平硬币；但把三个人的三张表合起来，关系却可能立刻暴露出完全不同的结构。

现在需要识别的，不再只是一次观察服从哪份随机概率，而是不同关系中重复出现的同一个人，究竟怎样把随机信息带到每一条关系里。

## 46.1 每一行都一样，三个人却能分辨两种世界

<a id="arrays-row-failure"></a>

先构造两份无限关系表。第一份在每个无序人对上独立放一枚公平0/1结果，反向格抄同一结果，对角为0。第二份给每个人独立指定一种隐藏颜色，两色各半；不同颜色之间记1，同色之间记0。

固定一个人，第二份表中其余人的颜色独立；无论他是什么颜色，每个关系为1的概率都是1/2。因此两份表的每一行，在略去自身对角后，都严格是iid Bernoulli(1/2)。逐行使用第43章，得到的随机指导概率在这里甚至都相同且不随机。

\[ \mathbb P\{X_{12}=X_{23}=X_{31}=1\}=\begin{cases}1/8,&\text{independent pairs},\\0,&\text{two-color model}.\end{cases} \]

三个人不可能两两异色，所以第二个概率为0。每行的表示都正确，却没有告诉我们不同的行怎样通过同一个顶点对齐。缺少的不是某一行更多的样本，而是跨行共享信息的组织。

这不否认另一条合法尝试：在分别交换下，把整行看成一个E的可数乘积空间值随机元，行向量本身组成交换列。但那份行向量指导测度怎样承受全部列重排，仍需进一步解析。一个序列表示没有自动完成这项共享结构的分析。

## 46.2 重新编号的是一群人，还是两群人

<a id="arrays-actions"></a>

\[ (X_{ij})\stackrel d=(X_{\pi(i)\pi(j)})\quad\text{joint exchangeability},\qquad (X_{ij})\stackrel d=(X_{\pi(i)\sigma(j)})\quad\text{separate exchangeability}. \]

所有置换均指任意有限置换，等律指全部有限联合分布。前式中i和j属于同一群体，例如人际关系；后式把行列当作两种群体，例如受试者与试题、学生与课程。分别交换蕴含共同交换，反向不成立：单位矩阵在共同编号下不变，单独交换两行却改变了它。

这项区分决定哪些输入需要共享。共同编号中(i,j)与(j,i)描述同一对象对的两个方向；分别编号中它们通常是两项不同的交叉关系。(i,i)在前者是真正的自我关系，在后者只是一格碰巧用了相同整数的普通数据。

## 46.3 关系为什么需要不止一层随机性

<a id="arrays-layers"></a>

考虑一张0/1关系表。整群人可能先处于某种共同环境；每个人有自己的属性；在这些信息已确定后，两个人之间还可能有一份仅属于这对人的随机选择。于是一个可计算的候选构造是：取独立的全局、顶点及无序对均匀数，用一个Borel函数生成关系。

\[ X_{ij}=F(U_0,U_i,U_j,W_{\{i,j\}}),\qquad i\ne j. \]

无全局依赖的两色例子只用顶点输入；独立边例子只用成对输入；先随机选择边概率、再独立生成全图，则用全局与成对输入。检查这些构造交换很容易：重新编号只重排独立随机数。但这还远未证明任意交换数组都能这样产生。困难的方向是从已经给定的联合律中找到这些层次。

## 46.4 把一部分顶点留作观察背景

<a id="arrays-background"></a>

暂从对称的、没有自我关系的数组开始。无限性允许把顶点分成目标N与无限背景R；目标子数组的律仍与原数组相同。背景记录B包含R内的全部关系。对目标顶点i，另记录它与所有背景点的关系，组成Yᵢ=(B,(Xᵢr)r∈R)。

这不是前面的行指导概率。每份Y保留了同一个有标签背景，因而不同人的档案可以在共同参照下比较。它是一项可数标准Borel资料，不是凭空假设的“真实属性”。接下来必须证明：给了这些档案，目标人对之间是否还留下不能分开的随机依赖。

在两色关系表中，若背景颜色串为c，一个人的关系串只能是c或它的补串。无需知道哪种颜色叫0，比较两份档案是否相同就能判定这两人同色还是异色。单行的Bernoulli指导律只留下1/2；保留同一背景坐标的档案却没有丢掉这种对齐。

## 46.5 额外资料是否真的改善预测，可以用范数检验

<a id="arrays-proof-mechanism"></a>

固定目标边ij和有界函数f。以𝓖=σ(Yᵢ,Yⱼ)为局部信息，以𝓗为全部Y档案再加任意有限组其他目标边的信息。若知道𝓗并不比𝓖更能预测f(Xᵢⱼ)，就能逐条剥去其他边，得到所需条件独立。第9章的正交投影给准确检验。

\[ \|\mathbb E[V\mid\mathcal H]-\mathbb E[V\mid\mathcal G]\|_2^2=\|\mathbb E[V\mid\mathcal H]\|_2^2-\|\mathbb E[V\mid\mathcal G]\|_2^2,\qquad V=f(X_{ij}). \]

问题被变成两个范数是否相等。它们只依赖目标值与观察资料的联合律，因此交换性可以作用于这项比较，而不必先猜出潜变量分布。

## 46.6 一次重新编号怎样排除剩余依赖

<a id="arrays-sandwich"></a>

把背景R再分成两个无限部分。固定i、j，把原背景单射到其中一半，把其余所有目标顶点单射到另一半。单射保持全部有限联合律，因而保持𝓗预测的L²范数。变换后，其他边都落在背景内部，或连接i、j中的一个与背景；没有另一条边能变成ij本身。

所以变换后的资料σ代数𝓙包含于𝓖。一边𝓖⊂𝓗，另一边范数相同的𝓙⊂𝓖，投影范数被两侧夹住。

\[ \|\mathbb E[V\mid\mathcal G]\|_2\le\|\mathbb E[V\mid\mathcal H]\|_2=\|\mathbb E[V\mid\mathcal J]\|_2\le\|\mathbb E[V\mid\mathcal G]\|_2. \]

因此两个预测相等。逐条使用条件期望，任意有限组不同目标边在全部Y条件下的测试乘积，等于各边只给定自己两个端点档案的条件测试乘积。完整的单射、σ代数与共同零集论证见[T-ARRAYS](../foundations/t-arrays.md#arrays-proof-independence)。这是表示定理的核心，而不是由表示公式反推出来的假设。

## 46.7 条件核必须在同一套版本上工作

<a id="arrays-common-kernel"></a>

取X₁₂给定(Y₁,Y₂)的正规条件核K。对称性使交换两个端点不改变该条件概率；为避免各端点各有一个例外零集，把K对这个二元群平均，得到处处对称的概率核。它在所有参数上有定义，仍是正确条件律版本。

对每条目标边使用同一核。状态空间标准Borel，取可数生成代数，对全部边、有限边族及这些测试只需删去一个可数并的零集，之后由单调类推广。第10章的核随机化再把每条边的剩余选择交给独立均匀数。

\[ \mathbb P\{X_{ij}\in A\mid(Y_k)_{k\ge1}\}=K(Y_i,Y_j,A),\qquad X_{ij}\ \stackrel d=\ \Gamma(K(Y_i,Y_j),W_{\{i,j\}}). \]

“相同有限边缘律”与“共同条件乘积律”不能混写；后者才保证这一随机化恢复整张数组，而非仅恢复每一条边。

## 46.8 这时de Finetti为什么终于可以使用

<a id="arrays-profile-director"></a>

背景不动、只重新编号目标点时，(Yᵢ)是一列交换的标准Borel随机元。第43章于是给随机指导概率ν，使Yᵢ在ν条件下iid。用U₀生成ν，再用独立Uᵢ生成每份档案，最后把核随机化交给成对W。

\[ Y_i=h(U_0,U_i),\qquad X_{ij}\stackrel d=F(U_0,U_i,U_j,W_{\{i,j\}}). \]

先前逐行套用失败，是因为各行指导概率没有保住关系对齐；这里先证明了“共同档案给定以后边确实可分”，才对档案列使用序列表示。两次调用同一定理，前置问题完全不同。全局输入携带的是档案的随机指导分布，不应未经证明等同于某个能直接观测的人群特征。

## 46.9 方向和对角不能藏进“类似处理”

<a id="arrays-directions-diagonal"></a>

对一般有向数组，必须把(Xᵢⱼ,Xⱼᵢ)看作一项无序对的完整资料，再证明不同无序对的条件独立；不能错误地要求两个方向独立。对角Xᵢᵢ则作为顶点标记进入档案。严格构造使用独立连续顶点标记确定成对记录的内部顺序，随后按原方向取回分量，得到下式。

\[ X_{ij}=F(U_0,U_i,U_j,W_{\{i,j\}})\quad(i\ne j),\qquad X_{ii}=D(U_0,U_i). \]

T-ARRAYS的[有序解码证明](../foundations/t-arrays.md#arrays-proof-ordered)同时覆盖这两项，所有相等模式都被实际编码。给定潜变量，反向边仍共用同一W。一个随机锦标赛可以让每对人恰好一个方向为1；若给两方向各一枚独立硬币，这项概率1的约束立即丢失。

## 46.10 两个群体怎样得到两套独立顶点输入

<a id="arrays-separate-proof"></a>

分别交换并不意味着先取一套共同顶点输入，再把它复制成两份。为了证明正确形式，可在共同编号空间中独立把顶点染成两类，仅存0类指向1类的原矩阵关系，其他格记†，并保留颜色。这份带标记关系共同交换，所以刚建立的定理适用。

表示中颜色只依赖U₀和单点输入。比较原颜色频率的强律与表示中的条件强律，得每类给定U₀后的概率仍为1/2。按颜色取回两套顶点后，它们服从各自的条件核；通过“先取类型、再独立取各类序列、最后交织”的有限乘积计算，证明两套序列条件独立。成对噪声不参与颜色选择，因此仍独立。

\[ (X_{ij})\stackrel d=\big(F(U_0,U_i,V_j,W_{ij})\big). \]

全部输入在此相互独立均匀；反向与对角没有共同顶点意义，Wᵢⱼ是按有序行列位置独立的数。完整核、抽取与高阶类型证明见[T-ARRAY-VARIANTS](../foundations/t-array-variants.md#array-variants-color)。条件颜色概率与无限出现性都已经核实，不能只看公式就跳过它们。

## 46.11 同一列还能把不同行连接起来

<a id="arrays-sharing-example"></a>

设Uᵢ、Vⱼ为独立公平±1变量，Xᵢⱼ=UᵢVⱼ。这个阵分别交换，每格也是公平±1；但任意2×2矩形的四格乘积恒为1。给每格独立重新抽签则只以概率1/2得到该乘积。行信息与列信息的共享，留下了单格、甚至某些成对比较看不见的约束。

在一般模型中，同列的格可以通过列潜变量依赖，例如Xᵢⱼ=Vⱼ；上一乘积例子即使两两独立，仍有矩形约束。准确的条件独立应是：给定全部相应的全局、行、列输入后，不同格的剩余成对选择独立。它从不等于“所有行列无条件独立”。

## 46.12 没有共同顶点的两块，是否一定独立

<a id="arrays-dissociation"></a>

若先非退化地随机选择p∈[0,1]，再按p独立生成整张图，即使两块没有共同顶点，也会通过p发生依赖。因而需要分清“顶点不相交”与“没有共同全局信息”。称共同交换数组分离，若任意不相交顶点集诱导的子数组独立；分别交换时要求行集合与列集合两类都不相交。

这一定义不要求相邻边独立。两色关系表就是分离的：不相交人群使用独立颜色；一旦共享顶点，它们仍可能满足三角约束。定义解决的是不同对象块能否独立抽样，不是把一切关系拆成独立格。

## 46.13 有限重新编号的平均，留下哪一份随机律

<a id="arrays-invariant-average"></a>

对前n个对象的所有置换平均一个有界有限模式测试f，得Aₙf。第45章有限群平均的条件期望身份在此逐n适用：Aₙf是给定Gₙ不变信息的条件期望。随着n增加，这些信息递减，第15章反向鞅给极限。

\[ A_nf=\frac1{|G_n|}\sum_{\pi\in G_n}f\circ T_\pi\longrightarrow\mathbb E[f\mid\mathcal I]\quad\text{a.s. and in }L^2. \]

𝓘是所有有限重新编号都消除不了的信息。这里使用有限群平均的递减极限，不是在无限有限置换群上假设存在一份Haar概率。取f,g依赖不相交的k、l个对象，独立抽两份编号表时发生碰撞的概率至多kl/n；条件于无碰撞，恰好等于一起抽样。因此两种平均之差趋0，得到给定𝓘后的块独立。

## 46.14 极端律究竟排除了什么

<a id="arrays-extreme"></a>

若𝓘含非平凡事件，按此事件与补集条件化，就把原律分成两份不同交换律。若𝓘平凡，则任何凸分解中的Radon–Nikodym密度都必须在重新编号下不变，因而只能恒为1；原律就是极端的。

分离性也与之等价。一个方向由上一节的条件块独立立即得到。另一方向用有限柱函数逼近一个不变事件，再把该函数涉及的对象移到不相交拷贝；分离性使两拷贝独立，不变性却让它们逼近同一事件，迫使其概率为0或1。[完整证明](../foundations/t-array-ergodic.md#array-ergodic-extreme)还处理分别交换中行列都必须移开的条件。

## 46.15 可观察的全局信息不是潜变量的名字

<a id="arrays-canonical-global"></a>

标准Borel记录空间的L²可分。对可数柱代数取不变条件期望，可以把𝓘编码成一个标准Borel值随机元，再真正析取出随机交换律Θ。上一节证明其条件律分离，因而极端；有限模式平均的全部极限又恢复Θ的决定性评价。

\[ \mathcal I=\sigma(\Theta)\quad\bmod P,\qquad P=\int\mu\,\mathcal L(\Theta)(d\mu). \]

这个极端律混合的分布唯一，证明见[T-ARRAY-ERGODIC](../foundations/t-array-ergodic.md#array-ergodic-unique)。但某一表示中的U₀可能装着完全不影响输出的额外随机数，所以不能宣布“观察最终恢复了U₀”。真正由记录识别的是条件概率律，不是人造编码的所有坐标。

## 46.16 省掉全局输入，不等于所有关系独立

<a id="arrays-no-global"></a>

固定表示的U₀以后，不相交块只使用互不交的独立输入，故条件律总是分离。如果原律极端，这些条件律只能几乎处处等于原律；固定一个好U₀值，便得到无需随机全局输入的表示。反向，没有全局输入的构造直接分离。

两色图因此无需全局输入，却仍不能拆成独立边；行列乘积阵也可没有全局输入，仍保留每个矩形乘积恒为1。极端性排除的是再混合不同总体规律的自由，而不是顶点共享带来的依赖。

## 46.17 一份表示公式怎样与另一份比较

<a id="arrays-law-criterion"></a>

表示不是唯一坐标系。对标准Borel E取可数生成代数𝓐，测试任意有限矩形或有限共同顶点集的全部格；每格放一个𝓐事件，再对公式中实际共享的独立输入积分。这些积分就是有限柱集概率。

\[ \int\prod_{i,j}\mathbf1_{A_{ij}}\big(F(z,u_i,v_j,w_{ij})\big)\,d(z,\mathbf u,\mathbf v,\mathbf w). \]

两个表示等律，当且仅当所有这些可数测试相同，充分性由π–λ与可数乘积唯一性得到。共同交换的积分必须反向共用W，并单独测试D的对角。比较单格、每行或少数矩远远不够；也不要求F与另一函数逐点相同。这个完整而适用的判据见[T-GRAPHONS](../foundations/t-graphons.md#graphon-proof-cylinders)。

## 46.18 把一条二元边的最后随机化积分掉

<a id="arrays-graphon"></a>

回到对称、无环的0/1图。给定全局z与两个顶点输入u,v，只剩一枚成对随机数。把它积分掉，留下边出现的概率W(z,u,v)。它是对称Borel函数，取值[0,1]；再取独立均匀数与该概率比较，恢复同一全图律。

\[ W(z,u,v)=\int_0^1\mathbf1_{\{F(z,u,v,w)=1\}}dw,\qquad X_{ij}=\mathbf1\{W(U_0,U_i,U_j)>W_{\{i,j\}}\}. \]

固定z时的W就是graphon；分离图可用一份确定W，一般图律可混合它们。W不是某一次图的邻接矩阵，也不是对未观察人群属性的唯一命名。它表达的是一份抽样规律；有向、多值及带权模型则需要相应的概率核，不能全都压成一个二元成功率。

## 46.19 子图概率为什么比度分布多出信息

<a id="arrays-patterns"></a>

\[ t(H,W)=\int\prod_{ab\in E(H)}W(x_a,x_b)\,d\mathbf x. \]

这不是“恰好出现H”的概率，只要求H的边都出现。要把其余边排除，再乘相应(1−W)，展开有限乘积即可。因此全部t(H,W)恢复所有诱导图概率，也就决定无限图律。第46.1节两份图的每行信息一样，却在三角形测试上分开，正是这个判据最小的可计算体现。

随机全局W时，图律先决定E t(H,W)。不同图的不交并给这些密度的乘积，故也识别整个可数密度向量的分布；[专题证明](../foundations/t-graphons.md#graphon-proof-patterns)用紧立方体上的Bernstein逼近补齐矩唯一性。被识别的仍是抽样规律，不是某份函数的原坐标。

## 46.20 相同概率律，甚至未必只差一次可逆改名

<a id="arrays-nonunique"></a>

在[0,1]上取保测但不可逆的T(x)=2x模1。W(x,y)=xy与V(x,y)=T(x)T(y)产生完全相同的图律，因为T(Uᵢ)仍是iid均匀数。若存在模零可逆保测S，使V(x,y)=W(Sx,Sy)，对y积分便得到S(x)=T(x)几乎处处。

但任何全测度集合都同时含几乎所有x与x+1/2，而T把它们合到一起，不可能在该集合上单射。这项反例比“把红蓝标签互换”更强：函数相等、可逆坐标等价与抽样律相等，确实是不同主张。更强的一般Hoover坐标分类在本章未证，不与有限柱集的完整等律判据混写。

## 46.21 三个人上的交换性还不够

<a id="arrays-finite-boundary"></a>

在三个顶点上均匀选一条边，是完全合法的有限交换图。若它能无限延拓，每个三元组都应恰有一条边。在X₁₂=1的事件上，所有k≥3与1、2均不能相连；随后三元组{1,k,l}又迫使所有k,l≥3两两相连，于是{3,4,5}含三条边，矛盾。

这与序列的有限延拓问题相呼应，但新增的障碍是重叠关系的共同约束。无限背景与单射重排真正使用了无限性；不能把表示的结论无条件赋给任意有限关系表。

## 46.22 三个指标之间还有成对共享的中间层

<a id="arrays-higher-example"></a>

若关系同时涉及三个人，只给每人一个属性、再给每个三元组一个独立数，未必已经写下最一般结构。允许每个无序人对拥有独立公平符号ξᵢⱼ，取三元关系为三个成对符号的乘积。

\[ X_{ijk}=\xi_{ij}\xi_{ik}\xi_{jk},\qquad X_{123}X_{124}X_{134}X_{234}=1. \]

单个三元关系是公平符号，但四面体的四个面共享其六条边，每个成对符号在乘积中出现两次。这个计算展示了合法的中间随机层；它本身不证明某一层在所有等律表示中都不可删除。表示定理提供足以覆盖所有律的结构，不提供每层潜变量的唯一命名。

## 46.23 固定有限阶的推广，归纳到底做了什么

<a id="arrays-higher-proof"></a>

对于r个人的无序关系，允许每个子集b携带一枚\(U_b\)，包括空集。要证明这不是过多的想象，T-ARRAYS同时处理全部低阶标签：给每个真子集记录它与无限背景能够共同看到的全部资料，再以相同范数夹逼证明顶阶关系在这些档案下条件独立。

\[ X_a=f_r\big((U_b)_{b\subseteq a}\big),\qquad |a|=r. \]

真正需要管理的是档案内部的顺序。专题独立加连续顶点标记，按标记而非外部整数排序，使低阶档案成为普通交换子集族；再归纳表示它们，以共同可测核生成顶层。有序r元组则按每个支持集存下全部满射取值，连同单点标记解码，因此重复指标也得到证明。[完整有限阶归纳](../foundations/t-arrays.md#arrays-proof-reservoir)逐步核对包含关系，不以“类似二维”代替。

## 46.24 多类高阶关系共享的是哪一个子集

<a id="arrays-multitype"></a>

若r个指标来自r种群体，分别重新编号，仍需每个非空坐标子集一份随机输入，而不只“行、列、最后噪声”三层。专题用有限种独立颜色，把关系嵌进共同编号对象，再条件抽回每类顶点。

\[ X_{i_1,\ldots,i_r}=F\left(U_0,\big(U^A_{(i_c)_{c\in A}}\big)_{\varnothing\ne A\subseteq[r]}\right). \]

抽取只使用单点颜色资料，不读取高阶噪声；因此相同的部分指标集合恰共享同一个随机数，不同集合保留独立性。条件类型概率、无限出现、核随机化及有限乘积身份均在[T-ARRAY-VARIANTS](../foundations/t-array-variants.md#array-variants-higher)实际证明。范围是固定有限阶、有限多类型、标准Borel目标；无限元关系与更一般部分群作用未据此宣称完成。

## 46.25 置换不变与正交混合仍有距离

<a id="arrays-rotation-boundary"></a>

第45章的可旋转序列结论不能按格复制成数组分类。矩阵Xᵢⱼ=ZᵢVⱼ，两个潜在列独立标准Gaussian，在任意有限行、列正交变换下保律；但单格四阶矩为9而二阶矩为1，每个2×2行列式为0。它既不是独立标准Gaussian格，也不是“每格正态”的必然模型。

若另假定全体格本来iid，才可用第45章两坐标旋转的特征函数方程得到Gaussian。一般旋转数组完整分类仍是本章登记的开放证明责任；本章完成的Aldous–Hoover是置换表示，不能偷换成另一种群对称的终审。

## 46.26 关系的对称性决定信息怎样共享

<a id="arrays-insight"></a>

最初的调查表逐行没有差别，三角形却能区别两种律。表示定理把这个裂缝填成了严格结构：共同环境在全局共享，个人资料在所有包含该人的关系中共享，成对资料在同一对象对上共享；高阶关系按每一个共同子集继续组织。

这既不是宣称所有关系独立，也不是找到了现实中的唯一隐藏原因。分离性与极端性说明何时总体混合可以消去；有限模式判据与非可逆坐标反例说明哪些律能够识别、哪些命名不能识别。数学在这里改变的是我们能够提出的问题：不再只问一格有多大概率，而是问几项关系重复使用了哪一份信息。

如果关系还要求“同类”的传递性，任意交换图便不再合格；三个对象的关系必须彼此约束。只保留哪些对象归为一类，会留下怎样的随机质量结构？表示已经指出应从哪里追查：从关系的共同概率律中，找出额外约束究竟限制了哪一层共享信息。

## 46.27 史料、证明路线与实际边界
