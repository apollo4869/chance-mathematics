# T-POINT-MEASURES: The State Space of Point Measures

Return to [Chapter48](../chapters/48-point-processes.md#points-state). E always satisfies the locally compact second-countable metric hypotheses of T-RIESZ, with its metric, compact exhaustion and cutoffs.

## 1. Why integer-valued measures really are point configurations

<a id="point-space-atoms"></a>

Let Mₚ(E) consist of Radon measures finite on compacts and integer-valued on every relatively compact Borel set. These are exactly Σmⱼδₓⱼ with distinct xⱼ, positive integer multiplicities mⱼ, and finite total multiplicity on every compact. No atomic decomposition theorem is needed. At any point with no atom, local finiteness and μ({x})=0 give a neighbourhood of mass less than one, hence of mass zero. A countable base makes the union of all such zero-mass neighbourhoods null. Positive atoms have integer masses, with only finitely many in each compact window. Exhaustion lists them all; the remaining non-atomic part is zero by the same argument.

## 2. Countable continuous tests and a vague metric

<a id="point-space-tests"></a>

Choose nonnegative χₘ∈\(C_c\) with χₘ≥1 on Kₘ. Continuous functions on compact windows are separable: interpolate rational values on finite metric nets using partitions of unity and refine the nets. After cutoff, choose a countable family (fⱼ) in \(C_c^+\) that uniformly approximates each nonnegative compactly supported continuous function within one larger compact set. Include χₘ and all nonnegative rational linear combinations. Equip Mₚ with the following metric.

\[ d(\xi,\eta)=\sum_{j\ge1}2^{-j}\bigl(1\wedge|\xi f_j-\eta f_j|\bigr),\qquad \xi f=\int f\,d\xi. \]

The tests separate measures, so d is a metric. Convergence in d bounds every χₘ integral and hence all masses on compact windows. Uniform approximation then extends coordinate convergence to all \(C_c\) tests. Conversely, coordinate convergence and the summable tail imply convergence in d. This is vague convergence, not convergence of total mass or of every bounded continuous test.

## 3. Bounded local counts produce compactness

<a id="point-space-compact"></a>

If ξₙ(Kₘ)≤aₘ for all n,m, successive extraction gives a subsequence with limits for every countable test. Local mass bounds extend these limits to a positive linear functional L on all compactly supported continuous functions. Positivity and linearity pass from the sequence; the approximation error is bounded by the local count bound times the uniform error. T-RIESZ gives a unique Radon limit μ. It remains integer-valued, as follows.

For a relatively compact open ball B with μ(∂B)=0, continuous inner and outer cutoffs give ξₙ(B)→μ(B), so μ(B) is an integer. For each centre all but countably many radii have zero boundary mass: disjoint spheres inside a finite-mass larger ball cannot have uncountably many positive masses. Such balls can therefore be arbitrarily small. If μ({x})<1, a sufficiently small continuity ball has mass less than one and hence zero. Countably many such zero balls cover the non-atomic points. Remaining singleton masses are integer limits along decreasing continuity balls. Thus μ∈Mₚ. The extracted limit is a point measure, and a set with prescribed local count bounds is relatively compact, with compact closure.

For a d-Cauchy sequence each coordinate is a real Cauchy sequence; χₘ gives local mass bounds. The preceding argument produces a convergent subsequence, and the Cauchy property yields convergence of the whole sequence. Thus d is complete. Finite configurations with multiplicities on a countable dense subset of E are dense: truncate to a large enough window, move its finitely many positions slightly, test finitely many functions, and control the metric tail. Hence Mₚ is Polish. This establishes the minimal topology for integer measures, without assuming Chapter49.

## 4. Evaluation sigma-field and measurable enumeration

<a id="point-space-measurable"></a>

Each map ξ↦ξfⱼ is measurable for the evaluation sigma-field, so vague Borel sets belong to that sigma-field. Conversely, approximate \(\mathbf1_U\) for open U increasingly by nonnegative \(C_c\) functions, using exhaustion and distance cutoffs. Then ξ(U) is measurable. Extend to all Borel sets first inside a relatively compact open window V, where ξ(V) is finite: complements can be handled by subtraction and disjoint unions by limits, so π–λ gives all Borel evaluations in V. Exhaust E by countably many windows. The sigma-fields coincide and are generated by the countable test coordinates.

Marking requires measurably enumerating occurrences, not just support points. Partition E into countably many relatively compact Borel pieces Dₘ, for example Kₘ∖Kₘ₋₁. Each contains finitely many occurrences. Choose a standard-Borel code b:E→B⊂(0,1). Sort each piece by b, repeating positions according to multiplicity. Its jth code is recovered from the rational-q tests ξ(Dₘ∩{b≤q})≥j and is therefore measurable. Finiteness ensures that the selected code belongs to B; decoding is measurable. Use a cemetery value when j exceeds the count. The countable pairs (m,j) enumerate the configuration. This is a construction tool, not an intrinsic identity for points.
