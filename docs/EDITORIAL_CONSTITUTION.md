# 写作宪章（持续有效）

这本书的目标并非通俗科普，也不是把现代概率论教材变成定义罗列。通过真实历史与数学逻辑的双线，让研究生或博士层次的读者看到每个概念如何被问题逼出来，并得到严格的数学结构。历史发生的顺序与现代推导顺序必须清楚区分。

## 正文约定
1. 从具体真实问题提出困惑，不凭空安插数学家未曾持有的现代观点。
2. 给出旧工具失败的例子和实质性限制。
3. 精确定义核心数学对象，并解释每一个假设的作用。
4. 定理、反例与证明要完整可靠；大型技术证明可拆为后续严格证明章节，但必须明示证明状态与交叉引用。
5. 说明新的观点如何统一先前结果，留下一个真正自然的下一问题。
6. 保留原创叙事的流畅性，不因为网页展示限制而缩短内容。

## 初稿权威与修订
现有 `chapters/*.md` 为六章重编的长篇工作稿，并非先前聊天内容的逐字复刻。原始聊天正文若获得，应视为核对删漏的重要来源。未经作者确认，不将改写稿标识为“与聊天逐字一致”。采用逐章审校、可追踪的差异记录。除非错误明显，不替换作者已接受的核心叙事路径。

## 文献与数学史
所有历史人物与日期、原始著作、术语的形成、现代定理归属，需核验可靠文献。参考 Kallenberg 第三版检查定义、定理假设及覆盖情况。不得照搬参考书版权内容。

## 全书的计划
七卷、初步约50章；不是字数限制或人工硬性拆分。已有第一至第六章。后续关键主题包括：各种收敛、强大数定律、测度扩张、弱收敛、条件期望、鞅、Markov/Poisson/Brownian、Itô、Lévy–Khintchine、random measures、exchangeability、de Finetti、Kingman、CRT 与随机几何。
