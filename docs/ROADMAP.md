# 项目路线图

状态说明：1–6 章为完整长篇工作稿，但未经逐字对照原聊天，也尚待逐定理审校；网站已有公开版本 https://chance-mathematics-six-chapters.goldenmath7.chatgpt.site/ 。公开网址仅作现状参照，不代表 Codex 拥有其部署权限或源仓库权限。

## 第一阶段：可维护性与真实性
- 核对本仓库的章节源 Markdown、生成 HTML、合订本是否相互一致；检查章节数、标题数、LaTeX 公式块数、正文丢失、重复等。
- 评估线上网站与本地构建之间的差异；若无法获得线上源码，仅以公开页面作为只读对照。
- 创建审校清单与逐章问题台账（数学、史料、排版、可访问性、中文术语）。
- 修复不涉及正文语义的显示问题与构建问题，添加测试；保留回滚途径。

## 第二阶段：六章 v1.1 审校
- 逐章审查数学定理假设、证明完整性、记号一致性、历史引证可靠性。
- 对少量必须修正的数学错误给出最小改动补丁，并附解释与作者审批项。
- 如果需要对齐最初聊天逐字内容，明确列出缺失的原稿，不可假称已自动恢复。

## 第三阶段：第七章起的连载架构
- 统一的章节文件模板（元数据、摘要、节、公式、定理、证明、反例、历史注释、引用）。
- 自动目录与交叉引用；支持公式编号、参考文献、图示、证明状态标签。
- 建立预览、回归测试、按章节审阅的发布流程。

## 第四阶段：约50章的长期写作
- 7卷主线：起源与早期发现；测度/收敛；信息/条件期望/鞅；随机过程；独立增量与Lévy；交换性/随机测度；随机树与随机几何。
- 以 Kallenberg 第三版作为覆盖度和定理严谨性检查，不照抄目录与措辞；历史叙事的连续性优先。
- 章与章之间始终保持问题递进，所有证明状态、未解问题与史料核验状态可追踪。
